# guardian_searcher

**Tag**: web

## 简介

A wrapper to search articles from The Guardian, using its open API. You need to register and get your api key to properly use this gem. It uses Faraday to make the API calls and has some classes that should help in formatting the results as easy to manage Ruby object.
