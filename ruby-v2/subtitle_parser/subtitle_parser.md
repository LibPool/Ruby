# subtitle_parser

**Tag**: tooling, filesystem

## 简介

Parse your .srt files into Subtitle objects. This objects represent one subtitle from the original file, with the order it appears on the movie, sentences (the subtitle itself), time of the movie when it starts and time when it ends.
