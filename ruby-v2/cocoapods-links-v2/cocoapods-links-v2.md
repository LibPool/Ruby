# cocoapods-links-v2

**Tag**: cli, testing

## 简介

This CocoaPods plugin linking functionality allows to easily test their pods.

                         This plugin adds the following commands to the CocoaPods command line:

                          * pod link <name>
                          * pod unlink <name>
                          * pod list links
