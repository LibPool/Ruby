# ddao-kwalify

**Tag**: serialization, tooling, data

## 简介

Kwalify is a parser, schema validator, and data binding tool for YAML and JSON. It was
   originally written by makoto kuwata. I've updated the code to get rid of all the 
   warning messages

## 官网

- 主页: http://www.kuwata-lab.com/kwalify/
- RubyGems: https://rubygems.org/gems/ddao-kwalify
