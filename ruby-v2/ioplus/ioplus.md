# ioplus

**Tag**: testing

## 简介

"ioplus" is appended IO#aio_read/aio_write methods. These provide similar functionality to aio_read(2)/aio_write(2).

This library need posix aio(4) and kqueue(2). Tested on FreeBSD 10.1 only.
