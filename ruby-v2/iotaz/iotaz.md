# iotaz

**Tag**: library

## 简介

Iotaz is an object relational mapping library. At the moment the library only supports the FireRuby library, providing access to the Firebird open source RDBMS, but this might be extended in future.

## 官网

- 主页: http://rubyforge.org/projects/iotaz/
- RubyGems: https://rubygems.org/gems/iotaz
