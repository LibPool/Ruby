# testrail_connector

**Tag**: web, cli, testing, networking

## 简介

A Ruby client that tries to match TestRail's API one-to-one, while still
    providing an idiomatic interface.
  This gem is a fork from testrailv2 of Kristine Robison and James Tsay. Gem has open dependencies of httparty and activesupport.
