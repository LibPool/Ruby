# tldrb

**Tag**: web, cli, networking

## 简介

Ruby client for tldr (&lt;https://github.com/tldr-pages/tldr&gt;).  Implemented with the Ruby on Bales command-line app framework (&lt;https://github.com/YellowApple/bales&gt;).
