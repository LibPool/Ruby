# jekyll-streetview

**Tag**: web, template

## 简介

jekyll-streetview adds a {% streetview %} Liquid tag to Jekyll sites. Pass a latitude/longitude or an address string and get a static Street View image with no JavaScript required. Powered by the Google Street View Static API.
