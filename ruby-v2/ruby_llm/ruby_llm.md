# ruby_llm

**Tag**: web, tooling, devops

## 简介

Build AI features the Ruby way. A delightful Ruby AI framework that feels at home in Rails: switch models without rewriting your code, then scale from a single call to production agents, RAG, and workflows. Features chat (text, images, audio, PDFs), image generation, embeddings, tools (function calling), structured output, Rails integration, and streaming. Works with OpenAI, Azure, Anthropic, Google Gemini, Vertex AI, AWS Bedrock, xAI, Cohere, DeepSeek, Mistral, Perplexity, OpenRouter, ElevenLabs, Deepgram, Ollama and GPUStack (local models), and any OpenAI-compatible API. Plain Ruby with a small set of runtime dependencies.
