# tlb-rspec2

**Tag**: web, testing

## 简介

TLB-Ruby component that provides support for load balancing tests written using rspec-2.x. This library consumes APIs provided by tlb-core.

## 官网

- 主页: http://github.com/test-load-balancer/tlb.rb
