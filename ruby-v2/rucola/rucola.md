# rucola

**Tag**: web, testing, tooling

## 简介

Rucola is an extension for RubyCocoa. It has a application skeleton generator and builds an &quot;opinionated&quot; application layout, like the one known from rails. And comes with RubyCocoa specific rake tasks.
