# text-to-html

**Tag**: web, template

## 简介

With more and more web code growing obsolete and in need of updating, it's handy to have a few tools that could convert plaintext to html elements.
    
    This gem will provide tools to convert plaintext to:
        - ordered/unordered lists
        - paragraphs
        - tables
        - anchor tags
        - more to come
    
    As part of my own current work, this gem is being developed as my professional needs arise.
