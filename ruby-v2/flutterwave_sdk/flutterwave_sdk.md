# flutterwave_sdk

**Tag**: library

## 简介

This is the official Ruby Gem For Flutterwave Payments which includes Card, Account, Transfer, Subaccount, Subscription, Mpesa, Ghana Mobile Money, Ussd, Payment Plans, and Transfer payment methods.

## 官网

- 主页: https://github.com/Flutterwave/Flutterwave-Ruby-v3.
- RubyGems: https://rubygems.org/gems/flutterwave_sdk
