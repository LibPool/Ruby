# ahocorasick-rust

**Tag**: library

## 简介

A Ruby gem wrapping the legendary Rust Aho-Corasick algorithm! Aho-Corasick is a powerful string searching algorithm that finds multiple patterns simultaneously in a text. Features include overlapping matches, case-insensitive search, find & replace, match positions, and configurable match strategies. Perfect for content filtering, tokenization, and multi-pattern search at lightning speed! (ﾉ◕ヮ◕)ﾉ*:･ﾟ✧
