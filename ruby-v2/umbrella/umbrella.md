# umbrella

**Tag**: devops, filesystem

## 简介

git based deployment tool that keeps its config files separate and can deploy applications consisting of more than one repository

## 官网

- 主页: http://github.com/pampa/umbrella
- RubyGems: https://rubygems.org/gems/umbrella
