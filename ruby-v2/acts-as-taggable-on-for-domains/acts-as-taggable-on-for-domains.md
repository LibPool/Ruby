# acts-as-taggable-on-for-domains

**Tag**: library

## 简介

Same as ActsAsTaggableOn but tagging happens within the context of a domain id. This means an object could be tagged with something for one domain, but the same object, in the context of a different domain id, could have completely different taggings.
