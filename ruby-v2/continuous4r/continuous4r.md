# continuous4r

**Tag**: web, testing

## 简介

Continuous integration tool which regroups in one place tests, quality and analysis tools in a Maven-like website.

- 主页: http://continuous4r.rubyforge.org
- RubyGems: https://rubygems.org/gems/continuous4r
