# openstudio

**Tag**: library

## 简介

Installs OpenStudio Ruby Bindings to help create EnergyPlus and Radiance Models

## 官网

- 主页: http://openstudio.nrel.gov
- 源码仓库: https://cbr.nrel.gov/openstudio-public/svn/
- RubyGems: https://rubygems.org/gems/openstudio

## 历史版本号

- 0.7.6 (2012-11-21)

## 获取地址

- RubyGems: https://rubygems.org/gems/openstudio
- gem 安装: `gem install openstudio`
- Bundler: `gem "openstudio"`
- 最新版本: 0.7.6
- 最新版归档: https://rubygems.org/downloads/openstudio-0.7.6.gem
- 版本锁定: `gem "openstudio", "~> 0.7.6"`
- 中央仓库: https://rubygems.org/
