# liquid-diagrams

**Tag**: library

## 简介

A Liquid plugin with support for Blockdiag, Erd, GraphViz, Mermaid,
Nomnoml, PlantUML, Svgbob, Syntrax, Vega, Vega-Lite and WaveDrom.
