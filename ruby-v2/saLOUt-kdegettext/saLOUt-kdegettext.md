# saLOUt-kdegettext

**Tag**: tooling, filesystem

## 简介

KDEgettext.rb is a parser that extends ruby gettext to work with the Qt/KDE framework provided by korundum. It allows creating catalog files (po-file) with the GNU GetText format.
