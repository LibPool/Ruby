# postseed

**Tag**: web, cli, database, data

## 简介

Postseed generates realistic seed data for PostgreSQL that never breaks a foreign key, a unique constraint or an enum, and is deterministic: the same schema, seed and version give identical output. It runs locally with a web Studio and a CLI. This gem bundles the engine and runs it with Node.js 20 or newer.
