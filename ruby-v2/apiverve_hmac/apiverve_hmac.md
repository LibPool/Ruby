# apiverve_hmac

**Tag**: web, security, tooling, data

## 简介

HMAC Generator creates Hash-based Message Authentication Codes for data integrity and authentication. Supports SHA-256, SHA-384, SHA-512, SHA-1, and MD5 algorithms.
