# autorubyconf

**Tag**: tooling

## 简介

Tool similar to the autotools for looking for dependencies before Ruby builds/compilations

## 官网

- 主页: https://rubygems.org/gems/autorubyconf
- 文档: https://www.rubydoc.info/gems/autorubyconf/0.1

## 历史版本号

## 获取地址

- RubyGems: https://rubygems.org/gems/autorubyconf
- gem 安装: `gem install autorubyconf`
- Bundler: `gem "autorubyconf"`
- 最新版本: 0.1
- 最新版归档: https://rubygems.org/downloads/autorubyconf-0.1.gem
- 版本锁定: `gem "autorubyconf", "~> 0.1"`
