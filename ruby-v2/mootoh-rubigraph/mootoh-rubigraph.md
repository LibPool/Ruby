# mootoh-rubigraph

**Tag**: web, networking, template

## 简介

a Ruby wrap for Ubigraph (http://www.ubietylab.net/ubigraph).  see http://www.ubietylab.net/ubigraph/content/Docs/index.html to get complete description about API.
