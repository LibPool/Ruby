# mbta-realtime

**Tag**: web, data

## 简介

The MBTA Realtime V2 API unifies "schedule, alert, 
                       vehicle position, and arrival prediction data". The MBTA Realtime gem
                       provides a Ruby interface to the API, presenting results using
                       sensible Ruby defaults.
