# tiling

**Tag**: library

## 简介

Tiling provides a simple window tiling system for linux.
This is for those who cannot (or don't want to) use a tiling window manager like
awesome or Xmonad.

## 官网

- 主页: http://lkdjiin.github.com/tiling
