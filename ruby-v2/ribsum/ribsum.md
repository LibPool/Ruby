# ribsum

**Tag**: library

## 简介

Ribsum is a lightweight Ruby gems library to generate Lorem Ipsum text. You can directly call the module functions (e.g. Ribsum.paragraph or Ribsum.paragraph(2)) or include Ribsum module to your class.
