# schepherd

**Tag**: serialization, filesystem

## 简介

Schepherd resolves a JSON Schema from a pinned OCI catalog, verifies it by digest and hands the local file to the validator you already use. The gem ships the native schepherd binary for Linux, macOS and Windows on x64 and arm64.
