# lolcommits-lolsrv

**Tag**: web

## 简介

Sync lolcommits to a remote server. After enabling, your next
  lolcommit will be uploaded, along with all existing lolcommits images
  that you've already captured. Each lolcommit is then sync'd after
  capturing.
