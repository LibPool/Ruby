# japanese_address_parser

**Tag**: web, tooling

## 简介

A faithful Ruby port of @geolonia/normalize-japanese-addresses (v3.1.3). Normalizes Japanese addresses using the geolonia japanese-addresses API at runtime; no Node.js required.
