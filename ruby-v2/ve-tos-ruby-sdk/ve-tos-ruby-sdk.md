# ve-tos-ruby-sdk

**Tag**: library

## 简介

Ruby SDK for Volcengine TOS object storage. PutObject, GetObject (range), HeadObject, DeleteObject, DeleteMultipleObjects, ListObjectsV2, and presigned URLs.
