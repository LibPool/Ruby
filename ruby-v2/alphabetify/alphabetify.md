# alphabetify

**Tag**: library

## 简介

Taking an existing alphabetic hash (of any length), will return the next hash in sequence.
                  If all characters in hash are rolled over, will append a new char (increase the length by 1.)
                  [eg. 'ZZZZ' -&gt; 'AAAAA']
                  [eg. 'AAAZ' -&gt; 'AABA']
