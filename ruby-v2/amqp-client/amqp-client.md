# amqp-client

**Tag**: cli

## 简介

A modern AMQP 0-9-1 Ruby client for RabbitMQ, LavinMQ and any other AMQP 0-9-1 broker. Very fast, fully thread-safe, with blocking operations, straight-forward error handling and no dependencies.
