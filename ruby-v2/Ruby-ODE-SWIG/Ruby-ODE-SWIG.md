# Ruby-ODE-SWIG

**Tag**: tooling

## 简介

Ruby language bindings for the Open Dynamics Engine (ODE), written using the Simplified Wrapper and Interface Generator (SWIG).

## 官网

- 主页: http://ruby-ode-swig.rubyforge.org/
- RubyGems: https://rubygems.org/gems/Ruby-ODE-SWIG
