# convertorio-sdk

**Tag**: web, filesystem

## 简介

Ruby SDK for the Convertorio API. Convert files between 20+ formats with AI-powered OCR for text extraction. Supports JPG, PNG, WebP, AVIF, HEIC, GIF, BMP, TIFF, ICO, PDF, and more.
