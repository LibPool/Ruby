# rails-pages

**Tag**: web, template, filesystem

## 简介

A really simple rails engine, serving text files from app/pages as HTML (currently only supports Markdown)

## 官网

- 主页: https://github.com/spieker/rails-pages
- RubyGems: https://rubygems.org/gems/rails-pages

## 历史版本号

- 0.0.1 (2012-12-27)

## 获取地址

- RubyGems: https://rubygems.org/gems/rails-pages
- gem 安装: `gem install rails-pages`
- Bundler: `gem "rails-pages"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/rails-pages-0.0.1.gem
- 版本锁定: `gem "rails-pages", "~> 0.0.1"`
