# buildrdeb

**Tag**: tooling, filesystem

## 简介

A buildr plugin contributing a new packaging method to package your project as a .deb file.

## 官网

- 主页: http://buildr.apache.org/
- RubyGems: https://rubygems.org/gems/buildrdeb
