# conference-mgeek.in-jekyll-theme

**Tag**: web, networking, template, filesystem

## 简介

This is jekyll theme template designed for conference website hosted by institute and colleges. create markdown files contact.md submitpaper.md … in the root directory and change theme in gem file as `theme:conference-mgeek.in-jekyll-theme` &copy; 2018 http://mgeek.in . I has one fullwidth layout, and fullwidthhome layout
