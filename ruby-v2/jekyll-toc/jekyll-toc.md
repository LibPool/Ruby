# jekyll-toc

**Tag**: web, tooling

## 简介

Jekyll (Ruby static website generator) plugin which generates a Table of Contents for the page.

## 官网

- 主页: https://github.com/toshimaru/jekyll-toc
- 更新日志: https://github.com/toshimaru/jekyll-toc/releases
- RubyGems: https://rubygems.org/gems/jekyll-toc
