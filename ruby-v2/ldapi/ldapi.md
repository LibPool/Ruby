# ldapi

**Tag**: web, serialization

## 简介

Simple read-only JSON API to an LDAP server.  Written in Sinatra with net-ldap and json.

- 主页: http://github.com/jayzes/ldapi
- RubyGems: https://rubygems.org/gems/ldapi
