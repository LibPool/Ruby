# ons-jwe

**Tag**: web, security, serialization, tooling, data

## 简介

RFC7516-compliant JSON Web Encryption (JWE) token generator that uses RSAES-OAEP and AES GCM.
Suitable for use with the ONS eQ Survey Runner.
