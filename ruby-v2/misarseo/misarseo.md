# misarseo

**Tag**: web, cli, filesystem

## 简介

Ruby client for the MisarSEO API (seo.misar.io): keyword research, site audits, rank tracking, backlinks, AI search visibility, Search Console, GA4 and Business Profile — 221 methods on one client, retries with backoff, typed plan-limit errors carrying the upgrade offer, and SSE crawl progress. No runtime dependencies beyond the stdlib.
