# drndump

**Tag**: database, data

## 简介

Drndump is a tool to dump Droonga database. You can use it for backup.

## 官网

- 主页: https://github.com/droonga/drndump
- 文档: https://www.rubydoc.info/gems/drndump/1.0.1
- RubyGems: https://rubygems.org/gems/drndump
