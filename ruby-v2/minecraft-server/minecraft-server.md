# minecraft-server

**Tag**: web

## 简介

Minecraft Server written purely in Ruby, capable of running as a Vanilla Server, Bukkit Server,
Minecraft Forge Server, Spigot Server, and a Sponge Server.

## 官网

- 源码仓库: https://github.com/MinecraftRuby/minecraft-server
- 文档: https://www.rubydoc.info/gems/minecraft-server/0.0.1.pre.45
- RubyGems: https://rubygems.org/gems/minecraft-server
