# yard-rubicle

**Tag**: template

## 简介

YARD plugin for template with Rubicle. Rubicle is an unofficial mascot of Programming Language Ruby.

## 官网

- 主页: http://rubicle.net/en/gems.html
- RubyGems: https://rubygems.org/gems/yard-rubicle
