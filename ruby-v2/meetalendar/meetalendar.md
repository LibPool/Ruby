# meetalendar

**Tag**: library

## 简介

This gem is a Comfortable-Mexican-Sofa Add-On and prensents all the needed functionality to search for relevant groups on meetup, remember the chosen ones and offers a task that can be called regularely to transcribe the meetup-groups events to a google calendar. TLDR: It allows the user to subscribe to meetup-groups events.
