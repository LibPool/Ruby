# jazz_hands2

**Tag**: web, cli

## 简介

Spending hours in the rails console? Spruce it up and show off those hard-working hands! jazz_hands replaces IRB with Pry, improves output through awesome_print, and has some other goodies up its sleeves. Only Ruby &gt;= 2
