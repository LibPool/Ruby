# stb-image

**Tag**: data

## 简介

stb_image.c bindings for loading basic image data from a variety of formats
(JPG, PNG, TGA, BMP, PSD, GIF, HDR, and PIC). Data can be loaded either as
LDR (8-bit channels) or HDR (32-bit float channels) data.
