# JRuby-OpenSSL

**Tag**: library

## 简介

JRuby-OpenSSL is an add-on gem for JRuby that emulates the Ruby OpenSSL native library.

## 官网

- 主页: http://jruby-extras.rubyforge.org/jopenssl
- RubyGems: https://rubygems.org/gems/JRuby-OpenSSL

## 历史版本号

- 0.1 (2009-08-18)

## 获取地址

- RubyGems: https://rubygems.org/gems/JRuby-OpenSSL

- Bundler: `gem "JRuby-OpenSSL"`
- 最新版本: 0.1
- 最新版归档: https://rubygems.org/downloads/JRuby-OpenSSL-0.1.gem
