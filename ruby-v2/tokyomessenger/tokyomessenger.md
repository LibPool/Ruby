# tokyomessenger

**Tag**: library

## 简介

A C based TokyoTyrant Ruby adapter that doesn't require TokyoCabinet or TokyoTyrant to be installed

## 官网

- 主页: http://github.com/mattbauer/tokyomessenger/
- RubyGems: https://rubygems.org/gems/tokyomessenger

## 历史版本号

- 0.5 (2009-12-21)

## 获取地址

- RubyGems: https://rubygems.org/gems/tokyomessenger
- gem 安装: `gem install tokyomessenger`
- Bundler: `gem "tokyomessenger"`
- 最新版本: 0.5
- 最新版归档: https://rubygems.org/downloads/tokyomessenger-0.5.gem
- 版本锁定: `gem "tokyomessenger", "~> 0.5"`
