# vagrant-ssh-config-manager

**Tag**: filesystem

## 简介

A Vagrant plugin that automatically manages SSH configurations. Creates and maintains SSH config entries when VMs are started and cleans them up when VMs are destroyed, with environment isolation and file locking support.
