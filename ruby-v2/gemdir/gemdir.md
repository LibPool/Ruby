# gemdir

**Tag**: library

## 简介

Include a local gems directory into any project without having to install the gems

## 官网

- RubyGems: https://rubygems.org/gems/gemdir

## 历史版本号

- 0.0.1 (2011-09-02)

## 获取地址

- RubyGems: https://rubygems.org/gems/gemdir
- gem 安装: `gem install gemdir`
- Bundler: `gem "gemdir"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/gemdir-0.0.1.gem
- 版本锁定: `gem "gemdir", "~> 0.0.1"`
