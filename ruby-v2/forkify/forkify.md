# forkify

**Tag**: data

## 简介

forkify.rb makes it easy to process a bunch of data using 'n'
  worker processes. It is based off of forkoff and threadify by Ara Howard.
  It aims to be safe to use on Ruby 1.8.6+ and Ruby 1.9.1+
