# ocran

**Tag**: cli, filesystem

## 简介

OCRAN (One-Click Ruby Application Next) packages Ruby applications for distribution on Windows, Linux, and macOS. It bundles your script, the Ruby interpreter, gems, and native libraries into a self-contained artifact that runs without Ruby installed on the target machine: a self-extracting executable (default), a directory (--output-dir), a zip archive (--output-zip), or a macOS .app bundle (--macosx-bundle). Fork of OCRA maintained for Ruby 3.2+; migrating code should replace OCRA_EXECUTABLE with OCRAN_EXECUTABLE.
