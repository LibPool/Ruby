# tcc

**Tag**: tooling

## 简介

Tiny C Compiler is a small and fast C compiler, which makes C behavor like a script language. This is the Ruby wrapper for its library, libtcc.

- 文档: https://www.rubydoc.info/gems/tcc/0.1.1
