# easyai

**Tag**: cli, serialization

## 简介

EasyAI 是一个 Ruby CLI 包装器，为 Anthropic Claude、Google Gemini、OpenAI Codex 三家命令行工具提供统一入口。
v2.0 起聚焦单机本地化：无远程下发链路，通过单一 ~/.easyai/config.json 集中管理多家 CLI 与多平台凭证、代理；
运行时仅向子进程注入环境变量，不污染当前 shell。
