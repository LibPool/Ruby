# sensu-plugins-redis

**Tag**: database, data

## 简介

This plugin provides native Redis instrumentation
                              for monitoring and metrics collection, including:
                              service health, database connectivity, replication
                              status, `INFO` metrics, key counts, list lengths,
                              and more.
