# fuzzake

**Tag**: filesystem

## 简介

Fuzzake is a small library to integrate it with your rake file to be able to run rake taks in a fuzzy way.

## 官网

- RubyGems: https://rubygems.org/gems/fuzzake

## 历史版本号

- 0.0.1 (2012-06-24)

- Bundler: `gem "fuzzake"`

- 最新版归档: https://rubygems.org/downloads/fuzzake-0.0.2.gem
