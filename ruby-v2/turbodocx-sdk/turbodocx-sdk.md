# turbodocx-sdk

**Tag**: web

## 简介

Official Ruby SDK for TurboDocx — digital signatures (TurboSign), partner management (TurboPartner), quoting/CPQ (TurboQuote), document generation (Deliverable), and signature webhooks (TurboWebhooks).
