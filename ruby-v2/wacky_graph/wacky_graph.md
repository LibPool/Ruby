# wacky_graph

**Tag**: web

## 简介

Wacky Graph is a gem extracted from Wacky Words Friends for using the Facebook graph API.

## 官网

- 主页: http://www.wackywordsfriends.com
- RubyGems: https://rubygems.org/gems/wacky_graph
