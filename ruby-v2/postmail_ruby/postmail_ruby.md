# postmail_ruby

**Tag**: web, networking

## 简介

PostmailRuby is a simple gem that adds custom Action Mailer delivery methods allowing you to send email via either SMTP or an HTTP API. The delivery method and all settings are configurable via environment variables so it can be easily switched at runtime without code changes.
