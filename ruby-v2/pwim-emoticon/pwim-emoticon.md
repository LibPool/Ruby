# pwim-emoticon

**Tag**: web, tooling

## 简介

Emoticon is a Ruby library for transcoding emoticons across different carriers for Japanese mobile phones.  It is derived from Jpmobile, a rails plugin for building mobile sites for Japanese mobiles created by Yohji Shidara
