# glut2

**Tag**: web, networking

## 简介

Glut bindings for OpenGL. To be used with the {opengl}[https://github.com/larskanis/opengl] gem.

## 官网

- 文档: https://www.rubydoc.info/gems/glut2/8.4.0
- RubyGems: https://rubygems.org/gems/glut2

## 历史版本号

- 8.4.0 (2024-09-08)

## 获取地址

- RubyGems: https://rubygems.org/gems/glut2

- Bundler: `gem "glut2"`

- 最新版归档: https://rubygems.org/downloads/glut2-8.4.0.gem
