# maven-tools

**Tag**: tooling

## 简介

adds versions conversion from rubygems to maven and vice versa, ruby DSL for POM (Project Object Model from maven), pom generators, etc

## 官网

- 主页: http://github.com/torquebox/maven-tools
- 文档: https://www.rubydoc.info/gems/maven-tools/1.2.3
- RubyGems: https://rubygems.org/gems/maven-tools
