# maxtsap_rqr

**Tag**: library

## 简介

A ruby library to create qrcode. Output: PS, JPEG, PNG, EPS, TIFF.

- 主页: http://maxtsap.github.com/rqr/
- RubyGems: https://rubygems.org/gems/maxtsap_rqr
