# DTR

**Tag**: testing, tooling

## 简介

DTR is a distributed test runner to run tests on distributed computers for decreasing build time.

## 官网

- 主页: http://dtr.rubyforge.org
- RubyGems: https://rubygems.org/gems/DTR
