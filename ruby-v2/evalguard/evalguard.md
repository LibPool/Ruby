# evalguard

**Tag**: web, networking

## 简介

Reservation gem for the upcoming EvalGuard Ruby SDK. The supported public surface today lives in the TypeScript (evalguardai-sdk on npm) and Python (evalguardai on PyPI) SDKs. https://evalguard.ai
