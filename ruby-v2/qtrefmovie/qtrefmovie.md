# qtrefmovie

**Tag**: filesystem

## 简介

QTRefMovie is a simple tool for generating QuickTime Reference Movie files from a Ruby script.

## 官网

- 主页: http://github.com/jonblock/qtrefmovie
- RubyGems: https://rubygems.org/gems/qtrefmovie
