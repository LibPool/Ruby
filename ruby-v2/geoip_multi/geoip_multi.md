# geoip_multi

**Tag**: database, data

## 简介

==Extends native ruby geoip gem. Adds support for netmask() and range_by_ip() methods to the GeoIP class and creates a new class GeoIPMulti that performs lookups on multiple GeoIP databases with a single lookup() method
