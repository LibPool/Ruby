# minitest-ok

**Tag**: testing

## 简介

Using Minitest::Ok, you can write:

* 'ok {1+1} == 2' instead of 'assert_equal 2, 1+1',
* 'ok {1+1} > 0' instead of 'assert_operator 1+1, :>, 0',
* 'ok {5}.in?(1..9)' instead of 'assert_include 1..9, 5',

and so on.
