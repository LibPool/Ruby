# rails-dbi

**Tag**: web, database, data

## 简介

A vendor independent interface for accessing databases, similar to Perl's DBI but compatible with Rails 3

## 官网

- 主页: http://www.rubyforge.org/projects/ruby-dbi
- RubyGems: https://rubygems.org/gems/rails-dbi
