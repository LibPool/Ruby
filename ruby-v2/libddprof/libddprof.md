# libddprof

**Tag**: filesystem, data

## 简介

libddprof contains implementation bits used by Datadog's ddtrace gem as part of its Continuous Profiler feature.

## 官网

- 主页: https://docs.datadoghq.com/tracing/profiler/
- 源码仓库: https://github.com/DataDog/libddprof/tree/main/ruby
- RubyGems: https://rubygems.org/gems/libddprof
