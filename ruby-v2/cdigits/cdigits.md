# cdigits

**Tag**: library

## 简介

Generate code with Luhn mod N algorithm using placeholder.
e.g)
Cdigits::Luhn.number('CA##-####-####-###?') #=> 'CA63-6485-2316-2675'
Cdigits::Luhn.easy #=> '16TPF8RETL'
