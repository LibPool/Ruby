# taxonomite

**Tag**: web, database, networking, data

## 简介

API documentaiton at: http://www.rubydoc.info/gems/taxonomite

Manages objects classified within a taxonomy and enforces a hierarchical tree structure. Works only with MongoDB currently - may try to abstract the database layer with later versions.
