# nezetic-ruby-xbmc

**Tag**: web, networking

## 简介

ruby-xbmc is a ruby wrapper for the XBMC Web Server HTTP API.  It provides a remote access to any XBMC running on the local network, in a simple way (methods follow the ones from XBMC API).
