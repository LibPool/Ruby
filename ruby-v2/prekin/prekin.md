# prekin

**Tag**: testing

## 简介

Return true or false when you specify the day of month (by Time class, Date class, DateTime class or String class). The criteria is whether the day is 'PREMIUM FRIDAY' or not. 'PREMIUM FRIDAY' is the last friday in month in Japan.
