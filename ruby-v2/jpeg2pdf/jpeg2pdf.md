# jpeg2pdf

**Tag**: filesystem

## 简介

jpeg2pdf is a free program that converts a directory of JPEG files to a PDF file.

## 官网

- 主页: http://koan.studentenweb.org/software/jpeg2pdf.html
- RubyGems: https://rubygems.org/gems/jpeg2pdf
