# logix_toolkit

**Tag**: cli

## 简介

A boolean algebra tools library for ruby that adds logic functions and operations 
(currently limited to AND, OR, CONDITIONAL operations with multiple parameters)
more functionality will be added later.
install via "gem install logix_toolkit"
require using "require 'logix_toolkit'"
see usage via the documentation or via typing "LogixToolkit.help" in the console
after requiring the library
