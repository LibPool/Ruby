# nifty-cloud-sdk

**Tag**: web, devops

## 简介

It is an operation library for Nifty Cloud APIs that the server making, starting, stoping, and the server status confirming etc.

## 官网

- 主页: http://cloud.nifty.com/api/
- RubyGems: https://rubygems.org/gems/nifty-cloud-sdk
