# link_scraper

**Tag**: web, filesystem

## 简介

Scrape website links' text and path with built-in scrubbing filter.  Designed to rapidly visit and scrape links from list of several URLs, then filters them based on your criteria.  For example, to only grab the links for inventory, staff, or contact us, etc.
