# rfeedreader

**Tag**: testing, tooling

## 简介

Feed parser to read feed and return first posts of this feed. Special parsing from sources like Flickr, Jumcut, Google video, ...

## 官网

- 主页: http://rfeedreader.rubyforge.org
- RubyGems: https://rubygems.org/gems/rfeedreader
