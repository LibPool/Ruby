# ricepaper

**Tag**: cli

## 简介

Ricepaper is a library that allows you to add URLs to Instapaper, either by using it as a CLI or as a Ruby library.

## 官网

- 主页: http://github.com/dakrone/ricepaper
- RubyGems: https://rubygems.org/gems/ricepaper
