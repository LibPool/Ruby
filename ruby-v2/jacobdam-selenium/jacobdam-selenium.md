# jacobdam-selenium

**Tag**: web, testing

## 简介

A project that wraps selenium API into object-oriented testing style and packages it into a RubyGem.

## 官网

- 主页: http://selenium.rubyforge.org
- RubyGems: https://rubygems.org/gems/jacobdam-selenium

## 历史版本号

- 1.1.16 (2009-12-28)

## 获取地址

- RubyGems: https://rubygems.org/gems/jacobdam-selenium
- gem 安装: `gem install jacobdam-selenium`
- Bundler: `gem "jacobdam-selenium"`
- 最新版本: 1.1.16
- 最新版归档: https://rubygems.org/downloads/jacobdam-selenium-1.1.16.gem
