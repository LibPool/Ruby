# glimmer-cw-browser-chromium

**Tag**: web

## 简介

Chromium Browser - Glimmer Custom Widget - Enables using the `browser` widget with the `:chromium` SWT style (e.g. `browser(:chromium)`), embedding the Chromium web browser engine instead of the default one.
