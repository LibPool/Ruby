# kindeditor

**Tag**: web, cli

## 简介

Rails KindEditor integration plugin with paperclip support for rails3 Rc,it supports active_record and mongoid!

## 官网

- 主页: http://github.com/doabit/kindeditor
- RubyGems: https://rubygems.org/gems/kindeditor
