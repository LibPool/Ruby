# libmpq-ruby

**Tag**: filesystem

## 简介

Uses libmpq to provie access to read, decrypting and unpacking
      MPQ files in Ruby

- 主页: http://github.com/beaucollins/libmpq-ruby
- RubyGems: https://rubygems.org/gems/libmpq-ruby
