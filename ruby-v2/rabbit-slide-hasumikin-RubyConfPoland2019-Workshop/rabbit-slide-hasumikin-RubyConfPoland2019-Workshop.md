# rabbit-slide-hasumikin-RubyConfPoland2019-Workshop

**Tag**: library

## 简介

It will cover:

- Introducing mruby/c which is Ruby implementation for microcontroller
- How mruby/c works
- Basics of microcontroller
- Hands-ons
  - Hello World on POSIX
  - Hello World on ESP32
  - Blinking LED
  - Taking temperature with thermistor
  - Multi tasking
