# lzfx

**Tag**: library

## 简介

Ruby bindings for lzfx. lzfx is a tiny, extremely fast compression library.

## 官网

- 主页: https://github.com/hmsk/lzfx
- RubyGems: https://rubygems.org/gems/lzfx

## 历史版本号

- 0.1.0 (2012-04-05)
