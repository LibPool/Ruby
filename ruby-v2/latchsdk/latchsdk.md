# latchsdk

**Tag**: web, security, networking, filesystem

## 简介

This SDK allows developers to integrate Latch on their Ruby services. Latch is a service that lets end-users add an extra level of security to their online accounts and services. With this version of the SDK, developers can pair and unpair users and check their latches status. For more information please visit https://latch.elevenpaths.com or the SDK page on GitHub https://github.com/ElevenPaths/latch-sdk-ruby
