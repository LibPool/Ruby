# interfax19

**Tag**: web

## 简介

A ruby wrapper for the interfax webservice (SOAP). Just like the Interfax gem, except this one is 1.9-compatible.

- 主页: http://github.com/innovapartners/interfax
- RubyGems: https://rubygems.org/gems/interfax19
