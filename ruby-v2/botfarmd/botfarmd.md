# botfarmd

**Tag**: testing, filesystem

## 简介

Botfarmd reads a configuration file that specifies Cinch bots with specific plugin suites. It then runs an arbitrary number of these bots in parallel as separate threads, so that users may have tailor-made settings on each separate channel they wish to run their Cinch bots on.
