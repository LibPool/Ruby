# geocode

**Tag**: library

## 简介

geocode, a ruby library and command-line tool for geocoding addresses and reverse geocoding coordinates.

## 官网

- 主页: http://github.com/dbrady/geocode/
- RubyGems: https://rubygems.org/gems/geocode
