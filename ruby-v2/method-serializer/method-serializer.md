# method-serializer

**Tag**: testing, serialization

## 简介

A simple class method wrapper, which allow to serialize method return value and arguments. 
    It can be use for ‘mocking’ or ‘caching’ or benchmarking or even as a nice example
    of practical Ruby meta-programming.
