# thermostat-JOP-BOUCKAERT

**Tag**: library

## 简介

As input it needs a setting with a wanted temperature, a temperature range and a current temperature.
      You can give an update to the thermostat with the current temperature. 
      Supports multiple units. (Kelvin, Fahrenheit, Celsius = default)
