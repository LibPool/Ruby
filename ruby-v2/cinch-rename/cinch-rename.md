# cinch-rename

**Tag**: library

## 简介

A plugin to easily rename a cinch IRC-bot so that either everyone or an admin can do it.

## 官网

- 主页: http://github.com/netfeed/cinch-rename
- RubyGems: https://rubygems.org/gems/cinch-rename
