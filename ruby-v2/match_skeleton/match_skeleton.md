# match_skeleton

**Tag**: data

## 简介

MatchSkeleton is a class equivalent to MatchData with negligible memory use when the identical strings are matched repeatedly while matched data are kept in the memory.  As long as the original string is not destructively modified, it behaves almost icentical to MatchData.
