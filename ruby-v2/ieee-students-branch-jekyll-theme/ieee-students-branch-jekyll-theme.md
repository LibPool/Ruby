# ieee-students-branch-jekyll-theme

**Tag**: web, testing, serialization, networking, template, filesystem

## 简介

This is jekyll theme template designed for IEEE Students Branch website hosted by institute and colleges. create markdown files contact.md submitpaper.md … in the root directory and change theme in gem file as `theme:conference-mgeek.in-jekyll-theme` &copy; 2018 http://mgeek.in . add topmenu: true, to add pages in navigation, add submenu: true for submenu pages and also add submenutype: <parent topmenu>, also specify order: <number> for all pages in yaml
