# balloon_hashing

**Tag**: library

## 简介

Pure Ruby implementation of the Balloon Hashing algorithm (Boneh, Corrigan-Gibbs, Schechter 2016). Supports SHA-256, SHA-512, and BLAKE2b. Memory-hard with provable protection against sequential attacks.
