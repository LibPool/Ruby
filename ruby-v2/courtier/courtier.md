# courtier

**Tag**: library

## 简介

Courtier is a multi-tenant configuration system for Ruby projects.
Courtier can configure almost any Ruby tool or library.

## 官网

- 主页: http://rubyworks.github.com/courtier
- RubyGems: https://rubygems.org/gems/courtier
