# gintonic-rails

**Tag**: web

## 简介

Gintonic is a Sass mixins collection, include normalize 2.1 modified, clearfix, font-face helper and CSS3 properties with vendor prefixes Webkit, Firefox &gt; 3.5, Opera and IE &gt; 8.
