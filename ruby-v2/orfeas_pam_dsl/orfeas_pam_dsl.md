# orfeas_pam_dsl

**Tag**: library

## 简介

A declarative DSL for defining privacy policies, PII fields, consent requirements, and retention rules using the Privacy Attribute Matrix (PAM) model for privacy-aware event monitoring. Part of the ORFEAS (Object-Relational to Event-Sourcing Architecture) framework.
