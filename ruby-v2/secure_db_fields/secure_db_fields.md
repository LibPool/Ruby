# secure_db_fields

**Tag**: database, security

## 简介

A narrow production-oriented field encryption layer: AES-256-GCM envelope, HMAC-SHA256 blind indexes, Ruby extension, MySQL UDF source, admin SQL contracts, and migration helpers.
