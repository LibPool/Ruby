# simple_bmp

**Tag**: web, testing

## 简介

As simple as you really need. Uses only 8bpp with no indexing. Imports BITMAPCOREHEADER and 24bpp BITMAPINFOHEADER. Exports BITMAPCOREHEADER. If it seems to work under &lt;=1.8.7, let me know -- I'll update gemspec.
