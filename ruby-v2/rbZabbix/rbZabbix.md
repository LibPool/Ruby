# rbZabbix

**Tag**: web, cli

## 简介

rbZabbix is a Zabby API and CLI. It provides a provisioning tool for
creating, updating and querying Zabbix objects (hosts, items, triggers, etc.) through the web
service based on the Zabby gem by Farzad Farid.
