# ruby-libtommath

**Tag**: web, networking, filesystem

## 简介

ruby-libtommath is a ruby extension encapsulating the LibTomMath multi-precision integer library (http://libtom.org/?page=features&amp;newsitems=5&amp;whatfile=ltm).  It has been written to be an almost complete drop in replacement for ruby's  Bignum.
