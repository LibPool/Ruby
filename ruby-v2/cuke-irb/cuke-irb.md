# cuke-irb

**Tag**: testing

## 简介

Cucumber plugin that enables user to stop the execution of a feature and inspect the environment using irb

- 主页: http://github.com/heim/cuke-irb
- RubyGems: https://rubygems.org/gems/cuke-irb
