# sql_genius

**Tag**: web, database, data

## 简介

SqlGenius gives Rails apps a mountable performance dashboard for SQL databases. Monitor slow queries, analyze query statistics, detect unused and duplicate indexes, and explore your database with optional AI-powered optimization.
