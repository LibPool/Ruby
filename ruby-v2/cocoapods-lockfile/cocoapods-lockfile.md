# cocoapods-lockfile

**Tag**: filesystem

## 简介

A Cocoapods plugin that generates the Podfile.lock file without the need to download the Pods files.

## 官网

- 主页: https://github.com/SotoiGhost/cocoapods-lockfile
- 文档: https://www.rubydoc.info/gems/cocoapods-lockfile/0.1.0
- RubyGems: https://rubygems.org/gems/cocoapods-lockfile

## 获取地址

- RubyGems: https://rubygems.org/gems/cocoapods-lockfile
- gem 安装: `gem install cocoapods-lockfile`
- Bundler: `gem "cocoapods-lockfile"`
- 最新版本: 0.1.0
- 最新版归档: https://rubygems.org/downloads/cocoapods-lockfile-0.1.0.gem
- 版本锁定: `gem "cocoapods-lockfile", "~> 0.1.0"`
