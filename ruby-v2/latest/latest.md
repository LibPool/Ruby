# latest

**Tag**: testing

## 简介

Latest keeps us up to speed by querying rubygems.org for a gem's most recent version number. Yep, that's all it does.

## 官网

- 主页: https://github.com/citrus/latest
- RubyGems: https://rubygems.org/gems/latest

## 历史版本号

- 0.4.0 (2012-03-07)
- 0.3.0 (2012-03-07)
- 0.2.0 (2012-02-14)
- 0.1.0 (2012-02-14)

## 获取地址

- RubyGems: https://rubygems.org/gems/latest
- gem 安装: `gem install latest`
- Bundler: `gem "latest"`
- 最新版本: 0.4.0
- 最新版归档: https://rubygems.org/downloads/latest-0.4.0.gem
- 版本锁定: `gem "latest", "~> 0.4.0"`
- 中央仓库: https://rubygems.org/
