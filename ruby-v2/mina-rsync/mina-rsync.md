# mina-rsync

**Tag**: web, devops, filesystem

## 简介

Deploy with Rsync to your server from any local (or remote) repository. 

Saves you the need to install Git on your production machine and deploy all of your development files each time! 

Suitable for deploying any apps, be it Ruby or Node.js.
