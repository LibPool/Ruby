# rails_malloc_trim

**Tag**: web

## 简介

Call malloc_trim(0) on GC
    Impact:
      - 99th percentile performance is slightly impacted.
      - CPU is very slightly higher

    Inspired by Philipp Tessenow's malloc_trim gem
