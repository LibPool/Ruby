# rails_cloudflare_turnstile

**Tag**: web, devops

## 简介

Rails extension for Cloudflare's Turnstile CAPTCHA alternative. This gem should work with
    Rails 6.x, 7.x, 8.x and with Faraday 1.x and 2.x.
