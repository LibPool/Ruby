# rubify

**Tag**: library

## 简介

Takes parsed s-expressions for other languages and emits formatted ruby using ruby_scribe.

## 官网

- 主页: http://github.com/rubiety/rubify
- RubyGems: https://rubygems.org/gems/rubify
