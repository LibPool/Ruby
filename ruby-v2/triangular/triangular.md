# triangular

**Tag**: web, filesystem

## 简介

Triangular is an easy-to-use Ruby library for reading, writing and manipulating Stereolithography (STL) files.

 The main purpose of Triangular is to enable its users to quickly create new software for Rapid Prototyping and Personal Manufacturing applications.
