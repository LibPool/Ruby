# neeto_ws_pusher

**Tag**: web, cli, security, networking, devops

## 简介

A lightweight Ruby gem for sending messages to WebSocket clients through an AWS SQS queue. Includes Rails integration with WebSocket authentication endpoint and User model extensions.
