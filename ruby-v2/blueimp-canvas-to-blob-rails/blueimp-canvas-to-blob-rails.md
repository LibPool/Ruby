# blueimp-canvas-to-blob-rails

**Tag**: web

## 简介

This gem wraps the blueimp JavaScript Canvas to Blob library as a Rails asset gem.  The library is by Sebastian Tschan, and the gem is packaged by Mike Virata-Stone.
