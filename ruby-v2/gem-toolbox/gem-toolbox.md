# gem-toolbox

**Tag**: library

## 简介

Gem-Toolbox is a RubyGems plugin that adds extra commands to RubyGems: open, cd, doc, history, readme and visit

## 官网

- 主页: http://github.com/gudleik/gem-toolbox
- RubyGems: https://rubygems.org/gems/gem-toolbox
