# rbenv-rehash

**Tag**: library

## 简介

Rubygems plugin to automatically run 'rbenv rehash' after (un)installing gems with executables. For optimal results, install within each installed ruby version.

## 官网

- 主页: http://github.com/ryansouza/rbenv-rehash
- RubyGems: https://rubygems.org/gems/rbenv-rehash
