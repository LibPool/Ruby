# rake_ci_tools

**Tag**: testing, tooling, devops

## 简介

Predined Rake tasks for building, testing and deploying xcode projects
    Includes Support for: - XCode: Build, Test
                          - Cucumber: calabash
                          - Vagrant: Run Cucumber Tests using Vagrant
