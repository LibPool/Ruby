# skaidb

**Tag**: web, cli, security

## 简介

A pure-stdlib Ruby client for skaidb. Speaks the binary wire protocol with SCRAM-SHA-256 auth and exposes a ruby-pg-style API (exec / exec_params, $1 placeholders, PG::Result-shaped results, streaming, batches, pooling, TLS).
