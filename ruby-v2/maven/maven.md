# maven

**Tag**: testing, serialization, filesystem

## 简介

maven support for rubygems based on maven 3.0-alpha-6. it allows to use xyz.gemspec file as pom file or the usual pom.xml files. there is also experimentel pom.rb with a ruby DSL. this gem is a stripped polyglot-maven which only includes the pmaven-jruby part. the executable runs only with jruby.
