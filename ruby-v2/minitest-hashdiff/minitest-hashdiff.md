# minitest-hashdiff

**Tag**: testing

## 简介

When assert_equal fails on two hashes, show exactly what changed: added, removed, and changed keys with type-change detection (nil to String, Integer to Float, symbol vs string keys), instead of two walls of inspect output. Zero configuration, Minitest loads it automatically. From the maker of rubyhash.dev.
