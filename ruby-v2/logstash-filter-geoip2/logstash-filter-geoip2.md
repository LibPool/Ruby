# logstash-filter-geoip2

**Tag**: library

## 简介

This gem is a Logstash plugin required to be installed on top of the Logstash core pipeline using $LS_HOME/bin/logstash-plugin install gemname. This gem is not a stand-alone program. Config key is geoip2.
