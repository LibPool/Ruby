# liblvm

**Tag**: library

## 简介

liblvm is a ruby gem to use the linux library liblvm2 in ruby

## 官网

- 源码仓库: https://github.com/malachheb/liblvm
- RubyGems: https://rubygems.org/gems/liblvm
