# solar-flair

**Tag**: web, testing

## 简介

Solar Flair is a flexible Jekyll theme allowing users to compile colorful websites. Built using the latest version of Bootstrap (4) and FontAwesome (5). The theme is developed for Solar Innovations and used in their Planning.Solar sites.
