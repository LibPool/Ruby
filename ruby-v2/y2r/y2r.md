# y2r

**Tag**: library

## 简介

Y2R is a transpiler translating YCP (a legacy language used to write parts of YaST) into Ruby. It will be used to translate YCP-based parts of the YaST codebase into Ruby, which will allow us to get rid of YCP completely.
