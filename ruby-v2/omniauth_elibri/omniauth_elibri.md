# omniauth_elibri

**Tag**: web, security

## 简介

Omniauth strategy, log into your website using eLibri.com.pl account. OAuth2 based strategy - requires you to provide id and secret that you can obtain from eLibri.com.pl site.

## 官网

- 源码仓库: https://github.com/elibri/omniauth-elibri
