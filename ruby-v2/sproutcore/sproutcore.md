# sproutcore

**Tag**: web, tooling

## 简介

SproutCore is a platform for building native look-and-feel applications on the web.  This Ruby library includes a copy of the SproutCore JavaScript framework as well as a Ruby-based build system called Abbot.

## 官网

- 主页: http://www.sproutcore.com
- 源码仓库: http://github.com/sproutcore/abbot
- 文档: http://guides.sproutcore.com
- 问题追踪: http://github.com/sproutcore/abbot/issues
- RubyGems: https://rubygems.org/gems/sproutcore
