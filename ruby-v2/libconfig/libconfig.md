# libconfig

**Tag**: web, networking, filesystem

## 简介

A Ruby library for reading/writing C libconfig config files (http://www.hyperrealm.com/libconfig/).

## 官网

- 主页: http://rubygems.org/gems/libconfig
- 源码仓库: https://github.com/cgore/ruby-libconfig
- RubyGems: https://rubygems.org/gems/libconfig
