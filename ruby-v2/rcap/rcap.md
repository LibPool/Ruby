# rcap

**Tag**: web

## 简介

A Ruby API providing parsing, generation and validation of CAP(Common Alerting Protocol) messages.

## 官网

- 主页: http://www.aimred.com/projects/rcap
- 源码仓库: https://github.com/farrel/RCAP
- 文档: http://www.aimred.com/projects/rcap/api
- RubyGems: https://rubygems.org/gems/rcap
