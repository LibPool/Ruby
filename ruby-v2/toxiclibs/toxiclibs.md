# toxiclibs

**Tag**: cli, testing

## 简介

Toxiclibs java libraries wrapped in a rubygem. Compiled and tested with JRubyArt-2.4 and processing-3.4

- RubyGems: https://rubygems.org/gems/toxiclibs
