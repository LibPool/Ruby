# moeffju-luhn

**Tag**: web, networking

## 简介

Adds methods to Fixnum and String to generate and validate Luhn check digits, e.g. for credit card numbers, civic numbers, some account numbers etc. More info: https://en.wikipedia.org/wiki/Luhn_algorithm
