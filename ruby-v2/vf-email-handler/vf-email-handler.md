# vf-email-handler

**Tag**: library

## 简介

Use this handler when you want to be ableto queue up emails via Amazons Simple QueueService, enabeling you to generatetons of emails and send them as fast as AmazonsSimple Email Service will let you. Check out thereadme on Github for more information.
