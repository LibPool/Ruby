# ruby-libnids

**Tag**: web, security, networking

## 简介

ruby-libnids is a Ruby binding for libnids library written in C programming language.  libnids homepage: http://libnids.sourceforge.net libnids author: Rafal Wojtczuk

## 官网

- 主页: http://ruby-libnids.rubyforge.org
- RubyGems: https://rubygems.org/gems/ruby-libnids
