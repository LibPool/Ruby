# confium

**Tag**: security

## 简介

Confium provides threshold cryptography for Ruby: FROST / CMP20 / GG18 signing sessions, X.509 certificate issuance (CNML-ready), composite PQ-migration signatures, and transparency-log anchoring. Powered by a Rust native extension (magnus + rb_sys) — no separate C ABI to install.
