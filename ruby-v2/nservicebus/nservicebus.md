# nservicebus

**Tag**: library

## 简介

The most popular open-source service bus for .net 
		Powerful, yet lightweight.
		Pluggable, yet simple to use.
		Enterprise development, done right.

		Zero Install - working pub/sub messaging in under 5 minutes.
