# syruppay_jose

**Tag**: testing

## 简介

Library for SyrupPay service's merchant.
                        This is implemented JOSE specification, RFC 7515, 7516.
                        support algorithm : JWE-A128KW, A256KW, A128CBC-HS256, JWS-HS256
