# prettyphoto-rails

**Tag**: web, networking

## 简介

Rails gem for easy prettyPhoto (v3.1.5) integration. See http://www.no-margin-for-errors.com/projects/prettyphoto-jquery-lightbox-clone/ for more information on how to use prettyPhoto.
