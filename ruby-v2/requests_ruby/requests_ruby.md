# requests_ruby

**Tag**: web, cli, security, networking

## 简介

A stdlib-only Ruby HTTP client modeled after python's requests library. Sessions, cookies, redirects, auth (Basic/Bearer/Digest), multipart uploads, streaming responses, hooks, and a friendly exception hierarchy - no external gems required.
