# xmltv2html

**Tag**: serialization, template, filesystem

## 简介

xmltv2html is a Ruby script that generates a static HTML page from  the output of XMLTV. This is different from other XMLTV -&gt; HTML programs in that the times are on the horizontal axis and the channels on the vertical axis. The HTML output can be modified using a CSS file. The prefered method to view a show's info is via DHTML (the default). With version 0.5.3+, the attributes (fonts, colors, size) of the  DHTML can be modified.
