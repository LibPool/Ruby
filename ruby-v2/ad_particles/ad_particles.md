# ad_particles

**Tag**: library

## 简介

ad_particles is SASS Module that defines a base set of variables that can used as a
    standard in component styling &amp; consistent theming. Particles, although not
    originally discussed by Atomic Design creator Brad Frost, are the abstract &amp;
    configuration structures that shape the Atomic design structure from the ground
    up.
