# passgen3k

**Tag**: web, testing

## 简介

A simple password genorator.
Functinos:
test - test function
gen(n) - genorate password of n length
gen_c(n,a,b,c,d) - genorates password of n length with coditions of booleans a, b and c.a - capital letters, b - numbers, c - special characters, d - lower case letters
