# rugem

**Tag**: library

## 简介

rugem is a wrapper of ruby command that can use gem library with -r option

## 官网

- 主页: http://akasakarb.rubyforge.org
- RubyGems: https://rubygems.org/gems/rugem

## 历史版本号

- 0.0.1 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/rugem
- gem 安装: `gem install rugem`
- Bundler: `gem "rugem"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/rugem-0.0.1.gem
- 版本锁定: `gem "rugem", "~> 0.0.1"`
- 中央仓库: https://rubygems.org/
