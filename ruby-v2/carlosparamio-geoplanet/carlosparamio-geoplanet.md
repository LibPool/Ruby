# carlosparamio-geoplanet

**Tag**: web, serialization, networking

## 简介

A Ruby wrapper for the Yahoo! GeoPlanet API. It uses JSON format by default to minimize bandwidth usage. See http://developer.yahoo.com/geo/ for more information about the API.
