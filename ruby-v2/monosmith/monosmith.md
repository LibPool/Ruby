# monosmith

**Tag**: library

## 简介

Runs a monorepo in Node, Go, Python, Rust, .NET, Ruby, PHP, C++, Dart, the JVM and Bicep: tasks from a cache, CI and releases

This gem holds the prebuilt smith binary for aarch64-mingw-ucrt and needs no Ruby code at run time.
