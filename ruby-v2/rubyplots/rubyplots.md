# rubyplots

**Tag**: filesystem, data

## 简介

RubyPlots can be set loose on a directory of datafiles or a singluar datafile.  It uses the file extension to determine a datafile of interest and, using the Latex PgfPlots library, creates a single pdf plot for each data file.  See the Homepage for questions.  Enjoy!
