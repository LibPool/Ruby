# faster_gem_script

**Tag**: cli

## 简介

A utility to make ruby "command line scripts" run much faster by using gem prelude instead of full rubygems

## 官网

- 主页: http://github.com/rdp/faster_gem_scripts
- RubyGems: https://rubygems.org/gems/faster_gem_script
