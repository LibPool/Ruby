# royalprint

**Tag**: cli

## 简介

💎 royalprint Ruby is perfect for simplifying the information that needs to go to the console, similar to printing in C++ command cout, PHP echo, log("Hi"), go("Hello mdf"), cout("whoami?")... and more.
