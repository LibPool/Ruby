# dump_hook

**Tag**: web, database, testing, data

## 简介

DumpHook speeds up your Rails system and acceptance tests by dumping and restoring database state instead of recreating it from scratch on every run. Supports PostgreSQL and MySQL. Works with Capybara, RSpec, Cucumber, and Minitest.
