# boogaloo

**Tag**: web, testing

## 简介

Boogaloo is a very simple cache server that provides permanent and temporary object persistence, with the ability for objects to &quot;expire&quot;. Boogaloo can also be used for housing custom services, such as a registry or specialized cache implementation.
