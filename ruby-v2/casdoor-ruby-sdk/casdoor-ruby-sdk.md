# casdoor-ruby-sdk

**Tag**: security

## 简介

Ruby SDK for Casdoor: sign users in with OAuth 2.0 / OIDC, verify the JWT tokens, and manage users, organizations, applications, roles, permissions and the other objects of Casdoor.
