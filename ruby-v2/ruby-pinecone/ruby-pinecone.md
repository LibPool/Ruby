# ruby-pinecone

**Tag**: web, database, networking, data

## 简介

Ruby library for interacting with the pineone vector database. This was built to hit a deadline. Better to consolidate work into a single ruby pinecone libary. So please rather use https://rubygems.org/gems/pinecone
