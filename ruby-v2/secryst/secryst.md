# secryst

**Tag**: serialization

## 简介

Secryst (scrying + crystal) reveals the hidden reading of a script — diacritization, vocalization, grapheme-to-phoneme — via local, sha256-verified IMF v1 ONNX models. Implements the interscript-ml contract (models.yaml index, byte tokenizer, golden parity). Sibling crystals: pip install secryst, npm i secryst.
