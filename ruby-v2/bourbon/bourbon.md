# bourbon

**Tag**: library

## 简介

Bourbon is a library of pure Sass mixins and functions that are designed to
    make you a more efficient developer.

## 官网

- 主页: https://www.bourbon.io/
- 源码仓库: https://github.com/thoughtbot/bourbon
- 文档: http://bourbon.io/docs/
- 问题追踪: https://github.com/thoughtbot/bourbon/issues
- RubyGems: https://rubygems.org/gems/bourbon
