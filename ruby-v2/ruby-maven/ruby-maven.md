# ruby-maven

**Tag**: filesystem

## 简介

maven support for ruby DSL pom files. MRI needs java/javac installed.

## 官网

- 主页: https://github.com/jruby/ruby-maven
- 文档: https://www.rubydoc.info/gems/ruby-maven/3.9.3
- RubyGems: https://rubygems.org/gems/ruby-maven
