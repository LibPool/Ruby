# Tamar

**Tag**: tooling

## 简介

A package of the RubyLuaBridge library, which includes Lua and relevant libraries. You will need a C++ compiler with the Boost library installed to build RubyLuaBridge, and both CMake and Make to build Lua.

## 官网

- RubyGems: https://rubygems.org/gems/Tamar
