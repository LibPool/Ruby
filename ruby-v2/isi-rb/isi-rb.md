# isi-rb

**Tag**: web, filesystem

## 简介

isi.rb converts ISI Export Format to BibTeX Format. This is a Ruby script. You can use this script as a library.  You can get the tagged Marked List in Web of Science by pushing the [SAVE TO FILE] button.
