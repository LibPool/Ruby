# mailMapper

**Tag**: filesystem

## 简介

Search and count emails from a text file, Ex. MailMapper.find("source", option=int); option 0 «default value» returns a hash with domain-key counter-value, option 1 returns a hash for user@mail -&gt; counter-value, option 2 returns an array with all mails
