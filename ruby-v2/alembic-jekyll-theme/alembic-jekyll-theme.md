# alembic-jekyll-theme

**Tag**: web

## 简介

A Jekyll boilerplate theme designed to be a starting point for any Jekyll website. Rather than starting from scratch, this boilerplate is designed to get the ball rolling immediately.

## 官网

- 主页: https://alembic.darn.es
- 源码仓库: https://github.com/daviddarnes/alembic
- 文档: https://github.com/daviddarnes/alembic/blob/master/README.md
- RubyGems: https://rubygems.org/gems/alembic-jekyll-theme
