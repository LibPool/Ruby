# youdao-fanyi

**Tag**: web

## 简介

A gem to wrap the Youdao Fanyi (fanyi.youdao.com) API. "fanyi" is "translation" in Chinese.

## 官网

- 主页: https://github.com/zhhailon/youdao-fanyi
- RubyGems: https://rubygems.org/gems/youdao-fanyi
