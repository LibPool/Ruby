# utopia-tags-google-analytics

**Tag**: web, tooling, data

## 简介

Utopia is a website generation framework which provides a robust set of tools
		to build highly complex dynamic websites.

		This package includes a useful &lt;google-analytics&gt; tag for easily integrating
		with Google Analytics.
