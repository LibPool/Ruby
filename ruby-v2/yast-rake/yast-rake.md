# yast-rake

**Tag**: cli, tooling

## 简介

Rake tasks that support work-flow of Yast developer. It allows packaging repo,
send it to build service, create submit request to target repo or run client
from git repo.

## 官网

- RubyGems: https://rubygems.org/gems/yast-rake
