# middleman-asciidoc

**Tag**: testing, serialization, template, filesystem, data

## 简介

Converts AsciiDoc files in the source directory to HTML pages. Allows page data to be specified using AsciiDoc attributes defined in the document header (as an alternative to YAML front matter).
