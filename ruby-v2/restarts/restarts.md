# restarts

**Tag**: library

## 简介

restarts.rb implements a new method Kernel#raise_condition which is similar to Kernel#raise for throwing exceptions, with the added feature of adding &quot;restarts&quot; next to the place where the exception is thrown so that they can be invoked from the exception handler somewhere higher up in the stack.
