# imagizer_engine

**Tag**: cli, devops

## 简介

Super simple ruby client to use the Imagizer Media Engine created by nventify. Imagizer is a real-time image processing engine on top of AMAZON aws. 
    Install the engine using the AWS Marketplace.     =You can find it at www.imagizercdn.com.
