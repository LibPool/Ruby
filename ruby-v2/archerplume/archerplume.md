# archerplume

**Tag**: web, testing

## 简介

ArcherPlume Blog FrameWork is a gem in which users can install and after installing , can copy the contents of the gem( in which is a rails application). Also,don't forget to take the survey when you run the server in the blog's directory, so you can have a better blog! Also RSpec supporthas been upgrade
