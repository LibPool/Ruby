# right_cloud_api_base

**Tag**: web, devops

## 简介

== DESCRIPTION:

right_cloud_api_base gem.

The gem provides base Query and REST API management functionalities for
Amazon, OpenStack, Rackspace, CloudStack, etc cloud services.
