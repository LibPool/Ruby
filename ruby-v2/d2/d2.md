# d2

**Tag**: library

## 简介

A cross-version compatible shortcut for invoking a Ruby debugger that will run properly under the currently executing environment.

## 官网

- 主页: https://github.com/brandur/d2
- RubyGems: https://rubygems.org/gems/d2
