# dynahash

**Tag**: library

## 简介

Dynahash allows you to access Hash keys as if they were properties. For example:  h = {:first_name => "Tony", "LastName" => "Heupel", "**the gender**" => :male};  h.first_name;  # => "Tony"  h.last_name; # => "Heupel"  h.the_gender # => :male
