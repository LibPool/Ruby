# daily_properties

**Tag**: cli, testing, template, filesystem

## 简介

This CLI gem helps home buyers and sellers to view the most recently sold properties within a given zipcode. Use 'daily-properties' command to run. It asks users for a zipcode input, and gives users a list of the most recently sold properties in the area. Users can type respective property number to get the url to view more details of the property.
