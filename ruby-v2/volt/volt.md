# volt

**Tag**: web, cli

## 简介

A reactive Ruby web framework where your Ruby code runs on both the server and the client (via Opal).

## 官网

- 主页: http://voltframework.com
- 文档: https://www.rubydoc.info/gems/volt/0.9.6
- RubyGems: https://rubygems.org/gems/volt
