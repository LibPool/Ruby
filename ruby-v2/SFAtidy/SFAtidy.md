# SFAtidy

**Tag**: web, networking, template

## 简介

Ruby interface to HTML Tidy Library Project, updated to avoid to avoid seg faults (see http://rubyforge.org/tracker/index.php?func=detail&aid=10007&group_id=435&atid=1744)

## 官网

- 主页: http://tidy.rubyforge.org/
