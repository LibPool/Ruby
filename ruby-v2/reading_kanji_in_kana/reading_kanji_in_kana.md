# reading_kanji_in_kana

**Tag**: web, networking

## 简介

This gem returns 'Yomigana' (reading Japanese kanji in kana) using a gem 'natto'. You need to install 'MeCab' before using this gem. To install MeCab, please consult 'http://taku910.github.io/mecab/'.
