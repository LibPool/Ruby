# testml-lite

**Tag**: testing

## 简介

TestML is an Acmeist testing framework. TestML::Lite is smaller bootstrap
version of TestML.

## 官网

- 主页: http://testml.org
- RubyGems: https://rubygems.org/gems/testml-lite

## 历史版本号

- 0.0.1 (2012-12-20)

## 获取地址

- RubyGems: https://rubygems.org/gems/testml-lite
- gem 安装: `gem install testml-lite`
- Bundler: `gem "testml-lite"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/testml-lite-0.0.1.gem
- 版本锁定: `gem "testml-lite", "~> 0.0.1"`
