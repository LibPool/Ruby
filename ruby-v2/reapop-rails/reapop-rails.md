# reapop-rails

**Tag**: web, networking

## 简介

Rails wrapper for Reapop JavaScript library (https://github.com/LouisBarranqueiro/reapop). The version number of this gem follows the version number of the original JavaScript library.

## 官网

- 主页: https://github.com/LouisBarranqueiro/reapop
- 文档: https://www.rubydoc.info/gems/reapop-rails/0.6.0
- RubyGems: https://rubygems.org/gems/reapop-rails

## 历史版本号

- 0.6.0 (2016-11-16)

## 获取地址

- RubyGems: https://rubygems.org/gems/reapop-rails
- gem 安装: `gem install reapop-rails`
- Bundler: `gem "reapop-rails"`
- 最新版本: 0.6.0
- 最新版归档: https://rubygems.org/downloads/reapop-rails-0.6.0.gem
- 版本锁定: `gem "reapop-rails", "~> 0.6.0"`
