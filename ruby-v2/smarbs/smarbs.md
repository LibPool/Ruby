# smarbs

**Tag**: library

## 简介

smarbs is a backup script written in ruby capable of doing intelligent and
automated backups using rsync.

## 官网

- 主页: http://smarbs.sourceforge.net
- RubyGems: https://rubygems.org/gems/smarbs
