# metalink

**Tag**: filesystem

## 简介

Horribly simple, completely unconfigurable library for creating metalink (version 3) files

## 官网

- 主页: https://github.com/timsjoberg/metalink-ruby
- RubyGems: https://rubygems.org/gems/metalink
