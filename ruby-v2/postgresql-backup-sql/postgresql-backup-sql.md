# postgresql-backup-sql

**Tag**: web, database, devops, data

## 简介

This gem automates PostgreSQL's backup and restore in your Rails project. It will inject two rake tasks that you can use to manage your data, either by using the local system or AWS S3 storage. forked from arturcp/postgresql-backup
