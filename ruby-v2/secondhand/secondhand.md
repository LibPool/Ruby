# secondhand

**Tag**: library

## 简介

Secondhand is a ruby-friendly wrapper around the Quartz Job Scheduler. Create jobs, tell Secondhand when they should run, then sit back and enjoy.

- 主页: https://github.com/amphora/secondhand
- RubyGems: https://rubygems.org/gems/secondhand
