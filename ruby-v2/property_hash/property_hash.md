# property_hash

**Tag**: library

## 简介

Access a nested Ruby Hash using Java-style properties as keys.

    For example: {:a => {:b => 123}} can be accessed as "a.b" and setting "a.b.c" => 456
    will create {:a => {:b => { :c => 456 }}}.
