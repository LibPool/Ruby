# ergo

**Tag**: tooling

## 简介

Ergo is an automated build tool with a slick set-logic based
state/rules system, perfect for performing continuous integration.

## 官网

- 主页: http://rubyworks.github.com/ergo
- RubyGems: https://rubygems.org/gems/ergo
