# datasift

**Tag**: web, networking, data

## 简介

The official Ruby library for accessing the DataSift API. See http://datasift.com/ for full details and to sign up for an account.

## 官网

- 主页: https://github.com/datasift/datasift-ruby
- 文档: http://dev.datasift.com/
- RubyGems: https://rubygems.org/gems/datasift
