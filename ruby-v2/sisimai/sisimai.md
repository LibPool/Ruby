# sisimai

**Tag**: data

## 简介

Sisimai is a Ruby library for analyzing RFC5322 bounce emails and generating structured data from parsed results.

## 官网

- 主页: https://libsisimai.org/
- 源码仓库: https://github.com/sisimai/rb-Sisimai
- 文档: http://libsisimai.org/
- RubyGems: https://rubygems.org/gems/sisimai
