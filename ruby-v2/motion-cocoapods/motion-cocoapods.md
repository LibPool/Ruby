# motion-cocoapods

**Tag**: library

## 简介

motion-cocoapods allows RubyMotion projects to have access to the CocoaPods dependency manager.

## 官网

- 主页: http://www.rubymotion.com
- 源码仓库: https://github.com/HipByte/motion-cocoapods
- 文档: https://www.rubydoc.info/gems/motion-cocoapods/1.11.0
- RubyGems: https://rubygems.org/gems/motion-cocoapods
