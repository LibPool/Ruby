# fmrest-spyke

**Tag**: web, cli, networking, filesystem, data

## 简介

fmrest-spyke is an ActiveRecord-like ORM client library for the FileMaker Data API built on top of fmrest-core and Spyke (https://github.com/balvig/spyke).
