# rtm-javatmapi

**Tag**: web, networking

## 简介

Ruby Topic Maps is a Topic Maps engine written in Ruby.
    This backend engine uses any Java TMAPI 2.0 compatible backend. See http://www.tmapi.org/2.0/.
    You can provide your own TMAPI 2.0 compatible implementation or use one of the existing ones:
    * rtm-ontopia
    * rtm-tinytim
    * rtm-sesametm
