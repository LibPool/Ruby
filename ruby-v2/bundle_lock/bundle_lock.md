# bundle_lock

**Tag**: filesystem

## 简介

Find out current and outdated gems in your gem file and create lock including maven.

## 官网

- 主页: https://github.com/lramos85/bundle_lock
- RubyGems: https://rubygems.org/gems/bundle_lock

## 获取地址

- RubyGems: https://rubygems.org/gems/bundle_lock
- gem 安装: `gem install bundle_lock`
- Bundler: `gem "bundle_lock"`
- 最新版本: 0.0.4
- 最新版归档: https://rubygems.org/downloads/bundle_lock-0.0.4.gem
- 版本锁定: `gem "bundle_lock", "~> 0.0.4"`
