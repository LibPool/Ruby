# amazon-chime-sdk-rails

**Tag**: web, devops

## 简介

amazon-chime-sdk-rails provides server-side API implementation for Amazon Chime SDK as wrapper functions of AWS SDK for Ruby, and basic controller implementation for Ruby on Rails application.
