# shrinkwrap

**Tag**: security, devops

## 简介

Shrinkwraps code for quick and safe deployment. Initial release will tar
    code, encrypt and sign it, then upload it to a CDN. This also contains 
    deployment tools for unwrapping and deploying these packages
