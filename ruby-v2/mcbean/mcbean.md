# mcbean

**Tag**: template

## 简介

McBean can convert documents from one format to another. McBean currently supports:

* HTML
* Markdown (a subset)
* Textile (a subset)
* Creole (a subset)

with the help of Loofah, Nokogiri, RDiscount, RedCloth and Creole.
