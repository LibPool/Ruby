# docgenerator-creole

**Tag**: web, networking, template, tooling

## 简介

The docgenerator-gem create documents with export feature as
LaTeX, HTML, Creole (a common wiki markup, see http://www.wikicreole.org ),
conTeXt (only rudimentory),
plain text (not very good supported) and
Wiki-markup like Wikimedia (no support any longer).

This gem extends the docgenerator-gem with a Creole-parser.
