# where_chain

**Tag**: web, database

## 简介

This is a Rails plugin that extends Active Record with additional methods: .like, .unlike,
.gt, .gte, .lt and .lte, so that you can replace the SQL strings like
Post.where('comments > 5') with Post.where.gt(comments: 5)
