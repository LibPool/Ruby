# google-cloud-bigtable-admin-v2

**Tag**: cli, testing, devops

## 简介

Administer your Cloud Bigtable tables and instances. Note that google-cloud-bigtable-admin-v2 is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-bigtable instead. See the readme for more details.
