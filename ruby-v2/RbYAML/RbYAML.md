# RbYAML

**Tag**: serialization, tooling

## 简介

A pure Ruby YAML parser and emitter, mostly supporting YAML 1.1.

## 官网

- 主页: http://rbyaml.rubyforge.org
- RubyGems: https://rubygems.org/gems/RbYAML
