# ncaa_scrape

**Tag**: web, networking, data

## 简介

As of October 2017, ncaa_scrape lets you scrape team names and team wins for Division I Men's college basketball from the NCAA RPI Rankings page. This gem uses nokogiri to scrape data from ncaa.com; if the NCAA website changes, this gem may fail. For more information, see readme at https://github.com/jtrudell/NCAA-Basketball-Scraper
