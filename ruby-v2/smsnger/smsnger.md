# smsnger

**Tag**: web

## 简介

A Ruby library to send text messenges for free via email (extracted from the SMS-Fu Rails plugin by Brendan Lim).

## 官网

- 主页: http://github.com/watsonian/smsnger
- RubyGems: https://rubygems.org/gems/smsnger
