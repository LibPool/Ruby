# internetkassa

**Tag**: library

## 简介

A library to make online payments using ABN-AMRO (Dutch bank) Internetkassa.

## 官网

- 主页: https://github.com/Fingertips/abn-amro_internetkassa/tree/master
- RubyGems: https://rubygems.org/gems/internetkassa
