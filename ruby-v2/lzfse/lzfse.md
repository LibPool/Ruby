# lzfse

**Tag**: web

## 简介

lzfse is a Ruby gem containing bindings for Apple's LZFSE and LZVN
compression algorithms. It binds Apple's reference implementation
and exposes compression and decompression APIs for both LZFSE and
LZVN.
