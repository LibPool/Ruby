# mcmire-mocha

**Tag**: testing

## 简介

Mocking and stubbing library with JMock/SchMock syntax, which allows mocking and stubbing of methods on real (non-mock) classes.

## 官网

- 主页: http://mocha.rubyforge.org
- RubyGems: https://rubygems.org/gems/mcmire-mocha
