# yml_builder

**Tag**: serialization, tooling

## 简介

Библиотека содержит набор классов для формирования и валидации прайс-листов
                          в формате Яндекс YAML (Yandex.Market).
                          Текущая версия поддерживает только упрощенные товарные карточки.
