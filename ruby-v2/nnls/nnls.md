# nnls

**Tag**: devops

## 简介

Ruby bindings for C. Lawson and R. Hanson 'Non-negative Less Square' algorithm implementation.

## 官网

- 主页: http://github.com/sotakone/nnls/
- RubyGems: https://rubygems.org/gems/nnls
