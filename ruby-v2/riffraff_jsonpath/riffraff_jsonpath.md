# riffraff_jsonpath

**Tag**: serialization, tooling, filesystem

## 简介

The gem implements a simple parser+evaluator for JSONPath expressions in Ruby. It is a fork of bruce-jsonpath which only adds support for underscore in fields and works with warnings enabled.
