# ai-crawler-index

**Tag**: serialization, networking, tooling, filesystem, data

## 简介

Give it a User-Agent string, get back what it is: 150 AI crawlers, search engines, SEO bots, archivers and dataset builders from 74 operators, bundled as one 124.3 KB JSON table. ai_crawler?(ua), identify(ua) -> {name, operator, category, verification_method}, robots_txt(stance). Zero dependencies, no network at require time, pure functions of the string you pass in. Data CC0-1.0 from the independent AI Crawler Index; code MIT.
