# geminabucket

**Tag**: web, devops

## 简介

Why run a gem server to host your gems when you have Amazon S3?
Geminbucket is Rubygem plugin that lets your use S3 buckets as sources.
S3 buckets are accessed with the official aws-sdk gem.
