# jekyll_asset_pipeline

**Tag**: tooling, filesystem

## 简介

Jekyll Asset Pipeline adds asset preprocessing (Sass, Less, ERB, etc.)
    and asset compression / minification / gzip (Terser, Closure Compiler,
    etc.) to Jekyll.
