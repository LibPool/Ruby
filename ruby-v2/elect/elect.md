# elect

**Tag**: library

## 简介

elect 是一个 Ruby gem，用于从代码和文档文件中检测并移除 AIGC 水印块。
支持目录/文件级扫描，提供 dry-run、自定义扩展名、目录排除等功能。
零运行时依赖，纯标准库实现。
