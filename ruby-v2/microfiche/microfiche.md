# microfiche

**Tag**: serialization

## 简介

Micorfiche is an assortment of microformat libraries. So far only XOXO is included, but other will be added soon. Also included in a JSON library, not strictly a micorformat, its usage is closely paired with these  other technologies, and so is included.
