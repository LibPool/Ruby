# fabricjs-rails

**Tag**: web, serialization, template, tooling

## 简介

Allows text,cufon,gestures,easing,parser,freedrawing,interaction,serialization,image_filters,gradient,pattern,shadow  on HTML5 canvas with FabricJs.
