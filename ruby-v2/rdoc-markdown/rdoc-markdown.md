# rdoc-markdown

**Tag**: database, data

## 简介

RDoc plugin to generate markdown documentation and search index as sqlite database for entire content.

- 主页: https://poshtui.com
- 源码仓库: https://github.com/skatkov/rdoc-markdown
- RubyGems: https://rubygems.org/gems/rdoc-markdown
