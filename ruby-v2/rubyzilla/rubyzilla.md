# rubyzilla

**Tag**: web

## 简介

Rubyzilla is a Ruby API for interfacing with bugzilla.

## 官网

- 主页: http://github.com/guitsaru/rubyzilla
- RubyGems: https://rubygems.org/gems/rubyzilla

## 历史版本号

- 0.1.1 (2011-01-26)

## 获取地址

- RubyGems: https://rubygems.org/gems/rubyzilla
- gem 安装: `gem install rubyzilla`
- Bundler: `gem "rubyzilla"`
- 最新版本: 0.1.1
- 最新版归档: https://rubygems.org/downloads/rubyzilla-0.1.1.gem
- 版本锁定: `gem "rubyzilla", "~> 0.1.1"`
- 中央仓库: https://rubygems.org/
