# apache-log-geo

**Tag**: cli, data

## 简介

An offline GeoIP CLI filter for Apache (common, combined) logs.
It's like grep but with a knowledge about what data an ip
holds. Requires MaxMind's GeoLite2 DB (GeoLite2-City.mmdb) installed.
