# cloudmersive-dlp-api-client

**Tag**: web, cli, devops, data

## 简介

Cloudmersive Data Loss Prevention allows you to scan input for Personally Identifiable Information (PII), Personal Health Information (PHI), Personal Financial Information and other types of sensitive data.  Advanced AI is used to both detect and redact with next-generation accuracy.
