# pocketbase

**Tag**: database, security, filesystem

## 简介

A Ruby port of the official PocketBase JavaScript SDK (pocketbase/js-sdk): record CRUD, auth (password, OAuth2, OTP), file uploads, realtime subscriptions over SSE, backups, settings, logs, cron jobs, SQL and batch requests. Zero runtime dependencies (stdlib only).
