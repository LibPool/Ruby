# unidom-standard

**Tag**: library

## 简介

Unidom (UNIfied Domain Object Model) is a series of domain model engines. The Standard domain model engine includes Standard and Standard Association models. Unidom (统一领域对象模型)是一系列的领域模型引擎。标准领域模型引擎包括标准和标准关联的模型。
