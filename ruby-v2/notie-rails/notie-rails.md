# notie-rails

**Tag**: web, networking

## 简介

A rails asset pipeline gem for notie.js. see notie.js documentation for more info: https://jaredreich.com/projects/notie.js/. This project is not associated with the notie.js project, it simply packages it for easy integration with rails.
