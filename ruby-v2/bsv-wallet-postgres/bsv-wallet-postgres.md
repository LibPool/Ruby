# bsv-wallet-postgres

**Tag**: database, data

## 简介

This gem is deprecated. PostgreSQL support is now built into the bsv-wallet gem itself. Install bsv-wallet and set DATABASE_URL to a postgres:// URL — no additional gem needed.
