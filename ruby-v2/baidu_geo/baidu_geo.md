# baidu_geo

**Tag**: web

## 简介

基于Baidu Geocoding API 提供从地址到经纬度坐标或者从经纬度坐标到地址的转换服务

## 官网

- 主页: https://github.com/luolinae86/baidu_geo
- 文档: https://www.rubydoc.info/gems/baidu_geo/0.1.0
- RubyGems: https://rubygems.org/gems/baidu_geo

## 历史版本号

- 0.1.0 (2017-10-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/baidu_geo
- gem 安装: `gem install baidu_geo`
- Bundler: `gem "baidu_geo"`
- 最新版本: 0.1.0
- 最新版归档: https://rubygems.org/downloads/baidu_geo-0.1.0.gem
- 版本锁定: `gem "baidu_geo", "~> 0.1.0"`
- 中央仓库: https://rubygems.org/
