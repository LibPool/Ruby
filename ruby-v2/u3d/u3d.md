# u3d

**Tag**: cli

## 简介

Provides numerous tools for installing, managing and running the Unity game engine from command line.

## 官网

- 主页: https://github.com/DragonBox/u3d
- 文档: https://www.rubydoc.info/gems/u3d/1.3.4
- RubyGems: https://rubygems.org/gems/u3d
