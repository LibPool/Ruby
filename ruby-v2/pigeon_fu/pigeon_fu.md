# pigeon_fu

**Tag**: web, networking

## 简介

PigeonFu is a Ruby gem (also can be as a Rails plugin, it'll support Rails 3.0.0 or above ASAP) as an unofficial Ruby SDK for the ChinaTelecom Open Platform(http://open.189works.com/).
