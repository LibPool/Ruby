# docme

**Tag**: template, filesystem

## 简介

A gem to support easy documentation for any file that recognizes `/* */` as a code block.  This gem lets you easily parse multiple files in a directory and generate documentation that can be viewed in the browser.  See the homepage and wiki for syntax and examples.
