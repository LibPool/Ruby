# worldmonitor

**Tag**: web, cli, networking

## 简介

Country briefs, risk scores, conflict/cyber/market/news feeds, and MCP tools from the World Monitor global-intelligence API without writing an HTTP integration. Stdlib-only (Net::HTTP), MCP-first — the same design as the official worldmonitor npm CLI.
