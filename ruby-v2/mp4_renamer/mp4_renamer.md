# mp4_renamer

**Tag**: filesystem

## 简介

Rename the mp4 and m4a files by adding the running time to the end of the filename
                          TL;DR rename 'media_file.mp4' to 'media_file_12_34.mp4' if the running time is '12:34' minutes
