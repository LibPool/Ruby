# win32_service_manager

**Tag**: web, networking

## 简介

A simple wrapper around Win32::Service to present a more 'God'  (http://god.rubyforge.org) like interface. Also presents all service  information as hashes rather than structs to save on wire transport and  multi-platform complexity.
