# csv2plist

**Tag**: filesystem, data

## 简介

Takes a comma-separated variable (CSV) file and generates a Property List (PLIST) file from it structured as an array of dictionaries, one for each row.

- 源码仓库: https://github.com/dhennessy/csv2plist
