# renumber

**Tag**: filesystem

## 简介

Allows renumbering non-sequential files sequentially. For example f00.txt, f03.txt, f99.txt -&gt; f0.txt, f1.txt, f2.txt. Usage: renumber directory_name [prefix] [suffix]
