# jekkyl-arumai

**Tag**: data

## 简介

The theme, named "Arumai" (meaning "wonderful" or "excellent" in Tamil), focuses on minimal design for the Jekyll framework. It integrates Bootstrap for styling and Prism for syntax highlighting.
