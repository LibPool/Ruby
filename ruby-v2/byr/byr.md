# byr

**Tag**: web, filesystem

## 简介

In the spririt of ledger, use text files to track your finances, but use Emacs org
mode to create and edit transactions.  Provides for ruby to fetch transaction files
from financial institutions using watir-webdriver.  Print nice reports with LaTeX, and
more.
