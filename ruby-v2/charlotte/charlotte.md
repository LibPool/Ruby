# charlotte

**Tag**: library

## 简介

A simple (but fast!) character set encoding/binary detector and auto-converter for common encodings (UTF-8/16/32, ISO-8859-1, MacRoman, etc.). Extends String with String.detect_encoding, String.autoencode.
