# byn

**Tag**: web, cli, testing, networking

## 简介

byn is a local-first secure secrets vault. This gem reserves the name; install the real CLI via `go install github.com/sandeepbaynes/byn/cmd/byn@latest`, Homebrew, or https://github.com/sandeepbaynes/byn. It installs no executable.
