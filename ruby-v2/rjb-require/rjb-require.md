# rjb-require

**Tag**: web, networking

## 简介

Adds the ability to import and map Java packages to nested Ruby modules/classes to RJB. Based on http://bit.ly/aBLnei

## 官网

- 主页: http://github.com/svenfuchs/rjb-require
- RubyGems: https://rubygems.org/gems/rjb-require
