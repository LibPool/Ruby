# IVLE

**Tag**: web, testing

## 简介

Basic Ruby gem wrapper for NUS IVLE LAPI interface. All methods are implemented (but not tested).

## 官网

- 主页: https://github.com/gyng/ivle
- 文档: http://fauxface.github.io/ivle/
