# rails-upgrade

**Tag**: web

## 简介

A simple battery of scripts for upgrading Rails app/checking them for required updates.

## 官网

- 主页: http://github.com/jm/rails-upgrade
- RubyGems: https://rubygems.org/gems/rails-upgrade
