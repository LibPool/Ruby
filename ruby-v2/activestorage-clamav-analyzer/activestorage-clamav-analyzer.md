# activestorage-clamav-analyzer

**Tag**: library

## 简介

Add ActiveStorage Analyzer class to perform ClamAV virus scans on
    ActiveStorage::Blob objects. Supports ClamAV daemon mode, custom arguments
    and callbacks on detection.
