# priit-sprockets-rails2

**Tag**: web

## 简介

The sprockets-rails2 gem allows Rails 2.3 apps to use the
                     same asset pipeline functionality introduced in Rails 3.1.
                     It does this by integrating the Sprockets gem into a Rails
                     2.3 app
