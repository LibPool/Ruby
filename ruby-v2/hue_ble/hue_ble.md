# hue_ble

**Tag**: library

## 简介

Control color temperature, brightness, and color of Hue light bulbs which supports Bluetooth LE.

## 官网

- 主页: https://github.com/NeoCat/ruby_hue_ble
- RubyGems: https://rubygems.org/gems/hue_ble

## 历史版本号

## 获取地址

- RubyGems: https://rubygems.org/gems/hue_ble
