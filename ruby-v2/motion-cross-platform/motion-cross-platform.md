# motion-cross-platform

**Tag**: testing, filesystem

## 简介

Adds namespaced rake tasks (rake ios, rake android, rake osx) and source directory conventions so one RubyMotion project can target iOS, Android, and macOS — shared code lives in app/, platform-specific code in app/ios, app/android, and app/osx, and per-platform configuration in a single Rakefile.
