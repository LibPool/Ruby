# wordpress-api

**Tag**: web, security, networking

## 简介

Methods for interfacing with the WordPress API. Currently
                   supports all unauthenticated get requests documented at the
                   WordPress API homepage &gt; http://wp-api.org. Requires v2 of
		   the AP
