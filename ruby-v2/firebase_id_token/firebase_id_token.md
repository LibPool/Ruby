# firebase_id_token

**Tag**: web

## 简介

A Ruby gem to verify the signature of Firebase ID Tokens. It uses ActiveSupport::Cache to store Google's x509 certificates and manage their expiration time, so you don't need to request Google's API in every execution and can access it as fast as reading from memory.
