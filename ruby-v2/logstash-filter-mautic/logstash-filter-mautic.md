# logstash-filter-mautic

**Tag**: web, networking, template, data

## 简介

This plugin lets you get the majority of you Mautic data into Elasticsearch for viewing using Kibana. Just setup a http input for logstash and a filter like so mautic { source =&gt; 'message'}. See the GitHub repository for more information
