# media-renamer

**Tag**: filesystem, data

## 简介

Provides a set of functions to scan file systems for media files, and dynamically rename them using their metadata. Files are renamed according to a customizable taxonomy. For example, use MediaOrganizer::Renamer to set filenames for a directory of photos to a standard such as: "&lt;date-taken&gt; - Ski Vacation.jpg". Currently supports only JPEG and TIFF files. Future releases will include support for music and additional image files.
