# logstash-input-packetloop_s3

**Tag**: web, networking, devops

## 简介

A fork of Logstash S3 input that contains a temporary fix with processing Cloudwatch logs from S3 bucket until https://github.com/logstash-plugins/logstash-input-s3/issues/165 PR is merged
