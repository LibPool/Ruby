# io-extra

**Tag**: library

## 简介

Adds the IO.closefrom, IO.fdwalk, IO.pread, IO.pwrite, and IO.writev
    singleton methods as well as the IO#directio, IO#directio? and IO#ttyname
    instance methods (for those platforms that support them).
