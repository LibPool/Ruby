# seven_gallery

**Tag**: web, filesystem

## 简介

"A Rails gallery engine.
    Includes creating multiple galleries and photos. 
    Multi uploading and cropping. 
    Can extend gallery and photo model or controller. 
    Configurable through yml configuration file."
