# citeproc-rb

**Tag**: web, networking

## 简介

Citeproc-rb is a Ruby port of Citeproc, a process for converting citations into a variety of formats using a macro language called Citation Style Language (CSL). For more details on Citeproc and CSL, please check  http://xbiblio.sourceforge.net/.
