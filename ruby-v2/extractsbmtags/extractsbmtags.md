# extractsbmtags

**Tag**: web, networking

## 简介

ExtractSbmTags is RSS::RDF::Item class adds on. This method is return array of tags using social bookmark service.  This method currently supports below services.  -  del.icio.us : http://del.icio.us -  Hatena Bookmark : http://b.hatena.ne.jp -  MM/Memo : http://1470.net/mm/
