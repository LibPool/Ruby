# cocoslicer

**Tag**: library

## 简介

Slicer the packed cocos2d resources(with tool TexturePacker) into the original ones. Don't support zwoptex now.

## 官网

- 主页: http://www.jtianling.com
- 文档: https://www.rubydoc.info/gems/cocoslicer/0.2.0
- RubyGems: https://rubygems.org/gems/cocoslicer
