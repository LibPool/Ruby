# kjappsms

**Tag**: library

## 简介

Screenscraps kjappsms.no to send SMS. To use this, you have to sign up for a account at www.kjappsms.no

## 官网

- 主页: http://github.com/fossmo/kjappsms
- RubyGems: https://rubygems.org/gems/kjappsms
