# connect_gsi_api

**Tag**: web

## 简介

本gemは、一回のリクエストで、一回だけ国土地理院提供のAPIを叩きます。APIの使用回数上限については、国土地理院が提示しているAPI利用規約を参照してください。また、APIの仕様上、日本の緯度・経度にしか対応していません。
