# opengl

**Tag**: web, networking

## 简介

An OpenGL wrapper for Ruby. opengl contains bindings for OpenGL.

Be sure to check out
{GLU}[https://github.com/larskanis/glu] and
{GLUT}[https://github.com/larskanis/glut]
gems.
