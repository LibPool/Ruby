# nant

**Tag**: tooling

## 简介

NAnt is a free .NET build tool. In theory it is kind of like make without make's wrinkles. In practice it's a lot like Ant.

## 官网

- 主页: http://nant.sourceforge.net/
- RubyGems: https://rubygems.org/gems/nant
