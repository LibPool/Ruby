# hamlify

**Tag**: template

## 简介

HTML to HAML conversion tool which wraps around standard html2haml and fixes issues with its output.

## 官网

- 主页: http://github.com/maxim/hamlify
- RubyGems: https://rubygems.org/gems/hamlify

## 历史版本号

- 1.0.0 (2009-10-05)

## 获取地址

- RubyGems: https://rubygems.org/gems/hamlify
- gem 安装: `gem install hamlify`
- Bundler: `gem "hamlify"`
- 最新版本: 1.0.0
- 最新版归档: https://rubygems.org/downloads/hamlify-1.0.0.gem
- 版本锁定: `gem "hamlify", "~> 1.0.0"`
