# redmint_composer

**Tag**: web, template

## 简介

A gem with recipes to create Rails application templates you can use to generate Rails starter apps. FORK of rails_app_composer gem

## 官网

- 主页: https://github.com/adrianescat/redmint_composer
- 文档: https://github.com/RailsApps/rails_apps_composer/wiki/tutorial-rails-apps-composer
- RubyGems: https://rubygems.org/gems/redmint_composer
