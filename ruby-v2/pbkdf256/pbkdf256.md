# pbkdf256

**Tag**: library

## 简介

A very simple, but fast (native) RFC compliant PBKDF2-HMAC-SHA256 ruby gem based on Colin Percival's C implementation.

## 官网

- 主页: https://github.com/johanns/PBKDF256#readme
- RubyGems: https://rubygems.org/gems/pbkdf256
