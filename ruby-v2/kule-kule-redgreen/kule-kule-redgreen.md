# kule-kule-redgreen

**Tag**: cli, testing, filesystem

## 简介

kule-redgreen colourises windows console output for tests.  This version works with ZenTest 4.0.0, autotest, snarl, XP and Vista.  Please see the README file for setup or issues with Snarl.
