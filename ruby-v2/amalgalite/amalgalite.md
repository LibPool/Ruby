# amalgalite

**Tag**: database, data

## 简介

Amalgalite embeds the SQLite database engine as a ruby extension. There is no
need to install SQLite separately.

- 问题追踪: https://github.com/copiousfreetime/amalgalite/issues
- RubyGems: https://rubygems.org/gems/amalgalite
