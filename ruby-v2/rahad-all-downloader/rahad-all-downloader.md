# rahad-all-downloader

**Tag**: web, cli, serialization, networking, data

## 简介

A dependency-free Ruby client to fetch video URLs and metadata from 13 platforms: TikTok, Facebook, Instagram, YouTube, X (Twitter), CapCut, Kwai, Snapchat, Threads, Likee, Pinterest, Dailymotion and Vimeo. Uses only the Ruby standard library (net/http, json, uri, openssl).
