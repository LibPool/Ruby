# svg_hearts_you

**Tag**: filesystem

## 简介

A heartwarming gem to inline SVG. SVG Hearts You provides helper
                          methods to inline SVG. You can directly inline for maximum CSS control,
                          or symbolize a file or folder of SVGs and reuse the symbols.
