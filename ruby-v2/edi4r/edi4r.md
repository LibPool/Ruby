# edi4r

**Tag**: serialization, data

## 简介

edi4r turns Ruby into a powerful EDI mapping language:
    - create or process UN/EDIFACT interchanges intuitively
    - validate messages with information from the original UN/TDIDs
    - integrate classical EDI data and XML documents through
      edi4r's generic EDI/XML translator (add-on gem, DTD provided).
