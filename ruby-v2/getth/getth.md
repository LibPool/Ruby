# getth

**Tag**: library

## 简介

This gem defines ordinal methods *first, second, third ... ninth, tenth &amp; last* for retrieving values from strings. Ruby Core already includes a Array#first and Array#last so only *second, third ... ninth &amp; tenth* have been added to the Array class.
