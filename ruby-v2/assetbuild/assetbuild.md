# assetbuild

**Tag**: tooling, filesystem

## 简介

Easily merge and compress multiple asset files together (currently supports CSS and coffee-script).

## 官网

- 主页: http://github.com/jimjeffers/assetbuild
- RubyGems: https://rubygems.org/gems/assetbuild

## 历史版本号

- 0.1.0 (2010-04-08)

## 获取地址

- RubyGems: https://rubygems.org/gems/assetbuild
- gem 安装: `gem install assetbuild`
- Bundler: `gem "assetbuild"`
- 最新版本: 0.1.0
- 最新版归档: https://rubygems.org/downloads/assetbuild-0.1.0.gem
- 版本锁定: `gem "assetbuild", "~> 0.1.0"`
