# json2sql

**Tag**: database, serialization, tooling

## 简介

Pure-Ruby SQL builder. No runtime dependencies. Supports SELECT (with JSON aggregation and nesting), INSERT, UPDATE, and DELETE for MySQL/MariaDB.
