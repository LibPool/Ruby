# aws_s3_export

**Tag**: devops

## 简介

Simple gem for export a directory to AWS S3. You set directory, bucket and keys and enjoy it.

## 官网

- 源码仓库: https://github.com/devmen/aws_s3_export
- RubyGems: https://rubygems.org/gems/aws_s3_export
