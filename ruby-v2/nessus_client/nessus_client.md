# nessus_client

**Tag**: cli

## 简介

Usable, fast, simple Ruby gem for Tenable Nessus Pro from v7.0.1 to v8.3.1.
    NessusClient was designed to be simple, fast and performant through communication with Nessus
    over REST interface.
