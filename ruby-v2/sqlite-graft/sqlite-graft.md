# sqlite-graft

**Tag**: database

## 简介

A SQLite extension which uses Graft to replicate to and from object storage.

## 官网

- 主页: https://github.com/orbitinghail/graft
- 文档: https://www.rubydoc.info/gems/sqlite-graft/0.2.1
- RubyGems: https://rubygems.org/gems/sqlite-graft
