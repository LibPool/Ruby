# sparqcode-urbanairship

**Tag**: web, networking

## 简介

Urbanairship is a Ruby library for interacting with the Urban Airship (http://urbanairship.com) API.  Includes updates from ScoutMob.

- 主页: http://github.com/SPARQCode/urbanairship
- RubyGems: https://rubygems.org/gems/sparqcode-urbanairship
