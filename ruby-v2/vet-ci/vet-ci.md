# vet-ci

**Tag**: library

## 简介

VetCI is a continuous intergration system. It's a work in progress, so documentation is slim right now. You'll probably want to wait until at least 0.0.5 to actually use it.

## 官网

- 主页: http://github.com/leeadkins/VetCI
