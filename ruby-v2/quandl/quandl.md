# quandl

**Tag**: web, cli

## 简介

A ruby implementation of the quandl client to be used as an ORM for quandl's restful APIs.

- 文档: https://www.rubydoc.info/gems/quandl/1.2.0
- RubyGems: https://rubygems.org/gems/quandl
