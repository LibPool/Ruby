# danabr75-opengl

**Tag**: web, networking

## 简介

PATCHED FOR WINDOWS: An OpenGL wrapper for Ruby. opengl contains bindings for OpenGL.

{GLU}[https://github.com/larskanis/glu] and
{GLUT}[https://github.com/larskanis/glut]
