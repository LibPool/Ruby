# multistockphoto

**Tag**: library

## 简介

Dieses Programm kann eigene Photos an mehrere definierte Photo-Sites (wie 
fotolia.de, zoonar.de, photocase.de, etc.) hochladen um sie dort zum Verkauf
anzubieten.
