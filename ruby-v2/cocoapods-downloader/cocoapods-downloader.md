# cocoapods-downloader

**Tag**: filesystem

## 简介

A small library for downloading files from remotes in a folder.

## 官网

- 主页: https://github.com/CocoaPods/cocoapods-downloader
- 文档: https://www.rubydoc.info/gems/cocoapods-downloader/2.1
- RubyGems: https://rubygems.org/gems/cocoapods-downloader
