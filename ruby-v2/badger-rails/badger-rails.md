# badger-rails

**Tag**: web, database, tooling, devops

## 简介

Badger-Rails makes use of Capistrano and Badger to create a configuration for easy deployment to a remote server.
Badger-Rails deploys to CentOs 6+ automatically building nginx, mysql, and of course ruby.
