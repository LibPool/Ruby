# build_spec_runner

**Tag**: web, testing, networking, tooling, devops, filesystem

## 简介

A gem to execute AWS CodeBuild build_spec.yml files locally.
AWS CodeBuild (https://aws.amazon.com/codebuild/) is an AWS product. This gem is a third-party creation not affiliated with AWS.
