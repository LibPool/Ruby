# vagrant-sshfs

**Tag**: web, networking

## 简介

A Vagrant synced folder plugin that mounts folders via SSHFS. 
    This is the successor to Fabio Kreusch's implementation:
    https://github.com/fabiokr/vagrant-sshfs
