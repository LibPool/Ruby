# stripper

**Tag**: web

## 简介

Stripper is a Ruby on Rails plugin that removes leading and trailing blanks from attribute values in your models.

- 主页: http://github.com/harukizaemon/stripper
- RubyGems: https://rubygems.org/gems/stripper
