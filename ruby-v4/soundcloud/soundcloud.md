# soundcloud

**Tag**: web, security, networking, devops

## 简介

The official SoundCloud API wrapper. It provides simple methods to handle authorization and to execute HTTP calls.

- 主页: https://dev.soundcloud.com
- 文档: https://www.rubydoc.info/gems/soundcloud/0.3.7
- RubyGems: https://rubygems.org/gems/soundcloud
