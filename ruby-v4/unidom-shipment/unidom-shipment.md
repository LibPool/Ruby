# unidom-shipment

**Tag**: library

## 简介

Unidom (UNIfied Domain Object Model) is a series of domain model engines. The Shipment domain model engine includes the Shipment and the Shipment Item. Unidom (统一领域对象模型)是一系列的领域模型引擎。装运领域模型引擎包括装运和装运项的模型。
