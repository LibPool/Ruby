# omq-backend-rust

**Tag**: web, networking

## 简介

Drop-in Rust backend for OMQ. Same socket API (REQ/REP, PUB/SUB, PUSH/PULL, DEALER/ROUTER, and all draft types), backed by the first-class omq-rs Ruby binding. Fully interoperable with the default Ruby engine.
