# moult

**Tag**: web, filesystem

## 简介

Moult sheds dead code. `moult hotspots` ranks files by a complexity x churn score (Prism-parsed ABC complexity per method x per-file git churn); `moult deadcode` lists confidence-graded unused-method and unused-constant candidates over a rubydex definition graph, with Rails entrypoint awareness. Every finding carries a confidence and its reasons, never a claim of certain death.
