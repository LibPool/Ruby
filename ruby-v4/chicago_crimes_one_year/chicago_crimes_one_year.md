# chicago_crimes_one_year

**Tag**: web, networking, data

## 简介

A free API Wrapper for Chicago Crimes from present searching back one year from the Chicago Open Data Portal. See https://data.cityofchicago.org/Public-Safety/Crimes-One-year-prior-to-present/x2n5-8w5q.
