# ip-api-io

**Tag**: web, cli, networking

## 简介

Ruby client for the ip-api.io IP intelligence platform: IP geolocation, email validation (syntax, MX, SMTP deliverability), fraud detection and risk scoring, VPN/proxy/Tor detection, ASN lookup, WHOIS, reverse/forward DNS and domain age. Zero runtime dependencies.
