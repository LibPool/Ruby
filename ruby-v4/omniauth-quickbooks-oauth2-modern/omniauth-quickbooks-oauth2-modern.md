# omniauth-quickbooks-oauth2-modern

**Tag**: security

## 简介

An OmniAuth strategy for authenticating with QuickBooks Online using OAuth 2.0. Compatible with OmniAuth 2.0+ and supports both sandbox and production environments with OpenID Connect userinfo fetching.
