# asciidoctor-confluence-fix

**Tag**: template, filesystem

## 简介

This is an implementation of asciidoctor/asciidoctor-confluence. Asciidoctor-Confluence allows to parse asciidoc files, transform them into HTML and then push them into a Confluence
