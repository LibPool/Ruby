# sentry-agents

**Tag**: library

## 简介

Provides Sentry Gen AI instrumentation for AI/LLM agents,
supporting multiple providers (Anthropic, OpenAI, etc.)
with auto-instrumentation for RubyLLM and LangChain.rb.
