# so-comment-hellban

**Tag**: web, networking

## 简介

This is a calculator for determining how close a user is to being
comment-hellbanned on Stack Overflow. You can find your flag counts at
http://stackoverflow.com/users/flag-summary/<stackoverflow_userid>.
