# neu-mods

**Tag**: web, networking, data

## 简介

Nokogiri-native, dependency-light reading/projection contract over MODS v3 documents, shared by the DRS front end (Cerberus) and API backend (Atlas). Pure functions over a document: selectors that locate nodes (for editing) and projections that return plain data (for indexing/display). No Rails, no persistence, no HTTP.
