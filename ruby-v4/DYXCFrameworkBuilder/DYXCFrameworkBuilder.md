# DYXCFrameworkBuilder

**Tag**: testing, serialization, tooling, devops

## 简介

DYXCFrameworkBuilder is a comprehensive Ruby tool for automatically building iOS private libraries into XCFramework format. It supports YAML configuration, automatic podspec parsing, Alibaba Cloud OSS upload, and private CocoaPods repository publishing.
