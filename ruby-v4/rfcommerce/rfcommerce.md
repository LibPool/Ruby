# rfcommerce

**Tag**: web

## 简介

Rfcommerce is an open source e-commerce framework for Ruby on Rails where you will be able to use this project as an Full-Support API.

## 官网

- 主页: http://railsfactory.org
- RubyGems: https://rubygems.org/gems/rfcommerce

## 历史版本号

- 0.0.3 (2012-03-22)

## 获取地址

- RubyGems: https://rubygems.org/gems/rfcommerce
- gem 安装: `gem install rfcommerce`
- Bundler: `gem "rfcommerce"`
- 最新版本: 0.0.3
- 最新版归档: https://rubygems.org/downloads/rfcommerce-0.0.3.gem
- 版本锁定: `gem "rfcommerce", "~> 0.0.3"`
- 中央仓库: https://rubygems.org/
