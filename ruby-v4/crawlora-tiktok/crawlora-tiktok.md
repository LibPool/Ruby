# crawlora-tiktok

**Tag**: web, cli, filesystem, data

## 简介

Ruby client for Crawlora's hosted TikTok API. Covers video, user, and hashtag search; profiles and posts; comments; trends; Creative Center; and Top Ads data across 53 endpoints.
