# peerpressure

**Tag**: cli, networking

## 简介

List live Claude Code and Codex sessions, send them messages, and hear back, from Ruby or the peer CLI. Idle sessions wake up and act. Honest delivery status (held, denied, expired) instead of a fake 'sent'. Local Unix sockets, same user, no network.
