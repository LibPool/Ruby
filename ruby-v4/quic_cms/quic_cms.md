# quic_cms

**Tag**: filesystem

## 简介

Very Simple Page and Menu CMS
                    be sure to add:
                      mount QuicCms::Engine => "/"
                    to the bottom of your routes file.  Run rake quic_cms:install:migrations and rake db:migrate
