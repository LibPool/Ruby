# em-couchbase

**Tag**: web, cli

## 简介

The official client library built atop of EventMachine for use with Couchbase Server.

## 官网

- 主页: http://couchbase.org
- 源码仓库: https://github.com/couchbase/couchbase-ruby-client-em
- 问题追踪: http://www.couchbase.com/issues/browse/RCBCEM
- RubyGems: https://rubygems.org/gems/em-couchbase
