# qtbindings

**Tag**: library

## 简介

qtbindings provides ruby bindings to QT4.x. It is derived from the kdebindings project.

## 官网

- 主页: http://github.com/ryanmelt/qtbindings
- 文档: https://www.rubydoc.info/gems/qtbindings/4.8.6.5
- RubyGems: https://rubygems.org/gems/qtbindings
