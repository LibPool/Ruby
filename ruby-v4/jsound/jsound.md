# jsound

**Tag**: web

## 简介

A Ruby interface for Java's javax.sound API. Runs on the JVM via JRuby.

## 官网

- 主页: http://github.com/adamjmurray/jsound
- RubyGems: https://rubygems.org/gems/jsound
