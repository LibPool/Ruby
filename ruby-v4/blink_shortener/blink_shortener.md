# blink_shortener

**Tag**: web

## 简介

Blink Shortener is a Ruby API wrapper for bl.ink that shortens any url.

- 主页: https://github.com/PaulChege/blink_shortener
- RubyGems: https://rubygems.org/gems/blink_shortener
