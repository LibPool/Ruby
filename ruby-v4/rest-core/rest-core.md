# rest-core

**Tag**: web, cli, networking, tooling

## 简介

Various [rest-builder](https://github.com/godfat/rest-builder) middleware
for building REST clients.

Checkout [rest-more](https://github.com/godfat/rest-more) for pre-built
clients.
