# psychowl

**Tag**: cli

## 简介

Language and script detection with a Rust engine, precompiled for Linux, macOS and FreeBSD, and an identical pure Ruby engine everywhere else. Mixed-language segments, batch detection, an ActiveModel validator and a CLI.
