# jquery-slick-rails

**Tag**: web

## 简介

Integrates Slick carousel, a jQuery plugin by Ken Wheeler, into your Rails app. THIS GEM IS DEPRECATED.

## 官网

- 主页: https://github.com/bodrovis/jquery-slick-rails
- RubyGems: https://rubygems.org/gems/jquery-slick-rails
