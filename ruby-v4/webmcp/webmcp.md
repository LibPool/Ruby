# webmcp

**Tag**: web, testing

## 简介

Define agent-callable tools once in Ruby and expose them to browsers via the WebMCP standard (document.modelContext): declarative form attributes, imperative registration payloads, and Origin-Trial header middleware. Currently in early development while the W3C spec stabilizes (Chrome origin trial).
