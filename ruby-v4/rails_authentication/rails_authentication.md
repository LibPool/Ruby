# rails_authentication

**Tag**: web, security, data

## 简介

Extends `bin/rails generate authentication` to install Confirmable, Recoverable, Registerable, Rememberable, Trackable, Timeoutable, Validatable, Lockable, and Invitable — all generated into your app as plain, editable code.
