# ace-runtime

**Tag**: web, cli, testing

## 简介

One duck-typed intent API for terminal runtimes: adapter registry with fail-closed resolution, side-effect-free detection, shared name sanitization, typed errors, central send-matrix validation, the ace-runtime send callback CLI, and the shared adapter contract-test suite.
