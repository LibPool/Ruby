# mikyung

**Tag**: cli

## 简介

Mikyung is a restful client built on top of Restfulie that allows real rest clients to be built.

## 官网

- 主页: http://restfulie.caelumobjects.com
- RubyGems: https://rubygems.org/gems/mikyung

- 0.7.0 (2010-04-08)
