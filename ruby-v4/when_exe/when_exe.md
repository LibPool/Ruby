# when_exe

**Tag**: web, serialization, networking, template

## 简介

A multicultural and multilingualized calendar library based on ISO 8601, ISO 19108, RFC 5545(iCalendar) and RFC6350. JSON-LD formats for TemporalPosition and TemporalReferenceSystem are available. This version is a beta version and in the evaluation stage. So, its APIs may be changed in future. Please refer to http://suchowan.at.webry.info/theme/a543700674.html for the recent history (Sorry only in Japanese).
