# phronomy

**Tag**: tooling

## 简介

Phronomy is a Ruby AI agent framework that provides composable building blocks — Agents, Workflows, Tools, Filters, and Tracing — for building AI agents in Ruby. Powered by RubyLLM for LLM abstraction.
