# hydra-file-access

**Tag**: web, filesystem

## 简介

Hydra-File-Access is a plugin Rails Engine containing the code for manipulating files in a Hydra application. The full hydra stack includes: Blacklight, Fedora, Solr, active-fedora, solrizer, and om
