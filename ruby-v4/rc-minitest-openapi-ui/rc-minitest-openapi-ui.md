# rc-minitest-openapi-ui

**Tag**: web, testing, template

## 简介

A mountable Rails engine that renders Swagger UI for an OpenAPI document, intended to pair with rc-minitest-openapi and rc-minitest-openapi-api.

## 官网

- 主页: https://github.com/RailsComposer/minitest-openapi
- RubyGems: https://rubygems.org/gems/rc-minitest-openapi-ui
