# ibm_db

**Tag**: web, data

## 简介

Rails Driver and Adapter for IBM Data Servers: {DB2 on Linux/Unix/Windows, DB2 on zOS, DB2 on i5/OS, Informix (IDS)}

- 主页: https://github.com/ibmdb/ruby-ibmdb

- 问题追踪: https://github.com/ibmdb/ruby-ibmdb/issues
- RubyGems: https://rubygems.org/gems/ibm_db
