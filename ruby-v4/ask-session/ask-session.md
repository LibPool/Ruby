# ask-session

**Tag**: web

## 简介

Provides immutable session records, event envelopes, an in-memory store with concurrency guardrails, a durable provider-backed store for restart-safe sessions, a replayable host with subscriptions, a runtime tool-lifecycle sink, and a state reducer that reconstructs session snapshots from event history.
