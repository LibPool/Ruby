# effective_logging

**Tag**: template

## 简介

Automatically log all sent emails, user logins, and page views. This also will log custom events from Ruby and JavaScript.

## 官网

- 主页: https://github.com/code-and-effect/effective_logging
- 文档: https://www.rubydoc.info/gems/effective_logging/4.5.0
- RubyGems: https://rubygems.org/gems/effective_logging
