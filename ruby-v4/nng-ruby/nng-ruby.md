# nng-ruby

**Tag**: web, networking

## 简介

Complete Ruby bindings for NNG, a lightweight messaging library. Supports all scalability protocols (Pair, Push/Pull, Pub/Sub, Req/Rep, Surveyor/Respondent, Bus) and transports (TCP, IPC, Inproc, WebSocket, TLS). Includes bundled libnng shared library.
