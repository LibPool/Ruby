# reviewer

**Tag**: testing, security, template, tooling, filesystem

## 简介

Run tests, linters, security audits, and formatters with a single command. Reviewer wraps your code quality tools into a consistent interface with git-aware file targeting, auto-detection, and multiple output formats.
