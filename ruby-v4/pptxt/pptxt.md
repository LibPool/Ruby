# pptxt

**Tag**: serialization, filesystem

## 简介

This gem can extract the xml info from a pptx file and convert it to human-readable text. It was intended to be used with git for seeing changes between revisions.

- 主页: https://gitlab.com/mjwhitta/pptxt
