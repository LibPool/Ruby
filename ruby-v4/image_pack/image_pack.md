# image_pack

**Tag**: web, filesystem

## 简介

Single API, vendored pure-C MozJPEG/libjpeg codec, in-memory compression and atomic file output, Ruby 2.7.1+ native JPEG execution; Ruby 3.4+ enables Fiber::Scheduler-aware offload. Ships vendored C sources — no system libjpeg, git, or CMake required.
