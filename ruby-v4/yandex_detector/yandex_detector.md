# yandex_detector

**Tag**: web, networking

## 简介

yandex_detector is a gem, wich uses Yandex.Detector API to detect via request's headers (see http://api.yandex.ru/detector/).

## 官网

- 主页: http://github.com/aishek/yandex_detector
- RubyGems: https://rubygems.org/gems/yandex_detector
