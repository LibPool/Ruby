# rails5_xhr_update

**Tag**: web, testing

## 简介

rails5_xhr_update is a program that can be used to help convert from the
``xhr :get, :action`` test syntax used in rails prior to Rails 5, to the
Rails 5 syntax: ``get :action, xhr: true``.
