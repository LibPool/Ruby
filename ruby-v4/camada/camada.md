# camada

**Tag**: web

## 简介

camada SDK for Ruby: inline enforcement of your snapshot (ordered custom rules, then allow, block, challenge), first-party beacon and proof-of-work challenge, batched event shipping. A Rack middleware for any Rack app (Sinatra, Rails via the Railtie, Hanami, plain Rack).
