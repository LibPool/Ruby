# fluent-plugin-arango-http-api

**Tag**: web, networking, data

## 简介

ArangoHttpApiOutput is a Fluentd output plugin that sends log data to an ArangoDB collection using the ArangoDB HTTP API. It supports creating collections and indexes if they do not exist.
