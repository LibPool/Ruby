# virtconsole

**Tag**: web, cli, testing, networking

## 简介

Provides a means to pass commands via script into the LibVirt console of an instance.
Designed specifically for use with the COMRedirSVC project.
(https://github.com/GearheadRed/COMRedirSVC)
