# random-location

**Tag**: testing, data

## 简介

Generates geographic coordinates randomly chosen near by the location and within the radius specified. It aims to provide a way to generate dummy data for geographical apps. NOTE that all results are approximate values since problems derived from the shape of the earth have not been taken into consideration.
