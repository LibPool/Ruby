# spree_dashboard

**Tag**: web, template

## 简介

Serves a built Spree React Dashboard at /dashboard with SPA semantics — the single-node topology where the dashboard and the Admin API share one origin. Developer Preview; becomes the default admin delivery in Spree 6.
