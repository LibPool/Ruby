# cfiber

**Tag**: library

## 简介

Continuations used to implement Fibers as provided by Ruby 1.9. Works in 1.8 as well.

## 官网

- 主页: http://www.github.com/chikamichi/cfiber
- RubyGems: https://rubygems.org/gems/cfiber
