# vincents_first_studio_game_gem

**Tag**: library

## 简介

This gem is made following the Ruby Course of Pragmatic Studio on online.pragmaticstudio.com.

The game is used to run a game "studio_game" with players and rounds. Each round a player finds a random treasure and randomly gets healed (w00ted) or damaged (blammed).
