# igo-ruby

**Tag**: web, networking, filesystem

## 简介

Ruby port of Igo Japanese morphological analyzer. Igo-ruby needs Igo's binary dictionary files.
    These files created by Java programs.
    See: http://igo.sourceforge.jp/
