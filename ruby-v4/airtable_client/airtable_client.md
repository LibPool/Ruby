# airtable_client

**Tag**: web, cli, networking

## 简介

Ruby client for the Airtable Web API with zero runtime dependencies: persistent Net::HTTP connections, client-side rate limiting, automatic retries with exponential backoff, error classification, batch operations with auto-chunking, and upsert support.
