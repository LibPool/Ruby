# lilac-async

**Tag**: web, cli, networking, tooling, filesystem, data

## 简介

Provides the `Fetchy` HTTP client, `Lilac::Resource` (signal-backed async data source), and selector helpers (`selector` / `select`). Designed for the lilac-compiled wasm variant; lilac-full already links the async gem in. Picked up automatically by `lilac build` via Bundler when the gem appears in the project's Gemfile.
