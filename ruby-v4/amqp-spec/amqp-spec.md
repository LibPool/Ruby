# amqp-spec

**Tag**: web, testing

## 简介

Simple API for writing asynchronous EventMachine and AMQP specs. Runs legacy EM-Spec based examples. Supports RSpec and RSpec2.

- 主页: http://github.com/arvicco/amqp-spec
