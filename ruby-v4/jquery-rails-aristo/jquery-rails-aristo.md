# jquery-rails-aristo

**Tag**: web, networking

## 简介

Integrates the "Aristo" jQuery UI Theme (see https://github.com/taitems/Aristo-jQuery-UI-Theme) for use with the asset pipeline in Rails &gt;= 3.1
