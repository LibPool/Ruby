# free_ruby

**Tag**: web, testing

## 简介

Coming soon: FreeRuby is a complete web framework that provides all the essential features of Rails but with a smaller footprint and minimal attack surface. It's specifically designed for teams who want to gradually move away from Rails while maintaining current applications.
