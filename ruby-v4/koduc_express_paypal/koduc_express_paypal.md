# koduc_express_paypal

**Tag**: library

## 简介

koduc_express_paypal is a simple gem used for Paypal Payment Gateway integration with partial and full refunds. This gem is written by KSolves. The main aim of this project is to deal with the one time Paypal payment using express checkout method using NVP(Name Value Pair). One can also make partial and full refunds.
