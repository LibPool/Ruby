# the_local

**Tag**: library

## 简介

the_local lets any gem or app declare Claude Code subagents ("locals") that know its conventions, and installs the aggregated set from every installed provider into a consuming app's .claude/agents/ — plus a delegation rule so the app's agent actually uses them.
