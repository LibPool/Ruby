# rwdziprwdanimatedgifs

**Tag**: web, template, filesystem

## 简介

rwdziprwdanimatedgifs is a animated gifs viewer using rwdtinker and RubyWebDialogs. Requires rwdtinker &gt;1.51rwdcalc is calculator rwdtinker and RubyWebDialogs
