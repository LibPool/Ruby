# hvor

**Tag**: web, cli, serialization, filesystem, data

## 简介

Hvor is a mountable Rails engine providing an ActiveJob that downloads and imports IP2Location LITE CSV zip archives (IPv4 + IPv6 ranges mapped to country_code) into an IPRange model, a cached Hvor.lookup(ip) API, and a lightweight mounted JSON API for looking up an arbitrary IP or the requesting client's own IP.
