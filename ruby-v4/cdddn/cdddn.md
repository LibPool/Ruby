# cdddn

**Tag**: web, testing, networking, devops

## 简介

Content Delivery &amp; Device Detection Network (CDDDN) is a rails engine that provides mobile detection functionality for use in CDNs, like CloudFront and Akamai. This engine specifically allows you to cache static pages in both desktop and mobile versions for the same domain &amp; url, rather than using an m.example.com approach.
