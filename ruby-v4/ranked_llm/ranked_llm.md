# ranked_llm

**Tag**: web

## 简介

A ranked list of AI API credentials (OpenAI, Anthropic, DeepSeek, Mistral, OpenRouter, ...) tried in order, falling back to the next on any failure, with per-model pricing and per-call spend logging. Extracted from Progentick.
