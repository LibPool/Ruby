# angularjs-on-rails

**Tag**: web

## 简介

AngularJS on Rails wraps the AngularJS 1.2.21 library for use in Rails 3.1 and above. This project is an application skeleton for a typical AngularJS web app. You can use it to quickly bootstrap your angular webapp projects
