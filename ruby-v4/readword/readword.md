# readword

**Tag**: filesystem

## 简介

Reads Word 97-2003 (.doc) and Word 2007+ (.docx) files without LibreOffice, Java or antiword, and prints their text, tables, headers, footers and footnotes as Markdown. Built for feeding Word documents to LLMs and coding agents, and safe on untrusted files.
