# hypertabular-wasm

**Tag**: web, tooling, filesystem

## 简介

The hypertabular gem's Magnus extension, prebuilt for wasm32-wasip1, for a ruby.wasm
interpreter built with `rbwasm build`: put this gem in that Gemfile instead of
hypertabular and the extension is linked into the interpreter, with hypercast-wasm beside
it. Same API and the same Rust core as the hypertabular gem. Not for a host Ruby, where
the hypertabular gem is the one to install.
