# stockpile-redis

**Tag**: web, database, networking

## 简介

stockpile-redis is a connection manager for Redis to be used with
{Stockpile}[https://github.com/halostatue/stockpile].

## 官网

- 主页: https://github.com/halostatue/stockpile-redis/
- 文档: https://www.rubydoc.info/gems/stockpile-redis/2.0
- RubyGems: https://rubygems.org/gems/stockpile-redis

## 历史版本号

- 1.1 (2015-02-10)
- 1.0 (2015-01-21)

## 获取地址
