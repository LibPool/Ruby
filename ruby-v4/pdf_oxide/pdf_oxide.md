# pdf_oxide

**Tag**: testing, template

## 简介

The fastest Ruby PDF library: 0.8ms mean, 5× faster than the industry leaders, 100% pass rate on 3,830 real-world PDFs. Idiomatic Ruby bindings for text extraction, Markdown/HTML conversion, and PDF creation and editing over the pdf_oxide Rust core (the libpdf_oxide cdylib shared by the Python, Java, Node, Go, and C# bindings).
