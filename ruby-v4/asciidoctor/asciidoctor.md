# asciidoctor

**Tag**: template

## 简介

A fast, open source text processor and publishing toolchain for converting AsciiDoc content to HTML 5, DocBook 5, and other formats.

## 官网

- 主页: https://asciidoctor.org
- 源码仓库: https://github.com/asciidoctor/asciidoctor
- 更新日志: https://github.com/asciidoctor/asciidoctor/blob/HEAD/CHANGELOG.adoc
- 问题追踪: https://github.com/asciidoctor/asciidoctor/issues
- RubyGems: https://rubygems.org/gems/asciidoctor
