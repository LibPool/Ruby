# sitemap_notifier

**Tag**: web

## 简介

Ruby on Rails plugin that automatically notifies Google, Bing, and Yahoo of changes to your models, i.e. changes to your sitemap.

## 官网

- 主页: http://github.com/lassebunk/sitemap_notifier
