# jquery-animate-enhanced-rails

**Tag**: web, networking

## 简介

Extend $.animate() to detect CSS transitions for Webkit, Mozilla, IE&gt;=10 and Opera and convert animations automatically.
http://playground.benbarnett.net/jquery-animate-enhanced/.
