# pressto

**Tag**: security

## 简介

Pressto generates print-ready puzzle and activity book interiors — word search, number search, sudoku (classic, killer, jigsaw), kakuro, mazes, cryptograms, fill-ins, math worksheets, and more — as Amazon KDP-ready PDFs. Every puzzle is software-verified: solvable, uniquely solvable where applicable, difficulty-graded, and deduplicated. This 0.0.x line reserves the name while the engines are built.
