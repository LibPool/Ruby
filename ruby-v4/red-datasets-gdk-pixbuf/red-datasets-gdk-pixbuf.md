# red-datasets-gdk-pixbuf

**Tag**: data

## 简介

Red Datasets GDK Pixbuf adds `#to_gdk_pixbuf` method to some datasets in Red Datasets. You can get `GdkPixbuf::Pixbuf` objects from a dataset.
