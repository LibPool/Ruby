# activerecord-precompiled

**Tag**: database, devops, filesystem

## 简介

At deploy time, activerecord-precompiled rewrites simple ActiveRecord query chains in your
application source (e.g. `User.where(name: n).first`) into direct calls on the
SQLite3 raw connection with SQL generated by ActiveRecord itself. The original
expression is kept as a fallback for any case the fast path does not cover.
