# stun-client

**Tag**: web, cli, security

## 简介

Library to act with STUN servers. It implements RFC3489 ("classic" STUN). It   has no authentication methods against STUN servers. It includes functions to   request STUN servers. Furthermore there is the possibility to detect the NAT   type.
