# zeroclick-sellers

**Tag**: web, cli

## 简介

Verify that a request really came from ZeroClick, check that the buyer can
pay before you do the work, return the refusal responses ZeroClick expects,
and report what was used. Ships Rack middleware, so it works in Rails,
Sinatra, Hanami and Roda alike.
