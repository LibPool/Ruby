# widebible

**Tag**: web, cli

## 简介

API client for widebible.com. Access 66 books, 31,102 verses across 4 translations (KJV, ASV, BBE, YLT), biblical people, places, topics, cross-references, glossary, timeline, and reading plans. Zero dependencies.
