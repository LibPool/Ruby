# aka_time

**Tag**: web

## 简介

AkaTime / aka_time / ArieKeren Time adalah Library Ruby Time untuk format Indonesia yang intuitif, independen, bisa digunakan baik dengan Ruby  murni maupun Rails. AkaTime / aka_time / ArieKeren Time is an intuitive Indonesian Time Format,  independent, could be used well with pure Ruby and also Rails.
