# statsample-optimization

**Tag**: data

## 简介

Install gsl, statistics2 and provides a C extension to optimize the following methods

* Vector#frecuencies
* Vector#set_valid_data
* Vector#check_type
* Dataset#case_as_hash
* Dataset#case_as_array
* Bivariate::Tetrachoric
