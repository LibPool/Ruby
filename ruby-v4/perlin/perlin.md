# perlin

**Tag**: web, networking

## 简介

Perlin Noise C extension

A Perlin/Simplex noise implementation based of
&lt;http://freespace.virgin.net/hugo.elias/models/m_perlin.htm&gt;. Implemented as a Ruby C extension.
