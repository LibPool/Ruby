# cpf_cnpj_plus

**Tag**: web

## 简介

Fornece métodos práticos para validar, gerar e formatar números de CPF e CNPJ (incluindo o novo CNPJ alfanumérico), com API para Ruby puro, validador opcional para Rails/ActiveModel e ferramentas de linha de comando.
