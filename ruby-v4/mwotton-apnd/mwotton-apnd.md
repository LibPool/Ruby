# mwotton-apnd

**Tag**: library

## 简介

APND (Apple Push Notification Daemon) is a ruby library to send Apple Push
    Notifications to iPhones.

## 官网

- 主页: http://github.com/itspriddle/apnd
- RubyGems: https://rubygems.org/gems/mwotton-apnd
