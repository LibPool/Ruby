# hoe-roodi

**Tag**: library

## 简介

hoe-roodi is a Hoe plugin to integrate the roodi code smell tool into your hoe
projects.

- 主页: http://github.com/erikh/hoe-roodi
- RubyGems: https://rubygems.org/gems/hoe-roodi
