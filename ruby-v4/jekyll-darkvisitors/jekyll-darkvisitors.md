# jekyll-darkvisitors

**Tag**: web, networking

## 简介

Jekyll plugin to generate a robots.txt to block AI scrapers via the Dark Visitors API (https://darkvisitors.com)

## 官网

- 主页: https://pettazz.com/jekyll-darkvisitors
- 源码仓库: https://github.com/pettazz/jekyll-darkvisitors
