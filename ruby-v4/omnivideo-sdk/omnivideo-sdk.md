# omnivideo-sdk

**Tag**: web, cli, networking

## 简介

Tiny Ruby client for the Omni Video API. Supports seedance-2 (video) and gpt-image-2 / nano-banana-2 (image) under the Gemini Omni Video family. Sign in and create a key at https://omnivideo.net/.
