# bundlebun

**Tag**: web, tooling, devops

## 简介

bundlebun bundles Bun, a fast JavaScript runtime, package manager, and builder, with your Ruby and Rails applications. No need to use Docker, devcontainers, `curl | sh`, or `brew`.
