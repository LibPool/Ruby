# ruby-oci8

**Tag**: web, cli

## 简介

ruby-oci8 is a ruby interface for Oracle using OCI8 API. It is available with Oracle 10g or later including Oracle Instant Client.

## 官网

- 主页: http://www.rubydoc.info/github/kubo/ruby-oci8
- 文档: https://www.rubydoc.info/gems/ruby-oci8/2.2.14
- RubyGems: https://rubygems.org/gems/ruby-oci8
