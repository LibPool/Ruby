# convert_sdk

**Tag**: web, testing

## 简介

The official Convert Experiences Ruby SDK. Provides bucketing-compatible A/B testing, feature flag evaluation, and personalizations for server-side Ruby applications (Rails, Sinatra, Hanami, and plain scripts). Zero runtime dependencies.
