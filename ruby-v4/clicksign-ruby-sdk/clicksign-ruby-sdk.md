# clicksign-ruby-sdk

**Tag**: web, cli, serialization

## 简介

Unofficial Ruby SDK for the Clicksign e-signature API (v3). Supports envelope management, signing workflows and webhooks. JSON:API compliant, no runtime dependencies beyond the Ruby stdlib.
