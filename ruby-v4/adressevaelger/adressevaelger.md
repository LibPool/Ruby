# adressevaelger

**Tag**: web, cli, networking

## 简介

HTTP client for the Danish Adressevælger autocomplete/search and Adressevask
address-wash APIs (Danmarks Adresseregister / DAR), with an optional
ETRS89/UTM32N → WGS84 helper via PROJ.
