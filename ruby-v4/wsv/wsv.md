# wsv

**Tag**: web, cli, networking, template, filesystem

## 简介

wsv is a Ruby CLI that previews a directory over HTTP/HTTPS. Stdlib-only, no runtime dependencies. Defensive by design: blocks dotfiles, binds to loopback, ships with TLS and CORS.
