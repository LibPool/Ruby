# philiprehberger-ip_addr

**Tag**: testing

## 简介

Parse and classify IPv4/IPv6 addresses with private, loopback, and multicast detection. Supports CIDR range operations including size calculation, membership testing, and enumeration. Built on Ruby stdlib ipaddr.
