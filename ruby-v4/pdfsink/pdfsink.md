# pdfsink

**Tag**: web, cli

## 简介

A Ruby gem that wraps the pdfsink-rs CLI, a fast pure-Rust PDF extraction
tool, providing text, word, object, table, link, and regex-search
extraction from PDFs for use in Rails applications.
