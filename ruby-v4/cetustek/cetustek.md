# cetustek

**Tag**: web, testing

## 简介

Cetustek is a Ruby wrapper for the 鯨躍 Cetustek e-invoice API (虛擬多通路, spec AVM-26-03): issuing and cancelling 電子發票 and 折讓單, the read-only queries, and 手機條碼 validation, over SOAP Web Services.
