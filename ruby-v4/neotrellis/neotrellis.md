# neotrellis

**Tag**: library

## 简介

Neotrellis is a ruby driver for Adafruit's NeoTrellis keypad.

## 官网

- 主页: https://github.com/nagius/neotrellis
- RubyGems: https://rubygems.org/gems/neotrellis
