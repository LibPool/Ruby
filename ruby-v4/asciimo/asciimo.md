# asciimo

**Tag**: library

## 简介

uses asciimo.js to generate colored ascii art text in 300+ fonts. It can be used from the commandline or inside Ruby code.

## 官网

- 主页: http://github.com/cowboyd/asciimo.rb
- RubyGems: https://rubygems.org/gems/asciimo
