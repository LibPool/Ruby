# ruby-libsamplerate

**Tag**: library

## 简介

Ruby binding for libsamplerate (aka "Secret Rabbit Code"). libsamplerate is an audio sample rate converter -- it adjusts the sample rate of raw audio.

- RubyGems: https://rubygems.org/gems/ruby-libsamplerate
