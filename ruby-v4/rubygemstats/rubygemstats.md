# rubygemstats

**Tag**: web, networking

## 简介

Scrape gem information from http://rubygems.org.

## 官网

- 主页: http://github.com/brg8/rubygemstats
- 文档: https://www.rubydoc.info/gems/rubygemstats/1.0.0
- RubyGems: https://rubygems.org/gems/rubygemstats

## 历史版本号

- RubyGems: https://rubygems.org/gems/rubygemstats
- gem 安装: `gem install rubygemstats`
- Bundler: `gem "rubygemstats"`
- 最新版本: 1.0.0
- 最新版归档: https://rubygems.org/downloads/rubygemstats-1.0.0.gem
- 版本锁定: `gem "rubygemstats", "~> 1.0.0"`
