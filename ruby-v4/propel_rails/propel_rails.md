# propel_rails

**Tag**: web, security

## 简介

Propel Rails is a modular framework built as a collection of independent gems
that work together seamlessly. It provides authentication, API generation with automatic
URL query string filtering and scoping, access control, AI integration, and more - all 
designed to work individually or as a cohesive framework with zero-configuration filtering.
