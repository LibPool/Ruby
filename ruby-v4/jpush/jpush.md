# jpush

**Tag**: web, cli, networking, template

## 简介

JPush's officially supported Ruby client library for accessing JPush APIs. 极光推送官方支持的 Ruby 版本服务器端 SDK. 相应的 API 文档：http://docs.jpush.io/server/server_overview/

## 官网

- 主页: https://github.com/jpush/jpush-api-ruby-client
- 文档: https://www.rubydoc.info/gems/jpush/4.0.11
- RubyGems: https://rubygems.org/gems/jpush
