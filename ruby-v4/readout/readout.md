# readout

**Tag**: library

## 简介

Readout defines a Stat — a self-describing metric (key, title, plain-English definition, unit, timeframe, declared inputs) with a normalized result shape (value, shape, as_of, exact) and a Source adapter port. It depends on nothing concrete: any source (e.g. tally rollups) plugs in behind a Stat, so the display layer never couples to where a number comes from.
