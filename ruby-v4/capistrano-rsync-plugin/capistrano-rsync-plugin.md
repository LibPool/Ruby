# capistrano-rsync-plugin

**Tag**: web, tooling, devops

## 简介

Plugin for Capistrano 3.7+ to deploy with rsync, based on a Gist by Stefan Daschek.

  Ideally suited to deploying static sites made with static-site-generators.
