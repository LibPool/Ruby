# trmnlp-test

**Tag**: web, testing, networking, devops

## 简介

Runs Playwright tests against TRMNL plugins in the trmnlp format: webhook, polling, static and serverless transforms (Python, Ruby, Node, PHP) with mocked HTTP and a frozen clock, on every TRMNL device model and framework version. The launcher runs the ghcr.io/excusemi/trmnlp-test Docker image.
