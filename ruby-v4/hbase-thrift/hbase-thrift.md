# hbase-thrift

**Tag**: library

## 简介

The barebones Thrift interface for HBase allowing anyone to create higher level HBase libraries.

## 官网

- 主页: http://github.com/AndrewO/hbase-thrift
- RubyGems: https://rubygems.org/gems/hbase-thrift
