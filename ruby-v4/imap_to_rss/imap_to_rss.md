# imap_to_rss

**Tag**: web

## 简介

IMAPToRSS turns messages on an IMAP server into RSS entries when the match a
handler.  Included handlers work for email from Amazon, HSBC and UPS.
IMAPToRSS automatically loads handlers for any other mail.
