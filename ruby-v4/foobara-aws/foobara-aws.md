# foobara-aws

**Tag**: security, devops

## 简介

Reads a Foobara manifest into a deployment plan — one unit per domain, its route, and which of its commands are callable without authentication — and synthesises the matching AWS CDK resources. The manifest is the single source of truth, so infrastructure never restates what the application already declares.
