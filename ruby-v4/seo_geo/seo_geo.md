# seo_geo

**Tag**: web, serialization, filesystem

## 简介

A Rails engine that replaces per-app SEO/GEO code with one configuration file and one layout line: meta tags, canonical folding, JSON-LD, crawler fallback bodies, purpose-based AI crawler policy, robots.txt, sitemap.xml, llms.txt, Markdown negotiation, IndexNow and OG images. GEO means Generative Engine Optimization, not geolocation.
