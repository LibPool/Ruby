# findxpand

**Tag**: web, template, devops

## 简介

One deploy. After that, approved fixes arrive as a manifest pushed to your own origin and no further release is needed. The corrected HTML is produced on the server, so crawlers that do not run JavaScript still see it. Zero runtime dependencies; it never makes an outbound request.
