# cadical

**Tag**: library

## 简介

A Ruby binding for CaDiCaL, a state-of-the-art incremental SAT solver.
The CaDiCaL C++ sources are vendored and compiled into the extension,
so there is no external dependency. Supports incremental solving, assumptions,
temporary constraints, fixed-literal queries and phase hints.
