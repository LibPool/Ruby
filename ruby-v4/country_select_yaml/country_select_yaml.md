# country_select_yaml

**Tag**: serialization, template, filesystem

## 简介

Provides a simple helper to get an HTML select list of countries by a YAML file.  The list of countries comes from the ISO 3166 standard.  While it is a relatively neutral source of country names, it will still offend some users.
