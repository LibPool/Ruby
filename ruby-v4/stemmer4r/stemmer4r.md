# stemmer4r

**Tag**: library

## 简介

Stemmer4r is a Ruby extension that wraps the snowball stemmer library (libstemmer).

## 官网

- 主页: http://stemmer4r.rubyforge.org
- RubyGems: https://rubygems.org/gems/stemmer4r
