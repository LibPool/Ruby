# cc-me

**Tag**: cli, tooling

## 简介

Ruby client for cc.me. Builds trampoline and inbox URLs and decrypts
deliveries; the cc-me CLI forwards inbox deliveries to a local endpoint.
Mirrors the canonical JavaScript client.
