# minitest-mock

**Tag**: testing

## 简介

minitest/mock, by Steven Baker, is a beautifully tiny mock (and stub)
object framework.

The minitest-mock gem is an extraction of minitest/mock.rb from
minitest in order to make it easier to maintain independent of
minitest.
