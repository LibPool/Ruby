# arfl-redgreen

**Tag**: web, cli, testing, networking, filesystem

## 简介

This gem is a fork from kule-redgreen. Go and check it out, then needed at http://github.com/kule/redgreen. arfl-redgreen colourises windows console output for tests. This version works with ZenTest 4.0.0, autotest, snarl, XP and Vista. Please see the README file for setup or issues with Snarl.
