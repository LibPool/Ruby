# ipregistry

**Tag**: web, data

## 简介

Look up IP addresses (single, batch, or the requester's own) and parse User-Agent strings with the Ipregistry API. Returns carrier, company, connection, currency, location, time zone, and threat data. Zero runtime dependencies, optional in-memory caching, and automatic retries with exponential backoff.
