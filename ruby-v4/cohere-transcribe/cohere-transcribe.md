# cohere-transcribe

**Tag**: web, cli, template

## 简介

A Ruby 4 API and CLI for Dense Cohere ASR checkpoints, with native audio decoding, Silero or energy VAD, MMS CTC word alignment, subtitle rendering, and a source-built C/C++ inference backend.
