# rollup_engine

**Tag**: library

## 简介

Turn facts into numbers. RollupEngine declares measures, rolls them up by time grain and dimension, and recomputes idempotently. Source-agnostic — feed it any facts (dimensions + measures); it does not depend on any particular event source.
