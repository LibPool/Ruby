# pg_multitenant_schemas

**Tag**: web, database, testing, template, data

## 简介

A production-ready Ruby gem providing PostgreSQL schema-based multitenancy with automatic tenant resolution, secure isolation, and high performance. Built for Rails 8+ and Ruby 4.0+, tested with latest stable versions. Features comprehensive test coverage (217 tests, 100% passing), complete YARD documentation, and interactive HTML documentation site. Perfect for modern SaaS applications with database-level isolation.
