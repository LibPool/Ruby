# kcfu

**Tag**: cli, filesystem

## 简介

KCFU (Kindle Clipping File Util) simply helps to parse the `My Clippings.txt` file into separated txt file with `Book Title 1.txt`, `Book Title 2.txt` based on the clippings's book title information.
