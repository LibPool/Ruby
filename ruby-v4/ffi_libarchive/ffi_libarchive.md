# ffi_libarchive

**Tag**: web, testing, networking, filesystem

## 简介

This library provides Ruby FFI bindings to the well-known [libarchive library](https://www.libarchive.org/).


*NOTE* This gem is refactored / optimized version of [ffi-libarchive](https://rubygems.org/gems/ffi-libarchive) with more tests to cover almost use-cases.
