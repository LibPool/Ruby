# protocol-mcp

**Tag**: web, cli, testing

## 简介

Multi-schema client and server Model Context Protocol (MCP) implementation. Implements the full MCP spec through transpilation of the MCP TypeScript definitions, making it easy to implement your server or client in Ruby.
