# phlex-cmdk

**Tag**: library

## 简介

Phlex components and a dependency-free JS runtime providing feature parity with the cmdk React command menu, plus scoped search, footer hints and ready-made themes. Agnostic about styling (CSS, SCSS or Tailwind) and JS wiring (plain listeners or Stimulus); progressively enhances with Turbo when present.
