# red_socket

**Tag**: web, cli, networking

## 简介

red-socket.com is a service providing push notifications to clients listening to websockets. Gem is a wrapper for the service to allow pushing messages.

## 官网

- 主页: http://red-socket.com
- RubyGems: https://rubygems.org/gems/red_socket
