# bug_reports_client

**Tag**: web, cli, filesystem

## 简介

Adds a fully-featured, customisable bug and feature reporting flow to any Rails app: a schema-driven form, screenshot uploads, a my-reports list, and signed closure webhooks from the companion bug-reports API which files GitHub issues.
