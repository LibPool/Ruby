# mobiscroll-connect

**Tag**: web, cli, security

## 简介

Ruby client for Mobiscroll Connect, the calendar connectivity layer for scheduling products. Google Calendar, Microsoft Outlook, Apple Calendar and CalDAV through one API, with OAuth 2.0 and webhooks. Backend only — works with your own UI.
