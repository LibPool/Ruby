# event_engine

**Tag**: tooling

## 简介

The runtime of the EventEngine pipeline: load the committed schema catalog aggregated from domain packs, build validated events, and dispatch them to registered handlers by process_type. Events are declared with event_engine-event_definition; durable delivery, transports, and the dashboard live in event_engine-delivery.
