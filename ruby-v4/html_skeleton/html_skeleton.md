# html_skeleton

**Tag**: template

## 简介

A simple helper for creating HTML calendars and tables.

    An example in a view: <%= HtmlSkeleton.new.calendar %>

    The calendar/table may be embelished by user supplied lambda's,
    e.g. for inserting link_to.
