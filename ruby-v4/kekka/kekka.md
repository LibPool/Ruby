# kekka

**Tag**: web, serialization, networking, tooling

## 简介

Kekka is a parser of the XML format XRR
    (XML Regatta Reporting: http://www.sailing.org/xml .) It accepts
    XML on this format and sorts it in boat, event and result hashes.
