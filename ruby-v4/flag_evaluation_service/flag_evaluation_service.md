# flag_evaluation_service

**Tag**: library

## 简介

Gema para acceder al servicio de evaluacion de flag mediante
   flag token y user id.

   Como incluir la gema?

    require "flag_evaluation_service"

   Como usar la gema?

    FlagEvaluationService.evaluate("0CD0ugXMh_ChjIrShodLiQ",1)
