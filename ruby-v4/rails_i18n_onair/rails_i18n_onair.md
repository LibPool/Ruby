# rails_i18n_onair

**Tag**: web, cli, database, serialization, filesystem

## 简介

Browse, edit and sync Rails I18n translations from a mounted web dashboard — or edit them in place by clicking the text on your own pages. Self-hosted, with YAML file or PostgreSQL JSONB storage.
