# voicetel

**Tag**: web, cli

## 简介

Idiomatic Ruby client for the VoiceTel REST API: provision numbers, place orders, validate e911, send SMS/MMS, manage 10DLC campaigns, and run support tickets, all with typed DTOs, structured errors, and automatic retry on 429/5xx.
