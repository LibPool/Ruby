# standard_id-provider

**Tag**: testing

## 简介

DEPRECATED — this gem is renamed to standard_id-oidc; 0.5.0 is the final release under this name. Extends StandardId with full OIDC Identity Provider capabilities: ID tokens, consent management, token introspection, token revocation, and discovery.
