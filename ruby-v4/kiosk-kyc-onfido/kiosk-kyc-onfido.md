# kiosk-kyc-onfido

**Tag**: web, networking

## 简介

This gem reserves the name for a planned Kiosk (https://kiosk.tech) integration, so that nobody can publish a harmful gem under it. It holds no code. The Kiosk gems are at https://github.com/kiosk-hq/kiosk.
