# activegraph

**Tag**: library

## 简介

A Neo4j OGM (Object-Graph-Mapper) for Ruby heavily inspired by ActiveRecord.

## 官网

- 主页: http://neo4jrb.io/
- 源码仓库: https://github.com/neo4jrb/activegraph/
- 更新日志: https://github.com/neo4jrb/activegraph/blob/master/CHANGELOG.md
- 问题追踪: https://github.com/neo4jrb/activegraph/issues
