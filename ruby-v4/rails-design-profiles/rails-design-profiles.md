# rails-design-profiles

**Tag**: web, serialization, template, filesystem

## 简介

Rails Design Profiles keeps public DESIGN.md references separate from executable design tokens. Install an openly licensed reference, review it with your team or AI tools, and define a versioned YAML token profile. The Rails helper emits the active profile as --rdp-* CSS custom properties, and Rails tasks switch the application-wide profile without copying third-party CSS, assets, or branding.
