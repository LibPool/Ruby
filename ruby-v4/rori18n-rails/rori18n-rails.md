# rori18n-rails

**Tag**: web, cli, devops

## 简介

rori18n is a Rails i18n CLI that replaces i18n-tasks write commands and adds capabilities it lacks: automatic hardcoded-string extraction from ERB, t() call injection, ERB fragment merging, Google Cloud Translation, deduplication, and key refactoring.
