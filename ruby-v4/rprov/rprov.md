# rprov

**Tag**: cli, database

## 简介

Rprov is a simple command line utility which helps
                    you provision and manage Redis instances easily.

## 官网

- 主页: http://github.com/cyx/rprov
- RubyGems: https://rubygems.org/gems/rprov
