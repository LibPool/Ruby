# terret-morph

**Tag**: web, networking, devops

## 简介

ctx[:summarizer] backed by Morph's Compact API: extractive line-level compression (surviving lines byte-identical), wire mirrored from the deployed agora integration. Zero runtime dependencies beyond stdlib net/http.
