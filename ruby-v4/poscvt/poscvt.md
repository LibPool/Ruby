# poscvt

**Tag**: library

## 简介

Position Converter is a ruby gem to gonvert positions (latitude/longitude) between different units. This gem does not have any user interfaces, but there are several  available, at least one for each of the major platforms; *nix, MacOS and MSW. It's best used as a desktop widget when woring with map programs.
