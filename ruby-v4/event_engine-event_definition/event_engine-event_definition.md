# event_engine-event_definition

**Tag**: web

## 简介

The plain-Ruby foundation of the EventEngine pipeline: the EventDefinition DSL and the shared schema-contract value objects, with no Rails dependency. Lightweight domain-pack gems depend on this contract instead of the full dispatch, registry, and Rails-engine machinery that lives in event_engine.
