# mpp_reader

**Tag**: filesystem

## 简介

Reads MS Project .mpp files (MPP14 format, Project 2010-2021) into structured Ruby objects: tasks, resources, assignments and calendars. Binary format ported from MPXJ. No native extensions, no runtime dependencies.
