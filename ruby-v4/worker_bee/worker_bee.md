# worker_bee

**Tag**: web

## 简介

WorkerBee encapsulates a simple pipeline of workers.

== Features/Problems:

* Simple API to wrap up the usual Thread/Queue patterns.
* Expressive shortcuts to make the pipeline really easy to read.
