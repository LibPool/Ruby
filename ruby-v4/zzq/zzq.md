# zzq

**Tag**: cli

## 简介

Pure Ruby implementation of MQTT — client and broker in one gem — built on async, io-stream, and protocol-mqtt. Fiber-first, pluggable transports (tcp, tls, ws, ipc), pluggable persistence (in-memory, PStore).
