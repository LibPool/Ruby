# solargraph-dr_talon

**Tag**: library

## 简介

Teaches Solargraph the metaprogramming in the Talon game framework for DragonRuby: Talon::Concern mixins (class_methods, included), the prop and state DSLs, and on_* lifecycle hook blocks, so LSP editors get autocomplete, hover and go-to-definition in Talon games.
