# padded_cell

**Tag**: web, testing

## 简介

Runs existing Minitest and Rails test suites with fork-per-test isolation, crash and timeout containment, seeded timing-aware scheduling and sharding. Discovery and scheduling are a Rust extension, precompiled for Linux, macOS and FreeBSD.
