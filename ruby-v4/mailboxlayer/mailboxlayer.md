# mailboxlayer

**Tag**: web, networking

## 简介

Ruby wrapper for mailboxlayer by apilayer. This gem depends on the apilayer gem, which provides a common connection-interface to various services of apilayer.net (such as currencylayer and mailboxlayer). See https://mailboxlayer.com/ and https://apilayer.com/ for more details.
