# rubygems-source-cli

**Tag**: cli

## 简介

Patches for gem serve, gem push, gem yank, and some utilities to allow use of non-Rubygems.org gem sources

## 官网

- 主页: https://github.com/kapoq/rubygems-source-cli
- RubyGems: https://rubygems.org/gems/rubygems-source-cli
