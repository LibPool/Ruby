# sendgo-rails

**Tag**: web

## 简介

Sendgo Ruby SDK를 Rails에 통합하는 공식 확장 젬입니다. Railtie 자동 등록, 설정 초기화 제너레이터, ENV 폴백 클라이언트를 제공합니다.
