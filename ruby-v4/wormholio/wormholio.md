# wormholio

**Tag**: networking, filesystem

## 简介

(Under development) Wormholio provides simple Upload/Download functionality for all file transfer methods. Currently supported transfer methods: FTP, FTPS, SFTP, SCP and S3. For documentation, visit the Git repo's README.md
