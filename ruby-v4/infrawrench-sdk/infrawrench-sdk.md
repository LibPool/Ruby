# infrawrench-sdk

**Tag**: web, cli, testing

## 简介

Generated Ruby client for the Infrawrench API (v1.39.0). Covers the published API surface only — operations marked x-internal in the spec are not generated. No runtime dependencies.

## 官网

- 主页: https://infrawrench.com/docs/team-and-billing/client-sdks
- 源码仓库: https://github.com/Infrawrench/Infrawrench
- 问题追踪: https://github.com/Infrawrench/Infrawrench/issues
- RubyGems: https://rubygems.org/gems/infrawrench-sdk
