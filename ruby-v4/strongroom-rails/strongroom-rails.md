# strongroom-rails

**Tag**: web, cli, database, security, networking

## 简介

Rails adapter for strongroomd, a Postgres-first authentication kernel that acts as the application's security coprocessor: Rails never sees password hashes or session secrets. Ships a strict HTTP client, encrypted-cookie login, rotation and logout helpers for ActionController::Base and ActionController::API, a request-level resolver and an optional Warden strategy. The daemon ships separately, as the strongroomd gem or crate; this gem only speaks to it over HTTP.
