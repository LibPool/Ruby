# terret-openrouter

**Tag**: library

## 简介

The one v1 model adapter for Terret: OpenRouter is OpenAI-compatible, so a single streaming implementation reaches the whole model space behind the provider-neutral ctx.llm seam. SSE streaming with tool calling, usage accounting, and retry with jittered backoff.
