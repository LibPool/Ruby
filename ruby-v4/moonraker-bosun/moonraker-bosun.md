# moonraker-bosun

**Tag**: web, database, filesystem, data

## 简介

bosun fetches configuration files and Moonraker database contents from a Klipper host through the Moonraker API, records them in a dedicated git branch, and pushes local changes back to the host after checking that nothing has changed there.
