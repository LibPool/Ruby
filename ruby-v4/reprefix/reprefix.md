# reprefix

**Tag**: library

## 简介

修改文件前缀，可以把当前文件夹和子文件夹下的的文件内容前缀和文件名前缀做替换  Usage:  $reprefix old_prefix new_prefix  old_prefix：需要修改的前缀例如BBA  new_prefix：新的前缀例如BZD  example：reprefix BBA BZ
