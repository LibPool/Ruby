# cocoapods-yaml

**Tag**: serialization

## 简介

1、iOS端按target以yaml文件管理依赖(本地/二方/三方统一)
                      2、pod yaml relation子命令查询依赖库正向/反向依赖关系
                      3、检查import写法错误问题
                      4、检查未被使用的依赖库和间接依赖的依赖库
                      5、TRIM_UNUSED_POD/pod install/update --trim 自动移除未使用依赖以加速编译
                      6、其他功能开发中...
