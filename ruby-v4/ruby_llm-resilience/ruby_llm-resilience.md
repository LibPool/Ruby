# ruby_llm-resilience

**Tag**: testing

## 简介

RubyLLM gives you every provider. This gives you what happens when one of them goes down: tier-aware circuit breakers, cross-provider fallback chains, and fail-open store semantics — battle-tested behind 450k+ production LLM calls.
