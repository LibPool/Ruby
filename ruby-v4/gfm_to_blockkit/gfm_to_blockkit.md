# gfm_to_blockkit

**Tag**: web, serialization

## 简介

AST-based converter from GitHub-Flavored Markdown (GFM) to Slack Block Kit block arrays, using commonmarker for parsing. Produces structured Block Kit JSON ready for the Slack API.
