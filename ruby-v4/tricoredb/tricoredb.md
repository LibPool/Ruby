# tricoredb

**Tag**: web, cli, database

## 简介

A dependency-free Ruby client for TriCoreDB: SQL with server-side parameters, session transactions, document, vector, graph, cache, LLM context and admin operations over the native framed protocol, with TLS, timeouts, cancellation and a thread-safe pool.
