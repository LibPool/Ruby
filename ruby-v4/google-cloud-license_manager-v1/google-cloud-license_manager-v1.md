# google-cloud-license_manager-v1

**Tag**: web, cli, testing, devops

## 简介

License Manager is a tool to manage and track third-party licenses on Google Cloud. Note that google-cloud-license_manager-v1 is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-license_manager instead. See the readme for more details.
