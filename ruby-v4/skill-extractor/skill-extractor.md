# skill-extractor

**Tag**: library

## 简介

Gazetteer candidates filtered by a MiniLM + MLP context classifier trained on 491K labeled samples, so prose like 'can-do attitude' doesn't become a skill. Runs on ONNX Runtime via the informers gem.
