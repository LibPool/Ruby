# ruby_llm-mongoid

**Tag**: library

## 简介

Drop-in Mongoid replacement for ruby_llm's ActiveRecord integration. Provides acts_as_chat, acts_as_message, acts_as_tool_call, and acts_as_model macros backed by MongoDB via Mongoid.
