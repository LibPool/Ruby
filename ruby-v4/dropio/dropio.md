# dropio

**Tag**: web, cli, networking

## 简介

A Ruby client library for the Drop.io API (http://api.drop.io). Please email jake@dropio.com with any questions.

## 官网

- 主页: http://github.com/dropio/dropio
- 文档: http://dev.drop.io/api-libraries/ruby-api-client-library/
- RubyGems: https://rubygems.org/gems/dropio
