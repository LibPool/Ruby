# ruby-libvirt

**Tag**: web

## 简介

ruby-libvirt allows applications written in Ruby to use the
libvirt API.

## 官网

- 主页: https://ruby.libvirt.org/
- 源码仓库: https://gitlab.com/libvirt/libvirt-ruby
- 文档: https://ruby.libvirt.org/api/index.html
- 问题追踪: https://gitlab.com/libvirt/libvirt-ruby/-/issues
