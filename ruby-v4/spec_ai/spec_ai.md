# spec_ai

**Tag**: web, testing, tooling, devops

## 简介

Spec AI analyzes a Rails application, builds grounded context (models, schema,
factories, existing specs), asks an RCrewAI crew for a structured test plan,
writes RSpec, runs it, and repairs failures. Provider-agnostic via RCrewAI
(OpenAI, Anthropic, Gemini, Azure, Ollama).
