# dotruby

**Tag**: library

## 简介

DotRuby is a universal runtime configuration system for Ruby tools.

## 官网

- 主页: http://rubyworks.github.com/dotruby
- RubyGems: https://rubygems.org/gems/dotruby

## 历史版本号

- 0.1.0 (2013-01-23)

## 获取地址

- RubyGems: https://rubygems.org/gems/dotruby
- gem 安装: `gem install dotruby`
- Bundler: `gem "dotruby"`
- 最新版本: 0.1.0
- 最新版归档: https://rubygems.org/downloads/dotruby-0.1.0.gem
