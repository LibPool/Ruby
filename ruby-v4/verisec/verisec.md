# verisec

**Tag**: web, security, filesystem

## 简介

Every VeriSec API as a method: faces, liveness, documents, MRZ, contact and risk screening, cheques, cards, banks and BIN lookups. Images from files, safe retries that never run a charged call twice, live-key OAuth, and Standard Webhooks verification. Standard library only.
