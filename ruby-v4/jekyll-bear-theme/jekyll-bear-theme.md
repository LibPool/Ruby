# jekyll-bear-theme

**Tag**: web

## 简介

jekyllBear is a clean, minimal Jekyll theme focused on readability and simplicity. Features a Pine Forest color palette with cool, nature-inspired greens, IBM Plex Mono typography, responsive design, tag system, life tracking visualization, and a distraction-free reading experience inspired by Bear Blog.
