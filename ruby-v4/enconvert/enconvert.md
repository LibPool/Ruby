# enconvert

**Tag**: web, serialization, template, filesystem, data

## 简介

Enconvert reads any web page or file into agent-ready Markdown, JSON, or screenshots -- every read scored 0.0-1.0 for render quality, so blocked or empty-shell pages never pass as real content. V2 API: perceive, discover, lookup, distill, ingest (URLs or files), and watch. Also converts 40+ file and document formats -- URL-to-PDF/screenshot/markdown, whole-site batch conversion, image conversion (jpeg/png/svg/heic/webp), and document conversion (docx/pptx/xlsx/odt/html/markdown/csv/json/xml/yaml/toml).
