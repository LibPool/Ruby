# protocol-mqtt

**Tag**: library

## 简介

Pure Ruby implementation of the MQTT 3.1.1 and 5.0 packet codec: encode, decode, VBI, properties, reason codes. Protocol::MQTT::Connection wraps an IO::Stream to read and write packets. No I/O beyond IO::Stream.
