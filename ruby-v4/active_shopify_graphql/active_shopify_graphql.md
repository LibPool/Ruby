# active_shopify_graphql

**Tag**: web, networking, tooling

## 简介

ActiveShopifyGraphQL provides an ActiveRecord-like interface for interacting with Shopify's GraphQL APIs, supporting both Admin API and Customer Account API with automatic query building and response mapping.
