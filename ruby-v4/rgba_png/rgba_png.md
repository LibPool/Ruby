# rgba_png

**Tag**: cli, filesystem

## 简介

Command line tool that creates PNG image files from rgba definitions in stylesheets.

## 官网

- 主页: https://github.com/nelsonr/rgba-to-png
- 文档: https://www.rubydoc.info/gems/rgba_png/1.0
- RubyGems: https://rubygems.org/gems/rgba_png

- 1.0 (2013-09-23)
