# stateless-mcp

**Tag**: web, serialization

## 简介

Serves the 2026-07-28 Model Context Protocol without sessions: every request is answered on its own, so any instance behind a load balancer can take any call. Rack middleware, JSON-RPC errors, cursors and tool schemas, with Rails support in stateless-mcp-rails.
