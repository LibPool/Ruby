# gphoto4ruby

**Tag**: library

## 简介

GPhoto4Ruby is used to control PPTP cameras (the ones that can be controlled with gphoto2) using power of ruby.

## 官网

- 主页: http://github.com/lonelyelk/gphoto4ruby
- RubyGems: https://rubygems.org/gems/gphoto4ruby
