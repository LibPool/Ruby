# learn-xcpretty

**Tag**: testing, tooling

## 简介

Xcodebuild formatter designed to be piped with `xcodebuild`,
  and thus keeping 100% compatibility.

  It has modes for CI, running tests (RSpec dot-style),
  and it can also mine Bitcoins.
