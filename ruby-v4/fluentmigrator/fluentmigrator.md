# fluentmigrator

**Tag**: library

## 简介

Fluent Migrator is a migration framework for .net much like Ruby Migrations.

## 官网

- 主页: http://github.com/schambers/fluentmigrator
- RubyGems: https://rubygems.org/gems/fluentmigrator

## 历史版本号

## 获取地址

- RubyGems: https://rubygems.org/gems/fluentmigrator

- Bundler: `gem "fluentmigrator"`
- 最新版本: 0.9.0
- 最新版归档: https://rubygems.org/downloads/fluentmigrator-0.9.0.gem
- 版本锁定: `gem "fluentmigrator", "~> 0.9.0"`
