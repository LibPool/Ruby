# jekyll-compress-flow

**Tag**: web, tooling, filesystem

## 简介

A Jekyll plugin that writes Brotli, Zstandard and gzip siblings next to text assets at the end of a build, so a precompressed-capable static server (e.g. Caddy's file_server precompressed) can serve them without per-request compression CPU.
