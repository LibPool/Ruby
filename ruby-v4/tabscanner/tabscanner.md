# tabscanner

**Tag**: web, data

## 简介

A Ruby gem that provides a simple interface for submitting receipt images to the Tabscanner API and retrieving parsed receipt data. Features include automatic polling, comprehensive error handling, debug mode, and environment-based configuration.
