# ruby-state-mach

**Tag**: web

## 简介

An enhanced state machine gem for ruby (doesn't require Rails). Provides more robust DSL state declaration syntax than other state machines. Multiple &quot;actions&quot; per event (i.e., next state, labmda, or a &quot;decider&quot;.
