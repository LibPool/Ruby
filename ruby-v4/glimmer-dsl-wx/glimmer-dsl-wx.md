# glimmer-dsl-wx

**Tag**: testing, tooling, data

## 简介

Glimmer DSL for WX (wxWidgets Ruby Desktop Development GUI Library). This is a Glimmer GUI DSL for the WxWidgets GUI toolkit using the latest wxruby binding, wxruby3. It supports a declarative hierarchical minimalistic Ruby DSL with Unidirectional/Bidirectional Data-Binding support to enable building desktop applications the Ruby way.
