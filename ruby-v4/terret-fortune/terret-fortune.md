# terret-fortune

**Tag**: testing, filesystem, data

## 简介

A worked example of the Terret extension story: a third-party gem that ships one tool (`fortune`, one line from a vendored list) and declares itself a bundle in a line of gemspec metadata, so a profile can stack it by name. Stdlib-only beyond terret-core. The running example of docs/cookbook/adding-a-tool.md, kept in lockstep with that page.
