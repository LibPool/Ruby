# cpfhub

**Tag**: web

## 简介

Official Ruby SDK for CPFHub.io — Brazilian CPF lookup API. Get name, gender and date of birth from any CPF in ~300ms. Full LGPD compliance. Supports Rails, Sidekiq and plain Ruby.
