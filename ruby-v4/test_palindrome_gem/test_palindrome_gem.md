# test_palindrome_gem

**Tag**: testing

## 简介

Allows for "Racecar".palindrome? for strings, returning true. Works for strings of upper, lower, mixed, and punctuated contents. Also works for integers, so that 1234321.palindrome? returns true. Uses mixins.
