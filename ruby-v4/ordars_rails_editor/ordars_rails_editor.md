# ordars_rails_editor

**Tag**: web, template

## 简介

A board-style WYSIWYG editor for Rails apps. Ships a bundled Tiptap/ProseMirror core (no external CDN), an etoland-style toolbar with color/highlight palettes and tooltips, an attachment panel with upload adapter, HTML source mode, a server-side sanitizer, and CSS-variable theming.
