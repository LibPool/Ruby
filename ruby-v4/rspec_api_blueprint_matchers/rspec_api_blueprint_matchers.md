# rspec_api_blueprint_matchers

**Tag**: web, cli, testing, networking

## 简介

API Blueprint Tools For RSpec - Matching http transactions against an API Blueprint document to ensure the API that you are implementing matches the API that is documented which your clients will expect to be the case.
