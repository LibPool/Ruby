# openid4vp

**Tag**: web, cli, security, serialization

## 简介

Verifier and Wallet implementation of OpenID4VP 1.0: DCQL, JAR request objects, client identifier prefixes, direct_post/direct_post.jwt/DC API response modes, encrypted responses and dc+sd-jwt, jwt_vc_json, mso_mdoc, ldp_vc formats.
