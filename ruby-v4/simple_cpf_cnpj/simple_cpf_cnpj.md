# simple_cpf_cnpj

**Tag**: library

## 简介

Provides the module CpfCnpj, with methods that detect, validate, and format CPFs and CNPJs (Brazilian federal ID numbers).

//

Fornece o módulo CpfCnpj, com funções que detectam, validam, e formatam CPFs e CNPJs.
