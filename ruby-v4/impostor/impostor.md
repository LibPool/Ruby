# impostor

**Tag**: web

## 简介

imPOSTor posts messages to forums

== FEATURES/PROBLEMS:

Makes automated posts to the following forum applications:

* Web Wiz Forums (WWF) 7.9
* Web Wiz Forums (WWF) 8.0
* PHP Bullitin Board (phpBB) 2.2
* PHP Bullitin Board (phpBB) 3.0
