# rubocop-tailwindcss

**Tag**: library

## 简介

Sorts Tailwind CSS classes in Ruby source - Phlex components and any class: string keyword - using Tailwind's own design system evaluated in an embedded JS engine. No node, no subprocesses: the official prettier-plugin order, autocorrected by rubocop -a.
