# robot_lab-am

**Tag**: cli

## 简介

Standalone background daemon that watches a repo's git activity, Claude Code session transcripts, and terminal commands, then infers the current goal/direction via a one-shot RubyLLM call to a local model. Writes an intent artifact any tool can read — robot_lab-to uses it to seed takeover runs, but nothing here requires RobotLab.
