# authaction-ruby-sdk

**Tag**: web, security

## 简介

JWT verification SDK for AuthAction. Fetches and caches JWKS from the well-known endpoint, validates RS256 tokens with issuer, audience, and expiry checks. Includes a Rails concern for controller authentication.
