# nextable

**Tag**: web, networking

## 简介

** NOT PRODUCTION READY ** 
A plugin for Rails that enables 'walking' of ActiveRecord models by implementing
next_record and #previous_record instance methods.
Documentation: https://github.com/tkbrigham/nextable
