# code2rubylearning

**Tag**: cli, filesystem

## 简介

command line tool that formats, given source code files, making them ready for pasting to the rubylearning.org forum.

## 官网

- 主页: https://github.com/rudicode/code2rubylearning
- RubyGems: https://rubygems.org/gems/code2rubylearning
