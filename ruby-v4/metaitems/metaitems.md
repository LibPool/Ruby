# metaitems

**Tag**: web, template

## 简介

Gem for Rails that can generate metaitems to your project.
For properly work require ActiveRecord, ERB, Playmo.
Metaitems is the functionality (model, view, controller, route) to manage 
name, description, keywords and url nick for html page.
