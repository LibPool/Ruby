# markdown-run

**Tag**: database, filesystem

## 简介

Run code blocks in Markdown files for Ruby, JavaScript, sqlite, psql, bash, zsh, and mermaid. Insert execution results next to the original code blocks. Generate SVG diagrams from mermaid blocks.
