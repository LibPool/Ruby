# ober

**Tag**: web

## 简介

Provides an alternative to the various remote applications that fulfill the same
purpose, such as capistrano or even chef. Installs Ruby applications to servers
on defined locations. 

Very early alpha. This will eventually deal with all the intricacies of bundler, 
RVM and rbenv, but for now, does really simple installations.
