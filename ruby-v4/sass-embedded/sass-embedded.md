# sass-embedded

**Tag**: library

## 简介

A Ruby library that will communicate with Embedded Dart Sass using the Embedded Sass protocol.

## 官网

- 主页: https://github.com/sass-contrib/sass-embedded-host-ruby
- 源码仓库: https://github.com/sass-contrib/sass-embedded-host-ruby/tree/v1.105.0
- 文档: https://rubydoc.info/gems/sass-embedded/1.105.0
- 问题追踪: https://github.com/sass-contrib/sass-embedded-host-ruby/issues
- RubyGems: https://rubygems.org/gems/sass-embedded
