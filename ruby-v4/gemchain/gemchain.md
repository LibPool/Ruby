# gemchain

**Tag**: testing

## 简介

When you maintain multiple gems that depend on each other, Gemchain helps you coordinate releases. It warns you before releasing a gem that others depend on, and can cascade updates through the dependency chain — updating constraints, running tests, and releasing each dependent gem in order.
