# gr_api_manager

**Tag**: web, security, filesystem

## 简介

Eliminates boilerplate from REST API development. Handles JWT and Bearer auth, CORS, route groups, declarative schema & type validation, type casting, multipart file uploads, raw binary/image/document bodies, Base64, hexadecimal, sliding-window rate limiting (429), Puma multi-worker concurrency, and dev mode stack traces.
