# event_engine-subscribers

**Tag**: library

## 简介

The subscriber layer for EventEngine: runs your in-app subscribers for events routed to it. Registers itself with the event_engine runtime as the :inline and :background processors, running subscribers synchronously or in a background job depending on which one an event's rule names.
