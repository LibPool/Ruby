# rake-rails

**Tag**: web

## 简介

Allows `rails` commands to be run via `rake`. For example: `rake generate`

## 官网

- 主页: https://github.com/alindeman/rake-rails
- RubyGems: https://rubygems.org/gems/rake-rails
