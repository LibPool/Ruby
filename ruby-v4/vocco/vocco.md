# vocco

**Tag**: tooling

## 简介

vocco is an extra super quick-and-dirty documentation generator based on Vim, written in Ruby.

## 官网

- 主页: http://github.com/jbe/vocco
- RubyGems: https://rubygems.org/gems/vocco
