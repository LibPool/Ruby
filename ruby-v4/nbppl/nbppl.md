# nbppl

**Tag**: web, cli, networking

## 简介

Provides simple API client to fetch exchange rate to PLN for selected currency and date from http://api.nbp.pl

## 官网

- 主页: http://github.com/meceo/nbppl
- RubyGems: https://rubygems.org/gems/nbppl
