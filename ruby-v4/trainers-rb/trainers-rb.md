# trainers-rb

**Tag**: serialization

## 简介

Training loop, LoRA, and optimization utilities for fine-tuning HuggingFace transformer models using torch-rb and transformers-rb. Supports full fine-tuning, LoRA adapters, learning rate scheduling, callbacks, and model serialization via safetensors.
