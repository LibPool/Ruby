# gangsterhat

**Tag**: web, testing, serialization, tooling

## 简介

Currently in development. This set of generators allows to quickly create JSON API CRUDs with RBAC, Pagination and Ember.js front-end. Includes following generators:
	* json_api_controller - generates JSON API controller
	* json_api_crud_controller - generates JSON API CRUD controller
	* json_api_model - generates model with pagination helper
	* json_api_frontend - generates Ember.js stuff for resource
	* json_api_scaffold - invokes json_api_crud_controller, json_api_model, json_api_frontend generators 
	Please, note, that it supports only RSpec test at this moment.
