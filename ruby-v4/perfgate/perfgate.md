# perfgate

**Tag**: database, testing

## 简介

Baseline converts selected RSpec examples into repeatable performance workloads, measures application-level signals (duration, SQL activity, allocations, GC), compares a pull request against a compatible default-branch baseline, and produces a clear CI merge-gate decision.
