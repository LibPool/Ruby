# omniflash-sdk

**Tag**: web, cli, networking

## 简介

Tiny Ruby client for the Omni Flash API. Supports seedance-2 (video + audio) and gpt-image-2 / nano-banana-2 (image) under the Gemini Omni Flash family. Sign in and create a key at https://omniflash.net/.
