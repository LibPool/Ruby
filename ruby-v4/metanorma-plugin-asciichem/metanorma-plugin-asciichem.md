# metanorma-plugin-asciichem

**Tag**: template, data

## 简介

Adds [chem] blocks and chem:[] inline macros to Metanorma AsciiDoc: chemistry written in AsciiChem parses to MathML for rendering, and @cite-annotated molecules resolve to dataset-type Relaton bibitems - one per (source, substance), anchored by InChIKey - automatically collected into the document's bibliography.
