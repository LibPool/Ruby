# ask-session-protocol

**Tag**: web, cli, serialization

## 简介

The contract between the ask session host and every client (terminal TUI, web console, bots, IDE) — plus the shared Client and Host. Defines the canonical session event vocabulary, the resolvable interaction types (approvals, plan proposals, user input), the client-to-host method surface, protocol versioning, and generated JSON Schema artifacts. No runtime, no transports — just the contract.
