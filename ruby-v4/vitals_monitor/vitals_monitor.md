# vitals_monitor

**Tag**: web, database, serialization, networking, template

## 简介

VitalsMonitor is a Rails engine that provides /vitals endpoints to monitor the health status of Postgres, Redis, and Sidekiq. Components can be enabled/disabled via configuration, and endpoints return HTML or JSON with appropriate HTTP status codes for monitoring.
