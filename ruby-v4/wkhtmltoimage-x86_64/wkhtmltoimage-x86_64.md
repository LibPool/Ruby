# wkhtmltoimage-x86_64

**Tag**: template

## 简介

Provides linux and Mac binaries for wkhtmltoimage project in an easily accessible package. Based on the wkhtmltopdf-binary gem of steerio. wkhtmltoimage is LGPL licenced.
