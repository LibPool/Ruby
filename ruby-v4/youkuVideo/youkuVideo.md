# youkuVideo

**Tag**: library

## 简介

通过网页或者 vid 解析出 YouKu 视频的 M3U8 播放地址

## 官网

- 主页: https://github.com/gonjay/YoukuVideo
- 文档: https://www.rubydoc.info/gems/youkuVideo/0.0.2
- RubyGems: https://rubygems.org/gems/youkuVideo

## 历史版本号

- 0.0.2 (2015-05-30)
- 0.0.1 (2015-05-30)

## 获取地址

- RubyGems: https://rubygems.org/gems/youkuVideo
- gem 安装: `gem install youkuVideo`
- Bundler: `gem "youkuVideo"`
- 最新版本: 0.0.2
- 最新版归档: https://rubygems.org/downloads/youkuVideo-0.0.2.gem
- 版本锁定: `gem "youkuVideo", "~> 0.0.2"`
- 中央仓库: https://rubygems.org/
