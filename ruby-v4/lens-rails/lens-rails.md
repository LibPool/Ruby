# lens-rails

**Tag**: web, serialization, filesystem

## 简介

Drop-in Rails gem that collects logs, metrics, and request traces via ActiveSupport::Notifications and ships them to a Lens instance. Uses gzip-compressed JSON — no protobuf, no OpenTelemetry SDK required.
