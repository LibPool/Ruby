# citrine-remote

**Tag**: web, networking

## 简介

Citrine::Remote：把服务器权威状态以 Signal 形态镜像到前端。视图层零修改获得实时同步——前端状态 = 服务器共享状态的镜像 + 本地瞬时 UI 状态。提供 Remote::Signal（乐观提案/权威回滚）、Hub（权威侧广播器）、Session（镜像侧分发）与可替换的传输适配器（CRuby TCP/WebSocket、Opal 浏览器原生 WebSocket）。
