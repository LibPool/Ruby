# atd-asset_bundler

**Tag**: web, template

## 简介

A Rails Engine that allows you to put assets in app/assets
                   and use a Rails template engine to render them. This version
                   is compatible with Rails 3.0

- 主页: http://github.com/atd/asset_bundler
