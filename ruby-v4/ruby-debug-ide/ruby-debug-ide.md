# ruby-debug-ide

**Tag**: cli

## 简介

An interface which glues ruby-debug to IDEs like Eclipse (RDT), NetBeans and RubyMine.

## 官网

- 主页: https://github.com/ruby-debug/ruby-debug-ide
- 文档: https://www.rubydoc.info/gems/ruby-debug-ide/0.7.5
- RubyGems: https://rubygems.org/gems/ruby-debug-ide
