# sloplint-judge

**Tag**: tooling

## 简介

A second catalog for sloplint whose rules are questions put to a System One model (Jev by default) rather than regexes: does this paragraph end by restating itself, does this sentence name anything a reader could check. Emits sloplint's own notes. Adds `sloplint check --judge` and a `sloplint-judge` executable.
