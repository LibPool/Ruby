# terret-ws

**Tag**: cli, security

## 简介

The v1 interface: one connection per agent, durable session events out, five client frames in, exact replay-then-tail reconnect on the append-only log, bounded-queue backpressure, heartbeat, and bearer auth. Ships as a plugin because the primary interface being a plugin is the architecture's point.
