# rapidhash

**Tag**: web, testing, networking

## 简介

This gem wraps rapidhash (https://github.com/Nicoshev/rapidhash/tree/master), the successor to wyhash and the fastest hash function passing all tests in SMHasher3.

## 官网

- 源码仓库: https://github.com/psadda/rapidhash-ruby
- RubyGems: https://rubygems.org/gems/rapidhash
