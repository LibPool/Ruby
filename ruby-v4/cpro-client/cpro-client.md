# cpro-client

**Tag**: web, cli, security

## 简介

Client Ruby des API G2B de Chorus Pro (PPF) : authentification OAuth2 PISTE, consultation de l'annuaire par SIRET ou SIREN, et dépôt de factures Factur-X.
