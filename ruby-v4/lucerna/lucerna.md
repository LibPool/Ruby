# lucerna

**Tag**: web

## 简介

Server-side Lucerna SDK: local Gates evaluation (feature flags, experiments, kill switches) with background runtime sync, and fire-and-forget People identify. Pure Ruby, zero runtime dependencies, Rails Railtie included.
