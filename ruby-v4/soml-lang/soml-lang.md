# soml-lang

**Tag**: tooling

## 简介

A strict parser and a generator for SOML that keeps member order or writes canonical form, with exact integers, instants, and durations, and an error message that says what is wrong and where. With a formatter, an editor that keeps comments and layout, and a syntax tree for linters.
