# css_splitter_opp_fork

**Tag**: web, testing

## 简介

***This is a fork of the css_splitter gem. We needed the latest &amp; greatest before 0.4.0 was available through rubygems.*** Gem for splitting up stylesheets that go beyond the IE limit of 4095 selectors, for Rails 3.1+ apps using the Asset Pipeline.
