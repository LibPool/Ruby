# spec-me-maybe

**Tag**: testing

## 简介

Adds the `maybe` syntax to RSpec:
     describe Thing do
      it 'is maybe equal to another thing' do
        maybe(Thing.new).will eq(another_thing) # Passes sometimes. Maybe.
      end
    end
