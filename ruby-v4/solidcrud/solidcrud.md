# solidcrud

**Tag**: web

## 简介

SolidCRUD provides a plug-and-play /admin dashboard for Rails applications. It auto-detects all ActiveRecord models and provides a complete CRUD interface with a modern, responsive Bootstrap UI. Features include search, pagination, intelligent form fields, and zero configuration required.
