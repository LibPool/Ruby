# lightwave

**Tag**: filesystem

## 简介

A set of libraries that handle reading Lightwave object files and (for the moment) turning them into a set of Xaml objects.

## 官网

- 主页: http://www.shaxam.com
- RubyGems: https://rubygems.org/gems/lightwave
