# ruby-netcdf-updated

**Tag**: library

## 简介

RubyNetCDF is the Ruby interface to the NetCDF library built on the NArray library, which is an efficient multi-dimensional numeric array class for Ruby. This is an updated version that works with Ruby 2.0. Contact cannot be established with the original developers.
