# t-rex

**Tag**: web, cli, networking

## 简介

This is a terminal curses RPN calculator similar to the traditional calculators from Hewlett Packard. See https://www.hpmuseum.org/rpn.htm for info on RPN (Reverse Polish Notation). Version 4.1.2: Fix stack handling during number entry with operators and ENTER.
