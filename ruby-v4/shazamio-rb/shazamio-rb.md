# shazamio-rb

**Tag**: web, filesystem

## 简介

A free Ruby library for the reverse engineered Shazam API. Search tracks and
artists, fetch charts, and recognize songs from an audio file using a pure
Ruby port of Shazam's audio fingerprinting algorithm.
