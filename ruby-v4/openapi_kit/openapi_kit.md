# openapi_kit

**Tag**: web, security

## 简介

What openapi_kit-generated Ruby code requires at runtime: the codecs that translate between wire values and Ruby types, the decoding primitives the generated structs are built from, and the credential extraction that a generated authenticator interface hands you.
