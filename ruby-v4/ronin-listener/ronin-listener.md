# ronin-listener

**Tag**: web, cli, serialization, networking, data

## 简介

ronin-listener is a small CLI utility for receiving exfiltrated data over DNS
or HTTP. Supports logging DNS queries and HTTP requests as TXT, CVS, JSON,
or NDJSON.
