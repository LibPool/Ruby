# acts_as_calculator_editor

**Tag**: web, serialization, networking, template

## 简介

A mountable Rails engine providing a Hotwire/Lexxy rich text editor, CRUD, validation preview, and JSON export for acts_as_calculator formulas and templates. Writes exclusively through acts_as_calculator's own service objects, in-process, rather than duplicating its persistence or calculation logic — so the host need not enable the core gem's HTTP API.
