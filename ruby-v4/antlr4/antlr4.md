# antlr4

**Tag**: tooling

## 简介

Ruby implementation of the Antlr4 runtime.
This is needed by any parser/lexer written in Antlr4 using the target 
langague=Ruby.

## 官网

- 主页: https://github.com/slaught/antlr4-ruby
- 文档: https://www.rubydoc.info/gems/antlr4/0.9.2
- RubyGems: https://rubygems.org/gems/antlr4
