# longfellow

**Tag**: library

## 简介

Ruby (FFI) bindings for google/longfellow-zk, the zero-knowledge library for
identity protocols. Generate and verify zero-knowledge proofs over ISO mdoc /
mDL verifiable credentials directly from Ruby.
