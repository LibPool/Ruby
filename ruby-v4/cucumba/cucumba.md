# cucumba

**Tag**: web, database, testing, data

## 简介

If you develop more than one rails applications that communicate with each other and you need to test them with something like capybara and also whant to communicate with database - this gem will help you

## 官网

- 主页: http://github.com/hxcoding/cucumba
- RubyGems: https://rubygems.org/gems/cucumba
