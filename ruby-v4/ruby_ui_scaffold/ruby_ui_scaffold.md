# ruby_ui_scaffold

**Tag**: web, testing, template

## 简介

Provides `rails g ruby_ui_scaffold` — a drop-in replacement for `rails g scaffold` that generates model, controller, routes, tests, and Phlex view classes wired to ruby_ui components (Input, Textarea, Checkbox, Button, Table, FormField, etc.).
