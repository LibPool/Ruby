# clicksend-opentelemetry

**Tag**: web, cli

## 简介

An instrumenter for Clicksend::Client that opens one CLIENT span per ClickSend API call, with retries as span events. Never records phone numbers, message text, bodies, query strings or credentials. Not affiliated with ClickSend.
