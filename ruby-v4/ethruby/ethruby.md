# ethruby

**Tag**: cli

## 简介

Ethruby project intent to implement full feature set of ethereum in pure ruby, to provide usable cli and ruby library.

## 官网

- 主页: https://github.com/ruby-ethereum/ethereum
- 文档: https://www.rubydoc.info/gems/ethruby/0.0.0
- RubyGems: https://rubygems.org/gems/ethruby

## 历史版本号

- 0.0.0 (2018-04-27)

## 获取地址

- RubyGems: https://rubygems.org/gems/ethruby

- 最新版归档: https://rubygems.org/downloads/ethruby-0.0.0.gem
