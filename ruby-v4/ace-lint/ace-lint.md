# ace-lint

**Tag**: serialization, tooling, filesystem

## 简介

ace-lint provides Ruby-native linting for markdown (kramdown), YAML (Psych), Ruby files (StandardRB/RuboCop), and frontmatter without Node.js or Python dependencies.
