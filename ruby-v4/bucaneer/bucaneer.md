# bucaneer

**Tag**: library

## 简介

Bucaneer is a Ruby library which allows you to control your BusPirate bitbang modes (I2C, SPI, etc).

## 官网

- 主页: http://github.com/nullobject/bucaneer
- RubyGems: https://rubygems.org/gems/bucaneer
