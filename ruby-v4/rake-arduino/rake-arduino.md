# rake-arduino

**Tag**: tooling

## 简介

rake-arduino allows you to easily build Arduino sketches using Rake.

## 官网

- 主页: https://github.com/wjbuys/rake-arduino
- RubyGems: https://rubygems.org/gems/rake-arduino
