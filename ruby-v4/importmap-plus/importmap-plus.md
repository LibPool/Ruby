# importmap-plus

**Tag**: web, tooling

## 简介

A drop-in replacement for importmap-rails. Same Importmap:: API, same pins, same import map, plus `bin/importmap pin --minify`, `--from esm.run` for jsDelivr's bundled builds, `--lock` to hold a package at a version, and a pin comment that records the CDN, minification and lock so later updates keep them. Use this gem or importmap-rails, never both.
