# ai2web

**Tag**: web, serialization, tooling

## 简介

The Ruby implementation of the AI2Web protocol - describe your website once and make it understandable and actionable to any AI agent. Fluent manifest builder, AI Readiness validator/scorer, capability negotiation, a framework-agnostic request handler for Rails/Sinatra/Rack, an SSRF guard, and llms.txt / agent.json projections (RFC-0015). Mirrors @ai2web/core. Zero runtime dependencies.
