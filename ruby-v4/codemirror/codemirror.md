# codemirror

**Tag**: web

## 简介

Ships the CodeMirror 6 code editor as prebuilt ES modules for modern Rails
applications. Works out of the box with Propshaft and import maps: the gem
registers its assets on the pipeline and provides import-map pins for the
CodeMirror core, languages and the One Dark theme.
