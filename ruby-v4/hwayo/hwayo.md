# hwayo

**Tag**: filesystem

## 简介

Hwayo is a Ruby gem that wraps the hwplib Java library to extract text from Korean HWP (Hangul Word Processor) files. It provides a simple interface to extract text content from HWP documents using the Java hwplib library.
