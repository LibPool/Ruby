# claude-matrix

**Tag**: web, cli, devops, data

## 简介

Transforms your local ~/.claude/ session data into a beautiful btop-style terminal dashboard — streaks, tool usage, token costs, work modes, and activity heatmaps. No cloud, no API calls.
