# solid_errors-frontend

**Tag**: web, filesystem

## 简介

Captures uncaught JavaScript exceptions, unhandled promise rejections, Stimulus controller errors and Turbo failures in the browser and reports them through ActiveSupport::ErrorReporter, so Solid Errors records them alongside server-side errors — with frames resolved back to your source files. A third-party companion gem, not affiliated with solid_errors.
