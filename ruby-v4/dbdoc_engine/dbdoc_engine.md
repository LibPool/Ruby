# dbdoc_engine

**Tag**: web, database, data

## 简介

A mountable Rails engine that provides a full-featured web interface for documenting database schemas — tables, columns, relationships, constraints, change tracking, ER diagrams, Excel export, and i18n support (EN/JA).
