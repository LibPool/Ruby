# genderapi

**Tag**: web, networking

## 简介

Official Ruby SDK for GenderAPI.io.

    This SDK allows determining gender from:
    - personal names
    - email addresses
    - social media usernames

    Supports:
    - country filtering
    - direct AI queries
    - forced genderization for nicknames or unconventional strings

    Built with HTTParty for easy HTTP handling.
