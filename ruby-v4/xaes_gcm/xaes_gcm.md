# xaes_gcm

**Tag**: library

## 简介

Ruby implementation of XAES-256-GCM (c2sp.org/XAES-256-GCM), an extended-nonce AEAD built on AES-256-GCM. Derives standard AES-256-GCM keys and nonces from 256-bit keys and 192-bit nonces.
