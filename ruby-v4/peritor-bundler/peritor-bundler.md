# peritor-bundler

**Tag**: library

## 简介

An easy way to vendor gem dependencies (with a tiny patch to allow shallow git cloning)

## 官网

- 主页: http://github.com/wycats/bundler
- RubyGems: https://rubygems.org/gems/peritor-bundler

## 历史版本号

- 0.7.0 (2010-04-01)

## 获取地址

- RubyGems: https://rubygems.org/gems/peritor-bundler
- gem 安装: `gem install peritor-bundler`
- Bundler: `gem "peritor-bundler"`
- 最新版本: 0.7.0
- 最新版归档: https://rubygems.org/downloads/peritor-bundler-0.7.0.gem
- 版本锁定: `gem "peritor-bundler", "~> 0.7.0"`
- 中央仓库: https://rubygems.org/
