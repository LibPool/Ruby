# crosspack

**Tag**: tooling

## 简介

The build matrix in crosspack.yml helps you to build and deliver your program without pain — one config drives a staged pipeline (deps → build → pack) that produces native packages for every platform: deb, rpm, PKGBUILD, winget and cask.
