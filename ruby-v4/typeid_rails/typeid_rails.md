# typeid_rails

**Tag**: web, template

## 简介

Renders a 128-bit UUID as a TypeID, a short type-tagged string such as "user_2n1t201rmv87aae5j4csam8000", and parses it back. Includes an ActiveRecord attribute type and an optional deterministic SHAKE128 derivation.
