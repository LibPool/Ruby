# ask-app-server

**Tag**: web, cli, serialization

## 简介

Exposes Ask::Agent::Session behind the standard app-server JSON-RPC/stdio protocol. Drop-in compatible with clients that speak the ZCode/Codex app-server protocol — Telegram bots, AI SDK providers, IDE extensions, and headless automation.
