# amazon-fps-ruby

**Tag**: web, networking, devops

## 简介

Provides a simple wrapper around the Amazon FPS SOAP web service.   == FEATURES/PROBLEMS:  Supports all features in the WSDL from Amazon:  https://fps.amazonaws.com/doc/2008-09-17/AmazonFPS.wsdl
