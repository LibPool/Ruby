# openssl-additions

**Tag**: library

## 简介

This gem provides a consistent, key-type-independent SPKI (SubjectPublicKeyInfo) class,
a way to generate an SPKI object from a key regardless of type, SSH public key to
OpenSSL key conversion, and more.
