# inbox_beam

**Tag**: library

## 简介

InboxBeam appends a message straight into your own mailbox using the IMAP APPEND command instead of sending email. Useful for landing app notifications, contact-form copies, and cron alerts in your own inbox without standing up a sending domain. Includes a drop-in Action Mailer delivery method.
