# mailsenpai

**Tag**: web, cli, networking

## 简介

Send transactional email through SMTP Senpai by MailSenpai, the EU-hosted SMTP relay and email API: API client (send, events, suppression list), webhook signature verification and an ActionMailer delivery method (:mailsenpai).
