# zotero-rb

**Tag**: web, cli, filesystem

## 简介

A feature-complete Ruby client for the Zotero Web API v3, providing full CRUD operations for items, collections, tags, and searches, plus file uploads, fulltext content access, and library synchronization. Built with a modular architecture and comprehensive error handling.
