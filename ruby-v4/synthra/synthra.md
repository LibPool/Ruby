# synthra

**Tag**: data

## 简介

A Ruby gem for defining data schemas in a custom indentation-based DSL and 
generating fake data with support for nested objects, arrays, cross-schema 
references, computed fields, behaviors, streaming generation, and multiple 
generation modes (random, edge, invalid).
