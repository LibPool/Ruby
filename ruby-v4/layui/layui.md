# layui

**Tag**: template

## 简介

Layui 是一款采用自身模块规范编写的前端 UI 框架，遵循原生 HTML/CSS/JS 的书写与组织形式，门槛极低，拿来即用。

## 官网

- 主页: https://github.com/witcan/layui
- RubyGems: https://rubygems.org/gems/layui

## 历史版本号

- 0.1.2 (2021-01-09)
- 0.1.1 (2020-12-29)
- 0.1.0 (2020-12-27)

- RubyGems: https://rubygems.org/gems/layui
