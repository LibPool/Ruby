# purp-ruby-gmail

**Tag**: web, networking, filesystem

## 简介

A Rubyesque interface to Gmail, with all the tools you'll need. Search, read and send multipart emails; archive, mark as read/unread, delete emails; and manage labels. [This is a fork of http://github.com/justinperkins/ruby-gmail which is a fork of http://github.com/dcparker/ruby-gmail]
