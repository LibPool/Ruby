# ivy4r

**Tag**: tooling

## 简介

Ivy4r is a Ruby interface for Apache Ivy dependency management library. Offers support for using Ivy with Buildr and Rake.

## 官网

- 主页: http://github.com/klaas1979/ivy4r
- RubyGems: https://rubygems.org/gems/ivy4r
