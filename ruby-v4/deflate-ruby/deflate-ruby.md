# deflate-ruby

**Tag**: filesystem

## 简介

DeflateRuby provides Ruby bindings for libdeflate, a heavily optimized library for DEFLATE, gzip, and zlib compression and decompression. Significantly faster than Ruby's built-in Zlib module.
