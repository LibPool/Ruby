# coatepec

**Tag**: web, cli, testing

## 简介

Coatepec is a local stdio MCP sidecar that keeps an isolated Rails test worker warm so coding agents can run targeted RSpec examples quickly, check specs for flakiness, and read routes, models, and controllers through structured read-only Rails APIs -- without exposing a general Rails console.
