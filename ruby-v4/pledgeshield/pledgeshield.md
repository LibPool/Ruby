# pledgeshield

**Tag**: web, security

## 简介

Personal device security auditor for Windows, macOS, and Linux. Scans for misconfigurations, exposed services, unpatched CVEs, privilege escalation vectors, and hardens 120+ attack surfaces. Think lynis but cross-platform, in Rust, one binary, no agent, no server.
