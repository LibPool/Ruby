# chrono_machines

**Tag**: library

## 简介

ChronoMachines offers a flexible and configurable solution for handling transient failures in distributed Ruby applications. It provides powerful retry strategies, including exponential backoff and full jitter, with customizable callbacks. Features optional Rust-powered native performance on CRuby with pure Ruby fallback for JRuby compatibility.
