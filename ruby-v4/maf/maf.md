# maf

**Tag**: cli, filesystem

## 简介

multi-agent-flow is a coordination layer for AI coding agents (Claude Code, Codex, opencode, Cursor, Hermes). Each agent works in its own git worktree. The agents share a Taskwarrior task board, file locks, and a knowledge graph through the coord CLI.
