# google-cloud-dataform-v1

**Tag**: cli, database, testing, devops, data

## 简介

Service to develop, version control, and operationalize SQL pipelines in BigQuery. Note that google-cloud-dataform-v1 is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-dataform instead. See the readme for more details.
