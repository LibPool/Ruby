# rhype

**Tag**: library

## 简介

RHype is a commandline tool and reusable library for interfacing with project management hosting services like Rubyforge.

## 官网

- 主页: http://rhype.rubyforge.org/
- RubyGems: https://rubygems.org/gems/rhype

## 历史版本号

- 0.1.0 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/rhype
