# stringify

**Tag**: library

## 简介

You can combine your N strings/arrays on a delimeter by using method 'Stringify.Combine_with(delimeter, &lt;comma separated strings/arrays&gt;)'. You can join any number of strings with strings or strings with arrays or arrays with arrays.
