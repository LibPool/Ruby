# ruby_kpi

**Tag**: library

## 简介

The KPI required to access a SmartM3 Smart Space. This gem provides the standard JOIN, LEAVE, INSERT, REMOVE, UPDATE, QUERY, SUBSCRIBE and UNSUBSCRIBE primitives
