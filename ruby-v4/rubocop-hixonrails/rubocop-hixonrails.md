# rubocop-hixonrails

**Tag**: web, testing

## 简介

RuboCop configuration with the following extensions:
    - rubocop-rails,
    - rubocop-performance,
    - rubocop-rspec
    - rubocop-rake.
    Easily extensible, created by Hix on Rails.
