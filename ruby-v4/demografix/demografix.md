# demografix

**Tag**: web, cli

## 简介

One client for the three Demografix APIs: gender, age, and nationality prediction from a name. Look up a single name or send a batch of up to 100 names in one request for bulk demographic analysis, optionally scoped to a country, and read the remaining quota carried on every response.
