# jekyll-better-related

**Tag**: library

## 简介

jekyll-better-related replaces Jekyll's built-in related_posts (which is just recency) with a proper relevance scorer using tag overlap, category match, and title keyword overlap. Drop-in replacement — no theme changes required.
