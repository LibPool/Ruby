# rutile

**Tag**: tooling, filesystem

## 简介

Flex and Bison functionality, but in ruby and 10 times slower! Don't use this for big projects, but if you need to
                            make a small language for a config file and don't want to learn a new language that is for making parsers, then
                            this gem might be for you!
