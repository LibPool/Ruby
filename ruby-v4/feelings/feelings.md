# feelings

**Tag**: serialization

## 简介

feelings brings the feels construct from the Probably language to Ruby. A decision model judges how well a description fits a value, and feelings turns that into conditionals, semantic match, bounded loops, chaos sampling, and replayable tapes. Descriptions and label sets can live in YAML. Works with any judge; ruby_decision_model is the default.
