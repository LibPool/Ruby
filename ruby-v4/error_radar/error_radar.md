# error_radar

**Tag**: web

## 简介

Captures unhandled exceptions from controllers, Rack, Sidekiq and ActiveJob, deduplicates them by fingerprint, and exposes a kanban dashboard (and optional RailsAdmin board) to triage them as tasks.
