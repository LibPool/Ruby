# data_miner

**Tag**: serialization, template, filesystem, data

## 简介

Download, pull out of a ZIP/TAR/GZ/BZ2 archive, parse, correct, and import XLS, ODS, XML, CSV, HTML, etc. into your ActiveRecord models. Uses Upsert internally for speed.

## 官网

- 主页: https://github.com/seamusabshere/data_miner
- 文档: https://www.rubydoc.info/gems/data_miner/3.0.0
- RubyGems: https://rubygems.org/gems/data_miner
