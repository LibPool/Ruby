# redlock

**Tag**: web, database, networking

## 简介

Distributed lock using Redis written in Ruby. Highly inspired by https://github.com/antirez/redlock-rb.

## 官网

- 主页: https://github.com/leandromoreira/redlock-rb
- 文档: http://www.rubydoc.info/gems/redlock/frames
- 问题追踪: https://github.com/leandromoreira/redlock-rb/issues
- RubyGems: https://rubygems.org/gems/redlock
