# flipp-mockserver-client

**Tag**: web, cli, testing, networking

## 简介

A Ruby Client for MockServer that enables easy mocking of any system you integrate with via HTTP or HTTPS (i.e. services, web sites, etc) modified to work with multiple Fipp requests
