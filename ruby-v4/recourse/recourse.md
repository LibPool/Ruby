# recourse

**Tag**: template, devops, filesystem

## 简介

Recourse adds a `recourses` method to config/routes.rb. One line draws the routes, controllers and views needed to browse and edit a resource, with no files added to the host app. Any controller, view or partial can be overridden by defining it in the app.
