# doublehelix

**Tag**: library

## 简介

doublehelix obfuscates Ruby codes in Double-helix style.
This is inspired by Perl's Acme::DoubleHelix.

## 官网

- 主页: http://github.com/mame/doublehelix
- RubyGems: https://rubygems.org/gems/doublehelix
