# reve_ai

**Tag**: web

## 简介

ReveAI was a lightweight Faraday-based wrapper for the Reve image generation API (create, edit, remix images). The upstream public API sunsets on August 14, 2026; this gem is deprecated and will be unmaintained after the shutdown.
