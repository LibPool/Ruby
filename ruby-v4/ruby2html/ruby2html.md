# ruby2html

**Tag**: web, template

## 简介

Ruby2HTML empowers developers to write view logic in pure Ruby, seamlessly converting it into clean, well-formatted HTML. Enhance your templating workflow, improve readability, and leverage the full power of Ruby in your views. Features include Rails integration, custom component support, automatic HTML beautification, and C-optimized rendering performance.
