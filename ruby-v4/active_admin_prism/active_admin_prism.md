# active_admin_prism

**Tag**: web

## 简介

Prism is an ActiveAdmin theme that replaces the default top navigation with a collapsible left sidebar, restyles panels, tables and Formtastic forms into a modern card-based look, and ships as a zero-config Rails engine.
