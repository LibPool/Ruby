# wideholy

**Tag**: web, cli

## 简介

API client for wideholy.com. Cross-religion verse of the day, random verse, side-by-side comparison, search suggestions, topic verses across Bible/Quran/Torah/Gita/Sutra, religious calendar, and commentary. Zero dependencies.
