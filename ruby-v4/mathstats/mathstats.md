# mathstats

**Tag**: data

## 简介

Mathstats is a basic statistics library. It is meant to be mixed into Array, but you can also use it as a standalone class.

## 官网

- 主页: http://github.com/bmarini/mathstats
- RubyGems: https://rubygems.org/gems/mathstats

- 0.9.1 (2009-11-03)
