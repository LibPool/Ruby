# pqc_rails

**Tag**: web, security

## 简介

pqc_rails provides zero-downtime-friendly post-quantum cryptography primitives (NIST-standardized algorithms such as ML-KEM and ML-DSA) for existing Rails applications, via native FFI bindings to liboqs.
