# protocol-zmtp

**Tag**: library

## 简介

Pure Ruby implementation of the ZMTP 3.1 wire protocol (ZeroMQ Message Transport Protocol). Includes frame codec, greeting, commands, NULL and CURVE mechanisms, and connection management. No runtime dependencies.
