# ruby_cms

**Tag**: web, security, template, tooling, filesystem, data

## 简介

RubyCMS is an install-only generator: `ruby_cms install` copies admin
controllers, views, models, helpers, and JavaScript for the modules you
select into your host app, which then runs entirely on the copied code (no
runtime engine to mount). `ruby_cms update`/`sync` keep the copied files in
step with the gem templates. Modules include:

- Visual editor with inline editing
- Content blocks with rich text support
- Permission-based access control
- User management & passkey (WebAuthn) login
- Analytics, audit log, media library, redirects, and more
