# arel-extensions

**Tag**: database, serialization

## 简介

Extends Arel and ActiveRecord with SQL operators and functions that aren't available out of the box, including array and JSON predicates, PostgreSQL full-text search (tsvector/tsquery), GIS/geometry predicates, and additional ordering helpers.
