# epubcheck

**Tag**: web, networking

## 简介

This is a command-line ePub check tool. It is wrapper of epubcheck(http://code.google.com/p/epubcheck/).

## 官网

- 主页: http://github.com/jugyo/epubcheck
- 文档: https://www.rubydoc.info/gems/epubcheck/3.0.1
- RubyGems: https://rubygems.org/gems/epubcheck
