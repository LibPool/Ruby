# metaweblog

**Tag**: web, cli, serialization

## 简介

Ruby client for metaWeblog API.
    This gem makes it easier for developers to talk with your Blog supporting
    metaWeblog API.
    This gem only depends on REXML provided as one of Ruby's standard lib.
