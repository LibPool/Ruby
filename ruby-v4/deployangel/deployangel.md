# deployangel

**Tag**: web, database, networking, devops, data

## 简介

Aggregates HTTP requests, background jobs, exceptions, and recurring schedules in-process and reports one small payload per process per minute to DeployAngel, which verifies each deployment and tells you, or your coding agent, when a release is cleared and safe to stop watching. It never sends request bodies, parameters, SQL, or user data.
