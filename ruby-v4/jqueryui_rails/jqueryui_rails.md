# jqueryui_rails

**Tag**: web

## 简介

No more need to download JQuery UI... just include jqueryui/yourtheme
    and everything just works!  Rails 3.1 and up...

## 官网

- 主页: http://github.com/tylergannon/jqueryui_rails
- RubyGems: https://rubygems.org/gems/jqueryui_rails

## 历史版本号

- 0.0.4 (2011-06-11)

## 获取地址

- RubyGems: https://rubygems.org/gems/jqueryui_rails
- gem 安装: `gem install jqueryui_rails`
- Bundler: `gem "jqueryui_rails"`
- 最新版本: 0.0.4
- 最新版归档: https://rubygems.org/downloads/jqueryui_rails-0.0.4.gem
- 版本锁定: `gem "jqueryui_rails", "~> 0.0.4"`
- 中央仓库: https://rubygems.org/
