# cocoapods-s3

**Tag**: devops

## 简介

This Cocoapods plugin allows you to use dependencies from a bucket in AWS S3.

## 官网

- 文档: https://www.rubydoc.info/gems/cocoapods-s3/1.0.1
- RubyGems: https://rubygems.org/gems/cocoapods-s3
