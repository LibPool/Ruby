# dht11

**Tag**: library

## 简介

Ruby conversion of DHT11 Python library which depends only on rpi_gpio.

## 官网

- 主页: https://github.com/tankenta/dht11
- RubyGems: https://rubygems.org/gems/dht11

## 历史版本号

- 0.1.0 (2019-08-16)

## 获取地址

- RubyGems: https://rubygems.org/gems/dht11
- gem 安装: `gem install dht11`
- Bundler: `gem "dht11"`
- 最新版本: 0.1.0
- 最新版归档: https://rubygems.org/downloads/dht11-0.1.0.gem
- 版本锁定: `gem "dht11", "~> 0.1.0"`
