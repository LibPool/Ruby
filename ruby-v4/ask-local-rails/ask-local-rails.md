# ask-local-rails

**Tag**: web, security, tooling, filesystem

## 简介

Railtie, install generator, and helpers wiring a Rails app into ask-local's stable .localhost URLs: host authorization, Action Cable origins, Procfile $PORT rewrite, and an agent skill for local development.
