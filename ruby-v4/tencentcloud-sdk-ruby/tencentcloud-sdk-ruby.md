# tencentcloud-sdk-ruby

**Tag**: web, devops

## 简介

方便 Ruby 开发者调试和接入腾讯云产品 API，并提供首次使用开发工具包的简单示例，快速获取腾讯云 Ruby SDK 并开始调用。
