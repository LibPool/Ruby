# naqsh

**Tag**: web, template

## 简介

Naqsh is a UI component system for Rails: server-rendered ERB components you copy into your app and own, powered by a versioned Hotwire behavior layer, a shadcn-compatible theming contract, and accessibility gates in CI. This release reserves the gem name while the first component wave is built.
