# maquina_remend

**Tag**: web, template

## 简介

A pure function that completes half-written markdown - unclosed emphasis, a
link whose URL has not arrived, a code span still open - so a renderer never
sees a broken document mid-stream. Idempotent, byte-identical on well-formed
input, with no runtime dependencies and no Rails.
