# reports_web

**Tag**: web, serialization, template, tooling, devops, filesystem, data

## 简介

Reports.Web is a report designer and PDF engine for Japanese business forms (invoices, estimates, delivery slips, labels, business cards). This gem builds print data (PREPEJ JSON) and renders it to PDF with the Reports.Web engine (C++ WebAssembly, Docker image ghcr.io/reportsweb/engine). Trial build: output carries a red SAMPLE mark until a purchased license file is configured in the engine.
