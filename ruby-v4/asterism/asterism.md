# asterism

**Tag**: filesystem

## 简介

Proxies for objects exposed by other Ruby processes and boards, a ROS 2 node speaking rmw_zenoh's wire format, CDR and generated message types. Pure Ruby; the same files are the mrbgem for mruby / PicoRuby.
