# sheetsu-ruby

**Tag**: web, networking

## 简介

Sheetsu (https://sheetsu.com) allows you to automate Google Spreadsheets and use them as a resource in a REST API. It's easier than using standard Google Spreadsheets API, because Sheetsu handles all the 'dirty' work for you.
