# rpm

**Tag**: library

## 简介

Ruby bindings for rpm. Almost a drop-in replacement for ruby-rpm. Uses FFI.

## 官网

- 源码仓库: https://github.com/dmacvicar/ruby-rpm-ffi

- 问题追踪: https://github.com/dmacvicar/ruby-rpm-ffi/issues
