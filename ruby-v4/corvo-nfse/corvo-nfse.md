# corvo-nfse

**Tag**: web, cli, networking, data

## 简介

A stdlib-only (net/http) Ruby client for the Corvo NFS-e electronic invoicing API: companies, certificates, invoices, webhooks, credits and billing, with result-style [data, error] returns and HMAC webhook verification.
