# timetabler

**Tag**: web, tooling

## 简介

Timetabler is a Polish public transportation timetable parser that allows you to extract bus schedules directly from websites in a code-friendly format.

## 官网

- 主页: https://github.com/kamilkowalski/timetable-parsers
- RubyGems: https://rubygems.org/gems/timetabler
