# image2pdf

**Tag**: cli, filesystem

## 简介

This is a pure Ruby command line program that converts a set of images
into a PDF document. It supports JPEG and PNG file formats.

Examples:
* image2pdf -o foo.pdf foo.jpg
* image2pdf -o bar.pdf bar/*.jpg
