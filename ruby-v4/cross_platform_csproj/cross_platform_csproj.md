# cross_platform_csproj

**Tag**: filesystem

## 简介

Offers functions which synchronize the file and folder structure to a CSharp project.  Users maintain a cross platform CSharp library using the file system.  Running these functions will update CSProject files to any changes as done on the file system.  This is particularly useful for creating cross platform libraries that would work with Windows, MonoAndroid and MonoTouch.
