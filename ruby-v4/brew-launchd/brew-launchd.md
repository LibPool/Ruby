# brew-launchd

**Tag**: library

## 简介

Companion tool for Brew (Mac Homebrew). An extension to start and stop Launchd services.

## 官网

- 主页: http://github.com/dreamcat4/brew-launchd
- RubyGems: https://rubygems.org/gems/brew-launchd

## 历史版本号

- 1.1.1 (2010-09-14)

## 获取地址

- RubyGems: https://rubygems.org/gems/brew-launchd
- gem 安装: `gem install brew-launchd`
- Bundler: `gem "brew-launchd"`
- 最新版本: 1.1.1
- 最新版归档: https://rubygems.org/downloads/brew-launchd-1.1.1.gem
- 版本锁定: `gem "brew-launchd", "~> 1.1.1"`
- 中央仓库: https://rubygems.org/
