# flood

**Tag**: testing

## 简介

Flood is a Ruby library for flood control. Flood control is limiting events processed to a maximum number in a specified time period.

## 官网

- 主页: http://github.com/nedski/flood
- RubyGems: https://rubygems.org/gems/flood
