# pico_phone

**Tag**: web

## 简介

pico_phone wraps Google's libphonenumber C++ library via a Rice native extension, providing phone number parsing, validation, and formatting for any country. It uses the same engine as Android's dialer and delivers native C++ performance for high-throughput server-side use.
