# samson_release_number_from_ci

**Tag**: tooling, devops

## 简介

Use this gem together with zendesk/samson, samson is a continuous deployment tool. By installing the gem, you can go to project setting page and choose your release number strategy. Currently it only supports samson's default and Buidkite's build number
