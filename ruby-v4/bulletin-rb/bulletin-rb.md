# bulletin-rb

**Tag**: web

## 简介

Bulletin persists, fingerprints, and triages the N+1 / unused-eager-loading / counter-cache warnings that Bullet detects, and exposes them through a mountable Rails engine — Flipper UI / PgHero style, with a Sentry-style issue model.
