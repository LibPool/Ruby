# cocoapods-hmap-simple

**Tag**: filesystem

## 简介

This plugin modifies HEADER_SEARCH_PATHS in Pods/Target Support Files/*/*.xcconfig
  replacing ${PODS_ROOT}/Headers/Public/* with a single hmap to speed up compilation.
