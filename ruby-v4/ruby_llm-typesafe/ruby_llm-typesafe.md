# ruby_llm-typesafe

**Tag**: library

## 简介

Adds a :typesafe provider to RubyLLM 2 that evaluates text or structured state against TypeSafe's typed Choice, Noul, and Score questions through Chat#with_schema. Structured output only: answers are calibrated probabilities, not generated text.
