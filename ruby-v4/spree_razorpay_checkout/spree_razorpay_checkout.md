# spree_razorpay_checkout

**Tag**: web

## 简介

Seamless Razorpay checkout integration for Spree 5.5. Features include Hotwire/Turbo compatibility, Zero Drop-off Webhook captures, native Spree Dashboard refunds, and the Affordability Widget.
