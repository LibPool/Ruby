# async-enumerable

**Tag**: networking

## 简介

Implementation of a subset of Ruby's Enumerable, using socketry/async to
perform operations in parallel wherever possible, while deferring to
Enumerable's implementation where not.

Async::Enumerable is in the same category as LazyEnumerable, but making a
different set of changes to how Enumerable works.
