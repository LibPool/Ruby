# fasttrack

**Tag**: web, data

## 简介

Fasttrack is an easy-to-use Ruby wrapper for
                      Exempi, a C library for managing XMP metadata.
                      Fasttrack provides a dead-easy, object-oriented
                      interface to Exempi's functions.
