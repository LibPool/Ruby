# runapi-gpt-image-2.5

**Tag**: web, cli

## 简介

The GPT Image 2.5 Ruby SDK provides text-to-image and image editing clients. Requests select `gpt-image-2.5-flare` or `gpt-image-2.5-sunburst`.
