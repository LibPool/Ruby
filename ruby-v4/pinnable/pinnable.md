# pinnable

**Tag**: web, cli, database, data

## 简介

A host-agnostic, mountable Rails engine for in-app visual feedback: enable it for some users, toggle comment mode, click any DOM element to leave a note that re-anchors on reload and is tracked open -> resolved. Hotwire/Stimulus, any database.
