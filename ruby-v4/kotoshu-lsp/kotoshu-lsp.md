# kotoshu-lsp

**Tag**: web, serialization

## 简介

Wraps the Kotoshu gem with a JSON-RPC LSP server so every LSP-capable editor (VS Code, Neovim, Emacs, JetBrains) gets inline spell-check diagnostics, code actions, and hover.
