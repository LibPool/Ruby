# spree_square

**Tag**: web, security

## 简介

Syncs a Square catalog (items, variations, categories, images, modifiers) into Spree Commerce, pushes completed Spree orders into Square as paid tickets, and keeps fulfillment status in sync in both directions via webhooks. Supports self-service OAuth ("Connect to Square" in the admin) as well as a hand-issued access token for local development.
