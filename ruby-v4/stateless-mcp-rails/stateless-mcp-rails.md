# stateless-mcp-rails

**Tag**: web

## 简介

Rails support for stateless-mcp: a tool is a controller action, routed by the Mcp-Method and Mcp-Name headers of the 2026-07-28 Model Context Protocol, and tools/list is drawn from the routes.
