# sequel-notion

**Tag**: web, database, data

## 简介

A Sequel database adapter that maps Notion databases and data sources to Sequel's Dataset interface. Supports multi-source databases, filtering, sorting, pagination, and CRUD operations via the Notion API (2026-03-11).
