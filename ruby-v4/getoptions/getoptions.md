# getoptions

**Tag**: cli, tooling

## 简介

Yet another command line option parser in Ruby, based on Perl's Getopt::Long module.

## 官网

- 主页: http://rubyforge.org/projects/getoptions/
- RubyGems: https://rubygems.org/gems/getoptions
