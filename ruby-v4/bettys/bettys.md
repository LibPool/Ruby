# bettys

**Tag**: cli

## 简介

Bettys is a terminal-based Tetris clone written in Ruby with ncurses, featuring four game modes (marathon, sprint, ultra, infinite), vim-style controls, hold piece, ghost piece, SRS rotation, and more.
