# paperclip_archive_processor

**Tag**: cli, filesystem

## 简介

Extract paperclip archive attachments to file or S3.

    Usage:

    has_attached_file :archive,
                      :url  => '/assets/games/assets/:id/archive.:extension',
                      :extract_archive => true
