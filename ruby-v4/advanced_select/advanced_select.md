# advanced_select

**Tag**: web, security, template, data

## 简介

AdvancedSelect provides helper-rendered Rails partials, Stimulus dropdown behavior, Turbo Stream-compatible option updates, plain CSS, and i18n defaults while leaving data loading, authorization, and endpoints to the host app.
