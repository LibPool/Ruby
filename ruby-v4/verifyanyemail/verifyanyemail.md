# verifyanyemail

**Tag**: web, cli, networking

## 简介

Official Ruby client for VerifyAnyEmail: real-time single and bulk email verification, catch-all/disposable/role detection, and signed batch webhooks. Built on the Ruby standard library (net/http) with no runtime dependencies.
