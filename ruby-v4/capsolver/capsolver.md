# capsolver

**Tag**: web, cli, testing, devops, data

## 简介

A Ruby client library for the Capsolver API. Supports ReCaptcha (V2/V3), Cloudflare (Turnstile), DataDome, GeeTest, MtCaptcha, AWS WAF, Yandex, and ImageToText.
