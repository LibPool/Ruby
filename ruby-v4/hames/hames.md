# hames

**Tag**: library

## 简介

Hames is a small plugin kernel for Ruby: services resolved by key in a context, typed events with four dispatch modes enforced at runtime, reversible registrations, and dependency-driven boot. It has no knowledge of LLMs and is reusable for any plugin-composed application. It is the kernel underneath the Terret agent harness.
