# activerecord-trino-adapter

**Tag**: web, cli, database, data

## 简介

A read-only ActiveRecord SQL adapter for Trino, built on top of the trino-client gem. Lets Rails applications query a Trino data warehouse using familiar ActiveRecord scopes, where clauses, and joins, while preventing accidental writes.
