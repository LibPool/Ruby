# themekit

**Tag**: library

## 简介

A tiny app that makes designing Yardstick Measure themes a whole lot more enjoyable.

## 官网

- 主页: http://github.com/yardstick/themekit
- RubyGems: https://rubygems.org/gems/themekit

## 历史版本号

- 0.1.0 (2010-02-25)

- RubyGems: https://rubygems.org/gems/themekit

- Bundler: `gem "themekit"`

- 最新版归档: https://rubygems.org/downloads/themekit-0.1.1.gem
