# huginn_live_tennis_agent

**Tag**: web, testing, security

## 简介

Polls the Live Tennis API (livetennisapi.com) and emits Huginn events on state transitions: match_started, score_changed, match_finished in live_scores mode, and new_fixture / fixture_updated in fixtures mode. Vendor-authored: we run the Live Tennis API. Uses only FREE-tier endpoints.
