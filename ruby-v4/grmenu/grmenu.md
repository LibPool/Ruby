# grmenu

**Tag**: cli

## 简介

GRmenu es una gema ligera para crear menus interactivos de navegacion en terminal (Linux/macOS/Windows) usando flechas arriba/abajo y Enter, con soporte para formularios multi-campo, modales 3D flotantes, control de fondo de ventana, Banners ASCII 3D, paleta de colores y estilos de marco, sin dependencias externas.
