# InforNutricional

**Tag**: library

## 简介

"Esta gema calcula datos relacionados con la información nutricional de un alimento como por ejemplo, las calorías, cantidad de grasas, proteinas, hidratos de carbono, azúcares, sal, entre otros. Así como el porcentaje de ingesta recomendada del alimento."
