# devise_social

**Tag**: security, tooling

## 简介

A Devise companion gem that wraps OmniAuth in a generator and a configuration DSL, so adding Google, Apple, GitHub, Facebook or Microsoft sign-in takes a single command. Placeholder release: the implementation ships in 0.1.0.
