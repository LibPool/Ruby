# vpndetection-rails

**Tag**: web

## 简介

Classifies the visitor behind each request - VPN, residential proxy, Tor, hosting, CDN, relay - and hands the answer to your controllers. Rack middleware, so it works in Sinatra, Hanami and Roda too; a Railtie inserts it for you in Rails.
