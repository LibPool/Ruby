# solrengine

**Tag**: web, cli, security, networking, tooling

## 简介

SolRengine gives Rails developers everything they need to build Solana dapps: wallet authentication (SIWS), RPC client, token portfolio, SOL transfers, and real-time WebSocket updates. One gem, full stack.
