# terret-core

**Tag**: library

## 简介

The core of the Terret agent harness: an append-only session log that is the single source of model-visible truth, a scoped tool registry with a vetoable execution pipeline, the agent turn/step loop as a replaceable plugin, and a provider-neutral LLM seam.
