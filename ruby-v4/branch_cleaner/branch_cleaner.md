# branch_cleaner

**Tag**: testing, filesystem

## 简介

Tired of cleaning your git repository's branches manually?
  This gem will delete all fully merged branches in your repo that are not
  1) the active branch
  2) the master branch
  3) any branch specified in your repo's .branches_to_keep file
