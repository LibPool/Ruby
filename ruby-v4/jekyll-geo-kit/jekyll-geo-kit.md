# jekyll-geo-kit

**Tag**: template

## 简介

Generates /<slug>.md companions for each post, declared via rel=alternate type=text/markdown, so LLM crawlers and AI agents can fetch clean Markdown instead of parsing HTML. Each document links back to the site's llms.txt index.
