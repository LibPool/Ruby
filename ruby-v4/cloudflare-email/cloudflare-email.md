# cloudflare-email

**Tag**: web, cli, template, devops

## 简介

A Ruby client and Rails integration for Cloudflare's Email Service. Send mail via an ActionMailer delivery method, receive mail via an ActionMailbox ingress backed by a shipped Cloudflare Email Worker template.
