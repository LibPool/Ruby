# r2corba

**Tag**: tooling

## 简介

OMG CORBA v3.3 compliant CORBA language mapping implementation for Ruby. Depends on ridl gem for providing native Ruby IDL compiler.

## 官网

- 主页: https://www.remedy.nl/opensource/r2corba.html
- 源码仓库: https://github.com/RemedyIT/r2corba
- 问题追踪: https://github.com/RemedyIT/r2corba/issues
- RubyGems: https://rubygems.org/gems/r2corba
