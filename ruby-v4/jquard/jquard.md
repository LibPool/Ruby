# jquard

**Tag**: web, tooling

## 简介

Jquard is a mountable Rails engine for building modern admin panels with a chainable resource DSL inspired by Filament (PHP). It generates Filament-style index, create and edit pages from your models, built on Rails defaults: Hotwire, Propshaft and precompiled Tailwind CSS.
