# asterism-games

**Tag**: web, cli, networking, devops

## 简介

A framework for the server side of a game on an Asterism network: the host (tables exposed as Asterism objects, the state put and saved, who is there, time), the rooms of an Asterism console and the permanent tables next to them. A game subclasses AsterismGames::Game and AsterismGames::Remote and writes only its rules and the methods it exposes. Comes with othello and a shared drawing board as samples, terminal clients for othello and mahjong (asterism-games play), and a mahjong commentator that draws a table in the browser (asterism-games commentate).
