# assinafy

**Tag**: web, security, template

## 简介

Ruby SDK for Assinafy. Covers the documented authentication, OAuth 2.1, account, user, document, signer, assignment, webhook, template, tag, and field APIs, plus the high-level upload_and_request_signatures helper.
