# rfid4r

**Tag**: library

## 简介

An RFID middleware using a Ruby wrapper for the PhidgetRFID-1023 reader.

## 官网

- 主页: http://rfid4r.rubyforge.org
- RubyGems: https://rubygems.org/gems/rfid4r

## 历史版本号
