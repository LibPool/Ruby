# pdfium

**Tag**: template

## 简介

Ruby bindings for Google's PDFium project.  It supports extracting text and images from PDF's as well as rendering pages to bitmaps

## 官网

- 文档: https://www.rubydoc.info/gems/pdfium/0.0.2
- RubyGems: https://rubygems.org/gems/pdfium
