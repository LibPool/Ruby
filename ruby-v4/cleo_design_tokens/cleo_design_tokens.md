# cleo_design_tokens

**Tag**: web

## 简介

Flattens Cleo's colour design tokens (packages/tokens/tokens/color) into frozen colors.primitives / colors.semantic lookups, with the theme passed alongside the key, plus a code-owned base-unit spacing API.
