# rom-tiger_beetle

**Tag**: library

## 简介

Experimental TigerBeetle support for ROM. Accounts and Transfers only, append-only, batch create + id lookup — no arbitrary queries, updates, or deletes, matching what the TigerBeetle protocol actually supports.
