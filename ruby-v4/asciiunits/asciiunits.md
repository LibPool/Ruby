# asciiunits

**Tag**: cli

## 简介

Checksummed parsanol PARG artifact, terminal tables and oracle-frozen conformance corpus for the unitsml(...) expression syntax of UnitsML. Runtime-agnostic: load the artifact with any Parsanol runtime (Ruby, Rust, wasm).
