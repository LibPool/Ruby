# nfe-io

**Tag**: library

## 简介

Official NFE.io SDK for Ruby — modern Ruby (3.2+), zero runtime dependencies, for issuing and managing Brazilian electronic fiscal documents (NFS-e, NF-e, NFC-e, CT-e).
