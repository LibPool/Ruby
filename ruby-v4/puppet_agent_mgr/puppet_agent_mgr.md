# puppet_agent_mgr

**Tag**: serialization, filesystem

## 简介

A simple library that wraps the logic around the locks, pids, JSON filesu and YAML files that makes up the Puppet Agent status.  Suppots Puppet 2.7.x and 3.0.x.
