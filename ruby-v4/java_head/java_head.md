# java_head

**Tag**: library

## 简介

JavaHead contains classes to represent Java packages and classes and to compile and execute them in Ruby. Use this in scripts to run Java programs from Ruby, or in IRB to develop Java in a sensible environment. Write simple code in both Java and Ruby and JavaHead will link them for you.
