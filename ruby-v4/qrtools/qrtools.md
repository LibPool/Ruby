# qrtools

**Tag**: library

## 简介

QRTools is a library for decoding QR Codes.  It relies on libdecodeqr for decoding.

## 官网

- 主页: http://qrtools.rubyforge.org/
- RubyGems: https://rubygems.org/gems/qrtools

- 1.0.0 (2009-07-25)
