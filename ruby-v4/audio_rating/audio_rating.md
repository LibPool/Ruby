# audio_rating

**Tag**: filesystem

## 简介

Library for reading embedded star-ratings in audio files.

Supports file formats: AIFF, FLAC, M4A, MP3, Ogg and WAV.

Uses library TagLib and Ruby interface taglib-ruby.
