# git-svn-mirror

**Tag**: library

## 简介

A command-line tool that automates the task of creating a GIT mirror for a SVN repo, and keeping it up-to-date.

## 官网

- 主页: http://github.com/alloy/git-svn-mirror
- RubyGems: https://rubygems.org/gems/git-svn-mirror
