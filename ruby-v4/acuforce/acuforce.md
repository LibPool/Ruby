# acuforce

**Tag**: web, filesystem, data

## 简介

Provides an API for the following actions:
* Logging in and Logging out
* Creating a sprint
* Finding a sprint
* Uploading tasks to a sprint from a CSV file
* Exporting tasks in a sprint to a CSV file
