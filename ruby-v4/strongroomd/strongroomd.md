# strongroomd

**Tag**: web, cli, database, security

## 简介

Prebuilt binaries of strongroomd, a Postgres-first authentication kernel that acts as the application's security coprocessor, and its strongroom-admin CLI. Each platform gem bundles both executables with a SHA-256 manifest the launchers check before running them; the platformless gem runs only an explicitly configured binary of the same version. Pair it with strongroom-rails.
