# versioner

**Tag**: web, serialization, filesystem

## 简介

Easily manage a version number for your Rails app. The version is stored in a YAML file within your app.

## 官网

- 主页: https://github.com/chaione/versioner
- RubyGems: https://rubygems.org/gems/versioner
