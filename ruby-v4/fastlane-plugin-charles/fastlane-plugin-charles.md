# fastlane-plugin-charles

**Tag**: serialization, filesystem

## 简介

Runs Charles Proxy from a fastlane lane, generating its .config file at runtime from a simplified YAML config that a team can commit and share, instead of hand-editing the XML Charles itself exports.
