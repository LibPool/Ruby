# cardinal-ai

**Tag**: web, networking

## 简介

Cardinal AI is a local, per-repo AI Kanban tool: columns are policies, cards become Claude-powered worker agents, and work ships as pull requests. Run `cardinal` inside any git repository to get a board for it at http://localhost:4000.
