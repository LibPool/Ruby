# rubytidy

**Tag**: library

## 简介

A tool to mimic "perltidy" for tidying up Ruby source

## 官网

- 主页: https://github.com/headius/rubytidy
- RubyGems: https://rubygems.org/gems/rubytidy

## 获取地址

- RubyGems: https://rubygems.org/gems/rubytidy

- Bundler: `gem "rubytidy"`
- 最新版本: 1.0
- 最新版归档: https://rubygems.org/downloads/rubytidy-1.0.gem
