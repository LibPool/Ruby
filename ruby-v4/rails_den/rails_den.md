# rails_den

**Tag**: web

## 简介

RailsDen is a full-featured Rails-native community platform from Oak Harbor Ventures, LLC. Distributed as one gem, RailsDen can run as a standalone community application or mount inside an existing Rails application, with forums, Classic and 3D Chat, moderation, private messaging, engagement, advertising and sponsorships, and plugin and theme support.
