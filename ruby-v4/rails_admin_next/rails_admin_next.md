# rails_admin_next

**Tag**: web, data

## 简介

A Rails engine that auto-generates an easy-to-use admin interface for your ActiveRecord data. A modernized fork of RailsAdmin, originally created by Erik Michaels-Ober, Bogdan Gaza, and contributors.
