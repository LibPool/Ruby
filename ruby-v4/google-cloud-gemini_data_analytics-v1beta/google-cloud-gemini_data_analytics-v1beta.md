# google-cloud-gemini_data_analytics-v1beta

**Tag**: web, cli, testing, tooling, devops, data

## 简介

Developers can use the Conversational Analytics API, accessed through geminidataanalytics.googleapis.com, to build an artificial intelligence (AI)-powered chat interface, or data agent, that answers questions about structured data in BigQuery, Looker, and Looker Studio using natural language. Note that google-cloud-gemini_data_analytics-v1beta is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-gemini_data_analytics instead. See the readme for more details.
