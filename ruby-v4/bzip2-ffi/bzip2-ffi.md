# bzip2-ffi

**Tag**: filesystem, data

## 简介

Bzip2::FFI is a Ruby wrapper for libbz2 using FFI bindings.

    The Bzip2::FFI Reader and Writer classes support reading and writing bzip2
    compressed data as an IO-like stream.
