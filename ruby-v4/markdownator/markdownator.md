# markdownator

**Tag**: serialization, template, filesystem, data

## 简介

Markdownator converts PDF, Word, Excel, PowerPoint, EPUB, HTML, CSV, JSON, XML, ZIP archives and images into clean Markdown suitable for large language models, using a pluggable converter architecture.
