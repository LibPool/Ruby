# mygem

**Tag**: library

## 简介

This is a simple example on how to create a gem and publish it on rubygems.org [flavored with bundler]

## 官网

- 主页: http://www.makevoid.com
- RubyGems: https://rubygems.org/gems/mygem

## 历史版本号

- 0.0.1 (2010-08-08)

## 获取地址

- RubyGems: https://rubygems.org/gems/mygem
- gem 安装: `gem install mygem`
- Bundler: `gem "mygem"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/mygem-0.0.1.gem
- 版本锁定: `gem "mygem", "~> 0.0.1"`
- 中央仓库: https://rubygems.org/
