# konpeito

**Tag**: tooling

## 简介

Konpeito is a gradually typed ahead-of-time compiler for Ruby with Hindley-Milner type inference and dual LLVM/JVM backends. Compile Ruby to CRuby C extensions (.so) or standalone JARs with seamless Java interop. Includes Castella UI, a reactive GUI framework powered by Skia, based on a port of Castella for Python (github.com/i2y/castella).
