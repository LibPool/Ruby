# grape_odata

**Tag**: web, cli, testing, networking, data

## 简介

The ODATA query pattern allows API's to talk to clients like Microsoft Excel, and other very popular client applications in a uniform way. If HTTP REST is the protocol, ODATA is a specific pattern that API's follow.
