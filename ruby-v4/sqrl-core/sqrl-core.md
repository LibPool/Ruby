# sqrl-core

**Tag**: web, cli, security

## 简介

A complete implementation of Steve Gibson's SQRL authentication protocol: EnScrypt, EnHash, the identity lock, S4 identity storage, the textual identity format, the client transaction state machine and a server-side protocol handler.
