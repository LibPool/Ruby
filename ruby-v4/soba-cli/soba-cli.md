# soba-cli

**Tag**: cli

## 简介

Soba is an autonomous CLI tool that fully automates GitHub Issue-driven development workflows. It monitors issues, creates implementation plans, generates code, and manages pull requests through seamless integration with Claude Code AI, enabling hands-free development cycles.
