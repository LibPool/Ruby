# selenium_screencast

**Tag**: web, testing

## 简介

Captures JPEG frames from Chrome via the CDP Page.startScreencast API and encodes them into a webm video with ffmpeg. Wires into RSpec/Capybara system specs with a single require, and its behavior (enable/disable, slow-motion factor, ffmpeg binary, debug output) can be controlled via environment variables.
