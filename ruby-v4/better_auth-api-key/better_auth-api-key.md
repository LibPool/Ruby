# better_auth-api-key

**Tag**: web, security, data

## 简介

Adds API key creation, verification, management, quotas, metadata, and permissions for Better Auth Ruby. Includes storage modes. Also supports API-key-backed sessions. Better Auth Ruby is an independent modern authentication framework for Ruby inspired by Better Auth.
