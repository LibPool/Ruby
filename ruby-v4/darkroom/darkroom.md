# darkroom

**Tag**: web, testing, filesystem

## 简介

Darkroom provides web asset compilation, bundling, and minification without any external tools, manifest files, or special comment syntax. CSS and JavaScript bundles are automatically generated based on import statements native to each language. Darkroom is also extensible, allowing support to be added for arbitrary file types.
