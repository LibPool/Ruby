# stoogish_treasure_hunt

**Tag**: library

## 简介

THIS IS A GAME WHERE YOU INPUT THE PLAYERS AND NUMBER OF ROUNDS AND THEY
RANDOMLY GET THEIR HEALTH, SCORE, POINTS AND TREASURES PRINTED TO THE SCREEN.
