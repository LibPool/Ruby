# css2less

**Tag**: library

## 简介

A ruby library which convert old CSS stylesheet into LESS dynamic stylesheet.

## 官网

- 主页: https://github.com/thomaspierson/libcss2less
- RubyGems: https://rubygems.org/gems/css2less

- 0.0.1 (2013-02-02)
- 0.0.0 (2012-04-23)
