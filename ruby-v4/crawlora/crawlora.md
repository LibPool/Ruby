# crawlora

**Tag**: web, cli, security, template, data

## 简介

Crawlora is a web-scraping API for structured public web data — search, marketplace, social, finance, media, reviews, and geodata — without running your own scrapers. This gem is the official, typed, batteries-included Ruby client: grouped helpers (client.bing.search) and dynamic operation calls for every endpoint, API-key and JWT auth, automatic retries with exponential backoff and Retry-After, numeric and cursor pagination, before/after middleware hooks, and client-side rate limiting.
