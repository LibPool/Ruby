# asciidoctor-beautify-uri

**Tag**: web, template, tooling

## 简介

An asciidoctor extension providing a uri:: block macro that resolves a
Spotify or YouTube URI live at build time (via oEmbed, no caching) and
renders a branded card carrying the resolved title, artist or channel,
a thumbnail, and a plain link out. Cards participate in the document's
cross-reference and counter system. A companion uri: inline macro cites
a track/video in running prose, optionally as a live Spotify Code
(code=true); layout=album renders a vertical Spotify card built around
one. Third-party providers register without modifying this gem.
