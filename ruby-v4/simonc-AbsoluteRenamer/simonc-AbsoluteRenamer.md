# simonc-AbsoluteRenamer

**Tag**: filesystem

## 简介

Unlike many batch renaming tools, AbsoluteRenamer is able to rename folders. AbsoluteRenamer is modular and can be extended to adapt itself to any kind of file or to add new options and features.
