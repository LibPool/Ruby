# acts-as-tbackend

**Tag**: web, cli, security, networking

## 简介

Pooled, circuit-broken, idempotent client for TBackend: persistent framed sockets, write_fact_once with deterministic ids, token auth, and a connection pool sized for multi-threaded Rails.
