# metanorma-mirror

**Tag**: serialization, template

## 简介

A typed node tree (blocks, inlines, marks) projected from Metanorma document models, with serializers and an output pipeline. metanorma-document and metanorma-standoc register their model classes; the format is the wire contract for renderers and tooling (the SMART document reader, the HTML JS renderer).
