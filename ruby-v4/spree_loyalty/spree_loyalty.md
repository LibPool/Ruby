# spree_loyalty

**Tag**: library

## 简介

A POS-agnostic points loyalty program for Spree Commerce: customers earn points on completed orders and redeem them for real Spree::StoreCredit, spendable through the store's existing Store Credit payment method — no new checkout code needed. Independent of any point-of-sale or payment provider.
