# motion-rubygems

**Tag**: library

## 简介

Not all (or even many) gems will work out of the box on RubyMotion. However some do, so it'd be nice to be able to use them.

## 官网

- 主页: http://github.com/ConradIrwin/motion-rubygems
- RubyGems: https://rubygems.org/gems/motion-rubygems
