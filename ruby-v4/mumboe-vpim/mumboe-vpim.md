# mumboe-vpim

**Tag**: data

## 简介

This is a pure-ruby library for decoding and encoding vCard and iCalendar data
("personal information") called vPim.

## 官网

- 主页: http://vpim.rubyforge.org
- RubyGems: https://rubygems.org/gems/mumboe-vpim
