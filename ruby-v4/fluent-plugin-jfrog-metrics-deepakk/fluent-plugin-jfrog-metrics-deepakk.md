# fluent-plugin-jfrog-metrics-deepakk

**Tag**: data

## 简介

Fluentd Plugin for converting JFrog Artifactory, Xray generated metrics (Prometheus Exposition Format) to target observability platform format (Splunk HEC, New Relic, DataDog)
