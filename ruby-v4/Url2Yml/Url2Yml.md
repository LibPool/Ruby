# Url2Yml

**Tag**: database, data

## 简介

Convert Heroku Style Database URLS into hashes you can plug into ActiveRecord::Base.establish_connection

## 官网

- 主页: http://elrikgroup.com/url2yml
- RubyGems: https://rubygems.org/gems/Url2Yml
