# jwt-pq

**Tag**: security

## 简介

Adds ML-DSA-44, ML-DSA-65, and ML-DSA-87 post-quantum signature algorithms to the ruby-jwt ecosystem, with optional hybrid EdDSA + ML-DSA mode. Uses liboqs via FFI.
