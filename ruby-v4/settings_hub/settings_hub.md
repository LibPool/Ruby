# settings_hub

**Tag**: web

## 简介

SettingsHub owns a settings page, the list of sections on it, the route each section is served at, and the check for who may see a section. It ships user sections itself, and other gems and the app register their own. Each thing a person can do is a plain object a page or an API can call.
