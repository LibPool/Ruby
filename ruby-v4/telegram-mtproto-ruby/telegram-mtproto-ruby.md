# telegram-mtproto-ruby

**Tag**: security

## 简介

A complete Ruby implementation of Telegram's MTProto 2.0 protocol with DH handshake, AES-IGE encryption, and TL schema support. Includes auth.sendCode, auth.signIn, contacts.getContacts, messages.sendMessage, and updates.getDifference methods.
