# overture_maps

**Tag**: web, data

## 简介

Download, import, query, sync, and serve Overture Maps open geospatial data: bbox-filtered GeoParquet extracts via DuckDB, PostGIS imports with GERS changelog syncing, an ad-hoc query API, a mountable REST/MVT engine, and an MCP server. Unofficial community gem, not affiliated with the Overture Maps Foundation.
