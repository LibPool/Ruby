# rusty_engine_ffi

**Tag**: library

## 简介

The Rust Engine is a tiny library written in rust to perform simple images manipulations.
    For now the library included four functions :
    - Image converter
    - Pixel sorting
    - Brush and Slim : two algorithms that will mess with the given image
