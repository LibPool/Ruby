# qualm

**Tag**: template

## 简介

qualm fails a pull request when an experienced reviewer would ask for the change to be simplified, and it tells the coding agent what to fix. It is a single Go binary that lives at github.com/tools4imps/qualm. This gem holds the name for the Ruby wrapper that will install that binary. Version 0.0.1 installs no command.
