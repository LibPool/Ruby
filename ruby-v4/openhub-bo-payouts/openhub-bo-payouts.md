# openhub-bo-payouts

**Tag**: library

## 简介

Pagos a terceros (QR y lotes ACH) vía Red Enlace (ATC) OpenHub, Bolivia. Núcleo en Rust compartido con los paquetes openhub-bo de Python y TypeScript. Integración no oficial, sin afiliación con Red Enlace (ATC).
