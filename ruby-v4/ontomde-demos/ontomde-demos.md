# ontomde-demos

**Tag**: web, testing, networking

## 简介

Installer for all ontomde demos.  == FEATURES:  Please refer to each specific enclosed demo.  === INSTALLATION: 1) download and install a ruby distribution (&gt;=1.8.6) ( http://rubyforge.org/frs/?group_id=167&amp;release_id=17128 ) 2) update ruby plateform $  set HTTP_PROXY=http://yourproxy:yourport (in case you need one) $  gem update --system 3) install ontomde-demo $  set HTTP_PROXY=http://yourproxy:yourport (in case you need one) $ gem install ontomde-demo
