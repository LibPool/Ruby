# jekyll-shopsavvy

**Tag**: tooling

## 简介

Adds {% shopsavvy_product %}, {% shopsavvy_deals %}, {% shopsavvy_price %} Liquid tags and a shopsavvy_lookup filter for embedding live product cards, deal feeds, and price lookups in Jekyll sites at build time.
