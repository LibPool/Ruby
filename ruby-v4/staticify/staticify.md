# staticify

**Tag**: web

## 简介

Tool for staticly caching Ruby web applications (based on Rack::Staticifier)

## 官网

- 主页: http://github.com/remi/staticify
- RubyGems: https://rubygems.org/gems/staticify

- RubyGems: https://rubygems.org/gems/staticify

- Bundler: `gem "staticify"`

- 最新版归档: https://rubygems.org/downloads/staticify-0.1.1.gem
