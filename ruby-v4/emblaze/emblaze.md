# emblaze

**Tag**: web, devops, filesystem

## 简介

Simple rake task to deploy a static website to aws s3
  Minifies and gzips assets.
  Requires ENV variables (can be read from .env or travis if in CI) :
  AWS_REGION
  AWS_BUCKET_NAME
  AWS_SECRET_KEY
  AWS_ACCESS_KEY
