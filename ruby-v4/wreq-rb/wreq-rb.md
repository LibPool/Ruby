# wreq-rb

**Tag**: web, cli, networking

## 简介

An ergonomic Ruby HTTP client powered by Rust's wreq library, featuring TLS fingerprint emulation (JA3/JA4), HTTP/2 support, cookie handling, proxy support, and redirect policies.
