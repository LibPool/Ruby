# widegita

**Tag**: web, cli

## 简介

API client for widegita.com. Access 18 Gita chapters, 700 verses with Sanskrit text and commentaries, Upanishads, Yoga Sutras of Patanjali, Hindu deities, philosophical concepts, topics, and Sanskrit glossary. Zero dependencies.
