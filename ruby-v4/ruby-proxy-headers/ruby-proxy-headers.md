# ruby-proxy-headers

**Tag**: web, networking

## 简介

Extensions for Ruby HTTP stacks to send custom headers on HTTPS CONNECT to a proxy
and read headers from the proxy CONNECT response (e.g. X-ProxyMesh-IP).
