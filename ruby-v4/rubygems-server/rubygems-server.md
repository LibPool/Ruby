# rubygems-server

**Tag**: web

## 简介

Gem::Server and allows users to serve gems for consumption by `gem --remote-install`.

- 主页: https://github.com/rubygems/rubygems-server
- RubyGems: https://rubygems.org/gems/rubygems-server
