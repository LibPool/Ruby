# solunar

**Tag**: serialization, devops, data

## 简介

A gem that wraps the C code from Rick Dawson that computes the sun and moon times based on date and coordinates. Takes a series of arguments, and returns a JSON of the hunting/fishing solunar forecast. While designed for hunting and fishing applications, this may be useful to other apps that need solar or lunar data.
