# logstash-input-jsqs_iam

**Tag**: library

## 简介

This gem is a logstash plugin required to be installed on top of the Logstash core pipeline using $LS_HOME/bin/plugin install logstash-input-jsqs_iam. This gem is not a stand-alone program
