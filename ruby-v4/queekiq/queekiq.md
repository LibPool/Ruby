# queekiq

**Tag**: database

## 简介

Queekiq is a small, framework-agnostic job queue built on Redis Streams, with no dependencies beyond the redis gem: consumer groups for parallel workers, reclaiming of abandoned messages, retries with backoff and a dead-letter stream, delayed re-enqueueing (deferral), heartbeats for long jobs, graceful shutdown, reconnection and built-in instrumentation.
