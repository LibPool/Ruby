# usernotification

**Tag**: filesystem

## 简介

You will have to create a notification table with:
notification table=&gt; user_id:who should get notified, UID:who created the notification, kind:what type of notification, seen:if the notification is read by the user or not.
The gem file will return a message and a link to know more details of the notification. 
Gem methods: read(notification_id, user_profile), link(notification_id, user_profile)
