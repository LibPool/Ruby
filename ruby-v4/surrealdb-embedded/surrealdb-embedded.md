# surrealdb-embedded

**Tag**: database, filesystem, data

## 简介

Adds embedded database support (mem://, surrealkv://, file://) to the SurrealDB Ruby SDK via FFI bindings to libsurrealdb_c. Requires libsurrealdb_c to be installed or SURREALDB_LIB_PATH to be set.
