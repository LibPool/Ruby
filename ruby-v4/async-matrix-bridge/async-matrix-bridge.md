# async-matrix-bridge

**Tag**: web, security, networking

## 简介

The server side of a Matrix bridge or bot: a Rack application that authenticates and deduplicates homeserver transactions, then hands each event to a block you pattern match on, concurrently. Built on async-matrix and the Socketry async ecosystem.
