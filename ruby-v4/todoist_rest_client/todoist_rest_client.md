# todoist_rest_client

**Tag**: web, cli

## 简介

Wraps the Todoist REST v1 and Sync v9 APIs with typed domain objects for tasks, projects, labels, sections, and comments, plus scheduling helpers for spreading tasks across days and numbered projects.
