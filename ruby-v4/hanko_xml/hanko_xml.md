# hanko_xml

**Tag**: serialization

## 简介

hanko_xml signs and verifies XML-DSig signatures by binding to libxmlsec1 through a Rust extension built with Magnus and rb-sys. It works with Nokogiri documents when Nokogiri is loaded, and verifies plain bytes without it.
