# mdom

**Tag**: template

## 简介

MDOM parses CSM documents into a document tree (AST) and translates it to Ruby source (safe by default: no embedded code is emitted) or to HTML. Markdown is treated as syntactic sugar for Ruby, so a `.rb.md` document is both readable Markdown and an executable Ruby program.
