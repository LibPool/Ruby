# the_whos

**Tag**: library

## 简介

Trabaja con los ID de IMDB para devolver en forma de array informacion como:/n
                  - los actores en una película y su sinopsis/n
                  - las películas de un actor/n
                  - las coincidencia entre películas y entre actores.
