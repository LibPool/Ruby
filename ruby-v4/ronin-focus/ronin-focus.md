# ronin-focus

**Tag**: web, cli

## 简介

ronin is a terminal focus timer with bushido spirit. Pomodoro sessions with warrior quotes on completion, shame on abandonment, and streak tracking. Zero dependencies. Runs on Ruby stdlib only.
