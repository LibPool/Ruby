# mt-wall

**Tag**: library

## 简介

mt-wall is a Ruby DSL and toolchain for declaratively describing MikroTik (RouterOS) firewall configuration -- address objects, groups, access rules and default policies -- and reconciling it onto devices with a Terraform-style plan/apply workflow suited to GitOps.
