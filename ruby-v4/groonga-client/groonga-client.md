# groonga-client

**Tag**: web, cli, testing, networking, template

## 简介

Groonga-client gem supports HTTP or
[GQTP (Groonga Query Transfer Protocol)](http://groonga.org/docs/spec/gqtp.html)
as the protocol using a client.
