# pushizo

**Tag**: web, networking

## 简介

Pushizo public API istemcisi: bildirim gönderme, kullanıcı/abonelik yönetimi, segment/şablon/kampanya ve webhook imza doğrulaması (Net::HTTP, bağımlılıksız).
