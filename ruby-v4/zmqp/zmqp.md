# zmqp

**Tag**: library

## 简介

Drop-in replacement for async AMQP library based on ZMQ/ZmqMachine (pre-alpha!).

- 主页: http://github.com/arvicco/zmqp
- RubyGems: https://rubygems.org/gems/zmqp
