# fluent-plugin-devo-radiant

**Tag**: library

## 简介

A production-hardened fork of fluent-plugin-devo 1.2.0 with buffered retry semantics, credential masking, multi-worker support, configurable minimum TLS versions, and a collision-free vendored syslog TLS namespace.
