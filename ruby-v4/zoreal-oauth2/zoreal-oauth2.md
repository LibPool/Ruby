# zoreal-oauth2

**Tag**: security

## 简介

The relying-party half of Login with ZOREAL: exchanges the authorization code your frontend received from @zoreal/oauth2-react, verifies the ID token against the provider's JWKS, and reads personal claims from /userinfo.
