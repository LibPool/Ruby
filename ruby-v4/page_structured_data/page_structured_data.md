# page_structured_data

**Tag**: web, serialization, template, data

## 简介

PageStructuredData keeps Rails SEO metadata, social sharing tags, and schema.org JSON-LD in one page object and one view partial. It renders page titles, basic meta tags, Open Graph tags, Twitter Card tags, breadcrumb JSON-LD, article and forum post JSON-LD, Person, Organization, and WebSite JSON-LD, and public interaction statistics.
