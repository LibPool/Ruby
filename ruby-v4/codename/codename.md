# codename

**Tag**: library

## 简介

Codename gem randomly generate codename based on list of names.

Supported names:

* stars          -  Western constellation names
* elements       -  Elements names
* colors         -  Color names
* cyclones       -  Names of tropical cyclones
* random         -  Random numbers (00000 - 99999)
