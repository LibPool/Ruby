# terret-mcp

**Tag**: web, cli, networking

## 简介

Mounts Model Context Protocol servers (stdio and streamable HTTP, via the manceps client) as namespaced tool sources behind ctx.tools, with per-server approval policy, per-call timeouts, and live tool-list reconciliation.
