# pzem016

**Tag**: web, cli, networking, template

## 简介

PZEM-016 is a cheap power monitoring thing you can get from aliexpress for usually very little money https://www.aliexpress.com/w/wholesale-pzem%2525252d016.html?spm=a2g0o.best.search.0.  This gem provides a library to talk to them with and some cli utils
