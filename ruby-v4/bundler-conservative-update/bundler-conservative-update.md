# bundler-conservative-update

**Tag**: testing

## 简介

Re-executes `bundle update` with --conservative, so only the gems you name are updated and transitive dependencies stay locked. Explicit strategies (--patch, --minor, --major, --strict), explicit scopes (--all, --source, --bundler, --ruby) and an opt-out are respected.
