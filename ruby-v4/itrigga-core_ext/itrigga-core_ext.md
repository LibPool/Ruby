# itrigga-core_ext

**Tag**: template, data

## 简介

Adds methods for 
    Hash: 
    - symbolize_keys
    - recursive_symbolize_keys
    Array:
    - to_csv (requires FasterCSV gem if ruby 1.8)
    - select_with_index
    - to_auto_complete_list
    - active_record_type_condition_rendering
