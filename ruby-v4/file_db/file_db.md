# file_db

**Tag**: database, filesystem, data

## 简介

You need to store informationen in a CSV File, because there is no need for a database? You can use FileDb to store all informationen in a CSV File and search in it like ActiveRecord (User.find(1212). See detailed Information at the github Page.
