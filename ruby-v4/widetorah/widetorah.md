# widetorah

**Tag**: web, cli

## 简介

API client for widetorah.com. Access 24 books of the Tanakh, 54 parashot, 63 Talmud tractates with daf pages, Mishnah, Rashi commentary, Jewish holidays, biblical figures, topics, and Hebrew/Aramaic glossary. Zero dependencies.
