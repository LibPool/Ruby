# fluent-plugin-splunk-hec-radiant

**Tag**: web, networking

## 简介

A modernized and actively maintained Fluentd output plugin for Splunk HTTP Event Collector (HEC) with updated dependencies, improved performance, and Ruby 3.x support. Forked from the original Splunk plugin with enhancements and bug fixes.
