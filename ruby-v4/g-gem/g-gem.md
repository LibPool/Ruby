# g-gem

**Tag**: library

## 简介

g-gem is a plugin for rubygems for integration with the gentoo's portage system

## 官网

- 主页: http://www.rubyforge.org/projects/g-gem
- RubyGems: https://rubygems.org/gems/g-gem

## 历史版本号

- 0.1.0 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/g-gem

- Bundler: `gem "g-gem"`

- 最新版归档: https://rubygems.org/downloads/g-gem-0.1.0.gem
