# git-2-s3

**Tag**: web, devops, filesystem

## 简介

A deployment strategy that takes a github repository and pushes the files into an S3 bucket using capistrano

## 官网

- 主页: http://github.com/heyaustria/git-2-s3
- RubyGems: https://rubygems.org/gems/git-2-s3
