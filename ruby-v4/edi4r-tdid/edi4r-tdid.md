# edi4r-tdid

**Tag**: web, networking, data

## 简介

The edi4r gem turns Ruby into a powerful EDI mapping language.

    This add-on gem provides the bulk of UN's Trade Data Interchange Directories.
    It enables you to process UN/EDIFACT data based on all TDIDs
    from 90.2 up to D.14B.
