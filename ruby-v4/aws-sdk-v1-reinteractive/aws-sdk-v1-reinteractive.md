# aws-sdk-v1-reinteractive

**Tag**: security, devops

## 简介

Version 1 of the AWS SDK for Ruby. Available as both `aws-sdk` and `aws-sdk-v1`.
Use `aws-sdk-v1` if you want to load v1 and v2 of the Ruby SDK in the same
application.

Patched by reinteractive to make the code be able to handle the new
AWS long security groups IDs.
