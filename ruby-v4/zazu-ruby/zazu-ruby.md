# zazu-ruby

**Tag**: web, networking

## 简介

Faraday-based Ruby SDK for the Zazu payment platform API. Wraps accounts, customers, invoices, payment links, transactions, and webhook endpoints. HTTPX adapter for HTTP/2 + persistent connections.
