# redis-actionpack

**Tag**: web, database

## 简介

Redis session store for ActionPack. Used for storing the Rails session in Redis.

## 官网

- 主页: http://redis-store.org/redis-actionpack
- 源码仓库: https://github.com/redis-store/redis-actionpack
