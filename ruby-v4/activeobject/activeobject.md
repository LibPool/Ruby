# activeobject

**Tag**: devops

## 简介

Active Object是用来访问LightCloud/TokyoCabinet/TokyoTyrant的工具，实现了持久化数据与对象的映射。 它类似于ActiveRecord，提供一组访问LightCloud/TokyoCabinet/TokyoTyrant的方法以及验证规则、回调函数和观察器。
