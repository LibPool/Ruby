# rails_google_map

**Tag**: web, template

## 简介

Rails view helpers that render an embedded Google Map from an address or lat/lng pair. Uses the Maps Embed API when an API key is configured and falls back to Google's keyless embed endpoint when it is not, so a map works without a key or a billing account.
