# icaprb-filter

**Tag**: web, networking

## 简介

Filter framework for ICAPrb-server. Does not work standalone. This gem includes a framework to create a content filter which allows to filter content instead of only the urls. It is extensible by plug ins. For example it can be used to enforce your companies network usage policies at the proxy.
