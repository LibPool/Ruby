# pgdd

**Tag**: web, database, data

## 简介

Boots a Rails application, reads its live database(s) and its ActiveRecord models, and writes Markdown database documentation: an index, one page per table with columns, keys, indexes, constraints, triggers, the migrations that changed it and the models backed by it, plus Graphviz entity relationship diagrams that link back to the pages.
