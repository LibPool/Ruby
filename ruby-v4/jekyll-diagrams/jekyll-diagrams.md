# jekyll-diagrams

**Tag**: library

## 简介

A Jekyll plugin with support for Blockdiag, Erd, GraphViz, Mermaid,
Nomnoml, PlantUML, Svgbob, Syntrax, Vega, Vega-Lite and WaveDrom.
