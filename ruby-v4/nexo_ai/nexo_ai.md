# nexo_ai

**Tag**: library

## 简介

An opinionated, drop-in agent harness for RubyLLM. Nexo composes the RubyLLM ecosystem into one coherent front door, adding a Sandbox+Permissions seam and a WorkflowRun lifecycle primitive.
