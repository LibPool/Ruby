# guitarparty-ruby

**Tag**: web, cli, networking

## 简介

Easy-to-use Ruby client for the Guitarparty API -- find the source code (instructions on how to use included) at https://github.com/mwhatters/guitarparty-ruby-client -- for more information on the Guitarparty API itself, visit http://www.guitarparty.com/developers/
