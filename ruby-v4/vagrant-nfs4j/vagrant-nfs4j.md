# vagrant-nfs4j

**Tag**: library

## 简介

A vagrant plugin that brings support of Vagrant NFS Synced Folders to Windows with 
nfs4j-daemon under the hood.

- 主页: https://github.com/gfi-centre-ouest/vagrant-nfs4j
