# agent-tome

**Tag**: cli, tooling

## 简介

A knowledge base that grows with every session your AI agent runs. Findings accumulate in a persistent, append-only store, so your agent can build on what it already knows instead of starting from scratch. Keyword-indexed and searchable from any CLI.
