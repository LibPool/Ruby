# goldlapel-rails

**Tag**: web

## 简介

This gem has been consolidated into the main goldlapel gem. Install `gem 'goldlapel'` and `require 'goldlapel/rails'` instead. This redirect gem remains installable for backward compatibility but emits a deprecation warning on load.
