# pdf-wrapper

**Tag**: library

## 简介

A unicode aware PDF writing library that uses the ruby bindings to various c libraries ( like cairo, pango, poppler and rsvg ) to do the heavy lifting.

- 主页: https://github.com/yob/pdf-wrapper
