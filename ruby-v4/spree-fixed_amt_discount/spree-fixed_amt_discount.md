# spree-fixed_amt_discount

**Tag**: library

## 简介

Adds a promotion calculator that spreads a single fixed discount amount across the actionable line items in proportion to their value, so each item's tax is recalculated correctly instead of the discount landing as one untaxed order-level adjustment.
