# scrap4rb

**Tag**: testing, filesystem

## 简介

scrap4rb reads Minitest test files and scores each test for size, branching, mocking, weak assertions and duplicated scaffolding. Per file it reports a refactor pressure, a remediation mode and an actionability class for an AI assistant. A Ruby port of the SCRAP algorithm by Robert C. Martin.
