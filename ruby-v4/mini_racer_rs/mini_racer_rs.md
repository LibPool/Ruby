# mini_racer_rs

**Tag**: web, tooling

## 简介

mini_racer_rs provides the same MiniRacer Ruby API as mini_racer 0.22.1 using Rust and V8 15.2. Releases provide precompiled native gems for supported Linux and macOS platforms, plus a source gem that builds with Rust and libclang. The project is not affiliated with the mini_racer maintainers.
