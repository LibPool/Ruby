# ruby_llm-opentelemetry

**Tag**: library

## 简介

RubyLLM OpenTelemetry will bridge RubyLLM instrumentation events to OpenTelemetry spans: every chat, tool call, and provider attempt, visible in your observability stack. This is a placeholder release - full implementation coming soon!
