# maintenance_on_steroids

**Tag**: database, data

## 简介

A powerful maintenance task runner leveraging ActiveJob::Continuable. Features include: form inputs with typed parameters, DB-stored artifacts, database role switching, live progress UI, pause/resume/cancel, and more.
