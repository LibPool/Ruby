# unirate-rails

**Tag**: web, cli, serialization, networking, template

## 简介

A mountable Rails engine wrapping the UniRate API (https://unirateapi.com) — free currency exchange rates, conversion, supported-currency listings, and VAT rates. Ships a configurable client, ActionView helpers (unirate_rate, unirate_convert), and a JSON proxy controller. Zero runtime dependencies beyond Rails.
