# mnky

**Tag**: web, devops, data

## 简介

Monkey is a super simple framework for automating workstation configuration and deployment. Tasks are written in Ruby with a cross-platform API for fetching data and making changes to the system. These can be set to run on a schedule or based on other triggers.
