# coderay-beta

**Tag**: library

## 简介

CodeRay is a Ruby library for syntax highlighting.
  I try to make CodeRay easy to use and intuitive, but at the same time
  fully featured, complete, fast and efficient.

  Usage is simple:
    CodeRay.scan(code, :ruby).div
