# ffiec

**Tag**: web, data

## 简介

The FFIEC (Federal Financial Institutions Examination Council) provides a SOAP web service for it's Public Data Distribution (PDD) Public Web Service (PWS).  Through this API you can obtain financial and structural information for most FDIC-insured institutions. The information available on this site is updated to reflect the most recent data for both prior and current periods.
