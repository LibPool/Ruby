# mysender

**Tag**: web

## 简介

m = Mysender::Mail.new(API_KEY) and then m.deliver(:emails =&gt; 'to@example.com', :subject =&gt; 'SUBJECT', :body =&gt; 'BODY', :reply_to =&gt; 'REPLY_TO if you want')
