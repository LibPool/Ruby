# CVEasy

**Tag**: web, database, networking, data

## 简介

CVEasy is a ruby interface for the Common Vulnerabilities and Exposures (CVE) database at http://cve.mitre.org.

## 官网

- 主页: http://github.com/mephux/CVEasy
- RubyGems: https://rubygems.org/gems/CVEasy

## 历史版本号

- 1.0.0 (2009-12-01)

## 获取地址

- RubyGems: https://rubygems.org/gems/CVEasy

- Bundler: `gem "CVEasy"`

- 最新版归档: https://rubygems.org/downloads/CVEasy-1.0.0.gem
