# warpdrive-proxy

**Tag**: testing, devops

## 简介

WarpDrive is a high-performance reverse proxy built on Pingora
(Cloudflare's Rust proxy framework). 

This is a stub gem. Install the platform-specific gem for your system:
- gem install warpdrive-proxy (RubyGems will auto-select the right platform)
