# pager-mogilefs-client

**Tag**: web, cli, networking, filesystem

## 简介

A Ruby MogileFS client.  MogileFS is a distributed filesystem written by Danga Interactive.  This client supports NFS and HTTP modes. This is experimental fork using RFuzz HTTP client.
