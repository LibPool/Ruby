# rtml

**Tag**: library

## 简介

RubyTML (or just RTML) is a Ruby framework for communicating with Ingenico's Incendo-based payment devices.

## 官网

- 主页: http://www.rubytml.com
- RubyGems: https://rubygems.org/gems/rtml
