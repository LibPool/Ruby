# jekyll-deskcrew

**Tag**: template, tooling, devops

## 简介

Add customer support to a Jekyll blog, docs site or product site: a live chat widget, an AI chatbot that answers from your knowledge base, a public help center, and support tickets with human-approved replies. The plugin injects the DeskCrew widget before </body> on every generated page and post through a post_render hook, configured entirely from _config.yml, no layout or include edits. Works with Minima, Just the Docs, Chirpy, al-folio and any theme; builds on Netlify, Cloudflare Pages, Vercel and GitHub Actions. Free plan, no credit card. An alternative to Tawk.to, Crisp, Intercom or Disqus-style support widgets for static sites.
