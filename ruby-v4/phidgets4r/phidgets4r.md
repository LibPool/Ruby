# phidgets4r

**Tag**: library

## 简介

Just a simple Ruby library to provide Ruby-style abstraction around the Phidgets C library.  Fork of the RubyForge phidget project.

## 官网

- 主页: http://github.com/kitplummer/phidgets4r
- RubyGems: https://rubygems.org/gems/phidgets4r
