# git_install

**Tag**: library

## 简介

rubygems plugin to allow you to install an "edge" gem straight from its github repository

## 官网

- 主页: http://github.com/rdp/git_install
- RubyGems: https://rubygems.org/gems/git_install

## 历史版本号

- 0.2.1 (2010-03-29)

## 获取地址

- RubyGems: https://rubygems.org/gems/git_install
- gem 安装: `gem install git_install`
- Bundler: `gem "git_install"`
- 最新版本: 0.2.1
- 最新版归档: https://rubygems.org/downloads/git_install-0.2.1.gem
- 版本锁定: `gem "git_install", "~> 0.2.1"`
- 中央仓库: https://rubygems.org/
