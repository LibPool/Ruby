# event_trigger

**Tag**: web, data

## 简介

EventTrigger provides a simple event system with pluggable notification providers (Slack, Email, Webhook, custom). Configure providers once, then call EventTrigger.trigger("event.name", data: {...}) and the gem dispatches to the enabled providers configured for that event. Works in plain Ruby and Ruby on Rails.
