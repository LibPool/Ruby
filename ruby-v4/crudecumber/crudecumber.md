# crudecumber

**Tag**: library

## 简介

Manually run through your Cucumber scenarios.

  Hit 'P' to pass a step, 'F' to fail, or 'S' to skip! 

  Run exactly as you would run Cucumber but instead use 'crudecumber' followed
  by your usual Cucumber arguments.
