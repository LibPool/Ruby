# jekyll-webp-resize

**Tag**: web, tooling

## 简介

[DEPRECATED] Use `jekyll-imagemagick` instead. WebP Image Generator for Jekyll 3 Sites that automatically generate WebP images for all images on your static site and serves them when possible.
