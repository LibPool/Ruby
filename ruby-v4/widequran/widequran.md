# widequran

**Tag**: web, cli

## 简介

API client for widequran.com. Access 114 surahs, 6,236 ayahs, hadith collections (Bukhari, Muslim), tafsir commentary (Ibn Kathir), juz/hizb divisions, Quranic people, topics, and glossary. Zero dependencies.
