# jekyll-assets

**Tag**: web

## 简介

A drop-in Jekyll Plugin that provides an asset pipeline for JavaScript,
CSS, SASS, SCSS.  Based around Sprockets (from Rails) and just as powereful
it provides everything you need to manage assets in Jekyll.
