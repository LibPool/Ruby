# wysihtml5_gem

**Tag**: web, template

## 简介

a quick a simple gem to wrap and install wysihtml5 into a rails gem so that its assets are served correctly

## 官网

- 主页: http://github.com/housekeeper/wysihtml5_gem
- RubyGems: https://rubygems.org/gems/wysihtml5_gem

## 历史版本号

- 0.3.0 (2012-11-13)

## 获取地址

- RubyGems: https://rubygems.org/gems/wysihtml5_gem

- Bundler: `gem "wysihtml5_gem"`

- 最新版归档: https://rubygems.org/downloads/wysihtml5_gem-0.3.0.gem
