# badline

**Tag**: filesystem

## 简介

Badline is a Commodore 64 emulator written in Ruby, implementing cycle-accurate timing and hardware behavior. Supports PRG/P00 programs, D64/D71/D81 disk images, T64 archives, TAP tapes, CRT cartridges, SID tunes and host directories mounted as a drive.
