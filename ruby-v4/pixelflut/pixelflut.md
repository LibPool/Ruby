# pixelflut

**Tag**: web, cli, networking

## 简介

Based on the idea of a simple server protocol to collaborate on a sharedcanvas named [Pixelflut](https://cccgoe.de/wiki/Pixelflut) this gemimplements a fast Ruby client version.
