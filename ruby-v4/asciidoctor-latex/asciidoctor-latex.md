# asciidoctor-latex

**Tag**: library

## 简介

An extension for Asciidoctor that converts AsciiDoc documents to LaTeX and provides LaTeX extensions to Asciidoc.

- 文档: https://www.rubydoc.info/gems/asciidoctor-latex/1.5.0.17.dev
- RubyGems: https://rubygems.org/gems/asciidoctor-latex
