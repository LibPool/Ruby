# pixavatar

**Tag**: tooling

## 简介

Pixavatar is a simple placeholder image generator that can be used as filler images where avatar images are missing

## 官网

- 主页: https://github.com/array101/pixavatar
- RubyGems: https://rubygems.org/gems/pixavatar
