# durable_agent

**Tag**: web, database, data

## 简介

Crash-safe, resumable agent conversations for Rails. Ships the pi-durable runtime as a sidecar process inside the gem that keeps its state in your app's database, Postgres or SQLite, which Rails reads with Active Record. Broadcasts over Turbo, and lets you write tools in Ruby.
