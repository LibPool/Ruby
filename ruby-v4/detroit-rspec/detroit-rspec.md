# detroit-rspec

**Tag**: testing, tooling

## 简介

RSpec plugin for Detroit build system. This plugin runs rspec specification durring the test phase.

- 主页: http://detroit.github.com/
- RubyGems: https://rubygems.org/gems/detroit-rspec
