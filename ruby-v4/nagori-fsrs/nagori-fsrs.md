# nagori-fsrs

**Tag**: library

## 简介

Nagori provides Ruby bindings for fsrs-rs (the `fsrs` crate), a Rust implementation of the Free Spaced Repetition Scheduler (FSRS-6): scheduling, memory-state replay, parameter optimization, and simulation.
