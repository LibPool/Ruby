# zim2epub

**Tag**: filesystem

## 简介

Convert zim files (for example exported from wikipedia) to epub format for reading on ebook readers.

## 官网

- 主页: http://rubygems.org/gems/zim2epub
- 源码仓库: https://github.com/chrisistuff/zim2epub
- RubyGems: https://rubygems.org/gems/zim2epub
