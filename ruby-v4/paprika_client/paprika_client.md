# paprika_client

**Tag**: web, cli, devops, data

## 简介

Read and write your own Paprika Recipe Manager data (recipes, nutritional info, and more) via Paprika's cloud sync API. Supports listing recipes, fetching full recipes, and writing changes back with correct sync hashing.
