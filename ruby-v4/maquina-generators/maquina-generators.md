# maquina-generators

**Tag**: web, security, tooling

## 简介

Rails generators that write standalone code into your app: passwordless (clave) and password (registration) authentication, Rack::Attack rules with a Security dashboard, Solid Errors, Mission Control Jobs, Solid Queue, and a full app setup.
