# searchapi-ruby

**Tag**: web, cli, filesystem

## 简介

Full-featured Ruby client for SearchAPI.io. Access 63 search engines including Google, Bing, Baidu, Yandex, DuckDuckGo, YouTube, Amazon, Walmart, Airbnb, TripAdvisor, social media profiles, ad libraries, and more.
