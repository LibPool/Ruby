# ruby_llm-code_mode

**Tag**: web, security

## 简介

A RubyLLM tool that runs model-generated Ruby code inside a secure
WebAssembly sandbox (SecurityBox), with explicit read-only and read-write
folder mounts so agents can work on host project folders safely.
