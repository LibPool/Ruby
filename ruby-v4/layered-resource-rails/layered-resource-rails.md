# layered-resource-rails

**Tag**: web, template, tooling

## 简介

A convention-over-configuration CRUD engine for Rails 8+, built on the layered-ui-rails gem. Declare a resource class, mount it in routes.rb, and get index, new/create, edit/update, and destroy actions with clean default views, Ransack-powered search and sorting, and Pagy pagination. Override any controller or view when you need full control - generators are included to help you create custom controllers and views.
