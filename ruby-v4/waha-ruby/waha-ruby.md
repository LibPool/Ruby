# waha-ruby

**Tag**: web, cli, networking

## 简介

Waha::Client is a framework-neutral Ruby SDK for WAHA (WhatsApp HTTP API): sessions, messaging, media, chats, contacts, presence, webhook HMAC verification, and an optional Rails adapter.
