# nvoip

**Tag**: web, security

## 简介

SDK Ruby oficial para integrar OAuth, chamadas, OTP, WhatsApp, SMS e saldo com a API v2 da Nvoip.

## 官网

- 主页: https://www.nvoip.com.br/
- 源码仓库: https://github.com/Nvoip/nvoip-ruby
- 文档: https://nvoip.docs.apiary.io/
- 问题追踪: https://github.com/Nvoip/nvoip-ruby/issues
- RubyGems: https://rubygems.org/gems/nvoip
