# philiprehberger-base_convert

**Tag**: data

## 简介

Encode and decode data in Base32 (Crockford), Base58 (Bitcoin), Base62, and Base85 (ASCII85) formats. Also supports arbitrary base encoding for integers from base 2 to 62.
