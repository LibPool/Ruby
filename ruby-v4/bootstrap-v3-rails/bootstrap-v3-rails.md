# bootstrap-v3-rails

**Tag**: web

## 简介

This is a personal gem to load bootstrap 3 intro the rails apps using a rails g bootstrap:install to put bootstrap into the application.css and application.js

## 官网

- 文档: https://www.rubydoc.info/gems/bootstrap-v3-rails/3.0.0.4
- RubyGems: https://rubygems.org/gems/bootstrap-v3-rails
