# ask-rails-harness

**Tag**: web, database, testing, data

## 简介

Rails Engine that mounts an admin AI agent at /ask. Ships Rails-aware tools (QueryDatabase, ReadModel, ReadLog, RunCommand, SchemaGraph, RouteInspector, RunTests), session persistence, audit logging, environment permissions, and service gem discovery. Previously developed as ask-rails (0.1.0–0.11.1).
