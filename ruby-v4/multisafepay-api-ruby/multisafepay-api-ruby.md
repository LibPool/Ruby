# multisafepay-api-ruby

**Tag**: web, cli, networking

## 简介

Unofficial MultiSafePay API Client for Ruby. Simplifies integrating with the MultiSafePay API. Supports all API methods. See https://docs.multisafepay.com/reference/ for more information.
