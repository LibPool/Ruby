# git2bit

**Tag**: library

## 简介

git2bit migrates issues with their comments and milestones from a github repo to a bitbucket repo

## 官网

- 主页: https://bitbucket.org/joeworkman/git2bit
- RubyGems: https://rubygems.org/gems/git2bit
