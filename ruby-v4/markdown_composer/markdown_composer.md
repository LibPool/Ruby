# markdown_composer

**Tag**: template

## 简介

Markdown filtering, composition, and transforms. Headless Ruby gem for non-destructive multi-source Markdown composition using human-readable multi-row plans. Select, include, compose, and transform fragments from multiple Markdown or HTML sources without changing the originals.
