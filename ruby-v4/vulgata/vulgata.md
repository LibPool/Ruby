# vulgata

**Tag**: web

## 简介

Vulgata is a Rails engine that creates a fully functional translation center for your application. Inspired by translation SaaS providers like PhraseApp and TranslationExchange, Vulgata aims to provide an on-premise, collaborative platform to translate and manage translations for your Rails application.
