# niksms

**Tag**: web

## 简介

This gem provides an easy-to-use Ruby SDK for connecting to the Kendez.NikSms SMS web service (REST & gRPC).

## 官网

- 主页: https://webservice.niksms.com
- 源码仓库: https://github.com/kendez/niksms-ruby-sdk
- RubyGems: https://rubygems.org/gems/niksms
