# utter

**Tag**: web, testing, devops

## 简介

Utter is a Domain-specific Microservices Framework written in Ruby. Utter helps you divide up your software project into fun-sized independently deployable API endpoints.

- RubyGems: https://rubygems.org/gems/utter
