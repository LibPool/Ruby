# ncupdater

**Tag**: testing, filesystem

## 简介

A small handy upgrade tool for ruby scripts. just provide a version file, and a url for latest version, and the script will handle the rest

## 官网

- 主页: https://github.com/nodes-cloud/ncupdater
- 文档: https://www.rubydoc.info/gems/ncupdater/0.0.6
- RubyGems: https://rubygems.org/gems/ncupdater
