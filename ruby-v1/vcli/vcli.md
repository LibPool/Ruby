# vcli

**Tag**: web, cli, networking, data

## 简介

Command Line Interface for the Abiquo API
Start with 'vcli target https://put.your.portal.api.fqdn.here/api'
then enter your login details 'vcli user your.user@name.com password'
finally you can run queries like 'vcli show datacenters' or 
'vcli show virtualdatacenters' i

There is a lot missing, it is work in progress.
