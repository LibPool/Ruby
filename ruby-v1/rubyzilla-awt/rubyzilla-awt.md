# rubyzilla-awt

**Tag**: web

## 简介

Rubyzilla is a Ruby API for interfacing with bugzilla.

## 官网

- 主页: http://github.com/awt/rubyzilla
- RubyGems: https://rubygems.org/gems/rubyzilla-awt

## 历史版本号

- 0.1.3 (2010-07-01)
- 0.1.1 (2010-02-22)

## 获取地址

- RubyGems: https://rubygems.org/gems/rubyzilla-awt
- gem 安装: `gem install rubyzilla-awt`
- Bundler: `gem "rubyzilla-awt"`
- 最新版本: 0.1.3
- 最新版归档: https://rubygems.org/downloads/rubyzilla-awt-0.1.3.gem
- 版本锁定: `gem "rubyzilla-awt", "~> 0.1.3"`
