# gem-sane-binary

**Tag**: library

## 简介

RubyGems plugin to allow gem install to generate executables that work for both Ruby 1.8 and 1.9

## 官网

- 主页: http://gnuu.org
- RubyGems: https://rubygems.org/gems/gem-sane-binary
