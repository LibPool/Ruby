# json-rpc-objects-msgpack

**Tag**: web, testing, serialization

## 简介

MessagePack serializing support for JSON-RPC Objects. JSON-RPC Objects is complete implementation of JSON-RPC objects with respect to specifications compliance and API backward compatibility.
