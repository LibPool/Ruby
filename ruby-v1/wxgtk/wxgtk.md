# wxgtk

**Tag**: library

## 简介

A wxWidgets-like wrapper for the Ruby-GNOME2 library.

- 主页: https://github.com/gbchaosmaster/wxgtk
- RubyGems: https://rubygems.org/gems/wxgtk
