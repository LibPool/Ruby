## 简介

# PaApi

A simple wrapper for the Parallels Automation APIs.

## Installation

Add this line to your application's Gemfile:

```ruby
gem 'pa_api'
```

And then execute:

    $ bundle

Or install it yourself as:

    $ gem install pa_api
