# fedtechjobber

**Tag**: web, cli, template, filesystem, data

## 简介

fedtechjobber is a simple command line utility that queries the USAJobs API for open tech federal job 
    postings and generates/emails an HTML report displaying available job data along with any available agency 
    GitHub profiles (via USA.gov's Social Media API).
