# openai-term

**Tag**: web, cli

## 简介

A modern terminal interface to OpenAI with a full TUI using rcurses. Features include interactive chat mode, conversation history, model selection, and more. Version 3.0.3: Add configurable request timeout and retry logic for transient API failures (timeout, 429, 500/502/503).
