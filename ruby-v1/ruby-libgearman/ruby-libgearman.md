# ruby-libgearman

**Tag**: cli

## 简介

These are the ruby wrappers for libgearman which can be used to provide Gearman Workers and to connect as Gearman Clients.

## 官网

- 主页: http://launchpad.net/gearman-interface
- RubyGems: https://rubygems.org/gems/ruby-libgearman

## 历史版本号

- 0.10.2 (2009-10-24)
