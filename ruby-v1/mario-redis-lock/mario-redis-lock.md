# mario-redis-lock

**Tag**: web, database, networking

## 简介

Yet another Ruby distributed lock using Redis, with emphasis in transparency. Requires Redis &gt;= 2.6.12, because it uses the new syntax for SET to easily implement the robust algorithm described in the SET command documentation (http://redis.io/commands/set).
