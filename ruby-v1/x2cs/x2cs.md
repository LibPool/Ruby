# x2cs

**Tag**: serialization, data

## 简介

A tool for converting XML data to CSV. Generally meant for entities with fields, as supposed to many nodes deep.

## 官网

- 主页: http://github.com/agmcleod/x2c
- RubyGems: https://rubygems.org/gems/x2cs
