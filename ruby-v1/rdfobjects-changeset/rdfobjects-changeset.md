# rdfobjects-changeset

**Tag**: web, networking

## 简介

An extension to RDFObjects to more easily work with RDF ChangeSets:  http://n2.talis.com/wiki/Changesets

## 官网

- 主页: http://github.com/rsinger/rdfobjects-changesets
- RubyGems: https://rubygems.org/gems/rdfobjects-changeset
