# lingohub

**Tag**: cli

## 简介

Client library and command-line tool to translate Ruby based apps with lingohub.

- 主页: https://lingohub.com

- 问题追踪: https://github.com/lingohub/lingohub_ruby/issues
- RubyGems: https://rubygems.org/gems/lingohub
