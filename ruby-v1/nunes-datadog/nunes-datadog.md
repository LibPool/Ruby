# nunes-datadog

**Tag**: web, data

## 简介

Adapter for the Nunes instrumentation library and the Datadog service.                         This adapter is required because the dogstatsd-ruby gem3 does not implement the same API as                         the statsd-ruby gem, which works out-of-the-box with Nunes.
