# crawdad

**Tag**: library

## 简介

Crawdad is an implementation of Knuth-Plass linebreaking (justification)
  for Ruby.

## 官网

- 主页: http://github.com/madriska/crawdad
- RubyGems: https://rubygems.org/gems/crawdad
