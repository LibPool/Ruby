# wechat_public_api

**Tag**: web, networking

## 简介

微信公众号开发API，包含对微信公众号菜单栏、客服消息、模板消息、帐号管理等接口的封装，API长期更新维护，建议使用最新版本，开发者使用文档：https://yuque.com/qianlansedehei/wechat_public_api
