# highcharts-rails

**Tag**: web

## 简介

Gem that includes Highcharts (Interactive JavaScript charts for your web projects), in the Rails Asset Pipeline introduced in Rails 3.1

## 官网

- 主页: http://northblue.org/
- 源码仓库: https://github.com/PerfectlyNormal/highcharts-rails
- 问题追踪: https://github.com/PerfectlyNormal/highcharts-rails/issues
- RubyGems: https://rubygems.org/gems/highcharts-rails
