# finance-ytd

**Tag**: web

## 简介

Most financial websites show the daily change of assets. The purpose of this gem is to provide year-to-date change.  Markets, ETFs, and mutual funds are supported via money.cnn.  Treasuries are supported via bloomberg.com.  Precious metals are supported using apmex.com, but require users to pass in last year's ending price.
