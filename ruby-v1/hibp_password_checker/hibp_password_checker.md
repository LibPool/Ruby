# hibp_password_checker

**Tag**: web

## 简介

hibp_password_checker uses the haveibeenpwned (have i been pwned) api, to send the first 5 chars of your SHA1'ed passowrd. Then it does a local comparision of list of returned hashes from haveibeenpwned.
