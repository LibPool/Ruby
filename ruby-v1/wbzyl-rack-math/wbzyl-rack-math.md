# wbzyl-rack-math

**Tag**: web, tooling

## 简介

This gem contains four modular Rack applications: Pi, Euler, Sqrt2, Phi (golden ratio).  These applications can be used to play with: * experiment with new and existing Rack Middleware * combine modular Sinatra app with Rack::Builder * embed one Rack application into another Rack application
