# itextomml

**Tag**: library

## 简介

itextomml provides native Ruby bindings to itex2MML, which converts itex equations to MathML.

## 官网

- 文档: https://www.rubydoc.info/gems/itextomml/1.6.2
- RubyGems: https://rubygems.org/gems/itextomml
