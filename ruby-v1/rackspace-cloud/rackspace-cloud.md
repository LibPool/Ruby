# rackspace-cloud

**Tag**: web, testing, devops

## 简介

rackspace-cloud is a Ruby gem that provides easy, simple access to the Rackspace Cloud APIs, and specifically the Cloud Servers API.

## 官网

- 主页: http://github.com/ejdraper/rackspace-cloud
