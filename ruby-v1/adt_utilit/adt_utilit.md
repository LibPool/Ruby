# adt_utilit

**Tag**: data

## 简介

&lt;in development&gt; AdtUtilit is a Ruby gem that provides a set of useful data type classes such as Linked List, Queue, Stack, StackQueue, and Polytree. Many intuitive methods are available for each class. See documentations for the details.
