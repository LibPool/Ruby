# textify

**Tag**: tooling

## 简介

A collection of simple, non-curses-based functions to assist building user interaction into text-only ruby scripts

## 官网

- 主页: http://github.com/jweissman1986/Textify
- RubyGems: https://rubygems.org/gems/textify
