# ruby-uuid

**Tag**: tooling

## 简介

UUID generator/parser in <300 lines. It fully supports UUID versions 1, 3, 4 and 5.

## 官网

- 主页: http://raa.ruby-lang.org/project/ruby-uuid/
- RubyGems: https://rubygems.org/gems/ruby-uuid
