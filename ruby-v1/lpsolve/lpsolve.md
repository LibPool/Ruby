# lpsolve

**Tag**: web, networking

## 简介

A Ruby library for using simplex-method Mixed Integer Linear Programming solver, lpsolve version 0.5.5. 
Pick up the C code for lpsolve at http://bashdb.sf.net/lpsolve-5.5.0.10i.tar.bz2
