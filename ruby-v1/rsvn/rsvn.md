# rsvn

**Tag**: library

## 简介

Gem to provide basic access to Subversion information (wraps Ruby SVN bindings).

## 官网

- 主页: https://github.com/bdnelson/rsvn
- RubyGems: https://rubygems.org/gems/rsvn

## 历史版本号

- 0.0.1 (2013-01-21)

## 获取地址

- RubyGems: https://rubygems.org/gems/rsvn
- gem 安装: `gem install rsvn`
- Bundler: `gem "rsvn"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/rsvn-0.0.1.gem
- 版本锁定: `gem "rsvn", "~> 0.0.1"`
- 中央仓库: https://rubygems.org/
