# fxcop

**Tag**: library

## 简介

FxCop Wrapper for running FxCop on Continuous integration. Comes with Rake Task or can be used with Standard Ruby

## 官网

- 主页: https://github.com/team-beast/fxcop
- RubyGems: https://rubygems.org/gems/fxcop
