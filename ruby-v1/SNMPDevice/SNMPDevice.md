# SNMPDevice

**Tag**: networking, filesystem

## 简介

This gem allows for gathering of information via SNMP, using the SNMP Library for Ruby, on network devices. It is manufacturer agnostic, and accepts a configuration file or hash when creating a new `Device` instance.
