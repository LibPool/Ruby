# webmockdump

**Tag**: web, testing

## 简介

Patch for webmock that instead of halting is doing and dumping the request for easier mocks development.

## 官网

- 源码仓库: https://github.com/nakilon/webmockdump
- RubyGems: https://rubygems.org/gems/webmockdump
