# rlogin

**Tag**: web

## 简介

Ruby library to connect to a BSD Rlogin server (RFC 1282).

## 官网

- 主页: http://rlogin.rubyforge.org
- RubyGems: https://rubygems.org/gems/rlogin

- 1.0.0 (2009-08-20)
