# rails-bootstrap-ui

**Tag**: web, filesystem

## 简介

Rails 3.1 gem that installs Twitter Bootstrap CSS and JS files, patches for will_paginate, and JQuery libraries for hotkeys and scrollable divs.

## 官网

- RubyGems: https://rubygems.org/gems/rails-bootstrap-ui
