# puppet_forge

**Tag**: web

## 简介

Tools that can be used to access Forge API information on Modules, Users, and Releases. As well as download, unpack, and install Releases to a directory.

## 官网

- 主页: https://github.com/puppetlabs/forge-ruby
- 问题追踪: https://tickets.puppetlabs.com/browse/FORGE
- RubyGems: https://rubygems.org/gems/puppet_forge
