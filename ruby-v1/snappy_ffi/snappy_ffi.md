# snappy_ffi

**Tag**: library

## 简介

FFI extension to to bring the Snappy compression library to Ruby. libsnappy must be installed.

## 官网

- 主页: http://github.com/delta407/snappy-ruby
- RubyGems: https://rubygems.org/gems/snappy_ffi

## 历史版本号

- 0.1.2 (2011-03-24)

## 获取地址

- RubyGems: https://rubygems.org/gems/snappy_ffi
- gem 安装: `gem install snappy_ffi`
- Bundler: `gem "snappy_ffi"`
- 最新版本: 0.1.2
- 最新版归档: https://rubygems.org/downloads/snappy_ffi-0.1.2.gem
- 版本锁定: `gem "snappy_ffi", "~> 0.1.2"`
- 中央仓库: https://rubygems.org/
