# rb-aes31

**Tag**: tooling, filesystem

## 简介

rb-aes31 is a pure-Ruby library for generating and parsing AES31-2008-3 format Audio Decision List files (ADL files).  
The library includes a complete low-level and strictly-validating Edit Decision Markup Language
parser-generator.
