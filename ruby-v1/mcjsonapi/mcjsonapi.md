# mcjsonapi

**Tag**: web, serialization, networking

## 简介

A gem to interact with a Minecraft (bukkit) server that has the 
    {JSONAPI plugin}[https://github.com/alecgorge/jsonapi] installed. It supports
    calling single and multiple methods.
