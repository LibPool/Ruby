# strokedb

**Tag**: database, data

## 简介

StrokeDB is an embeddable, distributed, document-based database written in Ruby. It is schema-free (allowing you to define any attribute on any object at any time), it scales infinitely, it even allows free versioning and integrates perfectly with Ruby applications.
