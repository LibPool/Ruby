# aws-cfn-resources

**Tag**: devops

## 简介

Mixes methods into AWS::CloudFormation::Stack to make it easy to retrieve resource objects created during stack creation.  Also provides a stack method for most AWS taggable resources, so that one can retrieve the AWS::CloudFormation::Stack object that created them.
