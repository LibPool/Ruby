# calc_sun

**Tag**: library

## 简介

Given a Julian Day Number of day,
                        latitude decimal, and
                        longitude decimal in the calls to instance methods
                        rise(jd, lat, lon),
                        noon(jd, lat, lon), and
                        set(jd, lat, lon)
                        see source code for more details
