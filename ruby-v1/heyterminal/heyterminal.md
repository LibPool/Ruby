# heyterminal

**Tag**: cli, tooling

## 简介

This is just another tool for running command lines from the terminal. I was inspired by my Google Assistance to build it. I just wanted to say to my terminal hey termianl do this. I'm currently usign it and it's proven more usefull and friendly than running bash scripts or other cli tools like thor.
