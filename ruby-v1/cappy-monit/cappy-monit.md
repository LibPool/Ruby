# cappy-monit

**Tag**: web, filesystem

## 简介

This library extends Capistrano to configure and control a *monit* daemon running on application servers. It replaces some of the standard tasks with monit versions and includes tasks and helpers to create monit configuration files. See below for instructions on downloading and configuring monit itself.
