# fitnio_export

**Tag**: data

## 简介

A tool for exporting activity data from Fitnio in GPX format (for importing into Runkeeper)

## 官网

- 主页: http://github.com/psionides/fitnio_export
- RubyGems: https://rubygems.org/gems/fitnio_export
