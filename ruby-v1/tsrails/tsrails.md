# tsrails

**Tag**: web

## 简介

TSWRails is a base Rails project that you can upgrade. It is used by
Taylored Software to get a jump start on a working app.

## 官网

- 主页: http://github.com/tayloredsoftware/tswrails
- RubyGems: https://rubygems.org/gems/tsrails

## 历史版本号

- 2.0.0 (2012-01-31)

## 获取地址

- RubyGems: https://rubygems.org/gems/tsrails
- gem 安装: `gem install tsrails`
- Bundler: `gem "tsrails"`

- 最新版归档: https://rubygems.org/downloads/tsrails-2.0.3.gem
