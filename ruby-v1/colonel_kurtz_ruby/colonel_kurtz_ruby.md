# colonel_kurtz_ruby

**Tag**: web, serialization, networking, data

## 简介

Colonel Kurtz Ruby is a lightweight shim between the JSON data that Colonel Kurtz (https://github.com/vigetlabs/colonel-kurtz) creates and POROs.
