# oauth2_provider

**Tag**: web, testing, security, networking, template

## 简介

A Rails plugin to OAuth v2.0 enable your rails application. This plugin implements v09 of the OAuth2 draft spec http://tools.ietf.org/html/draft-ietf-oauth-v2-09.
