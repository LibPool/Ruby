# jekyll-pwa-workbox

**Tag**: web

## 简介

A Jekyll plugin that makes your PWA / Website available offline and lets you install on desktop and mobile. 
					It generates and injects a precache list into a Workbox v5.1.4 service worker and handles the registration process in a secure way.
