# one_bus_away

**Tag**: web, networking

## 简介

This is a simple gem to query bus stops,delay times, and additional features. Thisdoes require that you apply for an API keyfrom One Bus Away --http://pugetsound.onebusaway.org/p/OneBusAwayApiService.action
