# gmail_oauth2

**Tag**: security

## 简介

The library uses gmail_xoauth, mail and monkey-patched
                          ruby imap library to support gmail oauth extensions 
                          such as X-GM-THRID. Supports fetching uids, emails, 
                          threaded emails, attachments and much more.
