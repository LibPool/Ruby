# ruby-xslt

**Tag**: web, serialization, networking

## 简介

Ruby/XSLT is a simple XSLT class based on libxml &lt;http://xmlsoft.org/&gt; and libxslt &lt;http://xmlsoft.org/XSLT/&gt;
