# activerecord-memsql

**Tag**: database

## 简介

The ActiveRecod MemSQL Adapter is an ActiveRecord connection adapter based on the standard mysql2 adapter.
This adapter is a customized version of the mysql2 adapter to provide support for MemSQL.
