# nullify_blanks

**Tag**: web, database, data

## 简介

Ruby on Rails plugin to ensure nullable databases columns are set to null rather than empty strings.

- 主页: http://github.com/pixeltrix/nullify_blanks/
- RubyGems: https://rubygems.org/gems/nullify_blanks
