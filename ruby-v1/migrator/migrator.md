# migrator

**Tag**: tooling

## 简介

Migrator is a Ruby library for building general purpose versioning systems in
the style of ActiveRecord's migrations.

## 官网

- 主页: https://rubyforge.org/projects/migrator/
- RubyGems: https://rubygems.org/gems/migrator
