# mud

**Tag**: cli

## 简介

Mud is a simple package manager for client-side Javascript. Used for installing new packages and resolving dependencies.

## 官网

- 主页: http://mudhub.org
- RubyGems: https://rubygems.org/gems/mud

## 历史版本号

- 0.0.4 (2011-05-29)

- RubyGems: https://rubygems.org/gems/mud
