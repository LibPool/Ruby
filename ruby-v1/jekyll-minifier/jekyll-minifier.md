# jekyll-minifier

**Tag**: template

## 简介

Jekyll Minifier using htmlcompressor for html, terser for js, and cssminify2 for css

## 官网

- 主页: http://github.com/digitalsparky/jekyll-minifier
- 源码仓库: https://github.com/digitalsparky/jekyll-minifier

- RubyGems: https://rubygems.org/gems/jekyll-minifier
