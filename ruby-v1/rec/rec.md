# rec

**Tag**: template, filesystem

## 简介

Deprecated. 
		I'm planning to discontinue this gem. Although it has enormous flexibility and power, 
		it is in my view too complex. 80% of requirements can be met through custom shell scripts
		which are much simpler to write and maintain. 

		Sifts through your log files in real time, using stateful intelligence to determine
		what is really important. REC can alert you (by email or IM) or it can simply condense
		a large log file into a much shorter and more meaningful log.
		REC is inspired by Risto Vaarandi's brilliant *sec* (simple-evcorr.sourceforge.net)
		but is original code and any defects are entirely mine.
		While event correlation is inherently complex, REC attempts to make common tasks easy
		while preserving plenty of power and flexibility for ambitious tasks.
