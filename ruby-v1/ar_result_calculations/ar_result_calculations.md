# ar_result_calculations

**Tag**: library

## 简介

Defines Array#calculation methods for ActiveRecord result sets. Provides
    #sum, #min, #max, #count, #mean, #regression, #slope.  Delegates to super()
    if not an AR result set where appropriate.
