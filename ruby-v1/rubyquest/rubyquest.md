# rubyquest

**Tag**: library

## 简介

The game development is still in its early days, the main goal is to provide a simple framework to create rpg quests in Ruby.

## 官网

- 主页: http://github.com/luizbranco/rubyquest
- RubyGems: https://rubygems.org/gems/rubyquest
