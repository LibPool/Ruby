# helldivers-theme

**Tag**: cli, filesystem, data

## 简介

A responsive, data-driven Jekyll theme designed for Helldivers 2 clans. Includes dynamic leader profiles, Twitch integration, RSS feeds, and a sci-fi terminal aesthetic.
