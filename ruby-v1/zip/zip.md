# zip

**Tag**: filesystem

## 简介

zip is a Ruby library for reading and writing Zip files. Unlike the official rubyzip, zip is compatible with Ruby 1.9.1.

## 官网

- 主页: http://github.com/postmodern/rubyzip2
- RubyGems: https://rubygems.org/gems/zip
