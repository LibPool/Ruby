# bootstrap-switch-rails-bcj-version

**Tag**: web, testing, networking

## 简介

A small gem for putting bootstrap-switch into the Rails asset pipeline, all credit for this goes to the original creator, Manuel van Rijn. see https://github.com/manuelvanrjin/bootstrap-switch-rails. this is created to include a tweak to the bootstrap-switch source that I needed for a specific project
