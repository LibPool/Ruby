# agiley-feedzirra

**Tag**: web, networking

## 简介

A feed fetching and parsing library that treats the internet like Godzilla treats Japan: it dominates and eats all. Forked from http://github.com/tommeier/feedzirra for Proxy support and upped to RubyGems for easy gem install.
