# unipept

**Tag**: web, cli, networking

## 简介

Command line interface to the Unipept (http://unipept.ugent.be) web services
    (pept2lca, taxa2lca, pept2taxa, pept2prot and taxonomy) and some utility
    commands for handling proteins using the command line.

## 官网

- 主页: http://unipept.ugent.be
- 源码仓库: https://github.com/unipept/unipept-cli
- 文档: http://unipept.ugent.be/clidocs
- 问题追踪: https://github.com/unipept/unipept-cli/issues
- RubyGems: https://rubygems.org/gems/unipept
