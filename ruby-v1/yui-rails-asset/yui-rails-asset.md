# yui-rails-asset

**Tag**: web

## 简介

A gem that transforms Yahoo's YUI library version 2.8.1 into an asset pipeline friendly resource for Rails 3.1+

## 官网

- 主页: https://github.com/hemanthpai/yui
- 文档: https://www.rubydoc.info/gems/yui-rails-asset/2.8.1
- RubyGems: https://rubygems.org/gems/yui-rails-asset

## 历史版本号
