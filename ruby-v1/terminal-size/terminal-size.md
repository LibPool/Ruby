# terminal-size

**Tag**: cli

## 简介

A tiny gem to accomplish a simple task: Determining the terminal size.

== Usage

    p Terminal.size # ⇒ {height: 90, width: 161}
    p Terminal.size! # to get 80×25 as a fallback instead of nil
