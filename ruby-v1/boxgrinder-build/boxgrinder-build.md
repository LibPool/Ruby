# boxgrinder-build

**Tag**: tooling, filesystem

## 简介

A tool for creating appliances from simple plain text files for various virtual environments.

## 官网

- 主页: http://boxgrinder.org/
- 源码仓库: https://github.com/boxgrinder/boxgrinder-build

- 问题追踪: https://issues.jboss.org/browse/BGBUILD
