# tcg-player-sdk

**Tag**: web, testing, serialization

## 简介

The tcg-player-sdk gem is a convenient wrapper to the TCGPlayer JSON API.  Easily query the entire API, with helpers and accessors for common queries.  This gem also provides helpers for Pokemon-specific queries.  A work in progress.
