# golddigger

**Tag**: database, filesystem, data

## 简介

This gem uses YQL to access the Yahoo! Finannce database to return the current price of gold.  There are may other elements returned but this class is filtered to only return the currrent price.  The class file golddigger.rb can be modified to filter and return elements other than current price.
