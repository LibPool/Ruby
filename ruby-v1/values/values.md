# values

**Tag**: library

## 简介

Simple immutable value objects for ruby.

    Make a new value class: Point = Value.new(:x, :y)
    And use it:
    p = Point.new(1,0)
    p.x
    =&gt; 1
    p.y
    =&gt; 0
