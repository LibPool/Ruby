# zutils

**Tag**: web

## 简介

Engine Rails com partials Bootstrap 5, helpers (bootstrap_flash, eval_with_rescue) e controllers Stimulus reutilizáveis (filtering, toastr, bootstrap-table, dropdown, tooltip) para os apps captei, sofia e reduz.
