# bridgetown-webp

**Tag**: web, tooling

## 简介

WebP Image Generator for Bridgetown sites that automatically generate WebP images for all images on your static site and serves them when possible. Includes the v0.6.1 version of the WebP utilities for Windows, Linux and Mac OS X 10.9 (Mountain Lion)
