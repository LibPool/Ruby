# mywowarmory-ruby

**Tag**: web, networking, tooling

## 简介

This library uses HTTParty to provide simple, reliable access to the MyWoWArmory API. Good for building reporting scripts and simple apps. Note that this library does not support the complete MyWoWArmory API at this time. See Features/Issues below for details.
