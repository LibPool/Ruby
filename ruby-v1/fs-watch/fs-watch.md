# fs-watch

**Tag**: filesystem

## 简介

Script to watch files and directories for changes and execute a command. (OSX Only)
    Similar to dnotify from linux.
    Usage: 
      $ fs-watch [dirsToWatch...] "echo 'execute me when something happens'"
