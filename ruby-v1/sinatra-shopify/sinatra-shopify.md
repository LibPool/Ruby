# sinatra-shopify

**Tag**: web

## 简介

A Sinatra extension for working with the Shopify API. Akin to the shopify_app gem but for Sinatra

## 官网

- 主页: https://github.com/jstorimer/sinatra-shopify/
- RubyGems: https://rubygems.org/gems/sinatra-shopify
