# app-info

**Tag**: filesystem

## 简介

Teardown tool for ipa, apk, aab, hap mobile files and Windows, macOS and dSYM file, even support for info.plist and .mobileprovision files

## 官网

- 主页: http://github.com/icyleaf/app-info
- 文档: https://www.rubydoc.info/gems/app-info/3.4.0
- RubyGems: https://rubygems.org/gems/app-info
