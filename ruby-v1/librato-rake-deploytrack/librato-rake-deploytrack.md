# librato-rake-deploytrack

**Tag**: web, devops

## 简介

Rake tasks to keep track of your deploys in Librato Metrics, using the Annotationstreams! Librato Rake Deploytrack is a collection of raketasks. So you should be able to include them in every application utilizing rake.
