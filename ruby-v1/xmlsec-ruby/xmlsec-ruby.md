# xmlsec-ruby

**Tag**: web, serialization, networking

## 简介

xmlsec-ruby is a project using SWIG to create ruby bindings
	for the xmlsec library (http://www.aleksey.com/xmlsec/).

- 主页: http://github.com/wonnage/xmlsec-ruby
