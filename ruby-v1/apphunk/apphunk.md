# apphunk

**Tag**: library

## 简介

Apphunk is a library that allows your applications to send messages to Apphunk.com

## 官网

- 主页: http://apphunk.com
- 源码仓库: http://github.com/apphunk/apphunk
- RubyGems: https://rubygems.org/gems/apphunk
