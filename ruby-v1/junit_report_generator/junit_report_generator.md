# junit_report_generator

**Tag**: testing, serialization, tooling, data

## 简介

Generating JUnit test result report (xml) from any format of data by super easy and flexible syntax.  Most of the CIs (Continuous Integration) can aggregate JUnit style reports with zero effort.
