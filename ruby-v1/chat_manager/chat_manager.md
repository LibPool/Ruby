# chat_manager

**Tag**: web, database, tooling, data

## 简介

ChatManager is a Rails engine that provides chat management, automatic title generation from initial prompts, and CSV export for individual or bulk chat downloads. It includes UI components with Stimulus-powered inline title editing and a database migration generator.
