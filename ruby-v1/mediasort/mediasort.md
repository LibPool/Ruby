# mediasort

**Tag**: filesystem

## 简介

Sort media files from a directory into another directory in the format of: &lt;YEAR&gt;/&lt;MONTH&gt;/&lt;YEAR-MONTH-DAY&gt;/&lt;FILENAME.EXT&gt;
