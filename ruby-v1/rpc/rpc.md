# rpc

**Tag**: web, database, serialization, networking

## 简介

Generic RPC library for Ruby. Currently it supports JSON-RPC over HTTP, support for AMQP and Redis will follow soon.

## 官网

- 主页: http://github.com/ruby-amqp/rpc
- RubyGems: https://rubygems.org/gems/rpc

## 历史版本号

- 0.2 (2011-05-04)
- 0.1 (2011-04-13)
