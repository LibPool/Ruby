# json_routes

**Tag**: cli, serialization

## 简介

JsonRoutes takes the routes of the parent application and organizes them into a JSON object, nested by resource.  It then provides routes in which that JSON can be easily accessed and parsed by a front-end client.  JsonRoutes was built to provid front-end clients with a way to access routes using names, rather than hard-coding URLs into their platform.
