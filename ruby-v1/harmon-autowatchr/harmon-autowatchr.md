# harmon-autowatchr

**Tag**: web, testing, networking

## 简介

Fork of viking's autowatchr library to fix some issues and add some features. Provides some autotest-like behavior for watchr (http://github.com/mynyml/watchr).

## 官网

- 主页: http://github.com/harmon/autowatchr
- RubyGems: https://rubygems.org/gems/harmon-autowatchr

- 0.1.5 (2010-12-15)
