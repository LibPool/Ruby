# dm-actionstamps

**Tag**: data

## 简介

A DataMapper plugin that works similar to the dm-timestamps in that it 'automagically' adds/updates the created_?, updated_? fields of your models.

- 主页: http://github.com/kematzy/dm-actionstamps
