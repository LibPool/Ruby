# action_annotation

**Tag**: web

## 简介

This gem introduces means for describing the content of methods in a human readable way. The descriptions are parsed and provided as hashes at runtime. This feature is intended to be used for controller actions to automatize parts of your rails application, but it can be included in other classes as well.
