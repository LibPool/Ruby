# z80

**Tag**: web, testing, networking

## 简介

Z80-Ruby is a Ruby binding for the Zilog Z80 CPU emulator (https://github.com/redcode/Z80). It is ideal for analysis, hacking, testing and debugging. All from the comfort of Ruby.
