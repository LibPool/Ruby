# owlscribble

**Tag**: testing, template

## 简介

OWLScribble converts a specific set of wiki text markup into HTML. (The syntax used in the markup is a knockoff of the markup used by OpenWiki; the 'OWL' in OWLScribble means &quot;OpenWiki-like&quot;.)  The OWLScribble.each_wiki_link method provides a way to customize the HTML produced for individual in-wiki page links. (Since the URLs for such links is custom to each site, and the user may wish to perform DB queries to control the display and/or linking of various links.)  The OWLScribble.each_wiki_command method provides a way to handle special processing instructions used in the markup.
