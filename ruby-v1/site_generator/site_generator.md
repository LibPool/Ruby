# site_generator

**Tag**: web, tooling

## 简介

In a Productized Rails Application (see the rails_product gem) it is necessary to add a site for each derivative application.  With the site_generator gem, you will be able to create a site within your application with the command: ./script/generate site &lt;site_name&gt;
