# mojura-mailchimp

**Tag**: web, template

## 简介

The module can be used by editing a pageview and select 'MailChimp subscription' as web module. The maintainer can select a MailChimp list. After saving, the user will see a small form, with which he or she can subscribe. Currently the users are added as pending users, meaning they will receive an email to confirm their subscription.
