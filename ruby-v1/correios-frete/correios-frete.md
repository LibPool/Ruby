# correios-frete

**Tag**: web, networking

## 简介

Calculo de frete utilizando o Web Service dos Correios (http://www.correios.com.br/webservices).
Os servicos de frete suportados sao PAC, SEDEX, SEDEX a Cobrar, SEDEX 10, SEDEX Hoje e e-SEDEX.
