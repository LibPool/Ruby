# harukizaemon-cascading_stylesheets

**Tag**: web, testing, filesystem

## 简介

Cascading Stylesheets is a Ruby on Rails plugin that enhances the behaviour of the built-in stylesheet_link_tag macro to include controller and action specific stylesheet files.
