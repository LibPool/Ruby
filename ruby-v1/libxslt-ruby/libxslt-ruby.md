# libxslt-ruby

**Tag**: library

## 简介

The Libxslt-Ruby project provides Ruby language bindings for the GNOME
    XSLT C library.  It is free software, released under the MIT License.

## 官网

- 文档: https://www.rubydoc.info/gems/libxslt-ruby/1.2.0
