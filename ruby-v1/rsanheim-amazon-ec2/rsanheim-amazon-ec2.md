# rsanheim-amazon-ec2

**Tag**: web, networking, devops

## 简介

An interface library that allows Ruby applications to easily connect to the HTTP 'Query API' for the Amazon Web Services Elastic Compute Cloud (EC2) and manipulate cloud servers.
