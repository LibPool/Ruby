# poison

**Tag**: library

## 简介

Poison is a programming language based on Potion by Why The Lucky Stiff
that runs on the Rubinius VM.

## 官网

- 主页: http://github.com/brixen/poison
- RubyGems: https://rubygems.org/gems/poison

## 历史版本号

- 0.1.0.dev (2010-11-07)

## 获取地址
