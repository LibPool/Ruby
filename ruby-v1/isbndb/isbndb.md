# isbndb

**Tag**: web, serialization

## 简介

Ruby ISBNdb is a amazingly fast and accurate gem that reads ISBNdb.com's XML API and gives you incredible flexibilty with the results! The newest version of the gem also features caching, so developers minimize API-key usage.
