# ink

**Tag**: library

## 简介

Ink is a wrapper for Pygments, a nice Python syntax highlighting library and formatters like RDoc, Markdown and Textile.

## 官网

- 主页: http://github.com/fnando/ink
- RubyGems: https://rubygems.org/gems/ink
