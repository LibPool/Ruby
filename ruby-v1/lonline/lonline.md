# lonline

**Tag**: library

## 简介

You will be able to execute the following operations:
    lonline.log.trace() -
    lonline.log.debug() -
    lonline.log.info() -
    lonline.log.warn() -
    lonline.log.error() -
    lonline.log.fatal() - Additionally, Lonline provides methods to get report about your logs.
