# ffi-uuid

**Tag**: library

## 简介

FFI Wrapper for libuuid with extra helpers for common UUID tasks like getting an array of uuids for quicker distribution

## 官网

- 主页: http://github.com/mmullis/ffi-uuid
- RubyGems: https://rubygems.org/gems/ffi-uuid
