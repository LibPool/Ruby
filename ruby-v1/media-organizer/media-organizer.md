# media-organizer

**Tag**: filesystem, data

## 简介

Dynamically renaming files using their metadata, according to a customizable pattern. For example, use media-organizer to set filenames for a library of photos to a customizable standard such as: "&lt;date-taken&gt; - Ski Vacation.jpg". Currently supports only JPEG, TIFF, MP3, M4A, WAV, FLAC, and OGG files.
