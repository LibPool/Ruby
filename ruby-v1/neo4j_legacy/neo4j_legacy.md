# neo4j_legacy

**Tag**: web

## 简介

A Neo4j OGM (Object-Graph-Mapper) for use in Ruby on Rails and Rack frameworks heavily inspired by ActiveRecord.
This fork enables this gem to be used in Rails 3.2 projects
