# hdcloud

**Tag**: devops, filesystem

## 简介

An easy-to-use rubygem for managing jobs, profiles and stores in HDCloud (www.hdcloud.com).

## 官网

- 主页: http://github.com/jacqui/hdcloud
- RubyGems: https://rubygems.org/gems/hdcloud

## 历史版本号

- 0.1.0 (2010-03-27)

## 获取地址

- RubyGems: https://rubygems.org/gems/hdcloud
- gem 安装: `gem install hdcloud`
- Bundler: `gem "hdcloud"`
- 最新版本: 0.1.0
- 最新版归档: https://rubygems.org/downloads/hdcloud-0.1.0.gem
- 版本锁定: `gem "hdcloud", "~> 0.1.0"`
- 中央仓库: https://rubygems.org/
