# asciidoctor-carousels

**Tag**: library

## 简介

An Asciidoctor extension that adds a carousel block to the AsciiDoc syntax. The carousel is constructed from visual blocks, such as image macros and Asciidoctor Diagram blocks, enclosed in an example block marked with the carousel style.
