# jquery-qtip-wrapper-rails

**Tag**: web, networking

## 简介

A simple wrapper around the great jQuery qTip tooltip plugin. (see: http://craigsworks.com/projects/qtip)

## 官网

- 主页: https://github.com/dondope/jquery-qtip-wrapper-rails
- 文档: http://craigsworks.com/projects/qtip
- RubyGems: https://rubygems.org/gems/jquery-qtip-wrapper-rails
