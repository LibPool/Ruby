# jekyll-theme-nixer

**Tag**: security

## 简介

A hard-core minimalist, single-author Jekyll theme with almost default browser styling, and a dark mode. Just a post list and posts, no menu, header, footer, or pages. Even the backlink from posts to home is missing.
