# yui

**Tag**: web

## 简介

The yui gem provides a Ruby API to drive graphical
(Qt, Gtk) or text-mode (ncurses) UIs with libyui

## 官网

- 主页: http://www.github.com/libyui/libyui-bindings
- RubyGems: https://rubygems.org/gems/yui
