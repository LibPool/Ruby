# tzinfo-data

**Tag**: database, data

## 简介

TZInfo::Data contains data from the IANA Time Zone database packaged as Ruby modules for use with TZInfo.

- 主页: https://tzinfo.github.io
- 源码仓库: https://github.com/tzinfo/tzinfo-data

- 问题追踪: https://github.com/tzinfo/tzinfo-data/issues
