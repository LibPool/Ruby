# mutate

**Tag**: library

## 简介

Adds Object#mutate (similar to Enumerable#map), Object#keep (Enumerable#select), Object#toss (Enumerable#reject), Object#impart (Enumerable#inject). Object#tap already exists for Enumerable#each (for side effects).
