# adamaig-ruby_activeworld

**Tag**: web, networking, filesystem

## 简介

A ruby binding, and sugary methods for the Activeworlds SDK. You must have the linux sdk  in your LD_LIBRARY_PATH to use this gem (libaw_sdk.41.so) See http://www.activeworlds.com
