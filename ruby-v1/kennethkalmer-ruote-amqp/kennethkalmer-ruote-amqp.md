# kennethkalmer-ruote-amqp

**Tag**: web, networking, template

## 简介

ruote-amqp provides an AMQP participant/listener pair that allows you to  distribute workitems out to AMQP consumers for processing.  To learn more about remote participants in ruote please see http://openwfe.rubyforge.org/part.html
