# cvss-suite

**Tag**: web, testing, networking

## 简介

This Ruby gem calculates the score based on the vector of the
Common Vulnerability Scoring System (https://www.first.org/cvss/specification-document)
in version 4.0, 3.1, 3.0 and 2.
