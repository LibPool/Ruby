# jekyll-crosseverything-to-medium

**Tag**: template, tooling, filesystem

## 简介

This generator cross-everything entries to Medium. To work, this script requires
  a MEDIUM_USER_ID environment variable and a MEDIUM_INTEGRATION_TOKEN, MEDIUM_ENTITY.

  The generator will only pick up posts with the following front matter:

  `crosseverything_to_medium: true`

  You can control crosseverything globally by setting `enabled: true` under the 
  `jekyll-crosserything_to_medium` variable in your Jekyll configuration file.
  Setting it to false will skip the processing loop entirely which can be
  useful for local preview builds.
