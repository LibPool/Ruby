# source_win_bat

**Tag**: filesystem

## 简介

sw, or SourceWinBat, is a utility to run Windows batch files from WSL /
MSYS2 / Cygwin and sync environment variables, doskeys, and working 
directories between batch files and their UNIX shell environments.
