# rml

**Tag**: template

## 简介

RML: Ruby Markup Language. Pure ruby xhtml markup, but with one big difference. RML is aimed to provide valid and only valid xhtml 1.0 markup.

## 官网

- 主页: http://rml.rubyforge.org/
- RubyGems: https://rubygems.org/gems/rml
