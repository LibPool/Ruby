# cocoapods-links

**Tag**: cli, testing

## 简介

This CocoaPods plugin linking functionality allows to easily test their pods.

                         This plugin adds the following commands to the CococPods command line:

                          * pod link &lt;name&gt;
                          * pod unlink &lt;name&gt;
                          * pod list links
