# var_block

**Tag**: web

## 简介

DSL for variable scoping / encapsulation for readability and organisation, by means of block indents and explicit variable declarations. Useful when organising complex conditions such as procs (case-in-point: complex `... if: -&gt; {}` Rails model validations
