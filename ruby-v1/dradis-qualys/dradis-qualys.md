# dradis-qualys

**Tag**: library

## 简介

This add-on allows you to upload and parse output produced from Qualys Vulnerability Scanner into Dradis.

## 官网

- 主页: https://dradis.com/integrations/qualys.html

- 问题追踪: https://github.com/dradis/dradis-ce/issues
