# jekyll-theme-dreamcast

**Tag**: cli

## 简介

A retro-futuristic Jekyll theme inspired by the iconic Sega Dreamcast console, featuring the signature orange and blue color scheme, smooth animations, and a nostalgic gaming aesthetic.
