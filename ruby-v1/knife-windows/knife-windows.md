# knife-windows

**Tag**: cli

## 简介

Plugin that adds functionality to Chef Infra's Knife CLI for configuring/interacting with nodes running Microsoft Windows

## 官网

- 主页: https://github.com/chef/knife-windows
- 源码仓库: https://github.com/opscode/knife-windows
- 文档: https://www.rubydoc.info/gems/knife-windows/5.0.7
- RubyGems: https://rubygems.org/gems/knife-windows
