# wordnet

**Tag**: library

## 简介

This library is a (high-performace) Ruby interface to WordNet®[wordnet.princeton.edu/]. WordNet® is an online lexical reference system whose design is inspired by current psycholinguistic theories of human lexical memory. English nouns, verbs, adjectives and adverbs are organized into synonym sets, each representing one underlying lexical concept. Different relations link the synonym sets.
