# rmovie

**Tag**: testing, filesystem

## 简介

rmovie is an extension to allow Ruby scripts to get info from video filespec.

## 官网

- 主页: http://rubyforge.org/rmovie
- RubyGems: https://rubygems.org/gems/rmovie

- 0.5.0 (2009-07-25)
