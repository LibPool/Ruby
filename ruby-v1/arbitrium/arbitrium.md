# arbitrium

**Tag**: web

## 简介

This gem was inspired by the overabundance of logic that I continually saw in controllers in the Rails app I was working on. I've decided to implement a straight ruby gem that has no dependencies on Rails.  This gem will remain simple in scope and will be modeled after the way that I like to write service object classes.
