# harvixture

**Tag**: web, testing, filesystem, data

## 简介

Harvixture is a tool that can be used to extract data, in the form of fixtures, from a Rails project.  It is done by pointing the harvixture at a request_path and dumping fixtures for all &quot;found&quot; ActiveRecord objects.
