# muding

**Tag**: tooling

## 简介

muding is a development framework for building multi-user environments. The purpose of the framework is to separate the lower level functionality common to all multi-user environments into a separate framework that can be developed through open-source. Developers using the framework can then build their multi-user environment on top of the framework, and update the framework code independantly of their own code.
