# rabbit-slide-kou-groonga-document-read-4

**Tag**: library

## 简介

4回目の「Groongaドキュメント読書会」は、前回の「Groongaドキュメント読書
会」でのフィードバックを反映して進めます。進め方は前回と同様に輪読会式
を使います。
