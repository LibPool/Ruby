# animation

**Tag**: library

## 简介

css3 animations plugin for compass, with core animation mixins, and optional defaul animations from animate.css.

## 官网

- 主页: https://github.com/ericam/compass-animation
- RubyGems: https://rubygems.org/gems/animation
