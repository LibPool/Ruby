# compass-core-sass37

**Tag**: cli, filesystem

## 简介

The Compass core stylesheet library with Sass 3.7 support. This library can be used stand-alone without the compass ruby configuration file or compass command line tools. Forked from the original Compass project to maintain compatibility with Sass 3.7.
