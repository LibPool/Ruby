# melt_baseline

**Tag**: library

## 简介

A Ruby gem used for High-Resolution Melting (HRM) background signal removal using a baseline method similar to that described by Wittwer & Palais (2009).  DOI: 10.1016/S0076-6879(08)03813-5.
