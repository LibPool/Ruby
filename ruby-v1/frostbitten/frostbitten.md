# frostbitten

**Tag**: library

## 简介

Gem that provides RCON commands for frostbite 2 engine games. BF3, BFBC2 and so on

## 官网

- 主页: http://github.com/mrevilme/frostbitten
- RubyGems: https://rubygems.org/gems/frostbitten
