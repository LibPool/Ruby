# capistrano-deploy-strategy-archive

**Tag**: web, tooling, devops, filesystem

## 简介

Provides an :archive deploy strategy for Capistrano. It takes an existing, pre-built archive and deploys it as-is. Useful when you've got a server making builds for you, which you then later deploy.
