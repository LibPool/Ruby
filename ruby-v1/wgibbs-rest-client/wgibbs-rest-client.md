# wgibbs-rest-client

**Tag**: web, cli, testing

## 简介

A fork of a simple REST client for Ruby, inspired by the Sinatra microframework style of specifying actions: get, put, post, delete.

- 主页: http://wgibbs.github.com/2009/10/09/rest-client-fork.html
