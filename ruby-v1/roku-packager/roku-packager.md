# roku-packager

**Tag**: filesystem

## 简介

Ruby library for packaging Roku applications. Requires a Roku in development mode and a zipped up application.

## 官网

- 主页: http://github.com/brookemckim/roku-packager
- 源码仓库: https://github.com/brookemckim/roku-packager
- RubyGems: https://rubygems.org/gems/roku-packager
