# tanzeeb-rufus-scheduler

**Tag**: library

## 简介

job scheduler for Ruby (at, cron, in and every jobs).

    By default uses a Ruby thread, if EventMachine is present, it will rely on it.

    This fork adds timezone support to cron schedules.
