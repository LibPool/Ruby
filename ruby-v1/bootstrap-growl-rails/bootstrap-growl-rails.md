# bootstrap-growl-rails

**Tag**: web, networking

## 简介

This Gem is intended as an asset wrapper for bootstrap-growl: https://github.com/mouse0270/bootstrap-growl. It turns Bootstrap alerts into "Growl-like" notifications.
