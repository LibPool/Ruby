# phone_sites

**Tag**: web, database, data

## 简介

This gem is for scraping data and organize workflow without storing
    something in databases. 
Usage: ```PhoneSites::GsmArena::Connection.get_manufacturers```
    will return list of manufacturers. 
Then you can call ```manufacturer.models```
    to get list of its models. Each model has method ```info``` that 

    takes model data from site with description
