# epiceditor

**Tag**: web, template

## 简介

EpicEditor for Rails - Is a Ruby on Rails engine which adds a JavaScript Markdown Editor to Rails 4 with split fullscreen editing, live previewing, automatic draft saving, offline support, and more.
