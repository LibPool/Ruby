# blueimp-file-upload-rails

**Tag**: web, filesystem

## 简介

This gem wraps the blueimp jQuery File Upload plugin as a Rails asset gem.  The plugin is by Sebastian Tschan, and the gem is packaged by Mike Virata-Stone.
