# language-converter

**Tag**: web, networking

## 简介

Free Language converter. Very easy to use. This language translaor you can do language conversion of word or text from one language to another language very easily   i.e. => require 'language_converter';
lc( 'Welcome', 'es','en'); . and thats it !! Its very easy to use and it free! :).For full description check
https://github.com/manish-shrivastava/language-converter .
