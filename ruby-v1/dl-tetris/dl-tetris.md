# dl-tetris

**Tag**: library

## 简介

Simple tetris clone written using the rubygame library. Arrow keys to move, up arrow to rotate. Space drops your piece to the ground.

## 官网

- 主页: https://github.com/lantins/tetris
- RubyGems: https://rubygems.org/gems/dl-tetris
