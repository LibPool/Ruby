# expectations

**Tag**: testing

## 简介

A lightweight unit testing framework. Tests (expectations) will be written as follows
  expect 2 do
    1 + 1
  end

  expect(1 + 1) == 2

  expect NoMethodError do
    Object.invalid_method_call
  end.
