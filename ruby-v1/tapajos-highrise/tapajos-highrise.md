# tapajos-highrise

**Tag**: web, testing, security, networking

## 简介

Based on the original API module from DHH, http://developer.37signals.com/highrise/, this gem is a cleaned up, tested version of the same. Contributors have added support for tags  which are not supported by the API directly  Configure by adding the following:  require 'highrise' Highrise::Base.site = 'http://your_site.highrisehq.com/' Highrise::Base.user = 'your_api_auth_token'q
