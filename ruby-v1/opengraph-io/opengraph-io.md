# opengraph-io

**Tag**: web, cli, networking

## 简介

A Ruby client for opengraph.io, a website scraper to grab OpenGraph tags or supplement them when they don't exist. See source at https://www.github.com/wbdana/opengraph-io-ruby

- 文档: https://www.rubydoc.info/gems/opengraph-io/0.1.2
