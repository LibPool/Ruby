# morfologik

**Tag**: library

## 简介

Ruby MRI bindings for morfologik-stemming library (Polish morphological analyzer)  written in Java.

## 官网

- 主页: http://github.com/snukky/morfologik
- RubyGems: https://rubygems.org/gems/morfologik

## 历史版本号

- 0.0.3 (2012-09-22)

## 获取地址

- RubyGems: https://rubygems.org/gems/morfologik

- Bundler: `gem "morfologik"`

- 最新版归档: https://rubygems.org/downloads/morfologik-0.0.3.gem
