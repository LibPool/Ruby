# gaudi

**Tag**: web, networking

## 简介

## DESCRIPTION

This gem provides setup, scaffolding and maintenance functions for [gaudi](http://github.com/damphyr/gaudi) installations.

## USAGE

To create a directory structure for a Gaudi based project:

```bash
gaudi -s project/root  
```
