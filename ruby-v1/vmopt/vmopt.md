# vmopt

**Tag**: testing, networking

## 简介

Internal virtual machine operations application： 
                          including Notepad operations, 
                          disk management, 
                          connectivity testing, 
                          drive management, 
                          system resource queries, 
                          network test, serial test, 
                          windows system power management
