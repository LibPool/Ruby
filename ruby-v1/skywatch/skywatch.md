# skywatch

**Tag**: library

## 简介

Simple alerting system that lets you define checks and alerts in any language that are then magically run on Heroku.

## 官网

- 主页: http://github.com/progrium/skywatch
- RubyGems: https://rubygems.org/gems/skywatch
