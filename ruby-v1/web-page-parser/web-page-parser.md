# web-page-parser

**Tag**: web, networking, tooling

## 简介

A Ruby library to parse the content out of web pages. Currently supports BBC News pages, The Guardian, Independent, New York Times, RT, Washington Post and The Intercept articles. Used by the News Sniffer project. https://www.newssniffer.co.uk
