# gemmate

**Tag**: library

## 简介

Gemmate uses Bundler to identify an application's dependencies and opens them in TextMate for quick reference.

## 官网

- 主页: http://github.com/devwout/gemmate
- RubyGems: https://rubygems.org/gems/gemmate
