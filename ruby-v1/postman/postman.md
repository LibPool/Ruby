# postman

**Tag**: web, testing

## 简介

postman is a ruby daemon for fetching mail for an address via pop3 and then delivering it to a specified webhook

## 官网

- 主页: http://github.com/moomerman/postman
- RubyGems: https://rubygems.org/gems/postman
