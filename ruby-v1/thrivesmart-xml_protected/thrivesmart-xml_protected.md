# thrivesmart-xml_protected

**Tag**: testing, serialization

## 简介

Keeps specified attributes of a model out of to_xml.  Do so by aliasing to_xml, and automatically sending in the correct :excludes to the original to_xml method, e.g. :excludes =&gt; [:attr1, :attr2, ...]
