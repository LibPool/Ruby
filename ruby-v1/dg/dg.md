# dg

**Tag**: tooling, devops

## 简介

DockerGo (DG)
=============

Provides tasks for quickly building docker and running (via fig) docker images.

Prerequisites:

- Git for version control.
- Mac or GNU/Linux environment.
- docker and fig are installed
