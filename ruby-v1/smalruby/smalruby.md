# smalruby

**Tag**: library

## 简介

smalruby is a 2D game development library. This is part of "Smalruby" project that is a learning ruby programming environment for kids.

## 官网

- 主页: https://github.com/smalruby/smalruby
- 文档: https://www.rubydoc.info/gems/smalruby/0.1.11
- RubyGems: https://rubygems.org/gems/smalruby
