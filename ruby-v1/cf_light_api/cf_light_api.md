# cf_light_api

**Tag**: web, database, devops, data

## 简介

A super lightweight API for reading App and Org data from CloudFoundry, cached in Redis.

## 官网

- 主页: https://github.com/springerpe/cf-light-api
- RubyGems: https://rubygems.org/gems/cf_light_api
