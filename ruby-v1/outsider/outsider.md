# outsider

**Tag**: filesystem

## 简介

rubygems plugin to allow a gem to install files outside its own directory

## 官网

- 主页: http://github.com/stcrocco/outsider
- RubyGems: https://rubygems.org/gems/outsider

- 0.0.1 (2010-10-04)

- Bundler: `gem "outsider"`

- 最新版归档: https://rubygems.org/downloads/outsider-0.0.2.gem
