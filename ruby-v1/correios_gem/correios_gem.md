# correios_gem

**Tag**: web

## 简介

Integracao com as APIs Sigep, Logistica Reversa,
                     Precificador (frete) e SRO, utilizando objetos Ruby para
                     requisicoes e respostas. Integrar com os Correios nunca foi
                     tao simples.
