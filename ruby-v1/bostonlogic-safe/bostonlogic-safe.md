# bostonlogic-safe

**Tag**: web, database, security, devops, filesystem, data

## 简介

Simple tool to backup databases (MySQL and PostgreSQL) and filesystem locally or to Amazon S3 or Rackspace Cloudfiles (with optional encryption)
