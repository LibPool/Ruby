# rubybukkit

**Tag**: web, networking

## 简介

RubyBukkit is Ruby library built on JRuby, which is used by CraftRabbit (https://github.com/rubybukkit/craftrabbit) and Rabbit (https://github.com/rubybukkit/rabbit), the Minecraft server mods.

## 官网

- 主页: http://github.com/rubybukkit/rubybukkit
- 文档: https://www.rubydoc.info/gems/rubybukkit/0.0.3
- RubyGems: https://rubygems.org/gems/rubybukkit
