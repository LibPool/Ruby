# openam-user

**Tag**: library

## 简介

OpenAM::User
    Librairie d'accès à OpenAM inférieur à la version 12.
    Cette librairie prend le compte utilisateur et le mot de passe.
    Si les informations sont correctes, le retour contient:
    - le prénom
    - le nom
    - l'uid
    - le token_id
    - la validité du compte
