# unidom-certificate

**Tag**: library

## 简介

Unidom (UNIfied Domain Object Model) is a series of domain model engines. The Certificate domain model engine includes Certificating model. Unidom (统一领域对象模型)是一系列的领域模型引擎。证书领域模型引擎包括认证的模型。
