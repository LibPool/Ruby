# capistrano-rbenv-install

**Tag**: web, networking

## 简介

Capistrano plugin for lightweight rubies management with rbenv.
Works with Capistrano 3 (only!). For Capistrano 2 support see:
https://github.com/yyuu/capistrano-rbenv
