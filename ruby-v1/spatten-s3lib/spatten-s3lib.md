# spatten-s3lib

**Tag**: web, networking, tooling

## 简介

This library forms the basis for building a library to talk to Amazon S3 using Ruby.  It is used as an example of how to build an Amazon S3 interface in The S3 Cookbook (http://thes3cookbook.sopobo.com)
