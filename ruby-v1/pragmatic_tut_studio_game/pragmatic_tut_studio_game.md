# pragmatic_tut_studio_game

**Tag**: library

## 简介

Pragmatic Studios tutorial completion!

A  very simple game with a number of game components:

	a simple Die(dice) system (including "Loaded Die")
	Different types of player classes (clumsy, berserker)
	Simple game turn system
	Simple treasure system with points
