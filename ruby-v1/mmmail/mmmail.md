# mmmail

**Tag**: networking

## 简介

Mmmm, a Minimalist mail library for Ruby. Works with SMTP or sendmail.

## 官网

- 主页: http://github.com/lsegal/mmmail
- RubyGems: https://rubygems.org/gems/mmmail
