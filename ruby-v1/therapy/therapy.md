# therapy

**Tag**: cli, template

## 简介

Therapy is a command line tool to help you interact with GitHub issues. Also supports offline viewing of said issues.

## 官网

- 主页: http://github.com/jeffrafter/therapy
- RubyGems: https://rubygems.org/gems/therapy
