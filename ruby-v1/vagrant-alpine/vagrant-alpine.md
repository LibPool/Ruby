# vagrant-alpine

**Tag**: cli, networking

## 简介

Vagrant support for Alpine Linux Guests.
    Features include: Detection, Set hostname, Configure networking DHCP or static,
    Halt/Shutdown the guest, RSync detection and installation, NFS client installation.
