# asciidoctor-pdf

**Tag**: library

## 简介

An add-on converter for Asciidoctor that converts AsciiDoc documents to PDF using the Prawn PDF generation library.

## 官网

- 主页: https://asciidoctor.org/docs/asciidoctor-pdf
- 源码仓库: https://github.com/asciidoctor/asciidoctor-pdf
- 更新日志: https://github.com/asciidoctor/asciidoctor-pdf/blob/main/CHANGELOG.adoc
- 问题追踪: https://github.com/asciidoctor/asciidoctor-pdf/issues
- RubyGems: https://rubygems.org/gems/asciidoctor-pdf
