# status_cat

**Tag**: web, devops

## 简介

This engine makes monitoring the status of your Rails environment easier.

    It provides a Rails action with a green light / red light list of configured services,
    such as:

     * ActionMailer
     * ActiveRecord
     * AWS S3
     * Delayed Job
     * Stripe
