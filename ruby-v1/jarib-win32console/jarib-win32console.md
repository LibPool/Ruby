# jarib-win32console

**Tag**: web, cli, networking

## 简介

This gem packages Gonzalo Garramuno's Win32::Console project, and includes a compiled binary for speed. The Win32::Console project's home can be found at:  http://rubyforge.org/projects/win32console  The gem project can be found at  http://rubyforge.org/projects/winconsole
