# coloregex

**Tag**: library

## 简介

Coloregex saves you from dealing with regex for colors, it contains all 147 named
colors including `transparant`.
And deals with any kind of color code: `hex`, `rgb`, `rgba`, `hsl`, `hsla` properly!
