# jruby-base32

**Tag**: library

## 简介

jruby-base32 is a fast port of the base32 gem with the computation done in pure java.

## 官网

- 主页: http://github.com/TheSkunkworx/jruby-base32
- RubyGems: https://rubygems.org/gems/jruby-base32
