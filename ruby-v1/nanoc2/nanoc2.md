# nanoc2

**Tag**: web

## 简介

a tool that runs on your local computer and compiles Markdown, Textile, Haml, ... documents into static web pages

## 官网

- 主页: http://nanoc.stoneship.org/
- RubyGems: https://rubygems.org/gems/nanoc2

## 历史版本号

- 2.2.3 (2010-02-20)

## 获取地址

- RubyGems: https://rubygems.org/gems/nanoc2
- gem 安装: `gem install nanoc2`
- Bundler: `gem "nanoc2"`
- 最新版本: 2.2.3
- 最新版归档: https://rubygems.org/downloads/nanoc2-2.2.3.gem
- 版本锁定: `gem "nanoc2", "~> 2.2.3"`
- 中央仓库: https://rubygems.org/
