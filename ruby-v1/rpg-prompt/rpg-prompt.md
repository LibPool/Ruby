# rpg-prompt

**Tag**: library

## 简介

Prompt that facilitates the management of characters and actions in a Role Playing Game. The set of rules can be programmed in Ruby to match your favourite set of rules. I have included an easy set of rules as an example, although in my games I use a commercial set of rules that I do not include for copyright reasons.
