# saxonc-libs

**Tag**: filesystem

## 简介

Downloads and installs the official SaxonC runtime files so other Ruby gems can link against them.

## 官网

- 主页: https://github.com/jakobjanot/ruby-saxonc-libs

- RubyGems: https://rubygems.org/gems/saxonc-libs

## 获取地址

- RubyGems: https://rubygems.org/gems/saxonc-libs
