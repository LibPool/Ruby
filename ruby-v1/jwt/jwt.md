# jwt

**Tag**: web, security, serialization

## 简介

A pure ruby implementation of the RFC 7519 OAuth JSON Web Token (JWT) standard.

## 官网

- 主页: https://github.com/jwt/ruby-jwt

- 问题追踪: https://github.com/jwt/ruby-jwt/issues
