# lsa_tdx_feedback

**Tag**: web

## 简介

LsaTdxFeedback provides a zero-configuration solution for collecting user feedback in Rails applications. It includes a modal interface that integrates with TeamDynamix (TDX) API for ticket creation, requiring no additional setup or configuration from the host application.
