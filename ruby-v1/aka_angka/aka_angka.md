# aka_angka

**Tag**: web

## 简介

AkaAngka / aka_angka / ArieKeren Angka adalah Library Ruby Angka untuk format Indonesia yang intuitif, independen, bisa digunakan baik dengan Ruby  murni maupun Rails. AkaAngka / aka_angka / ArieKeren Angka is an intuitive Indonesian Number Format,  independent, could be used well with pure Ruby and also Rails.
