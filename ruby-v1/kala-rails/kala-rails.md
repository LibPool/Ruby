# kala-rails

**Tag**: web

## 简介

Provides easy installation and usage of jQuery.kala javascript library for your Rails 3.1+ application.

## 官网

- 主页: http://github.com/archit/kala-rails
- RubyGems: https://rubygems.org/gems/kala-rails

## 历史版本号

- 0.1 (2012-04-29)

## 获取地址

- RubyGems: https://rubygems.org/gems/kala-rails
- gem 安装: `gem install kala-rails`
- Bundler: `gem "kala-rails"`
- 最新版本: 0.1
- 最新版归档: https://rubygems.org/downloads/kala-rails-0.1.gem
- 版本锁定: `gem "kala-rails", "~> 0.1"`
- 中央仓库: https://rubygems.org/
