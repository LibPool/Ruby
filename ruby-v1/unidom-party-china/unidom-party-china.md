# unidom-party-china

**Tag**: library

## 简介

Unidom (UNIfied Domain Object Model) is a series of domain model engines. The China Party domain model engine includes the Chinese Ethnicity enum code, the Marital Status enum code, the Political Affiliation enum code, the Religion Faith enum code, the Formal Schooling enum code, the Blood Group enum code, & the Business Registration enum code. Unidom (统一领域对象模型)是一系列的领域模型引擎。中国参与者领域模型引擎包括中国的民族、婚姻状况、政治面貌、宗教信仰、学历、血型、工商注册类型枚举编码。
