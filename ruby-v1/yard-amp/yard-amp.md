# yard-amp

**Tag**: library

## 简介

yard-amp is a YARD plugin that enables the automatic creation of YARD documentation from amp command declarations.

- 主页: http://github.com/michaeledgar/yard-amp
- RubyGems: https://rubygems.org/gems/yard-amp
