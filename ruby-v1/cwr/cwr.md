# cwr

**Tag**: web

## 简介

This fine gem gives you unparalleled access to the captain webhooks API. Once launched, this enables you to create webhooks beyond your hearts reasonable desires. Problem with too many people smashing your rails server down by polling to see if anything has changed? Problem no longer!
