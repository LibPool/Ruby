# capable

**Tag**: library

## 简介

Gem that will allow 'abilities' to be assigned to 'capable' objects that can be independantly expired and renewed.

## 官网

- 源码仓库: https://github.com/ericchapman/capable
- RubyGems: https://rubygems.org/gems/capable
