# hipchat-s3

**Tag**: filesystem

## 简介

Ruby library to upload files to s3 and alert users in hipchat with a link

## 官网

- 主页: http://github.com/jstin/hipchat-s3
- RubyGems: https://rubygems.org/gems/hipchat-s3

## 历史版本号

- 0.1.0 (2012-05-04)
