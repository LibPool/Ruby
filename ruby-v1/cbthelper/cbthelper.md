# cbthelper

**Tag**: web, testing, networking, template

## 简介

cbthelper wraps CrossBrowserTesting's (https://crossbrowsertesting.com/apidocs/v3/selenium.html) into an easy to use library.

## 官网

- 主页: https://help.crossbrowsertesting.com/selenium-testing/getting-started/cbthelper-ruby/
- 源码仓库: https://github.com/crossbrowsertesting/cbthelper-ruby
- RubyGems: https://rubygems.org/gems/cbthelper
