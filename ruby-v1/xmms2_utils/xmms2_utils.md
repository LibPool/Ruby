## 简介

# Xmms2Utils

This is a set of utilites for working with the ruby bindings for the XMMS2 client library.

## Installation

Add this line to your application's Gemfile:

```ruby
gem 'xmms2_utils'
```

And then execute:

    $ bundle

Or install it yourself as:

    $ gem install xmms2_utils
