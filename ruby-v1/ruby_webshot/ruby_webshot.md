# ruby_webshot

**Tag**: web, testing, networking, tooling

## 简介

Ruby Webshot gem will make nice webshots for you. I needed the webshot/screenshot functionality for one of my website and after trying few ruby gems currently available I found that they are not updated lately and that they are using depricated version of `PhantomJS`: 
    'webshot' [ https://github.com/vitalie/webshot ] 
    'screenshot' [ https://github.com/amire80/screenshot ].  
    Also, I had an issue with produced image CSS formating when I used webshot gem.
    So, I decided to start building a gem for myself and to share for anyone who need something like this.
    The Ruby Webshot Gem use latest `Webdrivers`.
