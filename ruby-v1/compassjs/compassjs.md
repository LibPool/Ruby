# compassjs

**Tag**: web

## 简介

Compass.js allow you to get compass heading in JavaScript by PhoneGap, iOS API or GPS hack.

## 官网

- 主页: http://ai.github.com/compass.js/
- RubyGems: https://rubygems.org/gems/compassjs

## 历史版本号

- 0.1.1 (2013-03-02)
- 0.1.0 (2012-11-27)

## 获取地址

- RubyGems: https://rubygems.org/gems/compassjs

- 最新版归档: https://rubygems.org/downloads/compassjs-0.1.1.gem
