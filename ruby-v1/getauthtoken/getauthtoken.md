# getauthtoken

**Tag**: web, cli, security

## 简介

Small CLI utility to acquire a Xaptum API authentication token and copy into your clipboard.

## 官网

- 主页: https://xaptum.com
- 源码仓库: https://github.com/dylanirlbeck/getauthtoken
