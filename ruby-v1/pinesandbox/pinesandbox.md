# pinesandbox

**Tag**: library

## 简介

Ruby SDK for Pine Computers: create a Computer for your project, attach to it, and drive its browser, desktop, shell and agent, with state that persists across stops and starts.

- 文档: https://console.pinecomputer.io/docs
