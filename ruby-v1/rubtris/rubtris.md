# rubtris

**Tag**: cli

## 简介

Rubtris is a Ruby clone of everyone's favorite tetromino-based puzzle game, played entirely on the command line. Install the Gem and simply run 'rubtris' on the command line to play. Thanks to Danny Burt for his contributions.
