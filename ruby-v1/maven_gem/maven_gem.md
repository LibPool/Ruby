# maven_gem

**Tag**: library

## 简介

MavenGem is a tool, library, and gem plugin to install any Maven-published
Java library as though it were a gem.

## 官网

- 主页: http://github.com/jruby/maven_gem
- RubyGems: https://rubygems.org/gems/maven_gem
