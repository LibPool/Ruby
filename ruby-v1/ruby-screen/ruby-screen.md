# ruby-screen

**Tag**: cli

## 简介

Ruby command line utility to manage GNU Screen configurations, and launch Screen using those configuration.

## 官网

- 主页: http://ruby-screen.rubyforge.org
- RubyGems: https://rubygems.org/gems/ruby-screen
