# fluent-plugin-jfrog-metrics

**Tag**: data

## 简介

Fluentd Plugin for converting JFrog Artifactory, Xray, RTFS generated metrics (Prometheus Exposition Format) to target observability platform format (Splunk HEC, New Relic, DataDog)
