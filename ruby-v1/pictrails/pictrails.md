# pictrails

**Tag**: web

## 简介

A Web Photo Gallery, written with Rails on rails, Pictrails can manage several photo galleries.

## 官网

- 主页: http://pictrails.rubyforge.org
- RubyGems: https://rubygems.org/gems/pictrails

## 历史版本号

- 0.5.0 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/pictrails
- gem 安装: `gem install pictrails`
- Bundler: `gem "pictrails"`
- 最新版本: 0.5.0
- 最新版归档: https://rubygems.org/downloads/pictrails-0.5.0.gem
- 版本锁定: `gem "pictrails", "~> 0.5.0"`
