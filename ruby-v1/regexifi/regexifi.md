# regexifi

**Tag**: testing

## 简介

A collection of tested common Regex experessions. Because why re-invent the wheel every time for a new project? Don't add a bunch of adhoc Regex epxressions for common things like email addresses, urls, usernames, timeformats - Regexifi instead!
