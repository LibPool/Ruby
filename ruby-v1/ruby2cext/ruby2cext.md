# ruby2cext

**Tag**: tooling

## 简介

Ruby2CExtension is a Ruby to C extension translator/compiler.

## 官网

- 主页: http://ruby2cext.rubyforge.org/
- RubyGems: https://rubygems.org/gems/ruby2cext

## 历史版本号

- 0.2.0 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/ruby2cext
- gem 安装: `gem install ruby2cext`
- Bundler: `gem "ruby2cext"`
- 最新版本: 0.2.0
- 最新版归档: https://rubygems.org/downloads/ruby2cext-0.2.0.gem
- 版本锁定: `gem "ruby2cext", "~> 0.2.0"`
- 中央仓库: https://rubygems.org/
