# epiabstractions

**Tag**: web, testing

## 简介

EPiAbstractions provides facades for many of the classes in EPiServers products which enable its users to decouple their code from the concrete implementations and thereby gaining the ability to unit test code that otherwise would depend on the concrete implementations.
