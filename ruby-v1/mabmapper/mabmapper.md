# mabmapper

**Tag**: serialization, data

## 简介

Mabmapper is a powerful and extendable processing engine to normalize any kind of
    input data into a simple intermediate format made of fields and values. It comes with a ready to use
    engine to process MabXML data. Hence the name Mabmapper.
