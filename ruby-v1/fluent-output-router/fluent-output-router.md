# fluent-output-router

**Tag**: library

## 简介

Depending on the message tag, this fluent plugin can start new instances of any other available output plugins for fluent (for example the fluent-plugin-s3). This way it is possible to have one fluent input get split into separate (s3) output instances. The output instances will be shut down individually when there is no traffic to an instance.
