# tokyocafe

**Tag**: web, networking

## 简介

TokyoCafe is a set of classes to help you talk to TokyoCabinet (http://1978th.net/tokyocabinet/) with Ruby

## 官网

- 主页: http://github.com/spk/tokyocafe
- RubyGems: https://rubygems.org/gems/tokyocafe

## 历史版本号

- 0.0.2 (2010-01-11)

## 获取地址

- RubyGems: https://rubygems.org/gems/tokyocafe
- gem 安装: `gem install tokyocafe`
- Bundler: `gem "tokyocafe"`
- 最新版本: 0.0.2
- 最新版归档: https://rubygems.org/downloads/tokyocafe-0.0.2.gem
- 版本锁定: `gem "tokyocafe", "~> 0.0.2"`
