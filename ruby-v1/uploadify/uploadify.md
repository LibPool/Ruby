# uploadify

**Tag**: web, filesystem

## 简介

Adds multi-file upload support to your Rails application using Uploadify, a JQuery plugin.

## 官网

- 主页: http://github.com/adeptware/uploadify
- RubyGems: https://rubygems.org/gems/uploadify
