# sho-mongrel

**Tag**: web, testing

## 简介

Mongrel patched to run on Ruby 1.9 and respect Rails cache directives. Nothing more, nothing less.

## 官网

- 主页: http://mongrel.rubyforge.org
- RubyGems: https://rubygems.org/gems/sho-mongrel
