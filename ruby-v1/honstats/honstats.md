# honstats

**Tag**: web, data

## 简介

HonStats is a Ruby library for extracting player statistics and other information from the Heroes of Newerth master server.

## 官网

- 主页: https://github.com/lloydpick/hon-stats
- RubyGems: https://rubygems.org/gems/honstats
