# engineyard-local

**Tag**: testing

## 简介

Engine Yard Local allows you to develop and test locally on your own computer using a virtual machine with an Engine Yard environment.

## 官网

- 文档: https://support.cloud.engineyard.com/entries/22355466-use-engine-yard-local
