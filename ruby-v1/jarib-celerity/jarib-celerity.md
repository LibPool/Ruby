# jarib-celerity

**Tag**: web, testing, template

## 简介

Celerity is a JRuby library for easy and fast functional test automation for web applications.  It is a JRuby wrapper around HtmlUnit â€“ a headless Java browser with  JavaScript support. It provides a simple API for programmatic navigation through web applications. Celerity aims at being API compatible with Watir.
