# appscake

**Tag**: web, devops

## 简介

AppsCake provides a pretty web interface that can be used to deploy
    AppScale over machines in Xen, KVM, Amazon EC2, or Eucalyptus. In
    short, it makes deploying AppScale a piece of cake!
