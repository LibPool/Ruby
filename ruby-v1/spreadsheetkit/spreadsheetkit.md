# spreadsheetkit

**Tag**: template

## 简介

Create XLSs using HTML+CSS. The objective is the same of PDKKit, but for spreadsheets.

- 主页: http://github.com/voraz/spreadsheetkit
- RubyGems: https://rubygems.org/gems/spreadsheetkit
