# verified

**Tag**: library

## 简介

CHECK GITHUB - THIS GEM WILL NO LONGER BE UPDATED - a simple gem to verify and parse MRZ codes and numbers on passports and UK drivers licenses. Useful if you need to comply with KYC or Money Laundering ID checks.
