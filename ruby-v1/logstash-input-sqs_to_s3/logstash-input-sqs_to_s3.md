# logstash-input-sqs_to_s3

**Tag**: library

## 简介

This gem is a logstash plugin required to be installed on top of the Logstash core pipeline using $LS_HOME/bin/plugin install gemname. This gem is not a stand-alone program. This version works with Logstash 5.
