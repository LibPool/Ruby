# red-arrow-gdk-pixbuf

**Tag**: library

## 简介

Red Arrow GDK Pixbuf adds `Arrow::Tensor#to_pixbuf` and `GdkPixbuf::Pixbuf#to_arrow`. `Arrow::Tensor#to_pixbuf` returns a `GdkPixbuf::Pixbuf`. `GdkPixbuf::Pixbuf#to_arrow` returns a `Arrow::Tensor`.
