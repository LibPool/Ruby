# coindcx

**Tag**: web, networking

## 简介

An official Ruby library to access coindcx exchange APIs, includes REST and WebSockets.

## 官网

- 主页: https://github.com/coindcx-official/coindcx-ruby-client
- RubyGems: https://rubygems.org/gems/coindcx
