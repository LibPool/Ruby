# asset_bom_removal-rails

**Tag**: web, filesystem

## 简介

Hooks into rails asset:precompile task to remove the BOM from any CSS files generated by SASS.  Firefox &lt; 52 has a bug when calculating SRI for CSS files with a BOM and removing it has no downsides so that's what we do.
