# parlement

**Tag**: library

## 简介

Forum and mailing list project aiming to be a complete Direct Democracy
    implementation where everybody can propose polls, vote on them, or delegate
    their voice to someone else.

		Trust through:
		- P2P cluster
		- PGP signatures
		- electoral lists
