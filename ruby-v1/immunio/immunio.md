# immunio

**Tag**: web, database, security, networking

## 简介

IMMUNIO protects your web app from security vulnerabilities by monitoring
requests in realtime. After a two minute installation, your application will be
protected from many of the top classes of attacks, including Cross-Site
Scripting (XSS), SQL Injection, Remote Command Execution, and Bruteforce.

This agent gem works in conjunction with the IMMUNIO service. Go to
https://immun.io to learn more and create an account.
