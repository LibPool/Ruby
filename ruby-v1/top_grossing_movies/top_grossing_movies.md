# top_grossing_movies

**Tag**: web, cli, networking, template

## 简介

Scrapes a newsday website: https://www.newsday.com/entertainment/movies/the-biggest-box-office-hits-of-all-time-1.5369007 and provides a CLI for viewing the top 25 top grossing movies of all time and details about each.
