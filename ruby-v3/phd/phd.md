# phd

**Tag**: web, database, networking, filesystem

## 简介

Phd is a tool to browse changes in disk space usage. It creates an sqlite3 index and creates SVG images of the usage. The svg uses area and color to display both file size and size change relative to the compared date. Phd is a near complete rewrite of philesight (http://zevv.nl/play/code/philesight/) with many changes.
