# jaybbb-ruby-aaws

**Tag**: web, devops, filesystem

## 简介

Ruby/AWS is a Ruby wrapper to the Amazon Product Advertising API. This version works with heroku as it looks for the .amazonrc file in Rails.root/config and also works for any Rails Version as the dependencie were removed
