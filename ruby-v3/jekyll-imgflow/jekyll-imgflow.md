# jekyll-imgflow

**Tag**: web

## 简介

ImgFlow provides automatic image optimization for Jekyll with support for multiple providers (Sharp, ImageMagick, LibVips, Imgproxy, Weserv, Flyimg), multiple formats (AVIF, WebP, PNG, JPG), and responsive image generation with modern picture tags.
