# govdelivery-tms

**Tag**: web, cli

## 简介

A reference implementation, written in Ruby,
                     to interact with GovDelivery's TMS API. The client is
                     compatible with Ruby >=2.5.8, and <= 2.7.1

## 官网

- 主页: http://govdelivery.com
- 文档: https://www.rubydoc.info/gems/govdelivery-tms/3.0.0
- RubyGems: https://rubygems.org/gems/govdelivery-tms
