# glimmer-dsl-web-icons

**Tag**: web, template, filesystem, data

## 简介

glimmer-dsl-web has no built-in icon story. glimmer-dsl-web-icons fills
that gap: it ships icon data from popular icon libraries (Lucide,
Heroicons, and Phosphor today) in glimmer-dsl-web's own native format --
arrays of [tag, attrs] pairs rendered as real SVG child elements -- plus
a small Icon component and registry so a project can render
`icon('circle-check', library: :lucide)` without hand-maintaining its
own SVG paths.
