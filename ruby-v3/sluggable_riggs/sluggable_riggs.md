# sluggable_riggs

**Tag**: testing, tooling

## 简介

Note: You need to specify a "slug" column in the db table for your sluggable asset, and then use the "slugged_column" class method, provided in this module, and pass into it the column_name you would like to slug (e.g. title, username, etc.). This gem will, in short, look at the column that you provide, and inject that attribute into various instance methods that will be used to build the slug for your sluggable asset.
