# jekyll-gis-blogger

**Tag**: web, serialization, template, filesystem, data

## 简介

A collection of Jekyll Liquid tags and hooks for GIS blogging: Leaflet maps, GPX track display with elevation profiles, StoryMapJS and lungkui.js story-map embeds, and sortable HTML tables from GeoJSON/CSV. Zero runtime dependencies beyond Jekyll.
