# cjk_index

**Tag**: tooling

## 简介

Builds a bigram search index in Ruby (with kana, old/new kanji and NFKC normalization), and queries it in Ruby or with a small browser runtime that returns the same results. Includes a Jekyll plugin and a CollectionBuilder preset.
