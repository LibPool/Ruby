# skill

**Tag**: filesystem

## 简介

Installs Agent Skills, folders holding a SKILL.md, from GitHub repositories, plugin marketplaces, and local folders into RubyLLM's app/skills and the folders Claude Code, Codex, Cursor, and other agents read. Records each skill's source and commit in skills.lock, shows what changes before an update, and refuses unsafe archives. Run it with `gem exec skill add owner/repo`.
