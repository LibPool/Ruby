# ruaur

**Tag**: database, data

## 简介

RuAUR is a Ruby gem that allows searching and installing packages from the Pacman sync database as well as the Arch User Repository (AUR).

## 官网

- 主页: https://gitlab.com/mjwhitta/ruaur
- RubyGems: https://rubygems.org/gems/ruaur
