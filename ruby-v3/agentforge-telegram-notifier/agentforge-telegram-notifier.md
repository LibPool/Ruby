# agentforge-telegram-notifier

**Tag**: web, cli, security, filesystem

## 简介

A credential-safe Ruby client for the Telegram Notifier public v1 API. Supports source-scoped inbox, notification, reply and file flows with optional Bearer auth, idempotent writes, retries and structured errors.
