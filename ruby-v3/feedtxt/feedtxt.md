# feedtxt

**Tag**: library

## 简介

feedtxt - reads Feed.TXT a.k.a. RSS (Really Simple Sharing) 5.0 ;-) - feeds in text (unicode) - publish &amp; share posts, articles, podcasts, 'n' more
