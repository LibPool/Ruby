# ruby-ogre

**Tag**: library

## 简介

Ruby bindings for Ogre. Note that this ruby-ogre gem downloads a real ruby-ogre gem from bitbucket site and then installs it.

## 官网

- 主页: https://github.com/abexsoft/ruby-ogre
- RubyGems: https://rubygems.org/gems/ruby-ogre
