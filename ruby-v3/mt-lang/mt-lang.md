# mt-lang

**Tag**: web, tooling

## 简介

A statically-typed, compiled programming language with C ABI interop, async/await, generics, pattern matching, and a comprehensive standard library. Includes the mtc compiler, LSP server (mtc lsp), and DAP debug adapter (mtc dap).
