# licentivo-sdk

**Tag**: library

## 简介

Licentivo adds license activation, machine-scoped device credentials, pinned signature verification, feature and expiry checks, policy heartbeats, permitted offline grants, floating seats and metered reserve/commit/cancel workflows to Ruby applications. Applications provide their activation UI, business block and durable results; the SDK manages the licensing protocol. See the documentation for pinned installation commands and working examples.
