# wechat_work_webhook

**Tag**: web, cli, networking, filesystem

## 简介

企业微信群机器人Webhook Ruby 客户端. 支持文本消息, markdown, 图片, 图文, 文件 消息 ( https://work.weixin.qq.com/api/doc/90000/90136/91770 ). A wechat work webhook Ruby client which support text, markdown, image, news, file message ( https://work.weixin.qq.com/api/doc/90000/90136/91770 ).
