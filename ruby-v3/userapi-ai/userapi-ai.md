# userapi-ai

**Tag**: web

## 简介

This library provides a convenient way to interact with the Midjourney via API offered by the UserAPI.ai website. All major methods are available, including: imagine, describe, upscale, variations, inpaint (vary region), pan, zoom, and reroll, working in the remix mode.
