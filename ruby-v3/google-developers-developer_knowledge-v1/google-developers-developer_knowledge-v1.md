# google-developers-developer_knowledge-v1

**Tag**: web, cli, testing

## 简介

The Developer Knowledge API provides access to Google's developer knowledge. Note that google-developers-developer_knowledge-v1 is a version-specific client library. For most uses, we recommend installing the main client library google-developers-developer_knowledge instead. See the readme for more details.
