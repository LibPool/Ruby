# Robbe_Bonne_thermostat

**Tag**: library

## 简介

this code will check the input temperature,range and wanted temperature.
    If the temp is not the same as the wanted temp, then it will put the cooling or heating on.
    It will show via the led if it cools (blue),if it heats (red) and else it will be green.
    It's possible to change the unit of the temperature and it will be automatically changed to Celsius.
