# i18n-generators

**Tag**: web, tooling, filesystem

## 简介

A Rails generator plugin & gem that generates Rails I18n locale files for almost every known locale.

## 官网

- 主页: https://github.com/hauleth/i18n-generators
- RubyGems: https://rubygems.org/gems/i18n-generators
