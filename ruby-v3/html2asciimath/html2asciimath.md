# html2asciimath

**Tag**: template

## 简介

Converts simple math formulae written in pure HTML to AsciiMath

## 官网

- 主页: https://www.plurimath.org/
- 源码仓库: https://github.com/plurimath/html2asciimath
- RubyGems: https://rubygems.org/gems/html2asciimath
