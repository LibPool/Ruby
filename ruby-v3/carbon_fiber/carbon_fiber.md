# carbon_fiber

**Tag**: library

## 简介

A high-performance Ruby Fiber Scheduler using a Zig native extension with libxev (io_uring on Linux, kqueue on macOS). Works as a pure Ruby Fiber Scheduler, as well as with the async gem.
