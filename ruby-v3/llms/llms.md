# llms

**Tag**: web

## 简介

Ruby library for interacting with various LLM providers including Anthropic, Google Gemini, xAI, and other OpenAI-compatible API providers (including local models). Supports streaming, event-handling, conversation management, tool-use, image input, and cost-tracking.
