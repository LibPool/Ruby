# ultimate_static_modal

**Tag**: template

## 简介

View helpers and Stimulus controllers for rendering ultimate_turbo_modal's <dialog> chrome on content that is not loaded via a Turbo Frame. Reuses UTMR's flavor classes and extends its exported Stimulus controller with a small frameless adapter.
