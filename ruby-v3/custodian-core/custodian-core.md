# custodian-core

**Tag**: cli, testing

## 简介

Custodian::Core resolves a chain of custody over a tree of responsibilities: it identifies the next responsible party and demands the action a previous ward could not fulfill, climbing the tree until someone can act. It carries no business rules from any specific domain - concrete domains are implemented as satellite gems that register actions into this core via a registry.
