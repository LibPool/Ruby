# vpim_icalendar

**Tag**: library

## 简介

This is a virtual gem, it exists to depend on vPim, which provides iCalendar support for ruby. You can install vPim directly.

## 官网

- 主页: http://vpim.rubyforge.org
- RubyGems: https://rubygems.org/gems/vpim_icalendar

## 历史版本号

- 1.1 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/vpim_icalendar

- Bundler: `gem "vpim_icalendar"`
