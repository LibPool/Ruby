# Puke

**Tag**: web

## 简介

Puke is a minimal grooveshark library for ruby, using the Tinysong.com api instead of grooveshark.com

## 官网

- 文档: https://www.rubydoc.info/gems/Puke/0.0.2
- RubyGems: https://rubygems.org/gems/Puke

## 历史版本号

- 0.0.2 (2011-10-15)

## 获取地址

- RubyGems: https://rubygems.org/gems/Puke
