# pcre2

**Tag**: library

## 简介

Wraps the PCRE2 library using FFI so it and the advanced functionality it provides can be used in Ruby projects

## 官网

- 主页: https://github.com/dv/pcre2
- RubyGems: https://rubygems.org/gems/pcre2
