# buttercms

**Tag**: web

## 简介

Butter makes setting up a company blog on Rails insanely easy. It's built for developers to save us from hosting, DB setup, themeing, maintaining yet another Wordpress install. It's designed to be quickly integrated to an existing Rails project.
