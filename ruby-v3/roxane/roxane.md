# roxane

**Tag**: web, template

## 简介

Roxane embeds the operating system's webview (WebView2 / WKWebView / WebKitGTK, via the webview C library) in a native window and bridges it to Ruby with an invoke/emit operation channel — a lightweight, Tauri-shaped way to ship a web frontend as a desktop app, in Ruby.
