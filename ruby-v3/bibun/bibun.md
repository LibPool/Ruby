# bibun

**Tag**: filesystem, data

## 简介

This gem allows to do simulation runs of systems of ordinary differential equations of one independent variable 
using numerical Runge-Kutta methods for approximation. Contains some features like calculation of separate additive
terms of the differential equations, calculation of custom expressions and logging and printing runs to csv files,
which engineers may find convenient.
