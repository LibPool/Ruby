# ask-computer

**Tag**: cli, security

## 简介

Drive desktop apps in the background via Cua Driver — screenshots, clicks, typing, sandboxed VMs, and encrypted Computer History. Wraps Cua's MCP tools as Ask::Tool subclasses and ships a bundled computer.use_computer skill.
