# vlad-git

**Tag**: library

## 简介

Vlad plugin for Git support. This was previously part of Vlad, but all
modules outside the core recipe have been extracted.

## 官网

- 主页: http://github.com/jbarnette/vlad-git
- RubyGems: https://rubygems.org/gems/vlad-git
