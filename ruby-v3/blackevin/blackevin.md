# blackevin

**Tag**: web

## 简介

Sign token requests, publish, read history and presence, and manage queues on Blackevin. Standard library only: no runtime dependencies. Ruby 3.0 and up. Works in Rails, Sinatra, Hanami or plain Ruby.
