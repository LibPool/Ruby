# aliyun-rails

**Tag**: web, devops

## 简介

支持 Rails 轻松访问阿里云服务，例如：弹性云主机（ECS）、负载均衡（SLB）、云监控（CloudMonitor）等。当前已支持短信服务、语音服务，可以直接调用！
