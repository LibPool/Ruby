# crowdin-cli

**Tag**: web, cli, filesystem

## 简介

A command-line interface to sync files between your computer/server and Crowdin.

## 官网

- 主页: https://github.com/crowdin/crowdin-cli/
- 文档: https://www.rubydoc.info/gems/crowdin-cli/0.7.0
- RubyGems: https://rubygems.org/gems/crowdin-cli
