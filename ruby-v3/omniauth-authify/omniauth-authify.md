# omniauth-authify

**Tag**: security

## 简介

An OmniAuth strategy that authenticates against Authify, a self-hosted, multi-tenant identity provider, using the OpenID Connect authorization code flow with PKCE, verifying ID tokens against the organization's JWKS.
