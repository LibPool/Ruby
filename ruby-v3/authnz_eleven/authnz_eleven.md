# authnz_eleven

**Tag**: web, security

## 简介

Generates a pre-built, security-conscious authentication system into a Rails app: DB-backed sessions with idle/absolute timeouts, paranoid flows, magic links, TOTP MFA, an admin area, and more, all opt-in via flags. Inspired by authentication-zero.
