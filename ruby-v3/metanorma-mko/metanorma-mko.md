# metanorma-mko

**Tag**: web, serialization

## 简介

The MN 116 wire contract as code: typed unit schema, bundle layout with manifest verification, hash-addressed assets, edition diffs, interlingual alignment, generated JSON Schemas, and the reference MCP server. metanorma-document composes this gem to export; polyglot consumers validate against the published schemas.
