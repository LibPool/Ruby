# safe_image

**Tag**: data

## 简介

Safe Image is a small Ruby image-processing boundary for untrusted uploads: helper-contained libvips thumbnails/probing, hardened ImageMagick compatibility operations, optimisation, SVG metadata probing, and optional atomic Landlock sandbox execution.
