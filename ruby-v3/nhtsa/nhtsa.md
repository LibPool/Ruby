# nhtsa

**Tag**: web, testing, data

## 简介

NHTSA offers data on safety ratings, recalls, complaints, civil penalty payments, and child safety seat inspection station locations through their various web APIs. The main motivation for this gem is to access the NHTSA WebAPIs and make the data available to use for any ruby application.
