# jekyll-turbo

**Tag**: cli, template

## 简介

jekyll-turbo is a plugin for Jekyll that seamlessly integrates Hotwire's Turbo Drive into your static site. It automatically injects the necessary script tag into your HTML output to enable client-side Turbo features, such as Turbo Drive and Turbo Frames.
