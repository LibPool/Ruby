# vdb

**Tag**: web, template, filesystem

## 简介

vdb mounts a self-contained D3-powered entity-relationship diagram at any
path in your Rails app. It reads db/schema.rb (and any additional schema files
you configure), infers FK relationships, and renders an interactive force-directed
graph with search, zoom, drag-to-rearrange, and position persistence.

Ships with zero asset-pipeline dependencies — D3 and Stimulus are loaded from CDN.
Recommended for development environments only.
