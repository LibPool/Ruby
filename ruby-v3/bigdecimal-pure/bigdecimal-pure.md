# bigdecimal-pure

**Tag**: tooling

## 简介

`require 'bigdecimal'` loads the native bigdecimal when it is installed and otherwise a pure Ruby BigDecimal that behaves like bigdecimal 4.x, NaN, modes, limit and BigMath to any precision included, for ruby.wasm and other places without a C compiler.
