# ace-herdr

**Tag**: cli

## 简介

Herdr agent orchestration with push delivery, agent bootstrap, dispatch, and a durable attempt-linked inbox for submission to the original Codex/Pi terminal, with explicit uncertain outcomes. Implements the ace-hitl provider delivery contract.
