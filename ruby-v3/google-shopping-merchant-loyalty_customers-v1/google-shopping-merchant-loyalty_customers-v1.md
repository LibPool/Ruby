# google-shopping-merchant-loyalty_customers-v1

**Tag**: cli, testing

## 简介

Programmatically manage your Merchant Center Accounts. Note that google-shopping-merchant-loyalty_customers-v1 is a version-specific client library. For most uses, we recommend installing the main client library google-shopping-merchant-loyalty_customers instead. See the readme for more details.
