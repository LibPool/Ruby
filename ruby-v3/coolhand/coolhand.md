# coolhand

**Tag**: web, networking, devops

## 简介

Automatically intercept and log LLM requests from Ruby applications. Supports OpenAI, official Anthropic gem, ruby-anthropic gem, Google Gemini, Google Vertex AI, AWS Bedrock, OpenRouter, and any other library using Net::HTTP (directly, or via Faraday's default adapter). Features a single unified Net::HTTP interceptor, streaming support, thread-safe operation, and automatic duplicate request prevention.
