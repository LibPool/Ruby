# edupage-cli

**Tag**: web, cli

## 简介

ActiveRecord-like prístup k Edupage - školy, žiaci, rozvrhy, domáce úlohy a známky - vystavený zhodne cez Ruby API, CLI, REST API a MCP server. Iba na čítanie.
