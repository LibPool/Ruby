# dtrexp

**Tag**: web, testing, networking

## 简介

Holds the gem name for the DTRExp Ruby port, which is in development. DTRExp is a compact string expression for date-time ranges and recurrence, evaluated by coverage. Spec, test vectors and the existing implementations: https://github.com/DTRExp/dtrexp
