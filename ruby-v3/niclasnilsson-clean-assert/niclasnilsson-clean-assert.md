# niclasnilsson-clean-assert

**Tag**: testing

## 简介

A Ruby library to get really clean asserts.  Example:  assert / "name != nil" / "not name.empty?" / "age &gt;= 21"  This will do three separate assertion checks and will give you an error message that includes the broken assertion code, the class and in which method. No need for having first the actual assertion and a strained error message that you normally have to write. This is executable, Design by Contract style.
