# no-ie6-rails

**Tag**: web, cli

## 简介

Simple rails extension that checks if client has IE6 browser, and displays small (and closable) overlay, suggesting to update browser to a modern one.

## 官网

- 主页: https://github.com/ivalkeen/no-ie6-rails
- RubyGems: https://rubygems.org/gems/no-ie6-rails
