# hookie

**Tag**: library

## 简介

Hookie provides a way to write git hooks with ruby without too much worrying about any of the plumbing required, you can easily write your own plugins and focus on the core of your functionality. 

    Hookie includes plugins for Jenkins, FishEye, and HipChat.
