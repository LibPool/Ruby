# ffi-openmpt

**Tag**: web, networking, template

## 简介

libopenmpt is a library to render tracker music (MOD, XM, S3M, IT, MPTM and dozens of other legacy formats) to a PCM audio stream. See https://openmpt.org/ for more information.
