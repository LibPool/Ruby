# lilac-router

**Tag**: tooling, filesystem

## 简介

Provides `Lilac::Router`, a signal-backed driver for SPA-style navigation against `window.location`. Designed for the lilac-compiled wasm variant; lilac-full already links the router gem in. Picked up automatically by `lilac build` via Bundler when the gem appears in the project's Gemfile.
