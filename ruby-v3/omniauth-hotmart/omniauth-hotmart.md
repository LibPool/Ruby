# omniauth-hotmart

**Tag**: web, security

## 简介

Simply a omniauth provider for Hotmart. Connect your Ruby on Rails application to the Hotmart suite of web applications. It uses OmniAuth/OAuth to connect with Hotmart's hotconnect.
