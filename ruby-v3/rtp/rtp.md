# rtp

**Tag**: library

## 简介

This is a pure Ruby implementation of RTP, initially geared
   towards use with RTSP (but not limited to).

## 官网

- 主页: http://github.com/turboladen/rtp
- RubyGems: https://rubygems.org/gems/rtp
