# samagotchi

**Tag**: web, cli, filesystem

## 简介

chi is an agent harness for local and OpenAI-compatible models (llama.cpp, mlx, oMLX, hosted APIs). It runs sessions in a terminal REPL or in background workers you can attach to from the terminal and a web UI, keeps memories in plain files shared as bundles, and extends through hooks, guardrails, plugins and MCP servers.
