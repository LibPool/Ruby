# rails-hyperdrive-layered-rails

**Tag**: web

## 简介

Ships Vladimir Dementyev's Layered Rails skill (from palkan/skills) as a rails-hyperdrive companion. The architecture core installs into any Rails app; each per-gem reference manual installs only when that gem is in the app's bundle.
