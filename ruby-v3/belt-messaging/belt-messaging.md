# belt-messaging

**Tag**: devops

## 简介

Belt plugin providing SMS and email messaging. SMS via AWS PinpointSMSVoiceV2, email via AWS SESv2. Includes phone verification, opt-in/opt-out handling, and Terraform infrastructure.
