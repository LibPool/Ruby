# active_nothing

**Tag**: web, networking

## 简介

A ruby gem inspired by a talk from Sandi Metz (https://youtu.be/9lv2lBq6x4A) and Yehuda Katz blogpost (http://yehudakatz.com/2009/10/04/emulating-smalltalks-conditionals-in-ruby/) for better conditions' flow.
