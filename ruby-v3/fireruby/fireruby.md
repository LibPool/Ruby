# fireruby

**Tag**: web

## 简介

FireRuby is an extension to the Ruby programming language that provides access to the Firebird open source RDBMS. FireRuby is based in the Firebird C API and has no additional dependencies. The FireRuby library wraps the API calls in a Ruby OO interface.
