# ipwhois

**Tag**: web, cli

## 简介

Simple, dependency-free Ruby client for the ipwhois.io IP Geolocation API. Supports single and bulk IP lookups (IPv4 and IPv6), free and paid plans, localisation, field selection, threat detection and rate-limit info.
