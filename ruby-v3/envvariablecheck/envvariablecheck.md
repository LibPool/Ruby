# envvariablecheck

**Tag**: template, filesystem

## 简介

envvariablecheck loads ~/.env into the environment before a Ruby
script runs, and reviews the file's keys and passwords against password best
practices. It ranks each secret, checks for reused and placeholder values,
and reports loose file permissions and a missing gitignore entry. The
review prints the env file in full.
