# jeffreyhunter77-R2Doc

**Tag**: security, template, tooling

## 简介

R2Doc is an improved generator for RDoc. It provides an improved output template for documentation (including search and frameless navigation), but also aims to be more extensible so that template authoring is an easier task with a wider set of options.
