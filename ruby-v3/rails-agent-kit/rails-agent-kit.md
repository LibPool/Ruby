# rails-agent-kit

**Tag**: web, database, data

## 简介

rails-agent-kit is a small Model Context Protocol (stdio) server. It exposes a Rails app's database schema (parsed from db/schema.rb without booting the app) and its routes to coding agents such as Cursor and Claude Code, and ships a Rails 8 conventions skill for Cursor/Claude (installed with `rails-agent-kit install-skills`).
