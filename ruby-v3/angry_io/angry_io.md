# angry_io

**Tag**: testing

## 简介

AngryIO guards the real $stdout/$stderr during tests: a write goes through to the stream and then raises, so accidental output fails loudly and the offending line is visible in the test output. Ships RSpec and Minitest adapters that self-register, gated by a configurable enabled callable.
