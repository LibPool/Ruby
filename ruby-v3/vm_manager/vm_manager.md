# vm_manager

**Tag**: testing

## 简介

This gem provides a common interface to many different types of virtual machine.  The use case that it was written for is when you need an external system as part of your test procedures.  Using a virtual machine with snapshot capabilities is extremely useful as you can reset the virtual machine to a known state at the start of every test.
