# nubank

**Tag**: web

## 简介

This gem provides a wrapper to Nubank's public API. It does not have any official support from Nubank nor is endorsed by them. This code is provided as is, I can't give you any guarantee that Nubank won't change the API calls in the future or you block your access accidentaly by overloading their API.
