# butler-http

**Tag**: web, cli, security, networking

## 简介

Butler is the modern Ruby HTTP client built for concurrent, resilient
applications: Fiber-native concurrency, HTTP/1.1 + HTTP/2 with
transparent ALPN negotiation, connection pooling, retries with
backoff+jitter, deadlines, circuit breakers, security-conscious
defaults, and observability.
