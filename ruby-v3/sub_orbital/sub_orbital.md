# sub_orbital

**Tag**: library

## 简介

A version of Orbital that can be run on lower end or embeded hardware. This will probably be a place holder for quite some time.

## 官网

- 主页: http://www.orbitalsoft.org/
- RubyGems: https://rubygems.org/gems/sub_orbital
