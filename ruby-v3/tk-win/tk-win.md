# tk-win

**Tag**: library

## 简介

RubyTk bindings for windows bundled with tcltklib.so and tkutil.so for windows RubyInstaller 1.9.1

## 官网

- 主页: http://www.dumbo.ai.kyutech.ac.jp/nagai/RubyTk/?Ruby%2FTk-Kit
- RubyGems: https://rubygems.org/gems/tk-win
