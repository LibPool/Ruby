# book_reading_tracker_gem

**Tag**: web, database, security, data

## 简介

BookReadingTrackerGem is a simple command-line Ruby gem that helps users manage their reading progress, books, authors, and categories. Built with Thor and ActiveRecord, and backed by a PostgreSQL (Supabase) database.
