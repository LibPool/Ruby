# ns_geo

**Tag**: web, testing, filesystem

## 简介

NsGeo is a rails engine. Add gem 'ns_geo' to your Gemfile. 
 Run bundle install. 
 Run rails ns_geo:install:migrations 
 rake db:migrate 
 rake db:migrate 
 rake db:migrate RAILS_ENV=test 
 rails ns_geo:import_locations
