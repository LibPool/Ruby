# keycloak-sdk

**Tag**: web, security

## 简介

Idiomatic Ruby facade over rack-oauth2 (auth) and the Keycloak Admin REST API, with a self-hardened JWT validator. Isomorphic to the Java/Python/Node/Go/C#/PHP/Rust SDKs.
