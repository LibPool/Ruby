# extattr

**Tag**: filesystem, data

## 简介

"extattr" is extended file attribute manipurator for Ruby.
Supported for FreeBSD (extattr), GNU/Linux (xattr) and Microsoft Windows (NTFS Alternative Data Stream (ADS) + NTFS Extended Attributes (EA)).
