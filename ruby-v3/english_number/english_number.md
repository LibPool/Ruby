# english_number

**Tag**: library

## 简介

Example: EnglishNumber.new(63).in_english # =&gt; 'sixty-three'.
 
                   EnglishNumber objects can be added, subtracted, multiplied, divided.

                   For now gem is deliberately limited to numbers maximum five digits long.

                   Lower limit might be set manually (see the source code)
