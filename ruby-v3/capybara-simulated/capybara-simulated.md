# capybara-simulated

**Tag**: web, testing

## 简介

A Capybara driver that runs JavaScript against an in-process JS-resident DOM — V8 via rusty_racer or QuickJS via quickjs.rb, whichever is installed. No Chrome, no Node toolchain. Forms submit through Rack::MockRequest, inline <script> + event handlers run, Hotwire / Stimulus / Turbo work, and Capybara DSL is unchanged. Sits between rack-test and full headless browsers.
