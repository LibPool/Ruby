# vektis-rails

**Tag**: web, cli, filesystem, data

## 简介

The Rails half of the VEKTIS Impact Tracking data path. Ships the ingest client, the emit seam,
off-request delivery, a controller concern, and the browser handoff for @vektis-io/tracker.
Explicit-call-only: the only events on the wire are the ones your code asks for.
