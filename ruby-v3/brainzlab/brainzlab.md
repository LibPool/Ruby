# brainzlab

**Tag**: web, database, networking

## 简介

Ruby SDK for the BrainzLab observability platform. Includes Recall (structured logging), Reflex (error tracking), and Pulse (APM with distributed tracing). Auto-instruments Rails, Sidekiq, GraphQL, Redis, and more.
