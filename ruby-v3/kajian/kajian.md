# kajian

**Tag**: testing, data

## 简介

Pustaka ruby untuk mengekstrak data acara kajian Islam dari berbagai situs di Indonesia. Dengan menggunakan DSL (Domain Specific Language), mudah untuk menambahkan situs-situs lain untuk diekstrak data acara kajiannya.
