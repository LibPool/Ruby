# boxxspring

**Tag**: web, cli

## 简介

The boxxspring gem is implements a client to the Bedrocket Media Ventrures Boxxspring property API.

## 官网

- 主页: http://bedrocket.com
- 文档: https://www.rubydoc.info/gems/boxxspring/2.9.5
- RubyGems: https://rubygems.org/gems/boxxspring
