# capgem

**Tag**: web, tooling

## 简介

Capgem is an extension to Capistrano which builds your Rails app to  a gem which can be installed anywhere.

## 官网

- 文档: https://www.rubydoc.info/gems/capgem/0.1
- RubyGems: https://rubygems.org/gems/capgem

## 历史版本号

- 0.1 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/capgem
- gem 安装: `gem install capgem`
- Bundler: `gem "capgem"`
- 最新版本: 0.1
- 最新版归档: https://rubygems.org/downloads/capgem-0.1.gem
- 版本锁定: `gem "capgem", "~> 0.1"`
