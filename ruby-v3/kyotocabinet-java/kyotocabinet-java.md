# kyotocabinet-java

**Tag**: library

## 简介

Wrapper for Kyoto Cabinet's Java library for use with JRuby, to provide the same interface as the native kyotocabinet-ruby gem for MRI.

- 主页: http://github.com/csw/kyotocabinet-java
