# cocoapods-try

**Tag**: library

## 简介

CocoaPods plugin which allows to quickly try the demo project of a Pod.

## 官网

- 主页: https://github.com/cocoapods/cocoapods-try
- 文档: https://www.rubydoc.info/gems/cocoapods-try/1.2.0
- RubyGems: https://rubygems.org/gems/cocoapods-try
