# fto

**Tag**: library

## 简介

FTO is an extensible Ruby library for formatting text strings.  In function it is similar to <tt>printf(3)</tt>; however, the syntax of the format effectors (sometimes called 'format descriptors') and the selection of effectors bundled with the package are based on the SYS$FAO user-mode system service found on OpenVMS.
