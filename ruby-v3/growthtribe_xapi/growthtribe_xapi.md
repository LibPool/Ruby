# growthtribe_xapi

**Tag**: web, networking

## 简介

A Ruby library for interacting with a Learning Record Store (LRS) using the xAPI). Forked and extended from https://github.com/Deakin-Prime/Xapi created by kodandapani.k@comakeit.com
