# bindery-cli

**Tag**: cli, tooling

## 简介

bindery 是脚手架工具：
`bindery init` 在当前目录初始化项目，
`bindery new book` 为单本书生成骨架（ID 自动生成），
`bindery build` 调用 Pandoc 批量构建 EPUB。
仅依赖 Ruby 标准库，不引入任何第三方 gem。
