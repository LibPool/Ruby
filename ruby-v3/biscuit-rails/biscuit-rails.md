# biscuit-rails

**Tag**: web, tooling

## 简介

Biscuit provides a configurable GDPR cookie consent banner for Rails 8+ applications. It manages consent state via a browser cookie, exposes a Stimulus controller for interactivity, and supports i18n and CSS custom property theming with no build step required.
