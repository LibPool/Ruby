# ontomde-uml2-kbjava

**Tag**: cli, testing, tooling, data

## 简介

ontomde-uml2-kbjava is a library to generate tests data as java code and java junit from Prot&#233;g&#233; 2000 data project generated with ontomde-uml2-kb.    ontomde-uml2-kbjava should be used through ontomde-java-frontend command line utility.  == FEATURES/PROBLEMS:  * generator assumes JPA persistence is used.  == SYNOPSIS:
