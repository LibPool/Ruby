# miniric

**Tag**: web, networking

## 简介

This is a simple hello world gem copied from https://guides.rubygems.org/make-your-own-gem/.
        Since I've been using echoe a number of times, this time I want to be able
        to create a Gem without echoe so i can fix sakuric ASAP which is breaking
        many environemnts.

        This gem tries to be able to give DEB and COLORS as 'ric' without all
        'ric' dependencies. Like a vanilla RIC version I can include in my stuff.
        Possibly depending on lolcat :).
