# huginn_datatable

**Tag**: database, tooling, data

## 简介

Huginn is the raven of Odin that represents thought and remembrance. It offers a lightweight, highly performant query layer for ActiveRecord datatables: filtered/ordered eager-loaded pagination with an enxuto count and a PostgreSQL fuzzy-search builder (pg_trgm, unaccent, ILIKE).
