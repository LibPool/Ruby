# sweet-moon

**Tag**: web

## 简介

A resilient solution that makes working with Lua / Fennel from Ruby and vice versa a delightful experience.

Support to LuaJIT, Lua 5.0, and 5.1. Lua C API for Lua 5, 4, and 3. LuaRocks and fnx integration.
