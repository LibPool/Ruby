# pacstream

**Tag**: library

## 简介

This library is designed to assist with using the PACSTREAM electronic ordering service used by the book industry in  Australia.

## 官网

- 主页: http://rbook.rubyforge.org/
- RubyGems: https://rubygems.org/gems/pacstream
