# trackdown

**Tag**: web, cli, database, devops, data

## 简介

Trackdown is a Ruby gem for IP geolocation in Rails applications. It reads request-bound location headers from Cloudflare and Amazon CloudFront, verifies CDN client-IP corroboration in automatic mode, or uses a local MaxMind database (BYOK). It returns country, city, emoji flag, region, continent, postal code, latitude, longitude, timezone, and related GeoIP fields.
