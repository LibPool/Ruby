# ask-token-usage

**Tag**: web

## 简介

A Rails-free foundation for token-based usage tracking. Count real tokens with tiktoken, price them per million, declare activity costs, and run a wallet/ledger engine against a pluggable store. Pair with ask-token-usage-rails for ActiveRecord persistence.
