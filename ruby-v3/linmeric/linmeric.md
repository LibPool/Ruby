# linmeric

**Tag**: web, cli, networking

## 简介

Simple command line calculator to make operations on matrices and functions. It allows easy ways to create, manipulate and export matrices and to integrate functions. A website with a whole tutorial has been provided at https://max-codeware.github.io/linmeric
