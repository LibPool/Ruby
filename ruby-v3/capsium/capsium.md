# capsium

**Tag**: web, networking, devops, filesystem, data

## 简介

Capsium facilitates the creation, management and deployment of content packages with ease. This gem provides a structured way to handle content, data, and metadata for various applications: it packages them into .cap files and serves them over HTTP.
