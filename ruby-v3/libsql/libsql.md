# libsql

**Tag**: database, data

## 简介

libsql embeds the libsql fork of the SQLite database engine as a ruby extension. There is no need to install libsql separately.

## 官网

- 主页: http://github.com/copiousfreetime/libsql-ruby
- 文档: https://www.rubydoc.info/gems/libsql/0.1.0
- RubyGems: https://rubygems.org/gems/libsql
