# rack-smart_compress

**Tag**: web, networking, filesystem

## 简介

Rack::SmartCompress intelligently compresses HTTP responses using Zstandard (zstd), Brotli (br), and Gzip with smart payload thresholding, content-type filtering, and zero setup overhead.
