# forklift

**Tag**: testing, data

## 简介

Testing tool that allows for transactionless fixture data within specific contexts (useful in Shoulda and Factory Girl)

## 官网

- 主页: http://github.com/thumblemonks/forklift/tree/master
- RubyGems: https://rubygems.org/gems/forklift
