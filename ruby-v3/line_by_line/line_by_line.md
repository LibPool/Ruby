# line_by_line

**Tag**: filesystem

## 简介

Display the content of a text-file line by line:
line_by_line -s [text-file]		character by character or
line_by_line -s [text-file] --fast		whole lines.

push return for the next line. Call with parameter --help (-h) for a usage-message
