# rabbit-slide-kou-rwc-2014

**Tag**: library

## 简介

この発表はミドルウェアの分野でもRubyの普及を促進することを目指します。Rubyで分散全文検索エンジンというミドルウェアを開発している経験から、Rubyで開発したミドルウェアを他の言語でのプロダクトと差別化するために気をつけるべきことを紹介します。この知見を使って、Rubyを活かしたミドルウェアがより多く開発されることを期待します。
