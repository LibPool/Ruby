# ollama-client

**Tag**: web, cli, serialization

## 简介

A deterministic, contract-driven Ruby client for the Ollama API. Provides chat, generate, embeddings, structured outputs, and model management with strict JSON schema validation, automatic model pulling, exponential backoff on timeouts, and observer-style streaming hooks. Designed for Rails, agents, CLIs, and production services — not a chatbot UI.
