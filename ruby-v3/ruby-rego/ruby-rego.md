# ruby-rego

**Tag**: web, cli, tooling

## 简介

Ruby::Rego provides a pure Ruby parser, compiler, and evaluator for the Open Policy Agent Rego language. It targets a clean, idiomatic Ruby API, deterministic evaluation, and a CLI for validation workflows.
