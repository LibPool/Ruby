# rdavila_friendly_id

**Tag**: web

## 简介

FriendlyId is the "Swiss Army bulldozer" of slugging and permalink
    plugins for Ruby on Rails. It allows you to create pretty URL’s
    and work with human-friendly strings as if they were numeric ids for
    ActiveRecord models.
