# unmagic-browser

**Tag**: web, template, devops

## 简介

Drive a real browser from Ruby for one-off page grabs and multi-step automation. Runs against local Chrome, any remote Puppeteer endpoint, or Cloudflare Browser Rendering — behind one Capybara-flavoured API with smart locators, auto-waiting, and sessions that outlive a single call.
