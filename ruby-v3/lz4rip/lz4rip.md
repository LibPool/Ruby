# lz4rip

**Tag**: library

## 简介

Ruby bindings (via Rust/rb-sys) for lz4rip, a pure-Rust LZ4 implementation. Block-format and frame-format compress/decompress with optional dictionary support and COVER-based dictionary training. Ractor-safe.
