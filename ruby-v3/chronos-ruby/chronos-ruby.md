# chronos-ruby

**Tag**: web, cli, networking

## 简介

Cliente oficial do Chronos para capturar e enviar exceções, métricas e dados de telemetria de aplicações Ruby e Rails. A gem centraliza sinais de observabilidade para facilitar o monitoramento, a análise de desempenho e o diagnóstico de falhas no Chronos Monitor. Conheça a plataforma oficial de recebimento e visualização dos dados em https://chronosmonitor.com.br.
