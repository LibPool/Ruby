# fast_xlsx

**Tag**: filesystem, data

## 简介

Writes Excel .xlsx files from Ruby through a native Rust extension (rust_xlsxwriter): 20,000 rows in under 100 ms, and memory that stays flat for large exports. Formats, formulas, tables, charts, conditional formats, data validation and more.
