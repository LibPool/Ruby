# majorsilence_reporting

**Tag**: template, data

## 简介

Ruby wrappers for Majorsilence Reporting -- render RDL reports to PDF, Excel, CSV, HTML and more via an in-process native library (Fiddle FFI) or a subprocess-based .NET runner.
