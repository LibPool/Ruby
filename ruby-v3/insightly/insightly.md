# insightly

**Tag**: web, networking

## 简介

Ruby library for integrating with http://Insight.ly . This gem makes it easy to talk to their recently released REST API.  This includes dealing with Contacts, Opportunities, Organisations, and Tasks. It was originally develped for http://www.truckingoffice.com
