# agent_sessions

**Tag**: cli, tooling, filesystem

## 简介

Supports 11 adapters for Claude Code, Codex CLI, Cursor CLI/IDE, Amp, opencode, pi, Gemini CLI, GitHub Copilot CLI, Qwen Code, and Grok Build; reads messages for nine agents, verifies store paths, maps sessions to projects, and audits sync exposure.
