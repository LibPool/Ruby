# asciidoctor-epub3

**Tag**: library

## 简介

An extension for Asciidoctor that converts AsciiDoc documents to EPUB3 e-book format.

## 官网

- 主页: https://github.com/asciidoctor/asciidoctor-epub3
- 文档: https://www.rubydoc.info/gems/asciidoctor-epub3/2.3.0
- RubyGems: https://rubygems.org/gems/asciidoctor-epub3
