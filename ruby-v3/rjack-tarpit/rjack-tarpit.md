# rjack-tarpit

**Tag**: testing, tooling

## 简介

TarPit provides the glue for an unholy union of build tools. TarPit includes general automation for any rubygems project. It originally used and remains heavily influenced by Hoe (e.g. Manifest.txt.) However, it fully supports use of Bundler. The gemspec benefits from sensible automation but remains in a &lt;project&gt;.gemspec per Bundler's requirements.
