# sasso

**Tag**: tooling

## 简介

Embeddable, dependency-free SCSS/Sass compiler aiming at byte-for-byte dart-sass parity, shipped as a Rust native extension (magnus + rb-sys).

## 官网

- 主页: https://github.com/momiji-rs/sasso-ruby
- 更新日志: https://github.com/momiji-rs/sasso-ruby/blob/main/CHANGELOG.md
- RubyGems: https://rubygems.org/gems/sasso
