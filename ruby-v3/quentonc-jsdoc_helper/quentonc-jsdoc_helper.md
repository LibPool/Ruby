# quentonc-jsdoc_helper

**Tag**: web, serialization, networking, template, tooling

## 简介

Rake tasks for jsdoc-toolkit, a Javascript documentation generator.  jsdoc_helper includes: * jsdoc-toolkit v2.1.0 * jsdoc-toolkit is an application, written in JavaScript, for automatically generating template-formatted, multi-page HTML (or XML, JSON, or any other text-based) documentation from commented JavaScript source code * learn more at http://code.google.com/p/jsdoc-toolkit * rake tasks to generate your jsdoc
