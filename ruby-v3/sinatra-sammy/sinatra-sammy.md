# sinatra-sammy

**Tag**: web

## 简介

A Sinatra extension that turns a Sinatra app into a one page app using the teamwork of Sammy.

## 官网

- 主页: http://code.quirkey.com/sammy
- RubyGems: https://rubygems.org/gems/sinatra-sammy
