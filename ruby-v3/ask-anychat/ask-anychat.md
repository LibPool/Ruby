# ask-anychat

**Tag**: web, cli

## 简介

Creates and manages the agents an Anychat workspace owns. Anychat gives a business an agent of its own — a page customers can visit, a chat they can talk to, and the words it answers with. This is the client layer only: the tool framing that exposes it to an agent (MCP servers, native Ask::Tools) is provided by the consumers.
