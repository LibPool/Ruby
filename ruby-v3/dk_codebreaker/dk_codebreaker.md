# dk_codebreaker

**Tag**: library

## 简介

Codebreaker is a logic game in which a code-breaker tries to break a secret code created by a code-maker.
                          The code-maker, which will be played by the application we’re going to write, 
                          creates a secret code of four numbers between 1 and 6.
