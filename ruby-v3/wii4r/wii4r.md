# wii4r

**Tag**: library

## 简介

Ruby C Extension for controlling Wii Remote devices via bluetooth connection. Binding of C wiiuse library (www.wiiuse.net)

## 官网

- 主页: http://github.com/KzMz/wii4r
- RubyGems: https://rubygems.org/gems/wii4r
