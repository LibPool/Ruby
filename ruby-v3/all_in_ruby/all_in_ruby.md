# all_in_ruby

**Tag**: filesystem

## 简介

Adds a 'write throwaway and utility scripts in Ruby' instruction to AI agent instruction files (CLAUDE.md for Claude Code, AGENTS.md for Codex), locally or globally. Additive and idempotent.
