# s3mirror

**Tag**: filesystem

## 简介

S3mirror allows you to copy an uploaded file to mirror(s) which are basically any s3 compatible storage.

## 官网

- 主页: https://github.com/scratchoo/s3mirror
- RubyGems: https://rubygems.org/gems/s3mirror
