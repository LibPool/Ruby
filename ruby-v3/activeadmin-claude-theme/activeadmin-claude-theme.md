# activeadmin-claude-theme

**Tag**: web

## 简介

Open-source Rails admin theme for Active Admin 3 and 4. Warm cream canvas, coral accents, editorial typography, and optional dark mode on AA4. Install with `rails generate activeadmin_claude_theme:install`. Community theme — not affiliated with Anthropic.
