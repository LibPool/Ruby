# xirr

**Tag**: tooling, data

## 简介

Calculates the XIRR of a cashflow (the internal rate of return for transactions on arbitrary dates, like Excel's XIRR) using a safeguarded-Newton solver, with an optional native C build. Also includes time-value-of-money, bond, depreciation, rate-conversion, and performance-metric functions.
