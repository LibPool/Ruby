# aikido-zen

**Tag**: web

## 简介

Zen by Aikido is an embedded Web Application Firewall that autonomously protects Ruby apps against common and critical attacks.

## 官网

- 主页: https://aikido.dev/zen
- 源码仓库: https://github.com/aikidosec/firewall-ruby
- RubyGems: https://rubygems.org/gems/aikido-zen
