# text-metrics

**Tag**: data

## 简介

Text Metrics computes readability scores (Flesch Reading Ease, Flesch-Kincaid Grade, SMOG, Coleman-Liau, LIX) along with word, sentence, syllable and character statistics, plus Levenshtein distance and similarity. English and French are supported.
