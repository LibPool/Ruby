# lex-rfp

**Tag**: template, data

## 简介

Generative AI-powered RFP and proposal automation for LegionIO. Ingests past proposals into Apollo, generates draft responses via LLM pipeline with RAG, and provides human-in-the-loop review workflows with analytics.
