# tuxedo-r

**Tag**: tooling

## 简介

Tuxedo is a Ruby code formatter written in Rust, distributed as a
precompiled native binary wrapped in this Ruby gem (the "R" is both Ruby and
Rust). It is `bundle exec`-compatible, and a linter is planned.
