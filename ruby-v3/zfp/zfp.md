# zfp

**Tag**: library

## 简介

Compress and decompress arrays of float/double/int32/int64 in 1-4
dimensions using ZFP's fixed-rate, fixed-precision, fixed-accuracy,
or lossless reversible modes. Accepts Ruby Array and Numo::NArray.
