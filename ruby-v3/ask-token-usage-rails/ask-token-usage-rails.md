# ask-token-usage-rails

**Tag**: web, tooling

## 简介

Adds an ActiveRecord-backed wallet store, has_token_wallet concern, token wallet/transaction models, an install generator with migrations, and an expiry sweep job to any Rails app using ask-token-usage.
