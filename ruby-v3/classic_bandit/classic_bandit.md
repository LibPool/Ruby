# classic_bandit

**Tag**: web, testing

## 简介

Implementation of classic multi-armed bandit algorithms in Ruby. Supports Thompson Sampling, UCB1, and Epsilon-Greedy strategies with a simple, consistent API for A/B testing and optimization tasks.
