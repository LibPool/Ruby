# rack-allowed_hosts

**Tag**: web, networking

## 简介

Rack::AllowedHosts allows you to whitelist the hostnames allowed to
    serve the site. This is helpful to protect against Host Header Injection.
    See: https://acunetix.com/vulnerabilities/web/host-header-attack
