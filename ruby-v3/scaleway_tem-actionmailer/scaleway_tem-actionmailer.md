# scaleway_tem-actionmailer

**Tag**: web, networking

## 简介

An ActionMailer delivery method backed by Scaleway Transactional Email (TEM)
over its HTTP API rather than its SMTP relay, so a containerised application
needs no outbound SMTP port. Symfony and Laravel have had a TEM mailer for
years; this is the Ruby one.
