# harmonious_dictionary

**Tag**: library

## 简介

和谐宝典用于检查输入是否包含中文或英文敏感词，并可替换为特殊字符。速度比常规的正则匹配要快10倍以上。生活在天朝，和谐宝典必须人手必备。
