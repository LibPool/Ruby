# numo-linalg-alt

**Tag**: library

## 简介

Numo::Linalg Alternative (numo-linalg-alt) is an alternative to Numo::Linalg.
Unlike Numo::Linalg, numo-linalg-alt depends on Numo::NArray Alternative (numo-narray-alt).
