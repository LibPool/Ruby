# simple_unit_converter

**Tag**: library

## 简介

This gem helps to convert units to different measurements unit. example mph to kmph, to use:- 10.2.mile_per_hour.to_kilometer_per_hour or simply 10.2.mph.to_kmph. Refer github for more details
