# xeno

**Tag**: web, devops

## 简介

xeno is a framework for durable AI agents built on Rails, runnable standalone (xeno new my-agent) or inside the Rails app you already have. Sessions survive restarts and deploys mid-turn, wait days for a human approval without holding a process, and resume exactly where they stopped.
