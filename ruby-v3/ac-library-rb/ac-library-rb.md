# ac-library-rb

**Tag**: library

## 简介

ac-library-rb is a ruby port of AtCoder Library (ACL).
DSU(UnionFind), FenwickTree, PriorityQueue, Segtree, SCC, 2-SAT,
suffix_array, lcp_array, z_algorithm, crt, inv_mod, floor_sum, max_flow, min_cost_flow......
