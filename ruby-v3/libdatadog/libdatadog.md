# libdatadog

**Tag**: data

## 简介

libdatadog is a Rust-based utility library for Datadog's ddtrace gem.

- 源码仓库: https://github.com/datadog/libdatadog-rb
- RubyGems: https://rubygems.org/gems/libdatadog
