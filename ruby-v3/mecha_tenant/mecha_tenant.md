# mecha_tenant

**Tag**: web, serialization

## 简介

MechaTenant enforces strict tenant isolation in Rails applications via a YAML model classification registry, explicit tenant_scope helpers, Prism AST static analysis of controllers, and behavioral IDOR route probing.
