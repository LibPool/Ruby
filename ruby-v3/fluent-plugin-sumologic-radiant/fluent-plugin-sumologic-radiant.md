# fluent-plugin-sumologic-radiant

**Tag**: web, security, networking

## 简介

A modernized and actively maintained Fluentd output plugin for Sumo Logic HTTP Collector with updated dependencies, improved performance, and Ruby 3.x support. Forked from the original Sumo Logic plugin with enhancements and security fixes.
