# a2ui-rails

**Tag**: web, template

## 简介

A Ruby port of Google's A2UI (Agent-to-User Interface) for Rails.
Uses DSPy.rb to generate typed UI descriptions from natural language,
rendered as ViewComponents via Turbo Streams.
