# easy_code_sign

**Tag**: library

## 简介

A Ruby gem for code signing operations using hardware tokens (HSM/smart cards) via PKCS#11. Supports SafeNet eToken, RFC 3161 timestamping, PDF visible signatures, and signature verification.
