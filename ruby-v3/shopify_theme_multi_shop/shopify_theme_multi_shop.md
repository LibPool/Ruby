# shopify_theme_multi_shop

**Tag**: cli, devops, filesystem

## 简介

Command line tool to help with developing Shopify themes. Provides simple commands to download, upload and delete files from a theme. Also includes the watch command to watch a directory and upload files as they change. github.com/shopify/shopify_theme with the ability to deploy to multitple shops.
