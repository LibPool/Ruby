# google-cloud-api_registry-v1beta

**Tag**: web, cli, testing, devops

## 简介

google-cloud-api_registry-v1beta is the official client library for the Cloud API Registry V1BETA API. Note that google-cloud-api_registry-v1beta is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-api_registry instead. See the readme for more details.
