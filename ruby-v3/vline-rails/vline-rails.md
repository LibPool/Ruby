# vline-rails

**Tag**: web

## 简介

A plugin that adds support for vLine video chat to any rails app.

## 官网

- 主页: https://vline.com
- 源码仓库: https://github.com/vline/vline-rails
- RubyGems: https://rubygems.org/gems/vline-rails
