# overspeeding

**Tag**: filesystem

## 简介

Using sensors overspeeding is detected, a photo is taken, number plate extraction is done on the image, and the number is stored in atext file, the number is picked up from the text file and stored as string. BUILT TO RUN ON A RASPBERRY PI RUNNING RASPBIAN WHEEZY
