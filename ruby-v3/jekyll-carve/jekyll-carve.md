# jekyll-carve

**Tag**: template, tooling

## 简介

A Jekyll plugin that renders Carve (.crv) pages to HTML. It is a
thin Jekyll::Converter over the native `carve-lang` gem (Carve.to_html);
no parser is reimplemented.
