# detroit-mast

**Tag**: tooling, filesystem

## 简介

Mast plugin for Detroit build system. Generate and update MANIFEST file for
your project.

## 官网

- 主页: http://detroit.github.com
- RubyGems: https://rubygems.org/gems/detroit-mast
