# rails_mfa

**Tag**: web, security

## 简介

RailsMFA is a provider-agnostic, plug-and-play gem that adds secure multi-factor authentication (MFA/2FA) to any Rails app. Supports SMS, email, and authenticator apps (TOTP) with customizable providers.
