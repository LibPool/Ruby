# bio-samtools

**Tag**: web, networking, filesystem

## 简介

Binder of samtools for ruby, on the top of FFI. 

  This project was born from the need to add support of BAM files to 
  the gee_fu genome browser (http://github.com/danmaclean/gee_fu).
