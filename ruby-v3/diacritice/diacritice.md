# diacritice

**Tag**: library

## 简介

Corectează într-un string cuvintele scrise fără diacritice. Momentan baza de date conține doar 11 cuvinte. Funcționează la fel ca metodele to_i, to_s adica aplici asupra stringului dorit metoda to_diacritice și stringul este corectat.
