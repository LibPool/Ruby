# gravatar_profile

**Tag**: web, networking, filesystem

## 简介

gravatar_profile is a Ruby Wrapper for getting GRAVATAR[http://gravatar.com] avatars and profile informations.

## 官网

- 主页: http://veerasundaravel.wordpress.com
- RubyGems: https://rubygems.org/gems/gravatar_profile
