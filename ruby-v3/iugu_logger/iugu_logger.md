# iugu_logger

**Tag**: web

## 简介

Standalone Ruby logging SDK implementing the iugu Logging Standard (ILS). No third-party logging gem dependency. Compatible from Ruby 2.4 (platform Rails 4.2) through Ruby 3.x (modern services).
