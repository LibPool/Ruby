# jekyll-theme-cvent-dev-portal

**Tag**: web, networking

## 简介

Provides consistent style elements for the Cvent Dev Portal Guide generated using Jekyll. Derived from jekyll-theme-guides-mbland v1.0.3 (https://github.com/mbland/jekyll-theme-guides-mbland/releases/tag/v1.0.3).
