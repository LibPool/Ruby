# chardet

**Tag**: library

## 简介

Character encoding auto-detection in Ruby. Base on Mark Pilgrim's Python port.

## 官网

- 主页: http://blog.vava.cn/
- RubyGems: https://rubygems.org/gems/chardet

## 历史版本号

- 0.9.0 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/chardet
- gem 安装: `gem install chardet`
- Bundler: `gem "chardet"`
- 最新版本: 0.9.0
- 最新版归档: https://rubygems.org/downloads/chardet-0.9.0.gem
- 版本锁定: `gem "chardet", "~> 0.9.0"`
