# rails-local-ci

**Tag**: web, tooling

## 简介

Ships ActiveSupport::ContinuousIntegration and a generator that installs bin/ci + config/ci.rb. Any Rails 6/7 app can `gem 'rails-local-ci'` and get the same Local CI DX as Rails 8.1 built-in. Upgrading to Rails 8.1 later = just remove the gem, zero code changes.
