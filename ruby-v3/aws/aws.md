# aws

**Tag**: web, networking, devops

## 简介

AWS Ruby Library for interfacing with Amazon Web Services including EC2, S3, SQS, SimpleDB and most of their other services as well. By http://www.appoxy.com

## 官网

- 主页: http://github.com/appoxy/aws/
- 文档: https://www.rubydoc.info/gems/aws/2.10.2
- 问题追踪: http://appoxy.lighthouseapp.com/projects/38441-aws/overview
- RubyGems: https://rubygems.org/gems/aws
