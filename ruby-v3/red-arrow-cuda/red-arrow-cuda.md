# red-arrow-cuda

**Tag**: data

## 简介

Apache Arrow CUDA is a common in-memory columnar data store on CUDA. It's useful to share and process large data.

## 官网

- 主页: https://arrow.apache.org/
- 文档: https://www.rubydoc.info/gems/red-arrow-cuda/25.0.1
- RubyGems: https://rubygems.org/gems/red-arrow-cuda
