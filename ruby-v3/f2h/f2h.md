# f2h

**Tag**: template

## 简介

Boilerplate code that provides sane default settings when making html5 assets using html,css and js from Flash creatives

## 官网

- 主页: https://github.com/ismk/Flash2HTML
- RubyGems: https://rubygems.org/gems/f2h
