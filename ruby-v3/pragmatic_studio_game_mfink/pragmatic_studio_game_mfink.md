# pragmatic_studio_game_mfink

**Tag**: filesystem, data

## 简介

Pragmatic Studio Game
This is a game built for the Pragmatic Studio's "Intro to Ruby" course.  Players are awarded points according to randomly selected treasures they find.  Loads players in "players.csv" by default.  .csv file structure: (player_name,initial_health).
