# bbcodelib

**Tag**: tooling

## 简介

Provides a fast, efficent BBcode parser for ruby via the bbcodelib package at sourceforge.

## 官网

- 主页: http://rubyforge.org/projects/bbcodelib/
- RubyGems: https://rubygems.org/gems/bbcodelib

- 1.0.0 (2009-09-30)
