# plugzapi-gem

**Tag**: web

## 简介

A plugzapi-gem facilita a integração com a API da Tecnospeed, permitindo a automação do envio de mensagens via WhatsApp. 
    Com uma interface simples e intuitiva, desenvolvedores podem realizar chamadas à API da Plugzapi sem complicações, 
    otimizando o tempo de desenvolvimento para um integração com WhatsApp
