# qr_reader-native

**Tag**: tooling

## 简介

The hot loops of the pure-Ruby qr_reader gem, compiled to C with the Spinel Ruby AOT compiler. qr_reader uses them automatically when this gem is installed; without it, qr_reader runs the same code as plain Ruby.
