# standard_audit

**Tag**: web, database, data

## 简介

StandardAudit is a standalone Rails gem for database-backed audit logging. On Rails 8.1+ it subscribes to Rails.event; on Rails 8.0 it falls back to ActiveSupport::Notifications. Generic, flexible, and works with any Rails application.
