# healthier

**Tag**: web, database, security

## 简介

Healthier provides comprehensive health check endpoints (live, ready, ping) for Rails applications with support for monitoring multiple backing services including PostgreSQL, MongoDB, Redis, RabbitMQ, Sidekiq, and ElasticSearch. It includes built-in authentication and flexible configuration options.
