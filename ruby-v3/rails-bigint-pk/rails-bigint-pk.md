# rails-bigint-pk

**Tag**: web, database

## 简介

Rails-bigint-pk modifies Rails so that it uses
                    64-bit primary and foreign keys.  It works with
                    MySQL and PostgreSQL and has versions for Rails
                    3 and 4.
