# stripe-workload-identity

**Tag**: web, cli, security, devops, data

## 简介

Lets Stripe::StripeClient.for_workload_identity authenticate on Google Cloud environments with a compatible metadata identity-token endpoint, using a Google-signed identity token instead of a long-lived API key. Does not depend on the `stripe` gem.
