# pinyin4r

**Tag**: library

## 简介

Pinyin4r is a ruby library supporting convertion between Chinese characters and most popular Pinyin systems.

## 官网

- 主页: http://shanexu.org/pinyin4r
- 文档: https://www.rubydoc.info/gems/pinyin4r/2.5.0
- RubyGems: https://rubygems.org/gems/pinyin4r
