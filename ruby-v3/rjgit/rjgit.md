# rjgit

**Tag**: library

## 简介

JRuby wrapper around the JGit library for manipulating git repositories in code.

## 官网

- 主页: https://github.com/repotag/rjgit
- 文档: https://www.rubydoc.info/gems/rjgit/7.0.0.0
- RubyGems: https://rubygems.org/gems/rjgit
