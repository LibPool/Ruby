# gridium

**Tag**: library

## 简介

Gridium makes integrating ruby and Selenium a breeze.  This is not for novice automation engineers.  Novices should checkout Capybara.  However, if you're comfortable with Selenium, and have used Capybara but find it not working well give Gridium a shot.
