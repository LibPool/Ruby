# anydoc-ruby

**Tag**: data

## 简介

Ruby bindings for the anydoc Rust crate. Converts Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV, and PDF documents into clean GitHub-Flavored Markdown, with one consistent output no matter which format goes in.
