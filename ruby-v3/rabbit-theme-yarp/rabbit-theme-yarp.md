# rabbit-theme-yarp

**Tag**: web, networking

## 简介

A YARP theme for Rabbit (http://rabbit-shocker.org/) with lots of turquoise.

Optimized for 16:9 (use with `--width=1600 --height=900 --paper-width=1600 --paper-height=900`).

Heavily inspired by the "debian" theme.
