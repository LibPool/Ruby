# protest-rails

**Tag**: web, testing

## 简介

Protest is a tiny, simple, and easy-to-extend test framework. Protest-rails brings that simplicity into the Rails world.

## 官网

- 主页: http://matflores.github.com/protest
- RubyGems: https://rubygems.org/gems/protest-rails
