# rails_notion_like_multiselect

**Tag**: web

## 简介

A beautiful, keyboard-navigable multiselect component for Rails applications, inspired by Notion's elegant UI/UX. Features include real-time search, inline item creation, full keyboard navigation, dark mode support, and customizable themes. Built with Hotwire Stimulus and Tailwind CSS for modern Rails applications.
