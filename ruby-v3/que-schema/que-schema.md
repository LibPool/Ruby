# que-schema

**Tag**: web, database

## 简介

Patches Rails' ActiveRecord schema dumper so applications using que-rb/que can use schema.rb instead of structure.sql. Round-trips Que's PostgreSQL functions, triggers, and options through the Ruby schema format.
