# content_spinning

**Tag**: library

## 简介

To spin some text, mainly for SEO purpose.

Spinning the string "Hi {there|you}! I'm {efficient|productive}." gives
these four strings :

* Hi there! I'm efficient.
* Hi there! I'm productive.
* Hi you! I'm efficient.
* Hi you! I'm productive.
