# kakurenbo-puti

**Tag**: library

## 简介

kakurenbo-puti provides an ActiveRecord-friendly soft-delete gem.
    This gem does not override methods of ActiveRecord.

    I think that kakurenbo-puti is cho-iketeru! (very cool!)
