# sidekiq-web_custom

**Tag**: web

## 简介

Have you ever needed to add custom buttons to the sidekiq UI?
    Have you ever needed to drain a queue that is not bound to a Sidekiq Process?
    This Gem allows you to to do all of that from the Sidekiq UI!
