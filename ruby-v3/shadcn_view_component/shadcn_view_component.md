# shadcn_view_component

**Tag**: web, template, data

## 简介

A 1:1 port of the shadcn/ui component registry to Rails ViewComponent. Same part names, same variants, same Tailwind classes and data-slot attributes; Radix UI behaviour reimplemented with Stimulus.
