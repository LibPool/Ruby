# quredis

**Tag**: database

## 简介

quredis (pronounced 'kurdis') is a little DSL for redis safe queues using brpoplpush.

## 官网

- 主页: http://github.com/cpatni/quredis
- RubyGems: https://rubygems.org/gems/quredis
