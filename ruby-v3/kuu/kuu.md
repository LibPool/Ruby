# kuu

**Tag**: web, cli, testing, security, networking

## 简介

Ruby binding for the kuu specification (https://github.com/kawaz/kuu). This early version delegates to the kuu-cli reference binary; a native implementation is planned to grow under this name. Reserved by the spec author.
