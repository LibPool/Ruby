# google-cloud-lustre-v1

**Tag**: cli, testing, devops, filesystem

## 简介

Google Cloud Managed Lustre delivers a high-performance, fully managed parallel file system optimized for AI and HPC applications. Note that google-cloud-lustre-v1 is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-lustre instead. See the readme for more details.
