# fxirb

**Tag**: library

## 简介

Fox-based graphical interface to IRB (IRB running within an FXText widget)

## 官网

- 主页: http://rubyforge.org/projects/fxirb/
- RubyGems: https://rubygems.org/gems/fxirb
