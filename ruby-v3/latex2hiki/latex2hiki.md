# latex2hiki

**Tag**: library

## 简介

latex2hiki is a format convert from latex to hikidoc.

## 官网

- 主页: https://github.com/daddygongon/latex2hiki
- 文档: https://www.rubydoc.info/gems/latex2hiki/0.1.1
- RubyGems: https://rubygems.org/gems/latex2hiki

## 获取地址

- RubyGems: https://rubygems.org/gems/latex2hiki
- gem 安装: `gem install latex2hiki`
- Bundler: `gem "latex2hiki"`
- 最新版本: 0.1.1
- 最新版归档: https://rubygems.org/downloads/latex2hiki-0.1.1.gem
