# amazon-product-advertising-api-prezjordan

**Tag**: web

## 简介

A nice rubyish interface to the Amazon Product Advertising API (MODIFIED to handle ResponseGroup), formerly known as the Associates Web Service and before that the Amazon E-Commerce Service.
