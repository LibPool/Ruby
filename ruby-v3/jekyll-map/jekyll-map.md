# jekyll-map

**Tag**: web

## 简介

jekyll-map adds a {% map %} Liquid tag to Jekyll sites. Pass a latitude/longitude or an address string and get a responsive static map image with no JavaScript required. Powered by the Mapbox Static Images API.
