# ffi-zlib

**Tag**: library

## 简介

ffi-zlib provides a very thin wrapper around zlib using the Ruby FFI library.

## 官网

- 主页: http://github.com/lucsky/ffi-zlib
- RubyGems: https://rubygems.org/gems/ffi-zlib

## 历史版本号

- 0.2.0 (2010-05-31)

## 获取地址

- RubyGems: https://rubygems.org/gems/ffi-zlib
- gem 安装: `gem install ffi-zlib`
- Bundler: `gem "ffi-zlib"`
- 最新版本: 0.2.0
- 最新版归档: https://rubygems.org/downloads/ffi-zlib-0.2.0.gem
