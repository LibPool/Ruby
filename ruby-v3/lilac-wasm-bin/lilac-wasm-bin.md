# lilac-wasm-bin

**Tag**: tooling

## 简介

Ships the lilac-full.wasm, lilac-compiled.wasm and the mruby-wasm-js JS bridge as a single Ruby gem so that `bundle install` is enough to make `lilac dev` and `lilac build` work — no npm install, no manual cp.
