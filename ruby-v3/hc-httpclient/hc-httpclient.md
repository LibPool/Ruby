# hc-httpclient

**Tag**: web, cli, networking

## 简介

A gem packaging of the {HttpComponents}[http://hc.apache.org/] (formerly Jakarta Commons) HTTP Client for JRuby.  * Provides commons-httpclient and commons-codec jars. * Provides a HC::HTTPClient::ManagerFacade for client and connection manager setup, start, shutdown.
