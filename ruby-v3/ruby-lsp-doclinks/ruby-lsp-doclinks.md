# ruby-lsp-doclinks

**Tag**: cli

## 简介

An addon for the VsCode RubyLsp extension that provides documentation links in hovers for constants, methods, and classesAn addon for the VsCode RubyLsp extension that provides documentation links in hovers for constants (classes/modules), and their methods
