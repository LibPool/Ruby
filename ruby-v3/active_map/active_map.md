# active_map

**Tag**: serialization

## 简介

Turn PostGIS-backed models into named maps. acts_as_mappable adds spatial scopes; Map classes declare layers; a mountable engine serves the manifest and per-layer GeoJSON consumable by the bundled Stimulus/Leaflet controller or any SPA map library.
