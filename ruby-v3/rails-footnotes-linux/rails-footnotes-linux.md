# rails-footnotes-linux

**Tag**: web

## 简介

Every Rails page has footnotes that gives information about your application and links back to your editor.

## 官网

- 主页: http://github.com/josevalim/rails-footnotes
- RubyGems: https://rubygems.org/gems/rails-footnotes-linux

## 历史版本号
