# benedictus

**Tag**: web, cli, testing, serialization, template

## 简介

Benedictus is a Rails developer's CLI for inspecting the execution plan
of any ActiveRecord relation, scope, or query object. It boots the host
Rails app, evaluates the expression you pass in, runs EXPLAIN (or EXPLAIN
ANALYZE inside a rolled-back transaction), parses the JSON plan, and
renders it as a colored, annotated tree with inline performance warnings.
