# chuck_norris_jokes

**Tag**: library

## 简介

This gem allows you to fetch and integrate chuck norris jokes from chucknorris.io. It has a 'name' mode via which you can replace 'Chuck Norris' with 'name'(not recommended unless you are an equivalent legend say like Rajnikanth)
