# okf-sqlite3

**Tag**: database

## 简介

OKF::Sqlite3 is the optional storage engine for the okf kernel: an FTS5-backed
cache of Open Knowledge Format bundles giving BM25-ranked, snippeted search, a
bounded memory footprint, and a warm cache shared across processes. It knows
nothing about MCP. This release reserves the gem name; the engine lands later.
