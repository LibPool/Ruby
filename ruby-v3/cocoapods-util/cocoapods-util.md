# cocoapods-util

**Tag**: library

## 简介

cocoapods-util是一个cocoapods插件，解决日常ios开发中遇到的一些问题。支持打包(编译)静态库、framework生成xcframework、二进制link源码、推送私有库跳过验证等功能。
