# mapit

**Tag**: web, testing

## 简介

Very, very simple gem that provides a helper to show a map of the specified address using Google Maps.

## 官网

- 主页: http://github.com/crowdint/mapit
- RubyGems: https://rubygems.org/gems/mapit
