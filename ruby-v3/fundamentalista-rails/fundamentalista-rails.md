# fundamentalista-rails

**Tag**: web, tooling, data

## 简介

A mountable engine on top of the fundamentalista gem: look up any listed company, read its statements, ratios, scores and valuation, compare peers with the magic formula, and keep watchlists whose valuation snapshots build a history. Uses the application cache for provider data.
