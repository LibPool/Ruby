# toys-ci

**Tag**: cli, testing

## 简介

Toys-CI is a framework for generating simple CI coordinator tools. It provides a declarative interface for configuring the tool and specifying individual jobs to run. The generated tool runs jobs specified using command line arguments, and produces a final report of the results.
