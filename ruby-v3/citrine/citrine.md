# citrine

**Tag**: web

## 简介

Citrine（黄水晶）：信号式响应 UI 框架。用纯 Ruby 写组件（state / computed 宏 + 赋值即更新），经 Opal 编译后渲染到浏览器 DOM、Canvas 与桌面（macOS .app）。水晶振荡器是信号的源头——名字致敬 Opal 开启的 Ruby→Web 宝石谱系。
