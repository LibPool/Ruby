# jimmu

**Tag**: web, database, serialization, networking, template, filesystem

## 简介

Jimmu (神武) is a lightweight Ruby web framework focused on simplicity.
It provides file-based routing, ERB templates, SQLite support via
Fiddle and the system libsqlite3, WebSocket support, cookies,
sessions, JSON/HTML/text responses, and a built-in development
server with no required gems beyond Ruby's standard library.
