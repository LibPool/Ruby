# two_percent

**Tag**: web

## 简介

TwoPercent is a SCIM 2.0 Rails Engine with partial RFC 7644 protocol compliance for IdP provisioning. Supports POST/PUT/PATCH/DELETE/Bulk operations for Users and Groups, publishes domain events via AetherObservatory, and integrates seamlessly with Rails applications.
