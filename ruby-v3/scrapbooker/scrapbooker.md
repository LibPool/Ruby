# scrapbooker

**Tag**: web

## 简介

Scrapbooker is a gem for rails that allows you to pull information from social media feeds then store the information locally.

## 官网

- 主页: http://griffithstudio.github.com/scrapbooker
- RubyGems: https://rubygems.org/gems/scrapbooker
