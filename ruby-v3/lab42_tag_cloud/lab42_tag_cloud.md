# lab42_tag_cloud

**Tag**: web, networking, devops

## 简介

Creating Tag Clouds with gamma correct color values and styles from a simple DSL.

This is a port of Elixir's tag_cloud https://github.com/RobertDober/tag_cloud to Ruby
