# glyphs

**Tag**: web, template

## 简介

Glyphs renders SVG icons as Phlex components (LucideIcon, PhosphorIcon, HeroIcon, ...) from rails_icons-synced icon sets, with configurable missing-icon handling and bundled RuboCop cops that validate icon names and autocorrect legacy icon helpers.
