# urirequire

**Tag**: library

## 简介

urirequire hijacks Kernel.require to download and eval Ruby code somewhere else on the internets.

## 官网

- 主页: http://rubyforge.org/projects/urirequire/
- RubyGems: https://rubygems.org/gems/urirequire

## 历史版本号

- 0.1.0 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/urirequire
