# gitfile

**Tag**: filesystem

## 简介

gitfile - a (light-weight) package manager for installing and updating projects from git repos

## 官网

- 主页: https://github.com/rubycoco/git
- 文档: https://www.rubydoc.info/gems/gitfile/0.0.1
- RubyGems: https://rubygems.org/gems/gitfile

## 历史版本号

- 0.0.1 (2020-10-29)

## 获取地址

- RubyGems: https://rubygems.org/gems/gitfile
- gem 安装: `gem install gitfile`
- Bundler: `gem "gitfile"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/gitfile-0.0.1.gem
