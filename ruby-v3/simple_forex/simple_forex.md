# simple_forex

**Tag**: web, security

## 简介

simple_forex lets you setup and use currency conversion in your Rails application. It includes a migration for a currencies table that stores all world currencies, including some cryptocurrencies. It also includes a rake task for retrieving up to date foreign exchange rates, and methods to conveniently convert between currencies.
