# intosql

**Tag**: web, database, serialization, filesystem, data

## 简介

Upload XLSX, XLS, ODS, CSV or JSON files and get SQL for PostgreSQL, MySQL, MariaDB, SQLite, SQL Server or Oracle back from the IntoSQL API, with webhook verification.
