# sealed_trail

**Tag**: web, security, template

## 简介

SealedTrail records create, update and destroy events on Active Record models with before/after values, the acting user, request id and IP address, and redacts sensitive attributes by default. It helps Rails teams produce audit evidence for security reviews.
