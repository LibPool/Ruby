# odt-ui-rails

**Tag**: web, template, tooling

## 简介

ODT UI for Ruby on Rails brings the ODT Design System directly into Rails applications with a Standalone CSS First architecture.

Key Features:
* Standalone CSS First: Ships pre-compiled design tokens and component styles with zero host build tools required (compatible with Propshaft, Sprockets, or no asset pipeline).
* Seamless Tailwind CSS v4 Interop: Full @theme preset configuration allowing custom utility classes to merge cleanly.
* Hotwire & Turbo Ready: Out-of-the-box ActionView helpers for Flash Toasts, Turbo Stream notifications, and Stimulus-powered Modals.
* Complete Component Set: Buttons, Badges, Cards, Alerts, Toasts, Modals, Headings, Text, Avatars, Inputs, Selects, Checkboxes, Radios, and Form Groups.
* Type Checked: Full RBS type signatures included for Ruby LSP and Solargraph autocompletion.
