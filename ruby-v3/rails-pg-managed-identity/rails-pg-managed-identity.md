# rails-pg-managed-identity

**Tag**: web, cli, database, devops, data

## 简介

Connects Active Record's PostgreSQL adapter to Azure Database for PostgreSQL flexible server with Microsoft Entra access tokens from managed identity, workload identity, a service principal or the Azure CLI. Tokens are fetched when connections are opened and refreshed before they expire, instead of a static password in database.yml.
