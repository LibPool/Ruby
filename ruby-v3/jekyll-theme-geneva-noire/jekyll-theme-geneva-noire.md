# jekyll-theme-geneva-noire

**Tag**: web, networking

## 简介

An adaptation of the [Carte Noire theme](https://github.com/jacobtomlinson/carte-noire) adapted for use in the CERN [C2MON](https://github.com/c2mon/c2mon) documentation
