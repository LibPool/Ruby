# ai_screen_analyzer

**Tag**: web

## 简介

AI Screen Analyzer é uma gem Rails que adiciona um botão flutuante em qualquer página para capturar a tela, enviar para análise com GPT-4V e exibir o resultado em uma barra lateral elegante.
