# unobtainium-faraday

**Tag**: web

## 简介

The unobtainium-faraday gem is a faraday-based driver implementation for
    unobtainium.

    Unlike built-in driver implementations, it does not provide a Selenium-like
    API, but rather one mostly identical to plain faraday.
