# jslintrb

**Tag**: tooling

## 简介

jslintrb is a packaged version of Douglas Crockford's JSLint JavaScript code checker.
 jslintrb uses SpiderMonkey via the Johnson
Ruby gem to interpret the JSLint javascript.
