# ghazel-rpm_contrib

**Tag**: library

## 简介

Community contributed instrumentation for various frameworks based on
the New Relic Ruby monitoring gem newrelic_rpm.

## 官网

- 主页: http://github.com/newrelic/rpm_contrib
