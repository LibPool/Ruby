# DhanHQ

**Tag**: web, cli, networking

## 简介

A production-grade Ruby SDK and Ruby client for Dhan API v2 built for algorithmic trading, portfolio monitoring, and live trading systems on NSE, BSE and MCX. Provides typed models, token lifecycle management, dry-validation contracts, resilient WebSocket streaming with auto-reconnect, and safety-focused order workflows for Ruby on Rails and standalone Ruby applications.
