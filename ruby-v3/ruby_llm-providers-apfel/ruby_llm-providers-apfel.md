# ruby_llm-providers-apfel

**Tag**: web

## 简介

Adds Apfel provider support to RubyLLM. Apfel is a macOS-only local server that exposes Apple's on-device Apple Intelligence model over an OpenAI-compatible API, letting RubyLLM talk to it like any other provider.
