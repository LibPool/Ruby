# indicator_hub

**Tag**: library

## 简介

IndicatorHub provides a clean, idiomatic interface for technical analysis by aggregating multiple Ruby gems (ruby-technical-analysis, technical-analysis, indicators) and optionally leveraging TA-Lib for high performance.
