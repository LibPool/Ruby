# newsmlg2

**Tag**: serialization, tooling

## 简介

Newsmlg2 provides a lutaml-model-based Ruby object model for IPTC NewsML-G2 (NAR). Parse, manipulate, build and serialize NewsML-G2 XML with full round-trip fidelity, including a builder DSL.
