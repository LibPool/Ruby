# cf-s3-invalidator

**Tag**: web, devops

## 简介

This lib fetches the names of all objects on an Amazon Web
    Services S3 bucket. Then it calls the Cloudfront invalidation REST API on the
    objects.

    The Cloudfront distribution must be based on the S3 bucket.
