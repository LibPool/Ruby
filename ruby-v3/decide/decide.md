# decide

**Tag**: library

## 简介

decide composes typed questions, match floors, and fail modes into named decisions. Ask a decision about a state and get a verdict that knows whether it matched, whether it failed open, and why. Works with any answer source; the ruby_decision_model gem (Typesafe Jev via OpenRouter) is the first.
