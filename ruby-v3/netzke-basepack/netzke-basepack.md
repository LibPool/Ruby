# netzke-basepack

**Tag**: tooling

## 简介

A set of feature-rich extendible Netzke components (such as Grid, Tree, Form, Window) and component extensions which can be used as building blocks for your apps

## 官网

- 主页: http://netzke.org
- 源码仓库: http://github.com/nomadcoder/netzke-basepack
- 文档: http://api.netzke.org/basepack
- 问题追踪: http://github.com/nomadcoder/netzke-basepack/issues
- RubyGems: https://rubygems.org/gems/netzke-basepack
