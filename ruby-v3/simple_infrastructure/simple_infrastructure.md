# simple_infrastructure

**Tag**: web, database, filesystem, data

## 简介

Simple Infrastructure provides a change-based approach to server configuration, similar to how Rails database migrations work. Each change is tracked as a versioned file, ensuring idempotency, auditability, and consistency across servers.
