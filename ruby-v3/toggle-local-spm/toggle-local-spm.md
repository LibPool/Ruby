# toggle-local-spm

**Tag**: cli

## 简介

A CLI that swaps a Swift Package Manager dependency in an .xcodeproj between its remote (git) reference and a local checkout in an adjacent sibling folder, and back again, without churning the underlying pbxproj object IDs.
