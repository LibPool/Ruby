# readwhitepaper

**Tag**: web, cli, security

## 简介

Ruby client for the ReadWhitepaper API — 30 cryptocurrency whitepapers with section-level content, 163 glossary terms, full-text search, and 3,458 translations across 15 languages. Zero dependencies.
