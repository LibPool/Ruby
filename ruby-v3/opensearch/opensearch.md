# opensearch

**Tag**: library

## 简介

OpenSearch is simple format of sharing of search results by A9. See opensearch.a9.com/ for detail.  This library is for OpenSearch version 1.0 or 1.1

- RubyGems: https://rubygems.org/gems/opensearch
