# closest_weightlifting_gem

**Tag**: web, cli, networking, data

## 简介

This gem uses the data available on the USA Weightlifting website (http://www.teamusa.org/usa-weightlifting/clubs-lwc/find-a-club) to create a simple CLI interface with all the gyms.
