# rigid_workflow

**Tag**: web, testing

## 简介

Rigid Workflow is a durable workflow orchestration engine for Rails applications.
It provides a DSL for defining durable workflows with support for:
- Sequential and parallel execution
- Controlled race conditions
- Wait signals and timeouts
- Retry logic with exponential backoff
- Rescuing from errors and compensating
- Persistent state and history
- Admin UI to inspect and manage workflows
- Built on Rails and ActiveJob
