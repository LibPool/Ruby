# cesri

**Tag**: web

## 简介

Cesri es una Gema Ruby que permite consumir los servicios Web de Comprobantes Electrónicos del Servicio de Rentas Internas, para fines de la facturación electrónica en Ecuador. Esta versión soporta únicamente la nueva modalidad "OFFLINE" del SRI.
