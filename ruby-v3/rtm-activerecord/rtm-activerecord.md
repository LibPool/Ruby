# rtm-activerecord

**Tag**: testing, data

## 简介

Ruby Topic Maps is a Topic Maps engine written in Ruby.
    This is the backend engine which holds all data in ActiveRecord objects.
    It's available on all ruby platforms but currently does not pass all specs.
