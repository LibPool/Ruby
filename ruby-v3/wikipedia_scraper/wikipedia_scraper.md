# wikipedia_scraper

**Tag**: serialization, data

## 简介

Scrape Wikipedia articles into structured JSON, preserving nested sections, Markdown-formatted text, lists, tables, and references. Ideal for LLM datasets, search indexing, and knowledge extraction.
