# weasy_pdf

**Tag**: web, template

## 简介

WeasyPDF generates PDFs from Rails views using WeasyPrint as backend.
Near-100% API compatible with Wicked PDF 2.x: same render pdf: options,
weasy_pdf_* view helpers (one-command rename from wicked_pdf_*),
same railtie auto-include behaviour. Native vite_ruby support.
No Chromium. No services. Modern CSS.
