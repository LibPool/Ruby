# maxmind-db-rust

**Tag**: web, filesystem

## 简介

An unofficial high-performance Rust-based gem for reading MaxMind DB files. Provides API compatibility with the official maxmind-db gem while leveraging Rust for superior performance. This library is not endorsed by MaxMind.
