# capserverext

**Tag**: web, database, networking, data

## 简介

Easily setup postgres, mysql databases and the nginx (http://sysoev.ru/nginx/) and apache web servers in any combination and on any posix host (ubuntu for now) using capistrano.  == FEATURES/PROBLEMS:  * install nginx from source/binary * setup &amp; configure nginx * add init script * tasks to start/stop nginx  == SYNOPSIS:
