# happypdf_json_schema

**Tag**: web, testing, serialization, filesystem

## 简介

happyPDF JSON Schema describes our PDF API in terms of available objects, their fields and links to url endpoints with related objects.
Besides ruby users can use a small lib with utility methods to load and test the schema files.
