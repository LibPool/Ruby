# fundamentalista

**Tag**: web

## 简介

Financial statements, ratios, Piotroski and Altman scores, multiples and discounted cash flow valuation for listed companies, from the SEC EDGAR XBRL API or Financial Modeling Prep. BigDecimal throughout, nil instead of exceptions on incomplete filings, one API over every provider.
