# tracemap

**Tag**: web, database, networking

## 简介

Rack middleware + OTel SDK config that sends traces, metrics, and logs to TraceMap via OTLP/HTTP. Auto-instruments Rails, Sinatra, Sidekiq, ActiveRecord, Redis, and Faraday.
