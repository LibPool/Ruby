# easydocforms

**Tag**: web, serialization

## 简介

EasyDocForms turns a blank PDF intake form into a hosted, mobile-friendly fillable form and returns the completed, pixel-exact PDF plus structured JSON answers. This gem wraps the Partner API: import a blank PDF, mint a hosted patient fill link, receive signed webhooks, and retrieve submissions. Zero runtime dependencies.
