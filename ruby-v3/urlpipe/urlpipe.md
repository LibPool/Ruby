# urlpipe

**Tag**: web, cli, template, data

## 简介

Official Ruby client for URLpipe. Get a page's Markdown, rendered HTML, a full-page screenshot, metadata, a summary, keywords, console errors or a Lighthouse audit, rendered in real Chrome. Handles long analyses, retries with idempotency keys, and webhook signature verification. No runtime dependencies.
