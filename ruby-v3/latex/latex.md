# latex

**Tag**: library

## 简介

Latex is a LaTeX text generation library for Ruby.

## 官网

- 主页: http://latex.rubyforge.org
- RubyGems: https://rubygems.org/gems/latex

## 历史版本号

- 0.1.3 (2009-07-25)
- 0.1.2 (2009-07-25)
- 0.1.1 (2009-07-25)

## 获取地址

- RubyGems: https://rubygems.org/gems/latex
- gem 安装: `gem install latex`
- Bundler: `gem "latex"`
- 最新版本: 0.1.3
- 最新版归档: https://rubygems.org/downloads/latex-0.1.3.gem
- 版本锁定: `gem "latex", "~> 0.1.3"`
