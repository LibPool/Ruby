# knoxcall

**Tag**: web, cli, security

## 简介

Ruby client for the KnoxCall multi-tenant API gateway and secrets platform: OAuth 2.1 + DPoP auth, route proxying, secrets, vaults, PKI, crypto, AI Gateway, and webhook verification.
