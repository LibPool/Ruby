# hark

**Tag**: library

## 简介

hark.com is a site that publishes movie quote sound bites
                     and still images.  This gem is used to access this
                     information in a programatic fashion.

## 官网

- 主页: http://www.hark.com/
- RubyGems: https://rubygems.org/gems/hark
