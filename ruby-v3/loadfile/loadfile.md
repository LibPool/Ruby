# loadfile

**Tag**: filesystem, data

## 简介

A ruby gem to manipulate
    .opt and .log files for Concordance® / Opticon®,
    .lfp files for Ipro eCap,
    and .dii files for Summation®.
    This software is not made or endorsed by Ipro®, Lexis-Nexis® or Dataflight®.
