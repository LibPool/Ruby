# liquid_xlsx

**Tag**: template, filesystem, data

## 简介

A Ruby library for generating .xlsx files from Excel templates using Liquid template syntax. Edit your template in Excel, write {{ variables }} and {% for %} loops in cells, and render the final file preserving styles, formulas, and merged cells.
