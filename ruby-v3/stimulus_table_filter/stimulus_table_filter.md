# stimulus_table_filter

**Tag**: web, template, data

## 简介

Stimulus controller and view helpers that add instant search, filter dimensions, multi-column sort, pagination and live footer stats to any Rails table. Everything is wired through data attributes, with no JavaScript dependencies or configuration required.
