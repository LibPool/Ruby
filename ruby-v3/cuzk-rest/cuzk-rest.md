# cuzk-rest

**Tag**: web, cli, tooling, data

## 简介

Idiomatic Ruby client for the Czech Real Estate Registry (ČÚZK) REST API. Provides access to cadastral data including parcels, buildings, units, ownership information, and reference registries.
