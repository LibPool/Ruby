# capistrano-procfile

**Tag**: web, filesystem

## 简介

Procfile defines what processes to run for whole application. This gem allows capistrano to export the Procfile to systemd init daemon (e.g. systemd, upstart) configurations. This makes the application integrating with systemd better.
