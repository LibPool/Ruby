# one-for-all-framework

**Tag**: web, database, data

## 简介

One-For-All is a high-performance Ruby web framework built for speed and aesthetics. It features a built-in CMS, premium Glassmorphism design, and supports multiple databases including SQLite, MySQL, and MongoDB.
