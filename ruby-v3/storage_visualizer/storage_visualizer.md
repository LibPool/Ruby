# storage_visualizer

**Tag**: testing, data

## 简介

This tool helps visualize which directories are occupying the most storage. Any directory that occupies more than 5% of used disk space is added to a visual hierarchichal storage report in the form of a Google Sankey diagram. The storage data is gathered using the linux `du` utility. It has been tested on Mac OSX and linux systems (Ubuntu &amp; CentOS), will not work on Windows. Run as sudo if analyzing otherwise inaccessible directories. May take a while to run.
