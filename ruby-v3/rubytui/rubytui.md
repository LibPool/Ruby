# rubytui

**Tag**: cli, template

## 简介

A zero-dependency terminal user interface library featuring
immediate-mode rendering with double buffering, constraint-based layouts,
a duck-typed widget system, cross-platform input handling, and Kitty
graphics protocol support for inline images.
