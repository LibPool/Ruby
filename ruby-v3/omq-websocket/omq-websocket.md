# omq-websocket

**Tag**: web, networking

## 简介

Adds ws:// and wss:// transports to OMQ, implementing ZeroMQ RFC 45 (ZWS 2.0). Built on async-websocket. Registers both schemes on require; no OMQ core changes required beyond the .connection_class hook (omq >= 0.27).
