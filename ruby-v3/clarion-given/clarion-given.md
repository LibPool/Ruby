# clarion-given

**Tag**: testing

## 简介

Clarion Given — keeper's edition of Jim Weirich's rspec-given.
An RSpec extension for Given/When/Then terminology in specifications.
Original by Jim Weirich (d. 2014), kept by the Lazarus Project.
