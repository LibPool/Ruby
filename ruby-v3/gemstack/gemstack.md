# gemstack

**Tag**: web, database, security, tooling, filesystem

## 简介

Ruby API + Next.js with one origin: routing, controllers, models (SQLite, PostgreSQL, MySQL), background jobs, mail, file storage, a TypeScript contract, generators and a development server. Authentication and realtime are the gemstack-auth and gemstack-realtime gems.
