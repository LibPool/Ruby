# email_login_link

**Tag**: web, networking

## 简介

Given an e-mail address this gem will check to see if it is able to determine 
                          the appropriate login URL for that service. For example user@gmail.com would
                          return https://accounts.google.com/ServiceLogin?service=mail&amp;continue=https://mail.google.com/mail/
