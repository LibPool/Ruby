# stable_diffusion_ruby

**Tag**: filesystem

## 简介

Run Stable Diffusion from Ruby. Supports local Python subprocess (SDXL) and remote Modal GPU endpoints (SD 3.5). Handles S3 file transfer, presigned URLs, and automatic backend dispatch.
