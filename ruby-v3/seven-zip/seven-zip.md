# seven-zip

**Tag**: filesystem

## 简介

SevenZipRuby (seven-zip) is a ruby gem library to read and write 7zip archives. This gem is based on seven_zip_ruby gem by Masamitsu MURASE (masamitsu.murase@gmail.com).
