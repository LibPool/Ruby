# clairity.css

**Tag**: library

## 简介

clairity.css is a responsive, semantic, classless CSS 
                    framework, with ambitions to grow into a complete (classful)
                    design system one day. It's loosely inspired by almond.css, 
                    sakura.css, Semantic UI, and others.
