# lilac-extras

**Tag**: tooling, filesystem, data

## 简介

Adds `data-tooltip` (bind the `title` attribute to a signal) and `data-autofocus` (focus the element after mount) to apps built with the lilac-compiled wasm variant. Picked up automatically by `lilac build` via Bundler when the gem appears in the project's Gemfile.
