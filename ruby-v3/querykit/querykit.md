# querykit

**Tag**: web, database, tooling

## 简介

QueryKit is a lightweight query builder and micro-ORM inspired by SqlKata and Dapper, providing a clean, fluent API for building SQL queries without the overhead of Active Record. Perfect for small projects and scripts.
