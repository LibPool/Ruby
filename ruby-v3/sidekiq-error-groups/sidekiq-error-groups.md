# sidekiq-error-groups

**Tag**: web, cli

## 简介

Adds an "Error groups" tab to the Sidekiq Web UI that groups retrying and dead jobs by their error class, with per-group retry/delete/kill actions, plus a Ruby API, a rake task and a CLI. Works with Sidekiq 6, 7 and 8.
