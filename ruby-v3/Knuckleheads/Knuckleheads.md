# Knuckleheads

**Tag**: filesystem, data

## 简介

Knuckleheads is played by:

	knuckleheads [ &lt; input file &gt; ]

where

	&lt; input file &gt; defaults to bin/players.csv

The scores are written to a file called high_scores.txt
