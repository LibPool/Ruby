# rdf-spec

**Tag**: testing

## 简介

RDF.rb extension that provides RSpec matchers and shared examples for RDF objects.

## 官网

- 主页: https://github.com/ruby-rdf/rdf-spec

- 问题追踪: https://github.com/ruby-rdf/rdf-spec/issues
- RubyGems: https://rubygems.org/gems/rdf-spec
