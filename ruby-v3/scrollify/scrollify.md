# scrollify

**Tag**: library

## 简介

Ruby gem for Luke Haas's scrollify jQuery plugin that assists scrolling and snaps to sections. Touch optimised.

## 官网

- 主页: http://www.github.com/rahullakhaney/scrollify
- 源码仓库: https://github.com/rahullakhaney/scrollify
- RubyGems: https://rubygems.org/gems/scrollify
