# studio_game2015_sp

**Tag**: filesystem

## 简介

This is a program I made while taking The Pragmatic Studio's intro course on Ruby. There are probably a ton of gems out there just like this one.

It takes a user input of number of rounds and file of filenames and prints to the screen a series of blams/w00ts, which then exports to a high score file.
