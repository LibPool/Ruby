# hr_lite

**Tag**: web

## 简介

Mountable Rails engine providing attendance with geolocation, leave management, holiday calendar, Indian payroll (PF/ESI/PT/TDS) with salary-slip PDFs, kudos with @mentions, appraisals and promotions — integrated into a host app via config hooks.
