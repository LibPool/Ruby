# kotoshu

**Tag**: template

## 简介

Kotoshu is a semantic spell checker for Ruby that uses FastText word embeddings (via ONNX) for context-aware spelling and grammar suggestions. Supports multiple languages with automatic detection, interactive review, and CI/CD integration.
