# tempmail_sdk

**Tag**: library

## 简介

五端（Go/npm/Rust/Python/C）之外的 Ruby 版临时邮箱 SDK，共享相同的渠道标识与顺序，提供统一的 Email 结构、渠道 fallback、代理/超时/TLS/遥测配置。
