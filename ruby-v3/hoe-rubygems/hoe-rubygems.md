# hoe-rubygems

**Tag**: testing, filesystem

## 简介

A Hoe plugin with additional RubyGems tasks. Provides support for
generating gemspec files and installing with a prefix.

## 官网

- 主页: http://github.com/jbarnette/hoe-rubygems
- RubyGems: https://rubygems.org/gems/hoe-rubygems

## 获取地址

- RubyGems: https://rubygems.org/gems/hoe-rubygems
- gem 安装: `gem install hoe-rubygems`
- Bundler: `gem "hoe-rubygems"`

- 最新版归档: https://rubygems.org/downloads/hoe-rubygems-1.0.0.gem
