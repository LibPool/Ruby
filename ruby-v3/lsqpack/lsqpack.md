# lsqpack

**Tag**: web

## 简介

A wrapper gem of the ls-qpack library. It strongly influenced by pylsqpack. It has same api of pylsqpack.

## 官网

- 主页: https://github.com/unasuke/lsqpack-ruby
- RubyGems: https://rubygems.org/gems/lsqpack

## 历史版本号

- 0.1.0 (2023-03-19)

## 获取地址

- RubyGems: https://rubygems.org/gems/lsqpack

- Bundler: `gem "lsqpack"`

- 最新版归档: https://rubygems.org/downloads/lsqpack-0.1.0.gem
