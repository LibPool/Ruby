# visiq

**Tag**: tooling

## 简介

VisIQ agent-governance SDK for Ruby — returns a permit, deny, approval_required, redact, escalate, or mask decision for a tool call or retrieval before your application executes it, evaluated in-process by the compiled VisIQ core that every VisIQ SDK shares. Installs with no compiler toolchain on macOS and Linux, x86_64 and arm64, with no Windows gem; malformed input denies, and core-load failures follow VISIQ_FAIL_MODE, which defaults to open.
