# cuzk-soap

**Tag**: web

## 简介

Enterprise-grade Ruby gem for ČÚZK WSDP (Webové služby dálkového přístupu) SOAP API. Provides professional access to Czech cadastral registry including certified extracts, ownership reports, batch processing and cost management.
