# odt-serenity

**Tag**: testing, template, filesystem, data

## 简介

Embedded ruby for OpenOffice/LibreOffice Text Document (.odt) files. You provide an .odt template with ruby code in a special markup and the data, and Serenity generates the document. Very similar to .erb files.
