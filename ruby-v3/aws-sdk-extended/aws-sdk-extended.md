# aws-sdk-extended

**Tag**: web, cli, devops

## 简介

Ships with API-compatible clients which support for (SNS) publishing, (SQS) sending, receiving,
    deleting (and more) messages which exceed the threshold of 256KB imposed by AWS services (up to 2GB).
