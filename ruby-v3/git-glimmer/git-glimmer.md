# git-glimmer

**Tag**: library

## 简介

Ruby/Git with fixes to use in Glimmer (Ruby Desktop Development GUI Library)

## 官网

- 主页: https://github.com/AndyObtiva/ruby-git
- 文档: https://www.rubydoc.info/gems/git-glimmer/1.7.0
- RubyGems: https://rubygems.org/gems/git-glimmer

## 历史版本号

- 1.7.0 (2020-08-06)

## 获取地址

- RubyGems: https://rubygems.org/gems/git-glimmer
- gem 安装: `gem install git-glimmer`
- Bundler: `gem "git-glimmer"`
- 最新版本: 1.7.0
- 最新版归档: https://rubygems.org/downloads/git-glimmer-1.7.0.gem
- 版本锁定: `gem "git-glimmer", "~> 1.7.0"`
- 中央仓库: https://rubygems.org/
