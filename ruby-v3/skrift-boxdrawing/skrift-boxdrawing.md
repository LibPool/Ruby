# skrift-boxdrawing

**Tag**: testing, template

## 简介

A Skrift plugin that renders Unicode box-drawing characters (U+2500..U+257F) as alpha buffers for a given cell size, independent of any font. Wire it in via Skrift::GlyphCache's `special:` hook.
