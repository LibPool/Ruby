# amp-git

**Tag**: library

## 简介

This gem provides git support to Amp. It is bundled with Amp itself.

## 官网

- 主页: http://github.com/michaeledgar/amp-git
- RubyGems: https://rubygems.org/gems/amp-git

## 历史版本号

- 0.1.0 (2010-11-03)
