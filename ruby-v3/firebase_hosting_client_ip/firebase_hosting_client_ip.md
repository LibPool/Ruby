# firebase_hosting_client_ip

**Tag**: cli

## 简介

Makes request.remote_ip return the client IP reported by Firebase Hosting's Fastly-Client-IP header, the only trustworthy source behind Firebase Hosting. Leaves REMOTE_ADDR intact and never infers the client from X-Forwarded-For.
