# jpzip

**Tag**: serialization, filesystem

## 简介

jpzip は日本の郵便番号を CDN 配信の JSON データから引く Ruby SDK。L1 LRU メモリキャッシュを内蔵し、任意の L2 永続キャッシュを差し込める。
