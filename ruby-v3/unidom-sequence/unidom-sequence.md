# unidom-sequence

**Tag**: library

## 简介

Unidom (UNIfied Domain Object Model) is a series of domain model engines. The Sequence domain model engine includes the Sequence model and its relative models. Unidom (统一领域对象模型)是一系列的领域模型引擎。序列领域模型引擎包括序列和与其相关的模型。
