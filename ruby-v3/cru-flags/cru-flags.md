# cru-flags

**Tag**: web, serialization

## 简介

Polls the flag service's per-(project, environment) JSON document, answers reads from a frozen in-memory snapshot with fail-static semantics, and ships a read-only Flipper adapter for the Rails fleet. CRuby only. See docs/design.md.
