# broadcast-objects

**Tag**: library

## 简介

broadcast-objects is a small gem that enables mass communication between objects. While this is usually restricted to communication to a singular
	object, broadcast-objects lets you 'broadcast' to many objects at once, and gives you full control over which objects recieve which broadcasts.
