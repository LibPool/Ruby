# widgetify

**Tag**: template

## 简介

An alternative to embed.ly, it allows an HTML page to be parsed for various meta HTML and open graph details

## 官网

- 主页: https://github.com/kreetitech/widgetify
- RubyGems: https://rubygems.org/gems/widgetify

- 0.0.1 (2012-08-10)
