# dhl_ecommerce_eu

**Tag**: web, networking

## 简介

Ruby API wrapper for DHL eCommerce EU. Currently only supports the Return Connect product. Check [here](https://developer.dhl.com/api-reference/ecommerce-europe/) for more info.
