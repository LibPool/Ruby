# rex-socket

**Tag**: networking

## 简介

The Ruby Exploitation (Rex) Socket Abstraction Library. This library
                          includes all of the code needed to turn sockets into Rex::Sockets with the functionality
                          for things like L3 pivoting used by Metasploit.
