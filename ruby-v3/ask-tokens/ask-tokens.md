# ask-tokens

**Tag**: web

## 简介

A Rails-free foundation for token-based usage tracking. Count real tokens with tiktoken, price them at any rate, declare activity costs, and run a wallet/ledger engine against a pluggable store. Pair with ask-tokens-rails for ActiveRecord persistence.
