# pinqloq

**Tag**: web, networking

## 简介

Pinqloq is a structured logging and log shipping SDK for centralized application logs. It captures HTTP request/response logs through a Rack middleware (Rails, Sinatra, Hanami, Grape, ...) and sends manual application events to the Pinqloq log management platform using in-memory buffering, batching, and HTTPS delivery.
