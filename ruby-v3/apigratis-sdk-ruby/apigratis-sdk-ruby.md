# apigratis-sdk-ruby

**Tag**: web

## 简介

SDK oficial Ruby da plataforma APIBrasil - WhatsApp, SMS, consultas CPF/CNPJ, veiculos, CEP, correios, pagamentos PIX/boleto e mais.
