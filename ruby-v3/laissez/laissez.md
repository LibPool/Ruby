# laissez

**Tag**: library

## 简介

Adds `lazy_accessor`, `lazy_reader`, and `lazy_writer` to the Module class.
                        Behaves just like its `attr_*` counterparts, except if the value is a Proc,
                        the return value of calling the proc is returned instead.
