# rails_semantic_logging

**Tag**: web, testing, serialization, data

## 简介

Provides a consistent, opinionated setup for structured JSON logging in Rails, with specific hooks for Sidekiq, ActiveJob, and Puma, as well as Datadog-friendly formatters.
