# i2peek

**Tag**: cli

## 简介

I2Peek is a standalone command-line application that provides a user-friendly terminal-based interface to monitor and display essential status information of I2P instances. It aims to simplify the process of checking I2P health and performance, offering an intuitive and efficient tool for both casual and advanced users.
