# facebox-render

**Tag**: web, networking, template

## 简介

FaceboxRender is a Rails plugin let you use lightbox seamlessly using Facebox library (http://famspam.com/facebox/)

## 官网

- 源码仓库: http://github.com/ihower/facebox_render
- RubyGems: https://rubygems.org/gems/facebox-render
