# classic_acts_as_list

**Tag**: web

## 简介

This is a hard fork off of acts_as_list v0.5.0, modernized for rails 5 and 6. It preserves backwards compatibility, rather than go in the break-everything-for-no-reason-direction the original maintainers went with.
