# examcert_exam_links

**Tag**: web, cli

## 简介

A dependency-free lookup table that turns a certification exam code such as SY0-701, SAA-C03, AZ-104, CISSP or PMP into the URL of its free exam breakdown and practice-question page on examcert.app. Useful for CLI tools, chat bots and study trackers that need to link to exam objectives.
