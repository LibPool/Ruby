# sluggable_danyeboah

**Tag**: library

## 简介

In order to use this to generate a slug:
  1. include it in your model
  2. call the generate_slug method in this module
  3. choose which column of the table will be used for making the slug using the class method sluggable_column :&lt;column name&gt;
