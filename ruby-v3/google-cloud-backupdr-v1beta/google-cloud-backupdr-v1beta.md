# google-cloud-backupdr-v1beta

**Tag**: web, cli, testing, devops

## 简介

google-cloud-backupdr-v1beta is the official client library for the Backup and DR Service V1BETA API. Note that google-cloud-backupdr-v1beta is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-backupdr instead. See the readme for more details.
