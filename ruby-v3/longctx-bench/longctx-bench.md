# longctx-bench

**Tag**: tooling

## 简介

Builds deterministic ~100k/200k token prompts, calls an OpenAI-compatible /v1/chat/completions endpoint and records status, latency, usage and errors. Intended for evaluating free-tier limits under long-context novel-continuation workloads.
