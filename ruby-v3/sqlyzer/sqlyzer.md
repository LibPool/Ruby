# sqlyzer

**Tag**: database, data

## 简介

Sqlyzer is a Ruby Mixin able to store, load, update and delete Ruby objects and their relationships in a database by automatically generating adapted tables and queries without a line of Sql.

- RubyGems: https://rubygems.org/gems/sqlyzer
