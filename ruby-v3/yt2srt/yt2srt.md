# yt2srt

**Tag**: library

## 简介

Quick Ruby script to convert Youtube Captions subtitles to SubRip (.srt) format

## 官网

- 主页: http://rubygems.org/gems/yt2srt
- 源码仓库: https://github.com/csrakowski/yt2srt/
- 问题追踪: https://github.com/csrakowski/yt2srt/issues
- RubyGems: https://rubygems.org/gems/yt2srt
