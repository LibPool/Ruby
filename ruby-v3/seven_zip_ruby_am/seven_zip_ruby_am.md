# seven_zip_ruby_am

**Tag**: filesystem

## 简介

SevenZipRuby (seven_zip_ruby_am) is a ruby gem library to read and write 7zip archives. This gem library calls official 7z.dll internally. This gem is the current code on the github repo as of May 2, 2019 which does not have the <2.4 restriction.
