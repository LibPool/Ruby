# git-fit

**Tag**: cli, data

## 简介

A git extension CLI for aggregating, managing, and exporting fitness activity data from multiple sources (Garmin, Strava, Keep, etc.)

## 官网

- 主页: https://github.com/Lax/git-fit
- 更新日志: https://github.com/Lax/git-fit/releases
- RubyGems: https://rubygems.org/gems/git-fit
