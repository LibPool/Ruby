# hey.rb

**Tag**: web, networking, filesystem

## 简介

hey sends load to a web application and reports a latency histogram, percentile distribution and per-phase timings. A file-by-file Ruby port of rakyll/hey: goroutines and channels become Async tasks and queues, and net/http becomes async-http. The gem is named hey.rb because hey was taken.
