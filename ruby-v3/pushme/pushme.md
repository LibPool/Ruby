# pushme

**Tag**: cli

## 简介

To use this gem you need Push Me. It's available for iOS and you find it on the App Store. Use the app to set up an Inbox. Once you've created an inbox, copy the identifier to your computer. Then run `pushme "message" "identifier" in your terminal to send yourself a notification.
