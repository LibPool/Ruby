# LiteRGSS

**Tag**: library

## 简介

LiteRGSS is a Game library that allows you to easly make Games with Ruby. LiteRGSS uses SFML to get Inputs and to display Graphics.

## 官网

- 主页: https://psdk.pokemonworkshop.fr/litergss
- 源码仓库: https://github.com/NuriYuri/LiteRGSS
- RubyGems: https://rubygems.org/gems/LiteRGSS
