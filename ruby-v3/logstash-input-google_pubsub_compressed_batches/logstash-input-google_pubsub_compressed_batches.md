# logstash-input-google_pubsub_compressed_batches

**Tag**: library

## 简介

This gem is a Logstash input plugin required to be installed on top of the Logstash core pipeline using $LS_HOME/bin/logstash-plugin install gemname. This gem is not a stand-alone program.
