# activerecord-multi-tenant-next

**Tag**: web, filesystem, data

## 简介

A maintained fork of activerecord-multi-tenant (Citus Data) with support for Rails 6.0 through 8.1. Drop-in replacement: same MultiTenant API, same require path.
