# hashira

**Tag**: filesystem

## 简介

Measures package coupling (Ca/Ce/instability, SDP violations, cycles), per-method cognitive complexity, near-miss code duplication, and twelve design smells in a Ruby codebase from the AST, then ranks files by cost against git churn. Findings are backed by file-level evidence, and a baseline ratchets edges and findings for CI — direction, not a score.
