# cloudlib

**Tag**: devops

## 简介

Cloudlib is a ruby library and commands for maintaining a library of books and articles on the Amazon 'cloud': S3 and SimpleDB.

## 官网

- 主页: http://github.com/jgm/cloudlib
- RubyGems: https://rubygems.org/gems/cloudlib

- 0.3.10 (2010-10-22)
