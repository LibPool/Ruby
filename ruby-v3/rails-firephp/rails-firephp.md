# rails-firephp

**Tag**: web

## 简介

Rails plugin to send messages to FirePHP (plugin of FireBug)

## 官网

- 主页: https://github.com/rheoli/rails-firephp
- RubyGems: https://rubygems.org/gems/rails-firephp

## 历史版本号

- 0.0.1 (2009-07-25)

- RubyGems: https://rubygems.org/gems/rails-firephp
- gem 安装: `gem install rails-firephp`
- Bundler: `gem "rails-firephp"`

- 最新版归档: https://rubygems.org/downloads/rails-firephp-0.0.2.gem
