# oml4r

**Tag**: web, cli

## 简介

This is a simple client library for OML which does not use liboml2 and its filters, but connects directly to the server using the +text+ protocol.  User can use this library to create ruby applications which can send measurement to the OML collection server. The gem ships with some example applications.
