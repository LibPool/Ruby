# summoner-engine

**Tag**: web, testing, serialization

## 简介

Summoner is a powerful Feature Toggle and Dynamic Configuration engine for Ruby on Rails. It goes beyond simple booleans by offering Attribute-Based Access Control (ABAC), strong typing, granular entity-specific overrides, YAML synchronization, and an elegant built-in Web UI. Fully backed by a robust caching layer for high performance.
