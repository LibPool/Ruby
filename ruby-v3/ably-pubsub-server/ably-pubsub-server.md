# ably-pubsub-server

**Tag**: web, cli, networking

## 简介

Ably Pub/Sub client for servers: backend services and other trusted runtimes. Construct clients with Ably::PubSub::Server.create_http_client or Ably::PubSub::Server.create_realtime_client.
