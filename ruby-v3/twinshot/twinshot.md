# twinshot

**Tag**: template, filesystem

## 简介

Save and compare screenshots of the functionality of other applications you want to copy end to end: compares a verified oracle tree against a current tree (structure check first, then per-file similarity through adapters — html by structure, txt by lines, png by pixels, binaries by bytes). Any unknown file is a failure.
