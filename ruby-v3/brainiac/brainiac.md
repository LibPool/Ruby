# brainiac

**Tag**: library

## 简介

Core orchestration engine that manages AI agent identity, long-term memory (brain), prompt construction, and dispatch. Communication channels are provided by plugins: brainiac-discord, brainiac-fizzy, brainiac-github, and more.
