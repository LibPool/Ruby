# nxgate

**Tag**: web, security

## 简介

SDK Ruby para integracao com a API NXGATE PIX. Suporta geracao de cobranças (cash-in), saques (cash-out), consulta de saldo, transacoes e webhooks. Inclui autenticacao OAuth2, assinatura HMAC e retentativas automaticas.
