# htmlentity_translator

**Tag**: template

## 简介

This gem is a simple libraty to help add or remoge HTML entities to a string the usage is simple "&amp;amp;this needs to be removed&amp;aacute;".decode_entities will remove all HTML entities, and "á now I need it encoded".encode_entities will replace non printable ascii with the corresponding HTML entitites
