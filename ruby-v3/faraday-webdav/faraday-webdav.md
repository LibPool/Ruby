# faraday-webdav

**Tag**: web, networking

## 简介

Adds WebDAV HTTP methods (PROPFIND, PROPPATCH, MKCOL, COPY, MOVE, LOCK, UNLOCK, REPORT, SEARCH) to Faraday connections.
