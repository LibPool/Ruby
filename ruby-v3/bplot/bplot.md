# bplot

**Tag**: library

## 简介

A 2D and 3D plotting module for SciRuby that uses syntax from Gnuplot and to a lesser degree Matlab.

## 官网

- 主页: http://rubygems.org/gems/bplot

- 文档: https://github.com/dcarrera/bplot/blob/master/Tutorial
- RubyGems: https://rubygems.org/gems/bplot
