# file_config_parser

**Tag**: tooling, filesystem, data

## 简介

Parse the configuration file using only the ruby standard library (no gems).
Parse the configuration items into a Hash.
Hash values should use the appropriate native Ruby data types. For example ‘debug_mode=off' would return in the hash,  'debug_mode: false'
