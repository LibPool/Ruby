# mercado_publico_cl

**Tag**: web, cli

## 简介

Cliente Ruby para la API de compras públicas del Estado de Chile (Mercado Público): licitaciones, órdenes de compra, proveedores y organismos, con reintentos, fechas en hora chilena e integración Rails.
