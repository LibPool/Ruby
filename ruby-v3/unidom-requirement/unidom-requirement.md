# unidom-requirement

**Tag**: library

## 简介

Unidom (UNIfied Domain Object Model) is a series of domain model engines. The Requirement domain model engine includes the Requirement and the Order Requirement Commitment model. Unidom (统一领域对象模型)是一系列的领域模型引擎。需求领域模型引擎包括需求和订单需求委托的模型。
