# tensicai

**Tag**: web, networking, template

## 简介

Ruby SDK for Tensic, a sovereign AI orchestration platform. Early preview - the public API is not stable and no HTTP transport is wired up yet.

## 官网

- 主页: https://tensic.ai
- 源码仓库: https://github.com/tensicai/ruby-sdk
- RubyGems: https://rubygems.org/gems/tensicai
