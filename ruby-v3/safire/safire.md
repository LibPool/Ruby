# safire

**Tag**: cli, testing, security, data

## 简介

A Ruby gem implementing SMART App Launch 2.2.0 and UDAP Security STU2 for healthcare client applications. It supports SMART OAuth 2.0 authorization, PKCE, private_key_jwt assertions, Backend Services, UDAP signed metadata discovery, and certificate-backed UDAP Dynamic Client Registration.
