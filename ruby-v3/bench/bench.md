# bench

**Tag**: library

## 简介

A wrapper DSL around the benchmark lib of the Ruby standard lib with the goal to make benchmarking as easy as possible.

## 官网

- 主页: http://bench.rubyforge.org
- RubyGems: https://rubygems.org/gems/bench
