# whatis

**Tag**: template, data

## 简介

WhatIs.this fetches any entity metadata from Wikipedia by title and renders it concisely and
    informatively. Think `WhatIs.these(list, of, user, entered, toponyms).map(&amp;:coordinates)` for
    example.
