# llm_meta_widget

**Tag**: web, cli, serialization

## 简介

Client-orchestrated chat widget: fetches host-side aiActions + .well-known/mcp.json manifests, dispatches tool_calls locally or directly to MCP endpoints, and consumes the llm_meta_server's SSE-streamed single_llm_calls API. Ships one helper + one partial + a served orchestrator.js. No Devise, no DB migrations, no chat_manager.
