# jekyll-baserow-headless-cms

**Tag**: filesystem, data

## 简介

A configurable Jekyll plugin that fetches content from Baserow tables and makes it available as Jekyll data files. Supports multiple collections, various field types, and automatic fallback to Jekyll collections.
