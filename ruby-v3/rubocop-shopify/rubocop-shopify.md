# rubocop-shopify

**Tag**: library

## 简介

Gem containing the rubocop.yml config that corresponds to the implementation of the Shopify's style guide for Ruby.

## 官网

- 主页: https://shopify.github.io/ruby-style-guide/
- 源码仓库: https://github.com/Shopify/ruby-style-guide/tree/v3.1.0
- RubyGems: https://rubygems.org/gems/rubocop-shopify
