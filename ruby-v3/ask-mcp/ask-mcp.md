# ask-mcp

**Tag**: web, security, networking

## 简介

Connect to MCP servers via stdio, SSE, and Streamable HTTP transports. Run as an MCP server exposing any Ruby object as a tool. Discover tools, resources, and prompts. OAuth 2.1 authentication.
