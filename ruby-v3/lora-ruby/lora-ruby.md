# lora-ruby

**Tag**: web, database, data

## 简介

Ruby bindings for the Lora in-memory graph database. Exposes the embedded Rust engine as a native extension via Magnus/rb-sys, so queries run in-process without a separate server.

## 官网

- 主页: https://github.com/lora-db/lora
- 源码仓库: https://github.com/lora-db/lora/tree/main/crates/bindings/lora-ruby
- 文档: https://github.com/lora-db/lora/blob/main/crates/bindings/lora-ruby/README.md
- 问题追踪: https://github.com/lora-db/lora/issues
