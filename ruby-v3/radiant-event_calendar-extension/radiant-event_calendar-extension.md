# radiant-event_calendar-extension

**Tag**: web, devops

## 简介

An event calendar extension that administers events locally or draws them from any ical or CalDAV publishers (Google Calendar, .Mac, Darwin Calendar Server, etc.)

## 官网

- 主页: http://github.com/radiant/radiant-event_calendar-extension
- RubyGems: https://rubygems.org/gems/radiant-event_calendar-extension
