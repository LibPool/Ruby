# vocabulary_to_csv

**Tag**: web, filesystem, data

## 简介

vocabulary_to_csv is a Ruby gem designed for extracting vocabulary lists from Vocabulary.com and saving the data into a CSV file. It employs the Nokogiri gem for web scraping.
