# spekmachine

**Tag**: web, testing, networking

## 简介

spekmachine is a modification of RSpec, (http://rspec.rubyforge.org/) which uses a state machine to test all transitions. It uses the Chinese Postman  algorithm to find the shortest way through all transitions.
