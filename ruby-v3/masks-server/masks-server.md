# masks-server

**Tag**: web, security

## 简介

A multi-tenant OpenID Connect and OAuth 2.0 provider with a signing key per tenant, SAML, SCIM, passkeys, and a management API. Mount it at the root of an app of its own, or inside an existing Rails app.
