# groundworkcss

**Tag**: web, testing, template, filesystem

## 简介

The official GroundworkCSS rails gem. Created by @ghepting and @ldewald. GroundworkCSS is a fully responsive HTML5, CSS and Javascript toolkit created by @ghepting. Note: If your app is still using GroundworkCSS 1.13.1, specify version "~0.4.3" of the `groundworkcss` gem in your Gemfile!
