# ripta-dm-paperclip

**Tag**: web, cli, filesystem, data

## 简介

File attachments as attributes for DataMapper 1.1, based on the original Paperclip by Jon Yurek at Thoughtbot; updated for ruby 1.9 and rails 3.2
