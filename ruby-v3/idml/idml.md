# idml

**Tag**: template

## 简介

Pure-Ruby toolkit for Adobe InDesign IDML: schema-faithful models with byte-faithful round-trip, RelaxNG validation, composition operations, and a full IDML-to-PDF rendering pipeline (text layout, tables, CJK vertical writing, text wrap, footnotes, PDF/A).
