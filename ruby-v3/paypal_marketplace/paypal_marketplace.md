# paypal_marketplace

**Tag**: web

## 简介

This is a ruby API wrapper for the Paypal marketplace API creating an onboarding link via the Paypal Partner Referrals API. This allows you to onboard users similar to Stripe connect and allow them to sell products on your platform and get payed via Paypal
