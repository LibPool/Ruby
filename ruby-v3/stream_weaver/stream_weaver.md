# stream_weaver

**Tag**: web, tooling, filesystem

## 简介

StreamWeaver enables GenAI agents and developers to rapidly build interactive web UIs using a declarative Ruby DSL. Features single-file execution, automatic state management, and agentic mode for AI-driven workflows.
