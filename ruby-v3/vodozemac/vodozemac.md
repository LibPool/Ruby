# vodozemac

**Tag**: security

## 简介

Olm and Megolm for Ruby, over the vodozemac crate by magnus. Accounts, sessions, group sessions, short authentication strings, the ed25519 and curve25519 key types and PkEncryption, with every key and ciphertext crossing the boundary as base64.
