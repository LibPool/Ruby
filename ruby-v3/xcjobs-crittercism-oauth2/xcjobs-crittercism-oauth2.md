# xcjobs-crittercism-oauth2

**Tag**: web, security, networking

## 简介

Crittercism plugin for xcjobs.
    You can upload dSYM using new api.
    If you use Xcode7, `/api_beta/dsym/` doesn't work.
    
    xcjobs: 
        https://github.com/kishikawakatsumi/xcjobs
