# capistrano-rsync-local

**Tag**: web, networking, devops, filesystem

## 简介

Deploy with Rsync to your server from any local (or remote) repository. 

Saves you the need to install Git on your production machine and deploy all of your development files each time! 

Works with the new Capistrano v3! Suitable for deploying any apps, be it Ruby or Node.js. Initially gem has been developed by Moll (https://github.com/moll/capistrano-rsync). Scm support is introduced by Seantan (https://github.com/seantan/capistrano-rsync).
