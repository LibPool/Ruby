# dispatch-rails

**Tag**: web, data

## 简介

Two ways to feed Dispatch from a Rails app: an optional floating bug-report widget for UI apps, and headless server-side exception tracking for API-only apps (Sentry-compatible wire format, structured error responses, and a programmatic report helper). Captures URL, user, and environment metadata automatically.
