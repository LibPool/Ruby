# multicard

**Tag**: web, cli

## 简介

Ruby SDK for Multicard.uz — payment gateway supporting Uzcard, Humo, and 9 wallet apps (Payme, Click, Uzum, etc.). Invoices, card payments, splits, holds, payouts, card binding, and webhook verification.
