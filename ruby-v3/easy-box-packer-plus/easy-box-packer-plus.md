# easy-box-packer-plus

**Tag**: library

## 简介

3D bin-packing with weight limit using first-fit decreasing algorithm. The functionality has been extended to include an internal options hash, allowing any desired values to be passed to the items, such as IDs and labels for each item. This ensures that when the gem returns the result, these keys are included in the output.
