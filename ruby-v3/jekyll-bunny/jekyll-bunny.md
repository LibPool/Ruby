# jekyll-bunny

**Tag**: library

## 简介

jekyll-bunny provides a simple {% bunny LIBRARY_ID VIDEO_ID %} Liquid tag for embedding Bunny Stream videos with a responsive iframe wrapper and support for Bunny Stream embed parameters.
