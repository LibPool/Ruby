# open-banking-io

**Tag**: web, security, data

## 简介

Authenticates with your API key and decrypts open-banking.io's zero-knowledge data envelopes locally with your exported private key (ECDH P-256 -> HKDF-SHA256 -> AES-256-GCM). The service only ever returns ciphertext it cannot read.
