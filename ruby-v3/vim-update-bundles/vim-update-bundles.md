# vim-update-bundles

**Tag**: library

## 简介

A utility that uses Git to install and remove your Vim plugins.

## 官网

- 主页: https://github.com/bronson/vim-update-bundles/
- RubyGems: https://rubygems.org/gems/vim-update-bundles
