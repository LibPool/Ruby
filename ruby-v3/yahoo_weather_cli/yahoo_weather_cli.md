# yahoo_weather_cli

**Tag**: cli

## 简介

Command line application that gets information from Yahoo! Weather RSS feed and prints it nicely on screen. You can provide your own format directives in order to customize output (see --help). Current weather conditions, forecasts up to five days and metric/english units available.
