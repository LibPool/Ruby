# skrift-color

**Tag**: template

## 简介

A Skrift plugin that renders COLR/CPAL (v0) colour glyphs - e.g. layered colour emoji - by compositing each layer with skrift's monochrome rasteriser into an RGBA buffer. The core renderer stays monochrome; colour is opt-in.
