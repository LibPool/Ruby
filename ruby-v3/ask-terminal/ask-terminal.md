# ask-terminal

**Tag**: web, cli, networking

## 简介

The first thin client of the ask ecosystem: an interactive terminal coding agent that speaks the canonical ask-session-protocol and nothing else. Spawns the host (ask-app-server) over stdio or attaches to a running host over its unix socket — the same protocol any other client (web console, bots) speaks, so multiple clients can share the same live sessions.
