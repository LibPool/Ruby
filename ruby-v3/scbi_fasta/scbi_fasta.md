# scbi_fasta

**Tag**: filesystem

## 简介

scbi_fasta is a ruby gem to read FASTA+QUAL files (DNA/RNA sequences).

## 官网

- 主页: http://www.scbi.uma.es/downloads
- RubyGems: https://rubygems.org/gems/scbi_fasta
