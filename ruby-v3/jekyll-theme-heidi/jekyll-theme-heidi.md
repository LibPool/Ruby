# jekyll-theme-heidi

**Tag**: library

## 简介

Heidi is a brazen two-column Jekyll theme that pairs a prominent sidebar with uncomplicated content. Based on Hyde by @mdo. Developed by Howlin Bash

## 官网

- 主页: https://gitlab.com/howlinbash/heidi

- 文档: https://github.com/mdo/hyde
