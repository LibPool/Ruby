# spree_doordash

**Tag**: web

## 简介

Dispatches completed Spree orders as DoorDash Drive deliveries — live delivery-fee quoting during checkout, dispatch on order completion, and delivery status synced back via webhooks. Companion extension to spree_square, keyed off the same per-location mapping pattern.
