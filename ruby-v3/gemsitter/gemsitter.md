# gemsitter

**Tag**: library

## 简介

Check if there are newer versions for your used gems are available and puts out a notification

## 官网

- 主页: https://github.com/mindbreaker/gemsitter
- RubyGems: https://rubygems.org/gems/gemsitter

## 获取地址

- RubyGems: https://rubygems.org/gems/gemsitter
- gem 安装: `gem install gemsitter`
- Bundler: `gem "gemsitter"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/gemsitter-0.0.1.gem
- 版本锁定: `gem "gemsitter", "~> 0.0.1"`
- 中央仓库: https://rubygems.org/
