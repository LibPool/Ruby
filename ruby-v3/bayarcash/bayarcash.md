# bayarcash

**Tag**: web, cli

## 简介

An expressive, framework-agnostic Ruby client for the Bayarcash Payment Gateway API. Supports API v2 (default) and v3, checksum generation, callback verification, FPX Direct Debit, and Manual Bank Transfer.
