# compass

**Tag**: library

## 简介

Compass is a Sass-based Stylesheet Framework that streamlines the creation and maintenance of CSS.

## 官网

- 主页: http://compass-style.org
- 源码仓库: http://github.com/chriseppstein/compass
- 文档: http://compass-style.org/docs/
- 问题追踪: http://github.com/chriseppstein/compass/issues
- RubyGems: https://rubygems.org/gems/compass
