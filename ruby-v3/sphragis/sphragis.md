# sphragis

**Tag**: web, security, devops

## 简介

Sphragis (Σφραγίς - Greek for 'seal') provides multi-provider PDF digital signatures. Supports hardware tokens (Fortify WebCrypto), cloud e-signatures (Harica), and more. Perfect for academic institutions and commercial use. Rails 6.1+ compatible.
