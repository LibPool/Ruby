# rules_ai

**Tag**: library

## 简介

This is a collection of different rules based functions, from calculating how many hours have passed, tesla multiplication, autonomous prompting ( such as a morning promptor ), user greeting, randomized rot13 alphabets, and calculating the size of a comic digest.
