# wirepayment

**Tag**: web, cli

## 简介

Server-side Ruby client for the Wire unified payment gateway: payment intents, charges, events, and webhook endpoints across Mongolian payment operators, with automatic retries, idempotency, cursor auto-pagination, and webhook signature verification.
