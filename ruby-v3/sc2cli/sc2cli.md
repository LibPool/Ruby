# sc2cli

**Tag**: web, cli

## 简介

A command line utility for accessing the StarCraft 2 API written in Ruby. Supports league boundaries, player league details, player match history and more.

## 官网

- 主页: https://gitlab.com/bitservices/ruby/sc2cli/
