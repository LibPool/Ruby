# chocomint

**Tag**: web

## 简介

chocomint は LLM のツール呼び出しを Ruby 側で厳格に監督するオーケストレータ。
機械的検証・意味的検証・自動再試行・監査ログを行い、LLM は提案者と監査者に限定し、
実行・判定・再試行・記録は Ruby が責任を持つ。Anthropic Messages API 互換の
監督プロキシサーバーと、ブラウザ上の AI エディタ (/edit) も提供する。
