# pasteboard

**Tag**: library

## 简介

Pasteboard wraps the OS X system pasteboard.  Pasteboard allows you to add
and retrieve multiple items and multiple item flavors to the pasteboard unlike
+pbpaste+ and +pbcopy+ which only allow text.
