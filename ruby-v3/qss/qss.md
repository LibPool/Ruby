# qss

**Tag**: web, template

## 简介

QSS sizes and places layout on a 1000-unit canvas grid (1 qnt = canvas width / 1000, pure CSS), ships compiled and SCSS sources, and audits views for rule violations. Includes a Rails engine for the asset pipeline; the auditors also run without Rails.
