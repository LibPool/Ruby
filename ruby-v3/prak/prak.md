# prak

**Tag**: library

## 简介

Modifications by Sven Winkler

== DESCRIPTION:

Replacement for grep. Recursively scans directories to match a given
Ruby regular expression. Prints highlighted results.

Based on the Perl tool 'ack' by Andy Lester.
