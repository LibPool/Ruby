# keal

**Tag**: library

## 简介

Keep alive program for the GNOME desktop environment on Linux, inspired by caffeinate(8) on MacOS.

## 官网

- 主页: https://github.com/pinecat/keal
- RubyGems: https://rubygems.org/gems/keal
