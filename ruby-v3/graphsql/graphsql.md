# graphsql

**Tag**: database, networking

## 简介

Map your GraphQL type's fields to ActiveRecord columns and associations, and GraphSQL turns each query's actual field selection into a right-sized SELECT and preload automatically — no more guessing which columns and associations a resolver needs to load.
