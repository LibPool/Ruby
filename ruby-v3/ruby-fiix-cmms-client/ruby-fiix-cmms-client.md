# ruby-fiix-cmms-client

**Tag**: web, cli, security, filesystem

## 简介

A Ruby gem wrapping the Fiix CMMS (Computerized Maintenance Management System) REST API with HMAC-SHA256 authentication. Supports all core operations: find, create, update, delete, batch, RPC, and file uploads. Zero runtime dependencies.
