# reductions

**Tag**: library

## 简介

Reductions is an addition to Enumerable that returns
    an array containing all of the intermediate values that would
    be generated in a call to Enumerable#reduce.

    (5..10).reductions(:+)    # =&gt; [5, 11, 18, 26, 35, 45]
