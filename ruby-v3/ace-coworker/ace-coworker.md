# ace-coworker

**Tag**: template

## 简介

ace-coworker composes the existing ace-assign lifecycle, ace-task ref resolution, and ace-hitl reporting for a prepared executor role. It owns the .ace-local/coworker/ run configuration and renders the executor brief.
