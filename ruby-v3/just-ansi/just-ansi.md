# just-ansi

**Tag**: library

## 简介

JustAnsi provides a rich set of methods to generate ANSI control codes for
attributes, colors, cursor movement and much more. It supports most control
codes, all attributes, 3/4bit-, 8bit- and 24bit-colors.
