# clowk-phlex

**Tag**: template, data

## 简介

The Ruby half of clowk-phlex: Phlex view components (charts, gauges, pickers) that render SVG/HTML markup + data-* attributes. Behavior and styles ship via the companion @clowk/phlex npm package.
