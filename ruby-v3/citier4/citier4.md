# citier4

**Tag**: web, networking

## 简介

IN DEVELOPPEMENT, Not for use! CITIER4 is CITIER for rails 4. CITIER (Class Inheritance &amp; Table Inheritance Embeddings for Rails) is a solution for single and multiple class table inheritance.
    For full information: https://github.com/petehamilton/citier/
    For the original version by ALTRABio see www.github.com/altrabio/
