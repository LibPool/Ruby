# docsteer

**Tag**: library

## 简介

DocSteer is a free Jekyll theme for documentation, help centres and internal knowledge bases. It is published as jekyll-theme-docsteer, per the Jekyll theme naming convention; this gem depends on it, so installing 'docsteer' gets you the theme. Use `theme: jekyll-theme-docsteer` in your _config.yml.
