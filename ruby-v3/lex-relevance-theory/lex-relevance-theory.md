# lex-relevance-theory

**Tag**: library

## 简介

Evaluates cognitive inputs by relevance (effect/effort ratio). High-effect low-effort inputs get attention; irrelevant inputs filtered. Based on Sperber & Wilson (1986) Relevance Theory.
