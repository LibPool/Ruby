# fb_filler

**Tag**: filesystem

## 简介

We all totally practice TDD. Clearly. But sometimes 
                       we inherit a project that wasn't as fastidious about it 
                       as we are. This gem takes a column name from the user and 
                       uses it to fill out a FactoryGirl file.
