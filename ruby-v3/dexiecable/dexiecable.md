# dexiecable

**Tag**: web, cli, database, data

## 简介

DexieCable augments ActionCable channels with a query DSL that mirrors the Dexie.js API, letting you push database mutations from the server to the client in real time. Includes an ActiveRecord macro (syncs_to_dexie) for automatic change syncing.
