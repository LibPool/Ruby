# angularjs-rails-gem

**Tag**: web

## 简介

Injects Angular.js into your asset pipeline as well as other Angular modules.

- 主页: https://github.com/confuseddesi/angularjs-rails/
- RubyGems: https://rubygems.org/gems/angularjs-rails-gem
