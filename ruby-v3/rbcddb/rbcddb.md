# rbcddb

**Tag**: web, database, testing, data

## 简介

Libcddb is a C library to access data on a CDDB server (freedb.org).  It allows you to:  1. search the database for possible CD matches; 2. retrieve detailed information about a specific CD; 3. submit new CD entries to the database.
