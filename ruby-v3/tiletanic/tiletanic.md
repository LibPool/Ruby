# tiletanic

**Tag**: library

## 简介

A Ruby port of the DigitalGlobe Tiletanic library for tile schemes, quadkeys, and geometry coverings.

- 问题追踪: https://github.com/DigitalGlobe/tiletanic-rb/issues
