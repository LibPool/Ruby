# maquina_newsletters

**Tag**: web, template

## 简介

MaquinaNewsletters is a Rails engine that provides functionality for creating, scheduling, and managing newsletter emails. It includes email templates, recipient management, and integration with ActiveStorage for assets. Built with Rails 8 and following best practices for email automation.
