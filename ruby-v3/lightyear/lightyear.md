# lightyear

**Tag**: tooling

## 简介

Lightyear is a Ruby framework for building hybrid human-agent organizations
where humans and AI agents work together as peers. Built by Pacific Robots.
This 0.0.0 release reserves the gem name; the framework is under active
development.
