# jsonrpc_interface

**Tag**: serialization, tooling

## 简介

JSONRPC Interface for Ruby projects realised in object oriented way. JRPC Request, JRPC Notification, JRPC Response, JRPC Error Response, JRPC Object Builder and JRPC Error Codes.
