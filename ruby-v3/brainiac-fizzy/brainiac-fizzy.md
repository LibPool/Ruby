# brainiac-fizzy

**Tag**: web, template, devops

## 简介

Full Fizzy integration for Brainiac — card assignment, comment routing, @mentions, cross-agent reviews, duplicate detection, deploy shortcuts, deployment tracking, and planning mode. Uses Brainiac's hook system for lifecycle integration (PR merge → card close, agent complete → column move).
