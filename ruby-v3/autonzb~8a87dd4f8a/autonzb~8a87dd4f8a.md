# autonzb

**Tag**: filesystem

## 简介

Ruby tool to automatically download x264 HD nzb movies files from newzleech.com & nzbs.org

## 官网

- 主页: http://github.com/pirate/autonzb
- RubyGems: https://rubygems.org/gems/autonzb
