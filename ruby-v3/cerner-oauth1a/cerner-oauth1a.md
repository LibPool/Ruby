# cerner-oauth1a

**Tag**: security

## 简介

A minimal dependency library for interacting with a Cerner OAuth 1.0a Access
Token Service for invoking Cerner OAuth 1.0a protected services or implementing
Cerner OAuth 1.0a authentication.
