# squarecloud-unofficial

**Tag**: web, devops

## 简介

An unofficial Ruby library for interacting with the Square Cloud API, providing Ruby developers with easy access to application management, backup systems, domains, and more

## 官网

- 源码仓库: https://github.com/kleeedolinux/squarecloud-sdk-rb
- RubyGems: https://rubygems.org/gems/squarecloud-unofficial
