# solid_queue-flightdeck

**Tag**: web

## 简介

Flightdeck is a mountable Rails engine that gives Solid Queue a fast, polished dashboard: jobs, failures, queues, processes, recurring tasks and live charts. Works in API-only hosts and ships its own precompiled assets.
