# eitil

**Tag**: web

## 简介

Eitil (eitje utility) never stops increasing your life's efficacy and productivity, yay!
                      Our gem currently exists of five seperate layers (Railties), which can be integrated as standalone gems. 
                      This design is very much like that of rails, thus affinity with integrating rails should make eitil feel familiar.
