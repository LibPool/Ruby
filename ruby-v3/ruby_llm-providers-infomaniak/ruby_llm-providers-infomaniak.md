# ruby_llm-providers-infomaniak

**Tag**: library

## 简介

Use the models hosted by Infomaniak AI Tools in Switzerland (Kimi, Qwen, Apertus, Mistral, ...) through RubyLLM: chat, streaming, tools, structured output, thinking, images and embeddings.
