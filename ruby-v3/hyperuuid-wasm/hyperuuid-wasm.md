# hyperuuid-wasm

**Tag**: web, tooling, filesystem

## 简介

The hyperuuid gem's Magnus extension, prebuilt for wasm32-wasip1, for a ruby.wasm
interpreter built with `rbwasm build`: put this gem in that Gemfile instead of hyperuuid
and the extension is linked into the interpreter. Same API and the same Rust core as the
hyperuuid gem. Not for a host Ruby, where the hyperuuid gem is the one to install.
