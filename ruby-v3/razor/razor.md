# razor

**Tag**: web, template, tooling

## 简介

'Razor is a static website generator. Describe layouts and pages in ruby. Write them with html and Mustache.
The concept behind razor is simple : layouts are described by classes, nested layouts by subclasses and pages by instances of these classes.'
