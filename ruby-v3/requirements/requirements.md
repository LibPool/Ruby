# requirements

**Tag**: library

## 简介

This is a mini rubygems plugin which shows the requirements of a gem after installing the gem (if there are any)

## 官网

- 主页: http://github.com/janlelis/requirements
- RubyGems: https://rubygems.org/gems/requirements

## 历史版本号

- 1.0.0 (2010-10-01)

## 获取地址

- RubyGems: https://rubygems.org/gems/requirements
- gem 安装: `gem install requirements`
- Bundler: `gem "requirements"`
- 最新版本: 1.0.0
- 最新版归档: https://rubygems.org/downloads/requirements-1.0.0.gem
- 版本锁定: `gem "requirements", "~> 1.0.0"`
- 中央仓库: https://rubygems.org/
