# algorithmix

**Tag**: data

## 简介

The gem contains various implementations of known and uknown data structures and algorithms. 
                          /Currently the gem contains: #stack, #queue, #deque, #binary_heap, #priority_queue, #linked_list,
                          #double_linked_list/
