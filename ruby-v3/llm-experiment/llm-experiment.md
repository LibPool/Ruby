# llm-experiment

**Tag**: cli, data

## 简介

A clean-room harness for measuring coding agents (Claude Code, Codex CLI): fresh Apple containers per trial, pinned toolchains, transcript parsing, exact statistics, and a sanitize gate for publishing results.
