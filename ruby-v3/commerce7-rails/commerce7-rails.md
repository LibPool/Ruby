# commerce7-rails

**Tag**: web, cli, security, template, data

## 简介

Activation/deactivation lifecycle, webhook dispatch, App Extension staff-JWT auth, the Commerce7 REST client, and the post-uninstall data purge Commerce7's security review requires — configured once, reused across every Commerce7 app.
