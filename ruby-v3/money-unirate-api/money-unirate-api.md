# money-unirate-api

**Tag**: web, networking

## 简介

A Money::Bank implementation backed by the UniRate API (https://unirateapi.com) — free currency exchange rates for RubyMoney. Fetches one base snapshot and derives all cross-rates, with optional TTL-based refresh.
