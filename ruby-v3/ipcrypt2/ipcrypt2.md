# ipcrypt2

**Tag**: security, data

## 简介

IPCrypt provides methods for encrypting and obfuscating IP addresses for privacy-preserving storage, logging, and analytics. Implements deterministic, non-deterministic (KIASU-BC), and XTS-based encryption.
