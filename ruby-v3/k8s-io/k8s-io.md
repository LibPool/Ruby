# k8s-io

**Tag**: web, cli, networking, devops

## 简介

Kubernetes official ruby client to talk to kubernetes clusters. Fork from https://github.com/kubernetes-client/ruby with Ruby version 3 support.

## 官网

- 主页: https://github.com/clearcodewizards/kubernetes-io
- 文档: https://www.rubydoc.info/gems/k8s-io/1.0.1
- RubyGems: https://rubygems.org/gems/k8s-io
