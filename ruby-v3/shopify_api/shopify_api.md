# shopify_api

**Tag**: web

## 简介

This gem allows Ruby developers to programmatically access the admin
section of Shopify stores.

## 官网

- 主页: https://shopify.dev/docs/apps
- 源码仓库: https://github.com/shopify/shopify_api
- 文档: http://api.shopify.com/
- RubyGems: https://rubygems.org/gems/shopify_api
