# efm

**Tag**: filesystem

## 简介

efm is a small Emacs-like file manager written in Ruby.

## 官网

- 主页: https://github.com/iavivai/efm
- RubyGems: https://rubygems.org/gems/efm

- RubyGems: https://rubygems.org/gems/efm
