# asciichem

**Tag**: testing, template

## 简介

AsciiChem is an ASCII syntax for representing chemical formulae, reactions, electron configurations, bonds, crystals, spectra, calculations, Z-matrices, and reaction mechanisms. It parses to a semantic model and renders to MathML, HTML, LaTeX, SVG, and CML. Math embedding uses Plurimath. Round-trips to native CML via chemicalml.
