# locale-data-import

**Tag**: web, filesystem, data

## 简介

Rails plugin to easily generate locale files (.yml) from unicode.org locale data like territories or languages.

## 官网

- 主页: http://github.com/camilleroux/locale-data-import
- RubyGems: https://rubygems.org/gems/locale-data-import
