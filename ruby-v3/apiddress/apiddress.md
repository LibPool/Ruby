# apiddress

**Tag**: web, networking

## 简介

Validate email addresses with the APIddress API. Stdlib net/http only, Ruby 3.0+, automatic retries.

## 官网

- 主页: https://api.apiddress.com
- 源码仓库: https://github.com/apiddress/sdk-ruby
- RubyGems: https://rubygems.org/gems/apiddress
