# jekyll_paperwiki_ipa

**Tag**: library

## 简介

A Jekyll plugin to format IPA (International Phonetic Alphabet) text, meant to be used with the PaperWiki theme.

- 主页: https://github.com/pomeloshark/jekyll_paperwiki_ipa
