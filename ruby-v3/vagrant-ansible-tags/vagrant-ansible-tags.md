# vagrant-ansible-tags

**Tag**: cli, filesystem

## 简介

A Vagrant plugin that adds --tags and --skip-tags options to the
    vagrant provision command, allowing Ansible tags to be passed directly
    on the command line without any Vagrantfile changes.
