# brainiac-discord

**Tag**: library

## 简介

Full Discord integration for Brainiac — per-agent bot gateway connections, message handling, session supersede, draft delivery, reaction handlers (cancel, thinking peek, feedback logging), worktree management, and GIF support. Uses Brainiac's hook system for lifecycle integration.
