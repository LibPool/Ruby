# puma-plus-core

**Tag**: web, networking

## 简介

The Go half of puma-plus: the HTTP/1.1, HTTP/2 and HTTP/3 frontend, the
request queue, and the scaling controller. Installed as a dependency of the
puma-plus gem; there is no reason to install it directly.
