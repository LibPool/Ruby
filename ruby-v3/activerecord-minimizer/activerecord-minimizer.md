# activerecord-minimizer

**Tag**: library

## 简介

Generates only the reader and writer per Active Record column (strict mode removes the other 19 attribute methods), compiles call sites to the calls those methods stood for, turns enum closures into plain methods and stops records allocating Hashes they never fill.
