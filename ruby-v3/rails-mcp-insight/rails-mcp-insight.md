# rails-mcp-insight

**Tag**: web, testing, security

## 简介

An MCP (Model Context Protocol) server that gives AI assistants (Claude, Cursor, Copilot, VS Code) deep, intelligent understanding of any Rails application. 15 tools covering routes, models, controllers, security, testing, and full request lifecycle tracing.
