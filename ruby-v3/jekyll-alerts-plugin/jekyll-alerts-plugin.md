# jekyll-alerts-plugin

**Tag**: library

## 简介

Adds GitHub-style alerts to Jekyll via `> [!NOTE]` blockquotes or a {% alert %} tag. Markdown is parsed inside the body and the stylesheet is injected automatically - no CSS import needed.
