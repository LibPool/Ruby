# kensho-cucumber-ruby

**Tag**: serialization

## 简介

Cucumber 7+ formatter that writes a Kensho v1 result bundle
(run.json + cases/<id>.json + attachments/) into ./kensho-results.
Each scenario becomes a Kensho case; each Gherkin step becomes a
Kensho step.
