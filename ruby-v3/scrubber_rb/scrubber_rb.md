# scrubber_rb

**Tag**: web, security

## 简介

Redact emails, phone numbers, credit cards, SSNs, IBANs, IPs, JWTs, API keys, private keys and Indian IDs (Aadhaar/PAN/UPI) from any string in a single pass through a Rust engine. Checksum-validated (Luhn, Verhoeff, mod-97) so random numbers are not mistaken for card numbers, and ReDoS-immune by construction. Ships a Rails log formatter, Rack middleware and an LLM prompt guard.
