# lingua-it-readability

**Tag**: library

## 简介

Text readability indexes and stats calibrated on Italian language. Inspired by Lingua::EN::Readability and the original Perl module Lingua::EN::Fathom. It prints some usefull readability stats including sentences, words, syllables and average values for words and sentences. Gulpease and Flesch for italian text is calculated.
