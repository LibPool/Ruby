# cinch-bitcoin

**Tag**: testing

## 简介

A gem/plugin for the Cinch IRC Framework that returns the value of Bitcoin in the specified currency. You can visit irc://rawr.sinsira.net #Lobby to get help, report issues , test the gem, or just chat.
