# rcli

**Tag**: cli, tooling

## 简介

This script creates, manages, installs, uninstalls and edits command-line ruby scripts. It also works as a useful library for building scripts.

## 官网

- 主页: http://github.com/edelbalso/rcli
- RubyGems: https://rubygems.org/gems/rcli
