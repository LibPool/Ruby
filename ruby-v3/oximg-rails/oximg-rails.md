# oximg-rails

**Tag**: web, tooling

## 简介

The Rails-facing half of oximg: builds and HMAC-signs URLs for a remote oximg server, for apps that let the server do the work instead of processing locally with the `oximg` gem. ActiveStorage glue is in progress.
