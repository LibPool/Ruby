# kit_api

**Tag**: web, cli, testing, serialization, networking

## 简介

A plain-Ruby client for the Kit (formerly ConvertKit) v4 API: subscribers, tags, custom fields, forms, sequences, broadcasts, purchases, webhooks and more. Net::HTTP and stdlib JSON only, plus a first-class simulated driver for tests.
