# chemicalml

**Tag**: serialization

## 简介

ChemML provides a lutaml-model-based Ruby object model for the Chemical Markup Language (CML). Parse, manipulate, and serialize CML XML with full round-trip fidelity. Designed as a sibling model to other chemistry model layers (e.g. AsciiChem).
