# ruby_llm-dagcache

**Tag**: filesystem

## 简介

Record RubyLLM agent runs as DAGs of tool/LLM calls, replay the canonical path on repeat tasks, and only call the LLM for net-new paths. Same mental model as the Python dagcache library.
