# podspec_bump

**Tag**: web, cli, testing, networking

## 简介

A command line tools to bump podspec version for CocoaPods. Inspired [Bump](https://github.com/gregorym/bump)

- 源码仓库: https://github.com/nakajijapan/podspec_bump
