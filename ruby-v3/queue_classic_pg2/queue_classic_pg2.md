# queue_classic_pg2

**Tag**: web, database, data

## 简介

Support for Postgres2 : queue_classic is a queueing library for Ruby apps. (Rails, Sinatra, Etc...) queue_classic features asynchronous job polling, database maintained locks and no ridiculous dependencies. As a matter of fact, queue_classic only requires pg.
