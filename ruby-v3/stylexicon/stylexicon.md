# stylexicon

**Tag**: template, tooling

## 简介

Stylexicon is a mountable Style Guide / Pattern Lexicon.  It makes it easy for a designer to build a style guide for a site, and to provide a eay for content creators to easily view a site's style guide / available content modules.  This helps to provide a consistent brand.
