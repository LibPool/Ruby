# saymaker

**Tag**: web, cli

## 简介

A zero-dependency client for saymaker.ai: text-to-image, photo edits and text- or image-to-video across Veo 3.1, Kling 3.0, Seedance 2.0, MiniMax H3, Nano Banana 2, GPT Image 2.5 and Seedream 5.0, on one API key.
