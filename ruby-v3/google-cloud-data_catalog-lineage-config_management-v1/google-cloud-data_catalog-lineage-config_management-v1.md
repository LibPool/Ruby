# google-cloud-data_catalog-lineage-config_management-v1

**Tag**: web, cli, testing, devops, data

## 简介

google-cloud-data_catalog-lineage-config_management-v1 is the official client library for the Data Lineage V1 API. Note that google-cloud-data_catalog-lineage-config_management-v1 is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-data_catalog-lineage-config_management instead. See the readme for more details.
