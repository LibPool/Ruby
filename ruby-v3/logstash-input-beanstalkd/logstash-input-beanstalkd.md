# logstash-input-beanstalkd

**Tag**: library

## 简介

This gem is a logstash plugin required to be installed on top of the Logstash core pipeline using $LS_HOME/bin/plugin install logstash-input-beanstalkd. This gem is not a stand-alone program. It can read jobs from a beanstalk tube.
