# misardev

**Tag**: web, cli, template, tooling, devops, filesystem

## 简介

Ruby client for the Misar.Dev API (misar.dev): create projects, write their files, build and deploy them to a subdomain or your own domain, start from templates, call the OpenAI-compatible chat completions endpoint, search your code and read usage. 21 resource groups and every route generated from the API, plus retries that honour Retry-After, typed plan-limit errors carrying the upgrade offer, SSE streaming and pagination. No runtime dependencies beyond the stdlib.
