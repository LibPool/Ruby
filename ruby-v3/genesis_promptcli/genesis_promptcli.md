# genesis_promptcli

**Tag**: cli, testing

## 简介

Genesis is a replacement project for InvisibleTouch that is used to manage provisioning of hardware. The promptcli is what asks if you want to perform something and has a timeout going with a default value if nothing selected in specified time period.
