# vershunt

**Tag**: tooling

## 简介

Maintain versioning information in a consistent way, then build debian packages consistently.

## 官网

- 文档: https://www.rubydoc.info/gems/vershunt/2.0.4
- RubyGems: https://rubygems.org/gems/vershunt

## 历史版本号

## 获取地址

- RubyGems: https://rubygems.org/gems/vershunt
- gem 安装: `gem install vershunt`
- Bundler: `gem "vershunt"`
- 最新版本: 2.0.4
- 最新版归档: https://rubygems.org/downloads/vershunt-2.0.4.gem
- 版本锁定: `gem "vershunt", "~> 2.0.4"`
