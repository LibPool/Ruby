# ruby_llm-llm_judge

**Tag**: web

## 简介

Answers probability, choice, and score questions with any RubyLLM chat model, using parallel per-answer ratings or one-call typed distributions. Plugs into RubyLLM 2.1's Judge API and also runs on RubyLLM 1.13 through 1.16.
