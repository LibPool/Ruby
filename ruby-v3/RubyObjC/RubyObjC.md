# RubyObjC

**Tag**: library

## 简介

RubyObjC allows Ruby and Objective-C code to be easily mixed.  Among its benefits, it allows developers to write Cocoa applications in pure Ruby.

- 主页: http://www.rubyobjc.com/doc
