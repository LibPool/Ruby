# citrine-native

**Tag**: template

## 简介

citrine-native：Citrine 组件的 CRuby 原生运行时**核心**（后端无关）。Renderer / App / StyleMatrix / Painter 协议 / Widgets 协议 + Memory 桩。控件实现按 backend: 选择：citrine-native-libui（libui）、citrine-native-gtk（GTK3）、以及未来的其它后端。
