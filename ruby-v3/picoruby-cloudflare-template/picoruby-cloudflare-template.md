# picoruby-cloudflare-template

**Tag**: web, template, tooling, devops

## 简介

Generate Rack-based Cloudflare Worker projects and configure PicoRuby cross builds. Export matching WebAssembly, ES modules, application bytecode, and binding registries for Wrangler.
