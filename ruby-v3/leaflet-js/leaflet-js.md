# leaflet-js

**Tag**: web, networking

## 简介

Wraps the Leaflet Javascript Mapping Library in a Rails asset gem. Also include Leaflet.Label and Leaflet.Draw plusins.  For more information about Leaflet please see http://leafletjs.com/
