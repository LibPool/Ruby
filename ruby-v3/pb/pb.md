# pb

**Tag**: cli

## 简介

PB is a Clipboard tool that provides pbcopy, pbread and pbpaste. It supports only Mac OS X :)

## 官网

- 主页: http://github.com/jugyo/pb
- RubyGems: https://rubygems.org/gems/pb
