# opapp

**Tag**: library

## 简介

A curated set of technologies and a workflow for developing, maintaining, and operating distributed applications. This gem is a metagem and depends on the various components required to develop on, participate in, or communicate with an OpApp Framework system. OpApp is built on the PanOps Platform.
