# plplot

**Tag**: library

## 简介

Provides PLplot functions in a Ruby module.  PLplot is a
cross-platform software package for creating scientific plots.

## 官网

- 主页: http://plplot.rubyforge.org/
- RubyGems: https://rubygems.org/gems/plplot

## 历史版本号

- 0.0.0 (2010-03-16)

## 获取地址

- RubyGems: https://rubygems.org/gems/plplot

- 最新版归档: https://rubygems.org/downloads/plplot-0.0.0.gem
