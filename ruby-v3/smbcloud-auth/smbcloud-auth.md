# smbcloud-auth

**Tag**: security, devops

## 简介

Ruby bindings for smbCloud Auth, powered by the shared Rust SDK and a native Magnus extension.

- 主页: https://github.com/smbcloudXYZ/smbcloud-cli/tree/main/sdk/gems/auth
