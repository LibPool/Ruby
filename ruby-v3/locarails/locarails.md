# locarails

**Tag**: web

## 简介

A maneira mais simples para instalar aplicacoes Rails na hospedagem Linux da Locaweb.

## 官网

- 主页: http://www.locaweb.com.br/rails
- RubyGems: https://rubygems.org/gems/locarails

## 历史版本号

- 1.2.1 (2009-10-03)
- 1.2.0 (2009-09-28)

## 获取地址

- RubyGems: https://rubygems.org/gems/locarails
- gem 安装: `gem install locarails`
- Bundler: `gem "locarails"`
- 最新版本: 1.2.1
- 最新版归档: https://rubygems.org/downloads/locarails-1.2.1.gem
- 版本锁定: `gem "locarails", "~> 1.2.1"`
- 中央仓库: https://rubygems.org/
