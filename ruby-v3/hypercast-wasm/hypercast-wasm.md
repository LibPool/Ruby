# hypercast-wasm

**Tag**: web, tooling, filesystem

## 简介

The hypercast gem's Magnus extension, prebuilt for wasm32-wasip1, for a ruby.wasm
interpreter built with `rbwasm build`: put this gem in that Gemfile instead of hypercast
and the extension is linked into the interpreter. Same API and the same Rust core as the
hypercast gem. Not for a host Ruby, where the hypercast gem is the one to install.
