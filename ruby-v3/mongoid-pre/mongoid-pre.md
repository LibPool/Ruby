# mongoid-pre

**Tag**: web

## 简介

ODM framework for MongoDB - This is a temporary gem to be able to use mongoid with rails 3 in heroku easily

## 官网

- 主页: http://mongoid.org
- RubyGems: https://rubygems.org/gems/mongoid-pre

## 历史版本号

- 2.0.0.pre (2010-02-13)
