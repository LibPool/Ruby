# startupgem

**Tag**: template, filesystem

## 简介

This gem is created for the Startup Institute interview.
Upon research on what Startup Institute has to offer, I am moved by the transformation the program offers to students’ lives. I would love to be part of a class with similar goals and crave.

Thank you all for the consideration and visiting my first gem.

Executable file
*Dir[“bin/startup”]

All the lib files are namespaced by module Startup
