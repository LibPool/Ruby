# perforce2svn

**Tag**: filesystem

## 简介

It loads each revision in a Perforce repository sequentially and commits each change into an exist or new or existing Subversion repository.  It also handles more complicated operations that may occur after a migration, like adding, deleting, copy, or updating files to make the entire migration functional.
