# gem-insturl

**Tag**: web, networking

## 简介

The insturl command installs a gem from a URL.

Examples:
* gem **insturl** http://.../foo.git
* gem **insturl** http://.../foo.gem
* gem **insturl** http://.../foo.tar.gz
