# roundhouse_ui

**Tag**: web

## 简介

Mountable Rails engine for Sidekiq or Solid Queue: grouped errors, argument search, filter-scoped bulk actions, enforced pause, snapshots, audit log. Mounts alongside or instead of Sidekiq::Web. Not affiliated with or endorsed by Contributed Systems LLC; Sidekiq, Sidekiq Pro and Sidekiq Enterprise are their trademarks.
