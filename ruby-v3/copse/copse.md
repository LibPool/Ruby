# copse

**Tag**: web

## 简介

Copse derives a hostname and a port for each Rails app and each git worktree, so several can run at once without colliding and without anyone choosing numbers. The web process stays in the foreground and owns the TTY, so binding.irb and debug keep working. No daemon, no reverse proxy, no privileged listener, and no runtime dependencies.
