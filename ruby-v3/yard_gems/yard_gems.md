# yard_gems

**Tag**: template

## 简介

Easily install a YARD backed site for viewing locally installed Rubygem docs. Install this and disable rdoc generation on gem install.

## 官网

- 源码仓库: https://github.com/dougbarth/yard-gems
- 问题追踪: https://github.com/dougbarth/yard-gems/issues
- RubyGems: https://rubygems.org/gems/yard_gems

## 获取地址

- RubyGems: https://rubygems.org/gems/yard_gems
