# roqs

**Tag**: library

## 简介

Ruby wrapper for liboqs via direct shared library method invocation. The wrapper is pretty stable since it is direct method invocation from shared library. Any upgrade to the liboqs, after compiled to a shred library, roqs can immediately utilize the upgraded library without any modification.
