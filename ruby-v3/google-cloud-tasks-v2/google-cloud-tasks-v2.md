# google-cloud-tasks-v2

**Tag**: cli, testing, devops

## 简介

Manages the execution of large numbers of distributed requests. Note that google-cloud-tasks-v2 is a version-specific client library. For most uses, we recommend installing the main client library google-cloud-tasks instead. See the readme for more details.
