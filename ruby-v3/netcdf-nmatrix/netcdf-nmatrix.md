# netcdf-nmatrix

**Tag**: filesystem

## 简介

A Ruby interface for reading and writing NetCDF files. NetCDF-NMatrix is a rewrite of the previous ruby-netcdf gem which uses NMatrix instead of NArray, and so is compatible with SciRuby.
