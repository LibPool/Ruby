# rdoc-perl_pod

**Tag**: tooling

## 简介

A parser for Perl's POD documentation format.  Allows Perl and Ruby
documentation to be used together.

## 官网

- 主页: https://github.com/rdoc/rdoc-perl_pod
- RubyGems: https://rubygems.org/gems/rdoc-perl_pod

## 历史版本号

- 1.0 (2010-12-23)

## 获取地址

- RubyGems: https://rubygems.org/gems/rdoc-perl_pod
- gem 安装: `gem install rdoc-perl_pod`
- Bundler: `gem "rdoc-perl_pod"`
- 最新版本: 1.0
- 最新版归档: https://rubygems.org/downloads/rdoc-perl_pod-1.0.gem
