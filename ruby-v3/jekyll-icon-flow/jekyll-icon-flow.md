# jekyll-icon-flow

**Tag**: library

## 简介

A Jekyll plugin providing {% icon %} and per-pack {% icon_<pack> %} Liquid tags. Each icon pack is an adapter that resolves names to SVG sources and normalizes output — same styling contract across packs.
