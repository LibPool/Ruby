# solargraph-dragonruby

**Tag**: web

## 简介

Adds YARD-documented DragonRuby GTK API pins (args, outputs, inputs, $gtk, Geometry, ...) to Solargraph so LSP editors get autocomplete, hover and go-to-definition in DragonRuby games.
