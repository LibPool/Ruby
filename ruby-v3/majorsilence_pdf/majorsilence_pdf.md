# majorsilence_pdf

**Tag**: security

## 简介

Ruby wrapper for the Majorsilence PDF native library -- create PDF documents in-process via an AOT-compiled shared library (Fiddle FFI), no .NET runtime required. Supports text styling, shapes, images, tables, fonts, encryption, annotations, hyperlinks, and PDF merging.
