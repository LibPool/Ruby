# active_agent_rails

**Tag**: web, template, tooling

## 简介

ActiveAgent provides a clean, unified interface to build AI agents with automatic tool/function calling, ActiveRecord-backed conversation memory, and an engine to stream real-time responses to a floating UI widget in your views.
