# license_auto

**Tag**: library

## 简介

LicenseAuto is a library for Open Source License collection job. Supported Language Package
                          Management including:
                            Ruby Gems, Java Maven Gradle, NodeJS npm, Erlang rebar, Debian launchpad.net, Golang
