# riemann-monitors

**Tag**: web, cli, networking

## 简介

This is a polite fork of riemann-tools, using my riemann-ruby-experiments gem instead of riemann-ruby-client.  As a result, events can be batched together to be sent in one message to a Riemann server.  Additionally, more control over the TCP socket options is given, and UDP isn&amp;#8217;t supported (yet?), because this gem primarily uses net_ruby_client.
