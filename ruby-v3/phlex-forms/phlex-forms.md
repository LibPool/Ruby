# phlex-forms

**Tag**: web, template, tooling

## 简介

phlex-forms gives Phlex apps a clean form builder: Form(model:) { |f| f.field :email } renders label + input + error/hint in one call, with type and required inferred from the model. Built on daisyui, it fixes what Rails and Phlex form builders get wrong about model binding, nested attributes, and DaisyUI styling.
