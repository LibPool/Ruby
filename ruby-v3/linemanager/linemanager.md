# linemanager

**Tag**: testing, filesystem

## 简介

LineManager is a thin wrapper over Foreman that allows
  programmatically starting and stopping processes from an Procfile, using 
  available Dotenv environments. Its primary purpose is to execute specs in
  clean, separated process environments.
