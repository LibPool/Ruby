# iremocon_control

**Tag**: library

## 简介

iRemoconに各種コマンドを送ることでコントロールします。
  赤外線送信、タイマ登録など一通りの機能を備えています。
  Unixコマンド"iremocon"からコントロールすることもできます。
  ネットワーク上からiRemoconを探す機能も備えており、ほとんど設定なしで利用できます。
