# lintus

**Tag**: serialization, tooling, filesystem

## 简介

Lintus reads linting rules from a YAML file at the root of your repository, asks the Typesafe Jev model each rule as a noul question against every matching file, and reports an offense wherever the model says so. Runs on a whole tree, a git diff, or the staged files of a commit.
