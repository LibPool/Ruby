# fluent-plugin-dynatrace-radiant

**Tag**: library

## 简介

A production-hardened fork of fluent-plugin-dynatrace with multi-worker support, configurable timeouts, TLS certificate options, and batch size limits. Ruby 3.0+ optimized.
