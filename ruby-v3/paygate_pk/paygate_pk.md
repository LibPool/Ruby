# paygate_pk

**Tag**: web, cli, template

## 简介

PaygatePk is a provider-agnostic Ruby/Rails client for payment gateways operating in Pakistan. 1.0 ships PayFast hosted-checkout (redirection) and callback verification with a one-line Rails view helper. Easypaisa REST (MA/OTC/Inquiry) lands in 1.1.
