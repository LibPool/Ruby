# morganchristiansson-css-sprites

**Tag**: filesystem

## 简介

The first step is generate the index:  $ rake css_sprites:update This will find all the images and make a bundle with them. Animated images (like GIF or APNG with two or more frames) are always excluded.  The plugin will create one image per format (a file with JPEG images, another file with PNGs, ...).  And that is all.
