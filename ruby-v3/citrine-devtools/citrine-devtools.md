# citrine-devtools

**Tag**: library

## 简介

DevTools 消息总线：浏览器桥接脚本把 M1 探针时序数据（write_log/flush_trace/event_stream）经 SSE 送达调试面板，并转发面板指令（set_signal/force_rerun/request_tree/request_graph）回被调试页执行。协议契约见 docs/PROTOCOL.md。
