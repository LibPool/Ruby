# frusdl

**Tag**: library

## 简介

FFI bindings to SDL, SDL_image, SDL_ttf, SDL_mixer, SGE and SFL_gfx

## 官网

- 主页: http://frusdl.rubyforge.org
- RubyGems: https://rubygems.org/gems/frusdl
