# openhub-bo-core

**Tag**: cli, security

## 简介

Sesión OAuth, transporte, errores y tipos compartidos de los clientes openhub-bo para Red Enlace (ATC) OpenHub, Bolivia. Núcleo en Rust compartido con los paquetes openhub-bo de Python y TypeScript. Integración no oficial, sin afiliación con Red Enlace (ATC).
