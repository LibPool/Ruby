# jekyll-timeline

**Tag**: template

## 简介

A Jekyll plugin providing {% timeline %} and {% event %} block tags that render a vertical timeline component. Pure HTML+CSS output — no JavaScript, no external dependencies. Supports icon libraries (Font Awesome, emoji, or plain text) and per-event color customization.
