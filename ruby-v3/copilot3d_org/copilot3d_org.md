# copilot3d_org

**Tag**: web, tooling

## 简介

A minimal Ruby gem that points to the Copilot 3D AI 3D model generator website and supports RubyGems and RubyDoc indexing.

## 官网

- 主页: https://www.copilot3d.org
- 文档: https://www.rubydoc.info/gems/copilot3d_org
- RubyGems: https://rubygems.org/gems/copilot3d_org
