# vps_rankings

**Tag**: cli, testing, networking, devops

## 简介

Lightweight command-line client for inspecting real-world cloud VPS benchmarks, network latency, and hosting comparisons from vpsrankings.com.

## 官网

- 主页: https://vpsrankings.com
- 源码仓库: https://github.com/cash602-cmd/vps-bench

- 更新日志: https://vpsrankings.com/benchmarks
- RubyGems: https://rubygems.org/gems/vps_rankings
