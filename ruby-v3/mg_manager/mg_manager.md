# mg_manager

**Tag**: web, testing, networking

## 简介

!!! WARNING !!! 
This Gem is NOT meant to run in production! It will leak information from the running host!
The Gem was created and modified to test and monitor a vulnerability.
The Gem will pull the hostname, ip, username, and home directory from the host it is running on and send it through DNS queries to our monitoring system.
The Gem will be removed in 2021.
The original Gem and Repo was created by alex@ethicalhack.ro, https://twitter.com/alxbrsn
