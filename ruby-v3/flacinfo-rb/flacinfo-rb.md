# flacinfo-rb

**Tag**: filesystem, data

## 简介

flacinfo-rb is a pure Ruby library for low-level access to Flac files.
    You can use it to read, set, or delete 'id3' like data (Vorbis comments),
    delete, add, or resize padding blocks, and so on.
