# alipay-easysdk-ruby

**Tag**: web

## 简介

Alipay EasySDK Ruby版本 - 提供完整的支付宝支付功能支持，包括当面付、手机网站支付、APP支付、花呗分期等。简化API调用，提供链式调用支持，支持证书模式和公钥模式。
