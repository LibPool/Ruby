# placet-rails

**Tag**: web, security

## 简介

placet-rails integrates the placet authorization library with Rails: per-action permission declarations (placet_permit / placet_resource), an enforcement verification hook, and mapping of placet scope plans onto ActiveRecord relations for list filtering.
