# efigence-influxdb

**Tag**: library

## 简介

This is a fork of official Ruby library for InfluxDB meant for v0.9.x support.

- 主页: https://github.com/efigence/influxdb-ruby/tree/support_v0.9.x

- RubyGems: https://rubygems.org/gems/efigence-influxdb
