# http3

**Tag**: web, networking

## 简介

An HTTP/3 server for Rack 3 applications, built on the quic gem and nghttp3 (HTTP/3 and QPACK). nghttp3 is built at install time and linked statically, and its Ruby bindings are available as HTTP3::Nghttp3.
