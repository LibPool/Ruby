# notey

**Tag**: library

## 简介

Notey is the notification layer for multi-tenant apps. Noticed delivers a notification on whatever channels a notifier declares; Notey stores which channels each person wants per notification type, gives them screens to set that, scopes an inbox to the account they are in, and groups notifications into digests instead of sending each one as it happens.
