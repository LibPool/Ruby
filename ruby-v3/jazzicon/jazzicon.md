# jazzicon

**Tag**: web, networking, tooling

## 简介

Jazzicon is a Ruby implementation of the javascript Jazzicon identicon generator (https://github.com/danfinlay/jazzicon).

## 官网

- 主页: https://github.com/Arux-Software/jazzicon_ruby
- RubyGems: https://rubygems.org/gems/jazzicon

## 历史版本号

- 0.1.0 (2025-01-27)

## 获取地址

- RubyGems: https://rubygems.org/gems/jazzicon

- Bundler: `gem "jazzicon"`

- 最新版归档: https://rubygems.org/downloads/jazzicon-0.1.0.gem
