# spree_menu_chat

**Tag**: library

## 简介

A read-only, retrieval-grounded chat assistant for Spree storefronts — answers customer questions about the menu, ingredients, dietary info, hours, and policies using the store's own synced catalog and Spree::Policy content. No cart or order mutation capability of any kind. Companion extension to spree_square, reused via a soft dependency for modifier-list grounding when present.
