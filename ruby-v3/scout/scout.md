# scout

**Tag**: web

## 简介

The scout gem reports metrics to Pingdom Server Monitor (server.pingdom.com), an easy-to-use hosted server monitoring service.

## 官网

- 主页: http://server.pingdom.com
- 源码仓库: http://github.com/scoutapp/scout-client
- 文档: http://scoutapp.com/info/developers
- RubyGems: https://rubygems.org/gems/scout
