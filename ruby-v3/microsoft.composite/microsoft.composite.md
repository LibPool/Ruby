# microsoft.composite

**Tag**: cli, tooling

## 简介

Prism (Composite Application Guidance for WPF) is designed to help you more easily build enterprise-level Windows Presentation Foundation 
(WPF) client applications. This guidance will help you design and build flexible composite WPF client applications-composite 
applications use loosely coupled, independently evolvable pieces that work together in the overall application.
