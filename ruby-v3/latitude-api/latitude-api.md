# latitude-api

**Tag**: web, cli, networking, devops, data

## 简介

A Ruby library for the Latitude.sh REST API. Covers servers, projects, virtual machines, Kubernetes clusters, storage, networking, firewalls, elastic IPs, SSH keys, teams, and more. Includes a client for the on-instance metadata service.
