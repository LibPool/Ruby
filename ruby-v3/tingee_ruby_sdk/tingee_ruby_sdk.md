# tingee_ruby_sdk

**Tag**: web, cli

## 简介

Pure-Ruby, zero-dependency client for Tingee (open-api.tingee.vn): HMAC-SHA512 request signing, bank-link sessions, the manual create-va/confirm-va OTP chain, unlink, and raw-body webhook signature verification. Built from a live-verified API contract.
