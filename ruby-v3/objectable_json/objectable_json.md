# objectable_json

**Tag**: web, testing, serialization

## 简介

ObjectableJSON is simple and clever JSON =&gt; Object Mapper. ObjectableJSON automatically analyze your JSON values and convert the values to Single Object. So, you can easily convert JSON to Single Object by only calling ObjectableJSON#parse method. Especially, this gem is powerful &amp; useful when you treat some API JSON response. Also, this gem can work for Hash.
