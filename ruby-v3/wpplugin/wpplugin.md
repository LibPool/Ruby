# wpplugin

**Tag**: cli

## 简介

WPPlugin is a command line tool that updates WordPress plugins. Great for WordPress installs that live in a Git repository.

## 官网

- 主页: http://github.com/markjaquith/WPPlugin
- RubyGems: https://rubygems.org/gems/wpplugin
