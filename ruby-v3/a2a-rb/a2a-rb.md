# a2a-rb

**Tag**: web, cli, serialization, networking, tooling, data

## 简介

Data model, serialisation, full client (JSON-RPC 2.0 + HTTP+JSON), streaming over SSE, push notifications, and server-side primitives for building A2A agents.
