# amazon-ec2

**Tag**: web, devops

## 简介

A Ruby library for accessing the Amazon Web Services EC2, ELB, RDS, Cloudwatch, and Autoscaling APIs.

## 官网

- 主页: http://github.com/grempe/amazon-ec2
