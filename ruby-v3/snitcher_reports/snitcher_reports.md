# snitcher_reports

**Tag**: web, cli, template

## 简介

Aggregates completed work across trackers into a unified per-user report. One set of organization credentials serves many users; the host application supplies configuration and ENV and receives a plain Hash, or a rendered console / Markdown / HTML report.
