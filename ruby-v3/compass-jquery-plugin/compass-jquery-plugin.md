# compass-jquery-plugin

**Tag**: web

## 简介

This plugin integrates jQuery-Rails, jQuery, jQuery UI and Themes, jqGrid and more into the Compass Sass framework.

## 官网

- 主页: http://github.com/kosmas58/compass-jquery-plugin
- RubyGems: https://rubygems.org/gems/compass-jquery-plugin
