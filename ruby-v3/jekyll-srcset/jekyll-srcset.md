# jekyll-srcset

**Tag**: library

## 简介

This Jekyll plugin makes it very easy to send larger images to devices with high pixel densities.

  The plugin adds an `image_tag` Liquid tag that can be used like this:

  {% image_tag src="/image.png" width="100" %}
