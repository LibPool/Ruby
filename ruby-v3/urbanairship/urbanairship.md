# urbanairship

**Tag**: web

## 简介

A Ruby Library for using the Airship web service API for push notifications and rich app pages.

## 官网

- 主页: https://github.com/urbanairship/ruby-library
- 文档: http://docs.urbanairship.com/reference/libraries/ruby/
- RubyGems: https://rubygems.org/gems/urbanairship
