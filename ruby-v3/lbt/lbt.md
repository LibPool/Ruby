# lbt

**Tag**: tooling

## 简介

Lbt is a build tool for LaTeX. It is useful for big documents.

## 官网

- 主页: https://github.com/ToshioCP/LaTeX-BuildTools
- 文档: https://toshiocp.github.io/LaTeX-BuildTools/
- RubyGems: https://rubygems.org/gems/lbt
