# ea

**Tag**: database, template, filesystem, data

## 简介

ea is a standalone Ruby gem for parsing Enterprise Architect data files (QEA format, Sparx XMI). It provides QEA database parsing, EA diagram rendering, and EA data validation. The UML bridge (Ea::Qea.to_uml) optionally requires the lutaml-uml gem.
