# pretty_feed

**Tag**: library

## 简介

PrettyFeed provides a modulizer you can include in a job, worker, class, rake task, etc,
which allows for simple pass/fail logging colorization.
Defaults are `truthy: 'green'` and `falsey: 'red'`.
