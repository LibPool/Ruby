# omniauth-vk_id

**Tag**: web, security

## 简介

Server-side OmniAuth 1.9 strategy implementing the VK ID OAuth 2.1 authorization code flow with PKCE. Works with VK apps registered via id.vk.com (not the legacy dev.vk.com classic OAuth).
