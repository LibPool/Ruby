# jekyll-theme-docsteer

**Tag**: library

## 简介

DocSteer is a fast, responsive Jekyll theme for technical documentation, help centres and internal knowledge bases: live search, six colour skins with dark mode, image lightbox, auto table of contents, bundled Font Awesome and SEO out of the box.
