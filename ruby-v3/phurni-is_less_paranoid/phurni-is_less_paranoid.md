# phurni-is_less_paranoid

**Tag**: library

## 简介

ActiveRecord 2.3 compatible gem "allowing you to hide and restore records without actually deleting them."  Yes, like acts_as_paranoid, only with less code and less complexity. Extended version to allow associated records to still be alive.
