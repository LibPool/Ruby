# lbs-config

**Tag**: testing, template

## 简介

Instala templates para el scaffold, incluye opciones para generarlos con erb, haml, simple_form, formtastic, bootstrap y cancan. Incluye la posibilidad de generarlos en Inglés y Español, con su respectivo inflection.
