# zpl_renderer

**Tag**: template

## 简介

Convert Zebra Programming Language (ZPL) labels to PNG or PDF entirely offline.
Ships a bundled Rust renderer for printer-dot-accurate output with Code 128,
QR, GS1, and other common shipping-label barcodes that scanners can decode.
