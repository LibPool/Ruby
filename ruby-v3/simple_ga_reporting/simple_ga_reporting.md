# simple_ga_reporting

**Tag**: web, serialization, filesystem, data

## 简介

This gem is powered by Legato gem. First of all, you create configuration YAML file as Google Analytics API. Then execute the simple Ruby code, and you obtain Google Analytics Reporting Data. Very simple.
