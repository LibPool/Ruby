# rlint

**Tag**: tooling

## 简介

Rlint is a coding standard analyzer. Used to check method/class name pattern, columns limit and others.(like Pylint)

## 官网

- 主页: http://rubyhideoutprogramming.blogspot.com/
- RubyGems: https://rubygems.org/gems/rlint

## 历史版本号

- 0.0.1 (2011-01-03)

## 获取地址

- RubyGems: https://rubygems.org/gems/rlint
- gem 安装: `gem install rlint`
- Bundler: `gem "rlint"`
- 最新版本: 0.0.1
- 最新版归档: https://rubygems.org/downloads/rlint-0.0.1.gem
