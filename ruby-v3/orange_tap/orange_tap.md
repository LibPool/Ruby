# orange_tap

**Tag**: serialization, filesystem

## 简介

OrangeTap hooks Ruby method calls (call/return) with TracePoint, assembles them into OpenTelemetry-style spans on a background thread inside the same process, and writes the result as an OTLP/JSON file.
