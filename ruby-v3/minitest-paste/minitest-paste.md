# minitest-paste

**Tag**: cli, testing

## 简介

minitest/paste is a Minitest plugin which collects
                          any test failures, compiles them and uploads them to
                          dpaste.com for easier sharing. After the upload is complete
                          it injects the link in your clipboard.
