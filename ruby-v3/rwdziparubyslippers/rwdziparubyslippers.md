# rwdziparubyslippers

**Tag**: web, filesystem

## 简介

rubyslippers is frontend for the RubyGems system using rwdtinker and RubyWebDialogs. Requires rwdtinker &gt;1.51rwdcalc is calculator rwdtinker and RubyWebDialogs
