# libvirt-ext

**Tag**: web

## 简介

ruby-libvirt is only a mapped api and unrubish. libvirt-ext extents functionality to be more rubish.

- 主页: http://github.com/DenisKnauf/libvirt-ext
- RubyGems: https://rubygems.org/gems/libvirt-ext
