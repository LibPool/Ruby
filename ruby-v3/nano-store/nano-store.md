# nano-store

**Tag**: database, data

## 简介

RubyMotion wrapper for NanoStore, a lightweight schema-less key-value document database based on sqlite.

## 官网

- 主页: https://github.com/siuying/NanoStoreInMotion
- RubyGems: https://rubygems.org/gems/nano-store
