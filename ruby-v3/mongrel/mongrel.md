# mongrel

**Tag**: web, networking

## 简介

A small fast HTTP library and server that runs Rails, Camping, Nitro and Iowa apps.

## 官网

- 主页: http://mongrel.rubyforge.org/
- 源码仓库: http://github.com/fauna/mongrel/
- 问题追踪: http://github.com/fauna/mongrel/issues
- RubyGems: https://rubygems.org/gems/mongrel
