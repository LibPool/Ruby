# dynamic-active-model-rails

**Tag**: web, database, tooling, filesystem, data

## 简介

Railtie for dynamic-active-model: declare databases in one initializer and get lazily built, reloadable models in CarsDB-style namespaces, with extension files in app/models/cars_db/ and automatic rebuilds after migrations.
