# ribusb

**Tag**: web

## 简介

RibUSB is a Ruby extension that makes USB devices accessible from Ruby via the libusb library (API version &gt;=1.0).

## 官网

- 主页: http://ribusb.rubyforge.net/
- RubyGems: https://rubygems.org/gems/ribusb

## 历史版本号

- 0.0.1 (2009-08-05)

## 获取地址

- RubyGems: https://rubygems.org/gems/ribusb

- Bundler: `gem "ribusb"`

- 最新版归档: https://rubygems.org/downloads/ribusb-0.0.1.gem
