# ohlala_rails_scaffold_templates

**Tag**: web, template

## 简介

A ridiculously opinionated set of scaffold templates for Rails 3 and later. Meant to be used for the Ohlàlà! Webdesigns projects but can be customized to any Rails developer's workflow.
