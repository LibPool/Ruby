# sam3d2_com

**Tag**: web, tooling

## 简介

A minimal Ruby gem that points to the Sam 3D 2.0 AI 3D model generator website and supports RubyGems and RubyDoc indexing.

## 官网

- 主页: https://www.sam3d2.com
- 文档: https://www.rubydoc.info/gems/sam3d2_com
- RubyGems: https://rubygems.org/gems/sam3d2_com

## 历史版本号
