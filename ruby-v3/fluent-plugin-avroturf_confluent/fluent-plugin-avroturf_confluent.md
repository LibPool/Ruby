# fluent-plugin-avroturf_confluent

**Tag**: serialization

## 简介

fluent-plugin-avroturf_confluent is formatter plugin developed for fluent-plugin-kafka/out_rdkafka2 to serialize messages in key-value pairs format into Avro format before shipping messages to Kafka brokers.
