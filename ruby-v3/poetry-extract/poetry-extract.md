# poetry-extract

**Tag**: library

## 简介

The optional design-extraction gem for Poetry: fetches a site's styleguide, brand, screenshot, and homepage markdown (context.dev), composes a DESIGN.md in one Claude call, derives Tailwind v4 @theme + CSS :root tokens deterministically, and hands the result to Poetry's AA-gated design importer.
