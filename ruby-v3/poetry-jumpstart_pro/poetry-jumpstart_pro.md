# poetry-jumpstart_pro

**Tag**: template

## 简介

An installer that replaces a Jumpstart Pro app's views with Poetry-native recreations, accessible, themeable and agent-legible, and reconciles Jumpstart's stylesheets with Poetry's tokens. Ships only Poetry views, never Jumpstart's source, and installs them as host app/views overrides.
