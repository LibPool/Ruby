# hackone

**Tag**: web, serialization, networking

## 简介

This gem is a ruby wrapper that similifies the parsing CommonHack and HackOne JSON. More information about HackOne can be seen at http://www.hackone.co and more information about CommonHack can be seen at http://commonhack.org
