# calview

**Tag**: cli, serialization, template

## 简介

A robust VCAL/iCalendar viewer that parses calendar invites and displays them in a readable format. Perfect for mutt email client integration and terminal viewing. Features include timezone support, recurrence parsing, multiple output formats (text, JSON, compact), and comprehensive error handling. Originally created to replace vcal2text with a leaner Ruby solution.
