# alap

**Tag**: web, tooling

## 简介

Server-side Ruby port of Alap, the expression parser that turns curated
link queries (.coffee + :time:7d:) into resolved link results. Ships the
parser, URL sanitization, SSRF guard, regex validation, and config
validation — same surface as the TypeScript, Go, Python, PHP, Java, and
Rust ports.
