# pg_peek

**Tag**: web, database, testing, data

## 简介

A Rails Engine that provides a web UI for monitoring and analyzing PostgreSQL query performance. Mount pg_peek into your Rails application to introspect database queries, analyze pg_stat_statements data, track Active Job queries, and parse SQLcommenter tags for performance optimization.
