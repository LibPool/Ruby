# terminal_rb

**Tag**: cli, testing

## 简介

Terminal.rb supports you with input and output on your terminal. Simple BBCode-like markup for attributes and coloring, word-wise line breaks, correct special key recognition and mouse event reporting enable you to implement your CLI app quickly and easily.
