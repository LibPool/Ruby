# nti_receipt_builder

**Tag**: web, template, tooling

## 简介

NtiReceiptBuilder ships a complete receipt designer — model, layout validation, millimetre-accurate renderer, Stimulus builder UI and print views — as a Rails engine. Host applications declare a Variables subclass that maps receipt placeholders to methods on their own receipt object, so the gem carries no domain vocabulary of its own.
