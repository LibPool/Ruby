# disinnovate-sprout-as3spec-library

**Tag**: testing

## 简介

AS3Spec is a tiny BDD framework for AS3, inspired by Bacon and RSpec. Built upon sprout project-generation tool for ActionScript/Flash/Flex/AIR.
