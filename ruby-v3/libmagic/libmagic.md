# libmagic

**Tag**: filesystem

## 简介

Ruby wrapper for the Unix file/libmagic utility, which can guess mime types and character sets.

## 官网

- 主页: https://github.com/cdd/libmagic
- RubyGems: https://rubygems.org/gems/libmagic
