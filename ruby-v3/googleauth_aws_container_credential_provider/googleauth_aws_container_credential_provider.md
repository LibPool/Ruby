# googleauth_aws_container_credential_provider

**Tag**: security, devops

## 简介

The googleauth gem supports AWS Workload Identity, but it cannot handle container credentials provided by ECS etc. via AWS_CONTAINER_CREDENTIALS_RELATIVE_URI. This gem enables it to use the container credential provider.
