# yamine

**Tag**: web, networking

## 简介

Gives every Ruby app a stable https://<app>.localhost URL instead of a memorized port. Explicit-run reverse proxy with zero-config name inference, git-worktree variants, per-host TLS, and agent-friendly list/get/doctor commands. Ruby stdlib only.
