# activeadmin_configurable_columns

**Tag**: database, template, data

## 简介

Lets every admin choose which columns of an ActiveAdmin index table they see. Adds a `configurable_columns` DSL to declare the available columns, renders a "Columns" picker in the index sidebar and on a central "Table columns" page, and stores each admin's choice in the database.
