# emf

**Tag**: tooling, filesystem

## 简介

Pure-Ruby parser for Windows Metafile (WMF), Enhanced Metafile (EMF), and EMF+ binary formats. Produces an OOP domain model that downstream gems (such as emfsvg) consume.
